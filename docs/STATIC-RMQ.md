# 位掩码静态 RMQ

`StaticRMQ<T,Cmp>` 是可独立组合的静态区间最优位置模板，既支持最小/最大值，也保留并列时的最左原编号。它不修改已有EulerLCA、后缀数组或普通dsu；需要组合时由使用者显式调用。

## 接口

构造复制输入数组和比较器，`query(l,r)` 查询0-based非空半开区间，返回原编号，值用 `rmq.a[id]` 读取。默认less求最小、greater求最大；可传有状态的const比较器，例如只比较记录的某个字段。相等指比较器互不优于，不要求T提供operator==，也不以数值哨兵表达空集。比较器必须在对象使用期间维持稳定严格弱序；浮点NaN不满足条件。

空数组可构造，但不能查询；要求0≤l<r≤n。重建用重新赋值新对象，不提供单点修改；所有公开数组和比较器只读。`small`、`better`为内部辅助，前者只允许非空同块区间。点值不参与加减，可直接使用signed64极值或可复制记录。n≤INT_MAX/2且内存可分配，这也使块边界与ST表位移的int运算安全。

## 为什么返回最左最优位置

在每块从左向右扫描，掩码中的置位按位置递增对应单调栈。新元素只弹出严格更差的旧元素：对后续包含新元素的区间，被弹出的旧位置永远不可能成为最优；相等元素不能弹出，否则会丢掉最左方案。查询[l,r)时，从r-1的栈快照中去掉l之前的位置，最低置位便是最左最优者。

跨块查询分为左侧剩余区间、右侧前缀和中间完整块。前两者用同一掩码函数处理，中间块用稀疏表两个重叠段合并。合并依据先比较优劣、再选较小编号，是幂等操作，所以稀疏表区间重叠不影响答案。比较器不用于编号打破元素间的等价关系，编号仅决定最终稳定选择。

## 复杂度和位运算范围

取 `b=max(1,bit_width(n))`，块数m=ceil(n/b)。每点入栈/弹栈至多一次，构造掩码O(n)。块间表占O(m log(m+1))，由于b=Theta(log(n+1))，它也是O(n)；查询只处理至多三个部分，为O(1)。该界假定元素复制/比较和32位位操作为O(1)，保存元素本身的额外成本依T而定。

在n≤INT_MAX/2范围内b≤30，移位总在0..29；对bit_width(s)-1的调用由s非零保护。small查询时包含r-1的栈位，因此截掉左侧后仍非零，不依赖对零求ctz的扩展行为。空数组直接返回，不访问ST表。

WIDA两个固定来源都采用常量B=64、块内前后缀值与单调栈掩码、块间ST表。它们在字长模型和实际int规模下很好用，但若把64视为固定常数直接写渐进“严格O(n)”会隐藏块间O((n/64)log(n/64))项。本实现用随n变化的块长，并用掩码统一两端查询，省去pre/suf两份元素数组；同时增加稳定位置返回和可传有状态比较器。

## 来源、正式用法与边界

- WIDA固定commit `cfdb12db6792eb2303798541fb5c760ed2bc618b`，打印稿《08 - 数据结构.md》“基于状压的线性RMQ算法”和jiangly收集《06 - 状压RMQ（RMQ）.cpp》。两份源代码分别编译，用独立扫描答案核对最小/最大值，不冒用它们所列提交作为本库AC。
- kuangbin 3.2.1，印刷页57：1-based闭区间最大值，转换为 `query(l-1,r)` 后读值；示例277覆盖这一模型。3.2.2二维RMQ仍未覆盖，父目录3.2保留partial。
- 用法276：[Library Checker Static RMQ](https://judge.yosupo.jp/problem/staticrmq)，官方题面仓库固定commit `e64660561a995c357cdc61ddee1bde68b80528db`；n,q≤500000、值0..10^9、0-based半开区间。此题直接输出最小值。
- 用法277：[洛谷P3865](https://www.luogu.com.cn/problem/P3865)，正式静态区间最大值模板；n≤100000、q≤2000000、值0..10^9、1-based闭区间。题面提示最大数据0.8秒；本地最大形状测试不证明该评测机时限已通过。
- 用法278演示signed64数组的最左最小/最大位置，包括空构造（q=0）。它是API演示，不单独计正式模板覆盖。

## 验证

`tests/static_rmq_probe.cpp` 穷举长度0..8的三值数组全部区间；测试2的幂、块边界附近长度，升序/降序/重复值/signed64极值。每份核心3130463个小区间由独立扫描得到最左最小/最大答案，另在50万元素上用独立线段树验证100万次查询。有状态比较器按记录字段排序，检查负载字段与原编号一致；同时检查每次查询最多6次比较、构造比较次数和表格单元数的线性上界。

`tests/static_rmq.py` 在普通/ASan+UBSan下测试header/copied各assert/NDEBUG四种形式，并拒绝五种错误变体：并列取右、每点清空候选、错误弹出相等值、未截左边界、漏中间块。两份WIDA固定源码另行编译比对。每份完整用法均验证driver/expanded/minimal-copy三种形式、71组输入；正式最小值包含50万n/q，正式最大值包含10万n/200万q。证据保存源/输入/输出/二进制摘要，不代表重跑全库。
