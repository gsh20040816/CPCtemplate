# 斐波那契最小循环节

`FibonacciPeriod` 求标准 Fibonacci 状态 `(F_k,F_(k+1))` 模 m 首次回到 `(0,1)` 的正下标。它返回精确最小 Pisano 周期，而不是某个保证可行的上界。

## 接口与范围

- `period(m)`：1≤m≤2^64−1；返回 unsigned int128。约定 π(1)=1。对象可以重复调用，保留的只有 PollardRho 随机状态。
- `fib(k,m)`：k 为 unsigned int128，m 为正 unsigned64，返回相邻两项模 m。递归倍增，至多128层，未改成手工 DFS 栈。
- `is_period(k,m)`：检查正 k 与完整相邻状态。只检查 F_k=0 会把零点间距错当周期。
- `prime_period(p)` 是内部辅助，调用者若直接使用须保证 p 为素数且 p≥2。其他辅助成员无需改动。

最小周期满足 π(m)≤6m，仍可能超过64位。例如 m=14901161193847656250=2·5^27，答案89406967163085937500。API用法展示128位十进制输出；P4994和来源int协议只在各自已证明的小范围内转换为64位。

复制核心需按顺序带上 Mod64、Prime64、PollardRho。文件include为了复用已有PollardRho会引入兼容头的其他内容，但手册复制依赖不含那些无关组件。随机分解属于Las Vegas过程：返回因子必须精确，随机性影响耗时；不可把总时间写成确定O(log m)。除分解m及各素数的p±1之外，每次状态检查耗费O(log k)次模运算，递归空间O(log k)。

## 为什么是最小周期

Fibonacci转移矩阵 A=[[1,1],[1,0]] 的行列式为−1，在任意模数下可逆；周期就是A的乘法阶。相邻状态为(0,1)等价于矩阵单位元。

对p≠2,5，特征根满足x²−x−1=0。5为二次剩余时两根在F_p内，阶整除p−1；否则在F_(p²)内，Frobenius交换两根，其乘积为−1，故A^(p+1)=−I，阶整除2(p+1)。由二次互反律，可按p%5判断。p=2,5分别直接给出3,20。

把候选值的每个素因子q反复试除，只有除后仍为单位状态才接受。循环结束后若存在更小的阶，该阶必整除候选，候选与真实阶之商中必含某个还能被除掉的素因子，矛盾。因此得到素数模数的最小周期。只分解64位的p±1；非剩余情形额外添加因子2，避免把可能超过64位的候选送入64位分解器。最大unsigned64整数本身为合数，因此合法素数p的p+1不会溢出。

对相邻素数幂p^e、p^(e+1)，旧阶t整除新阶；又有A^t=I+p^eB，二项式展开得(A^t)^p=I模p^(e+1)，所以新阶只能是t或pt。逐层实际检查即可准确选择。不能无条件假定π(p^e)=p^(e−1)π(p)；这涉及Wall–Sun–Sun问题，本项目不声称已找到反例，也不以有限测试证明一般相等式。

不同素数幂互素，由中国剩余定理，整体阶是各阶的最小公倍数。先除gcd再乘，结果与所有部分lcm都不超过6m。倍增计算2b−a、c+d使用128位；a²、b²要分别模m之后再相加，不能直接相加两个128位平方，后者可能需要129位。

## 题目与验证

[洛谷P4994](https://www.luogu.com.cn/problem/P4994)要求最小n>0满足F_n=0、F_(n+1)=1模M，2≤M≤706150；已核对官方定义和M=2输出3的样例。用法335归为正式模板问题，用法336为完整64位API，用法337仅复现HDU3977来源协议。HDU官方题面未能访问，因此不把来源协议列为已核对正式题目。

`python3 tests/fibonacci_period.py` 和加 `--sanitize` 可重跑。小模数逐项递推；大模数由Python任意精度2×2矩阵检查周期，再用GNU factor给出的每个素因子q检查t/q均不是周期。这是最小性证书，不依赖另一份同样的素数幂提升代码。还检查任意128位下标的相邻两项、闭式2幂/5幂、完整原来源的兼容副本，以及头文件、NDEBUG、实际展开、手册最小复制四种程序。

故障变体覆盖不缩减候选、只检查F_k=0、64位截断和未约减平方和溢出。无已知素数幂例外可用于杀死“无条件提升”变体，因此该分支的必要性由上述阶的证明说明，不伪造测试反例。没有新增线上AC、评测时间或速度排名声明。
