# 固定编号的可合并 Splay

`MergeSplay(vector<long long>)`为原编号0..n−1建立独立单点集合。旋转、合并与改值都不改变原编号；排序键为(值,原编号)，重复值保留为不同元素。节点池始终n+1个槽，不依赖额外并查集或离散化。

- `merge(u,v)`合并两点所在集合，已同集合返回false。
- `same(u,v)`判同集合，`size(id)`返回集合大小。
- `set(id,val)`改变元素值，保持集合及编号；`value(id)`读取值。
- `rank(id)`返回集合内1-based名次。
- `kth(id,k)`返回第k小的原编号optional，非法signed64 k返回nullopt；值用value读取。

允许空数组；对元素的操作要求编号合法，元素数小于INT_MAX。值支持完整signed64，只比较不加减。查询也会伸展，不能缓存内部根；a及辅助函数仅供内部使用。普通值拷贝独立，重建用新对象赋值。

## 合并与改值

先把u、v分别伸展。若同集合，第二次伸展后第一个节点要么就是第二个，要么有父亲；否则二者各为根。按根的size选较小集合，递归访问其全部节点。每个节点先保存旧左右儿子，再清空链接并插入大集合，随后递归处理保存的儿子。不存在显式DFS栈，也不新建节点。

insert在新节点伸展过程中逐次pull受影响节点，最终整棵树大小正确。set先伸展目标并拆下两侧；若左侧非空，伸展其最大值后接上右侧，再按新值插入原节点。身份不变，集合不变，新的并列次序仍由原编号确定。

初始化O(n)、空间O(n)。每个元素被搬移后所属集合至少翻倍，故总搬移次数O(n log(n+1))。结合伸展树插入的均摊界，全部成功合并总成本O(n log²(n+1))；其他操作除value为O(1)外，均摊O(log(n+1))。单次非合并访问最坏O(n)，递归深度可达O(n)；合并的成本按上述总界计。本地Darwin测试设置512MiB栈，不代替在线资源验证。

## 来源和用法

kuangbin3.4.2印刷67–72页用可合并Splay处理删边、改点权和连通块第k大。用法290为[UVA1479](https://onlinejudge.org/external/14/1479.pdf)的实际Splay程序：离线倒序恢复删边及旧点权，k转换为(long long)size−k+1，非法查询贡献0且仍计入均值分母。不再依赖离散化或并查集。用法289的频数线段树替代方案及原有证据保留。

用法291对应[洛谷P3224](https://www.luogu.com.cn/problem/P3224)：桥连通集合，Q返回第k小权值对应的顶点编号，不能输出权值；不存在时−1。两题均为竞赛应用，未计入正式模板题覆盖。用法292展示合并返回值、改值、kth和size/rank接口。

3.4.2和父项3.4现记为local-tested，表示实际来源算法已实现并本地验证；不代表HDU3726原站资源或线上AC已验证。WIDA其他复杂Splay应用不因此自动覆盖。

## 验证证据

`tests/merge_splay_probe.cpp`枚举n≤6所有集合划分，n≤4枚举−1/0/1值，较大n补顺逆序、全相等和signed64极值。核对任意两点合并、逐点改值后的独立集合标签与排序、名次、kth、父指针、子树大小、BST序、唯一访问及复制隔离。另有100份随机历史、十万节点深递归搬移和平衡合并。

每种核心形式100126案例、52219946次小规模核验、53219944次总核验。头文件/抄写×assert/NDEBUG四种形式，在普通和ASan/UBSan模式均通过。六种错误变体被独立参考拒绝；插桩逐次证明成功合并的实际搬移节点数等于较小集合大小。

完整driver/expanded/minimal-copy各执行UVA1479的104份输入、P3224的82份输入、API的81份输入。UVA另逐项记录全部查询，用正序BFS及实际点权排序核对，避免均值抵消错误。P3224含n=100000、q=300000。证据见`verification/merge-splay-{normal,sanitizer}.json`；没有新增线上AC或排名声明。
