# WIDA 在线模板：树链剖分 LCA

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `f71f21dda2565060cd2d8f371f9c241ab507d593`，路径 `01 - 常用在线模板汇总/02 - 图、树、网络流/04 - LCA（树链剖分解）.cpp`。它使用 `vector`，但没有包含头文件，也没有 `std::`，单独编译失败。

`work(root)` 做两次 DFS。根深度仍是 1。重儿子是子树更大的孩子，相等时保留先遇到的。`lca` 沿链顶往上跳，`clac` 返回边数。没有线段树，成员 `idx` 声明后没有使用。

单点、一条边、四点路径和一棵六节点树的全部点对，与沿父节点走到根的结果一致。没被 `work` 走到的点，以及第二次调用 `work`，这轮没有测。

`python3 tests/wida_lca_hld.py` 在普通 `-O2` 和 ASan/UBSan 下输出 `ok`。没有新的在线 AC，也没有新增模板。来源保持 partial。
