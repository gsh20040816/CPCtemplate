# 模 2 压位高斯消元

`GaussXor::solve(a,n)` 接受 m 行 n+1 列的 01 字符串增广矩阵，输出系数秩、可解性、一个特解及完整零空间基。补齐高斯消元的常用模 2 性能版本；与 `GaussMod<2>` 的逐元素计算相比，每次异或更新 64 个系数，不调用逆元。

## 来源审计与边界

已核对 kuangbin 2018 PDF（SHA256 `f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad`）正文 37–39 页 2.10.1。该节除异或消元外还含 POJ1681 最少开关应用。此批只完成通用方程组部分，来源行保留 partial；最少开关不能直接输出特解中 1 的个数，应用建模与最小化驱动仍待补。

参照 [OI Wiki 高斯消元](https://oi-wiki.org/math/numerical/gauss/)的线性方程组/自由变量分类，放入固定官方导航“数学 → 数值算法 → 高斯消元”。该页浮点消元与精度分析仍未完整审计，数学覆盖表不标整页完成。

不变式：每轮从尚未选主元的行中选择当前列非零行，再异或消去其他所有行的该列。已处理主元列在新主元行中均为零，因此从当前列所在机器字开始异或不会破坏前面的主元；同一字内更早的自由列也为零。结束后主元列为单位列，剩余行系数全零，有非零右端项则无解。

自由变量全部置零时，主元变量等于右端项，得到 particular。每次令一个自由变量为 1、其余为 0，将该自由列各主元行系数填入主元变量，得到一个齐次解。各基向量在自由列上组成单位矩阵，所以独立且数目恰为 n-rank，张成完整零空间。所有解为特解异或任意基子集；共有 2^(n-rank) 个解，计算数量时调用者自行选模数或大整数，不能无条件写 `1LL << dim`。

- 无解仍返回系数秩，particular/kernel 为空；有解但零变量时 particular 也为空，应看 consistent 判断。
- m=0 时有 n 个自由变量；n=0 时任意一个右端项 1 即无解。显式 n 消除空矩阵的列数歧义。
- 支持矩形、零矩阵、重复方程、迟到矛盾；输入不改变。
- 每行 n/64+1 个机器字，增广右端项在第 n 位，包含 n 恰为 64 倍数时的独立字。
- 时间 O(mn+mn min(m,n)/64+n²)，输出最坏就有 n² 字符。返回的基字符串方便抄写和按位组合；消元内部才采用压位存储。
- 精确有限域运算，不采用 eps；不适用于实数线性方程，不保证最小汉明重量。

## 完整用法与验证

example-143 对应 Library Checker [System of Linear Equations (Mod 2)](https://judge.yosupo.jp/problem/system_of_linear_equations_mod_2)。行列数各≤4096，系数各行及右端向量均连续 01 字符。把 b[i] 追加到第 i 行。输出第一行是 kernel.size()，不是系数矩阵秩。后面输出特解和所有基向量；无解输出 -1。

`tests/gauss_xor.cpp` 穷举所有 m,n≤3 的增广矩阵，以及 600 份最多 10 变量的随机系统。参考枚举全部输入向量得到独立的像空间及全部解；同时验证系数秩、可解性、基独立性、所有仿射组合恰等于参考解集。另以已知秩的单位块和保秩行变换构造 56 份字边界/矛盾系统，并验证 4096 阶反单位阵、零矩阵和矛盾零行。

固定 Library Checker `e64660561a995c357cdc61ddee1bde68b80528db` 的 36 组官方生成数据，普通与 ASan/UBSan 共 72 次本地 checker 接受，覆盖最大随机、低秩及长宽矩形；错误输出负对照拒绝。`tests/usage_checkers.py` 对打印样例采用完整解集枚举，拒绝错误特解、错误无解和相关基；不将输出匹配某个参考特解作为唯一判据。

证据见 `verification/gauss-xor.json`、`gauss-xor-official*.json`。没有线上 AC、排名或 GitHub CI 结果。
