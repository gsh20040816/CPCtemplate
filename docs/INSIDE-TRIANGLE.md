# 成都2025 I：用凸多边形切线计数包含三角形

正式题名为 **Inside Triangle**，官方题解标题写作 **Inside Polygon**。本应用复用 `IntegerPlane` 和 `convex_tangents_i64`，不另增一个只包装本题的组件。代码为 `verify/codeforces/106161I.compact.cpp`，打印用例 example-242。

## 题面与接口边界

[官方两页题面](https://codeforces.com/gym/106161/problem/I) 给出两个逆时针凸多边形 P、Q，各自无三点共线，Q **严格在 P 内部**。选取 P 的三个不同顶点，统计组成的三角形 **非严格包含 Q** 的方案数，接触三角形边界也应计入。

输入顺序为 T；每组 n、n行P坐标、m、m行Q坐标。T≤1000，3≤n,m≤300000，坐标绝对值≤10^9，各组的 n 之和、m 之和分别≤500000。输出每组一个整数。CF题面为3秒／1024MiB；不把本地观测当作评测通过或时间上限保证。

[官方题解](https://contest.ucup.ac/download.php?id=2567&r=1&type=attachments) 第29–32物理页采用切线区间和旋转计数。本实现保留现有对数时间切线内核，使用下面独立推导的前缀和表达式。总复杂度是 **O(n log m+n+m)**，不是题解完整旋转切线版本的 O(n+m)。

## 合法弦端点

将 P 的下标展开到整数轴。称有向弦 i→j 合法，当 Q 的所有顶点都位于该弦左侧或线上，即叉积非负。凸性使顶点条件等价于整个 Q 都在闭左半平面。

固定 i，其他外顶点发出的射线按角度单调排列在小于半周的顶点内角内；Q 严格位于该内角。因此合法 j 构成前缀 `[i+1,f[i]]`。相邻逆时针边一定合法，反向相邻边一定非法，故 `i+1≤f[i]≤i+n−2`。

从 P[i] 查询 Q 的左切点 k。切线接口的 left 定义是 Q 全在 `P[i]→Q[k]` 的左侧，故它是指向 Q 的射线范围的首端。由于上述角域小于半周，`cross(P[i],P[j],Q[k])>=0` 恰好判断 j 是否还在合法前缀内。包含整条 Q 边时，接口的最近端点规则不改变切线方向。这里必须保留等号。

f 单调不减：当合法弦 i→j 的起点移到 i+1 时，弦右侧沿外多边形边界形成的被排除区域缩小；此前位于左侧的 Q 仍在左侧。代码维护一个只增不减的 j；每个外点各调用一次 O(log m) 的切线查询。扩展 `f[i+n]=f[i]+n`，只需长2n的数组。

## 前缀和计数

固定展开后的第一个点 a，第二点 b 必须在 `[a+1,f[a]]`。第三点 c 要满足三条边均合法：

- a→b：上面的区间限制
- b→c：`c≤f[b]`
- c→a+n：`f[c]≥a+n`

定义 g 为首个满足 `f[g]≥a+n` 的下标。Q 有正面积，所以同一条弦的两个方向不可能同时合法，否则 Q 必须完全落在一条直线上。因此 `g>f[a]`；对于每个合法 b，还必有 `f[b]<a+n`。这两点自动保证 `b<c<a+n`，不需要再截断 c 的范围。

于是每个 b 恰贡献 `max(0,f[b]-g+1)`。f 单调，令 h 为 `[a+1,f[a]]` 中第一个满足 `f[h]≥g` 的位置。若不存在贡献为0；否则用 f 的前缀和求

`sum(f[h..f[a]]) - (f[a]-h+1)*(g-1)`。

a 逐次增加时，阈值 a+n、g、h 都不减；已被 h 越过的位置不会重新有效。j、g、h 三个游标的总移动量都是 O(n)，不在内层重新扫描。每个合法无序三角形恰在它三个顶点分别充当 a 时各计一次，最终除以3。

## 数值、内存与前提

答案不超过 C(300000,3)=4499955000100000，除3之前不超过13499865000300000，均可用 signed64。前缀和也用 long long，乘法明确由 `1LL` 提升。展开下标不超过3n，数组访问只发生于0..2n-1，给定规模可用 int。叉积由既有 signed128 内核计算。

P、Q和两个展开数组占 O(n+m) 空间。严格嵌套、凸性、方向均是题面保证；程序不作通用多边形校验。若把 Q 移到 P 边界、允许退化线段或反向输入，上述切线存在性、区间和除3证明都不能直接沿用。

## 独立验证设计

小规模答案完全独立地枚举所有 `a<b<c`，再用 Python 任意精度整数逐一检查每个 Q 顶点是否位于三条三角形边的闭左半平面。该参考不调用切线、不构造 f，也不使用前缀和计数式。

覆盖官方三组样例2/4/6、内部格点三角形穷举、随机严格嵌套凸包、P/Q各自循环移位、正行列式整数仿射变换、整条内边恰贴三角形边、单顶点接触、零答案、±10^9与1000组重置。

最大规模使用整数几何证书：

1. 取75000条互异正斜率的本原整数边，按斜率排序，接上90/180/270度旋转，得到30万点严格凸、中心对称的 R；平移和二倍放缩使中心为整数原点。以 P=10R 和包含原点的微小三角形 Q，逐条验证所有偏移 h−1 的弦严格保留 Q。原点在 Q 内，所有对径弦都穿过 Q，故恰有 `f[i]=i+h-1`，h=n/2。合法循环间距的亏量和为 h−3，给出闭式 `n(h-1)(h-2)/6`；n=300000时为1124977500100000
2. n=3、m=300000：把 R 放入一个精确验证严格包含它的大三角形，答案为1
3. n=m=300000：P=10R、Q=9R，中心在 R 内保证严格嵌套。直接计算 Q 的有向二倍面积，并验证它大于 P 包围盒的宽乘高；矩形内任何三角形的二倍面积至多等于该乘积，所以答案为0。这一不等式在实际数据上检查，不能仅凭“中心对称”假设

最大用例各自为独立输入，避免违反总顶点数限制。实际驱动、完整打包和最小依赖复制各测断言开/关，共6种形式；负对照改变贴边等号、除数或计数端点，须在正常退出且无诊断的情况下被独立答案拒绝。
