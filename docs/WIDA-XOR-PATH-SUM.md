## 接口与边界

XorPathSum(parent,value)接受同长度0-based数组；parent必须是一棵固定有根树，唯一根父亲为-1，根编号可以任意。1≤n≤200000，点权为[0,2^27)整数。sum()返回所有无序端点对u≤v的简单路径的点权异或值之和，包含n条单点路径；set(x,value)改变一个点权并返回新总和。不是只求某条路径的xor，不改变树拓扑，不支持link/cut或换根。内部辅助函数与t不是公开修改接口；对象完整复制后相互独立。

初建O(27n)，单次修改摊还O(27logn)，读取总和O(1)，空间O(27n)。初建DFS递归，链上深度可达n；不改成显式调用栈。每个节点保存两份首尾聚合信息、虚子树计数和64位配对数，常数较大，应按sizeof(Node)乘(n+1)再加构造期邻接表估算内存。本机sizeof(Node)=1568字节，n=200000时节点数组约299.1MiB，另需构造期邻接表、输入数组与递归栈；不适合直接放进256MiB限制。n=200000时最坏总和不超过200000×200001/2×(2^27-1)，在signed64范围内。

## 聚合不变量

Info.path是实链上点权xor；up/down逐位记录该链簇内每个点到上端/下端路径xor的0/1数量。Info.sum是簇内所有无序路径的xor和。拼接两个相邻簇时，新路径必然一端在左簇、一端在右簇；逐位a.down[bit][j]乘b.up[bit][j xor 1]恰好计入该位为1的跨簇路径。上端计数把右簇路径xor整体异或左簇path，下端同理，因此拼接结合律对应同一实际路径集合。

单点实链簇带若干虚子树时，cnt记录各虚子树从连接端到内部点的xor计数；pairs[bit][x]记录中心点该位等于x时，跨不同虚子树或中心到子树的贡献。加入分支用旧cnt算交叉项，再增加cnt；删除必须先减少cnt，再扣交叉项，避免把同一分支内部路径算作跨分支。分支内部答案另外累计到sum，中心单点答案为自身点权。

access依次把旧右儿子转虚、把新右儿子的旧聚合转实，再更新当前簇。必须保存修改前的子簇Info用于从父节点扣除旧贡献，不能拿修改后的Info扣旧值。最终把修改点旋到根，此时它的tot覆盖整个固定树。没有翻转标记，所以无需pushAll；splay旋转保持中序对应实链顺序。

## 原稿的整数范围

原稿add/del中的两个int计数先做int乘法，再加到i64配对数。构造根下两个各50000点分支时，50000×50000超过INT_MAX。普通构建在本机对期望2500100001得到-1794867295；UBSan定位到原稿第89行的signed integer overflow。该溢出探针单独运行，不把其预期失败混入新组件通过记录。

新组件在乘法前显式使用1LL；同一宽分支反例，以及27位全1的加权版本均通过。原稿文件没有被改动。我们尚未取得原比赛的完整题面、主程序及约束，故不能断言原题必然触发这个问题。
