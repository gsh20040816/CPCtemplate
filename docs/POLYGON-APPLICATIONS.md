# 最近点对端点与多边形包含用法

本批补足 issue #12 的正式用法，并将已有 Minkowski 和与凸包二分组合成完整比赛应用。只维护 vector 版，最近点对保持递归分治。本地验证不能当成线上 AC 或速度排名。

## 最近点对的原输入编号

`closest_pair_i64(p, &ids)` 返回 `optional<__int128_t>` 距离平方，并写入原输入的 0-based 下标；不改变 `p`，不需要坐标到编号的额外映射。最优解可任选。重复点距离为0，但下标必须不同；不足两点返回 `nullopt`，同时把 `ids` 重置为 `{-1,-1}`。省略端点参数的旧调用保持可用。

内部先按坐标排序下标。进入 `solve(l,r)` 前该段是横坐标划分得到的点集，返回后按纵坐标排序；中间横坐标在递归前保存。两边递归结果为局部距离上界，归并后只比较横向距离小于当前上界的带内点，按纵坐标从后向前扫描至纵向距离达到上界为止。点集在左右两半各自满足距离下界，固定高度带内候选点数受常数约束，因此每层线性，总计 O(n log n)，辅助空间 O(n)。不采用“只看按 x 排序后相邻几个点”的错误启发式。

局部 `best` 用于分治剪枝；`distance` 同时维护全局最优值与端点，最后返回的局部最优值和端点对应的距离一致。距离相同无需覆盖旧端点。坐标绝对值≤10¹²，差先转 int128，距离平方至多8×10²⁴，哨兵2¹²⁰大于所有合法距离。

[Library Checker closest_pair](https://judge.yosupo.jp/problem/closest_pair) 输入多组点，总点数≤500000、坐标绝对值≤10⁹，输出原下标。现为 example-134，支持重复点；29组固定版本官方数据在普通与ASan/UBSan下共58次本地checker接受，错误输出负对照被拒绝。参考版本与数据、驱动指纹见 `verification/closest-pair-official*.json`。

原 [P7883](https://www.luogu.com.cn/problem/P7883) example-62 仍输出距离平方。其题目点互异、n≤400000、坐标绝对值≤10⁷，平方距离至多8×10¹⁴，故该驱动转 `long long` 安全；不可把这一转换推广到模板的万亿坐标范围。该用法重新展开编译验证。

## 一般多边形和凸多边形的边界

[AOJ CGL_3_C](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=CGL_3_C&lang=en) 是独立几何模板题：n≤100、q≤1000，整数坐标绝对值≤10000，输入逆时针简单多边形，允许凹形。example-135 保留边界顺序直接调用 `polygon_contains`，输出0外部、1边界、2内部。

不能为了查询更快把凹多边形先变成凸包。通用查询先判点在线段上，再采用半开纵坐标区间累计绕数，因此水平边、恰好经过顶点的查询不会漏掉或重复计数；反转边界方向也不影响非零绕数的真假。自交多边形不在契约内。空集、单点、线段的退化结果按已有接口约定处理。

`convex_contains_i64` 要求严格逆时针凸包，无共线边内点，不重复首点；支持任意循环起点。先处理首点两侧射线和边界，再二分所在扇形，最后用扇形外边判断内外。原点到中间顶点的扇形对角线是内部，不会自动当成多边形边界。每次查询 O(log n)；不满足凸包契约时不能直接使用。

## Minkowski 差与 P4557

[P4557](https://www.luogu.com.cn/problem/P4557) 的两组点各自凸包记为A、B。第二组平移d后相交，等价于存在a∈A、b∈B使a=b+d，即d∈A+(-B)。因此把B坐标取负后分别求严格凸包，再求Minkowski和，最后对原平移向量做闭集查询。不要同时把查询向量也取负。输出条件是 `contains != 0`，边界相切也算冲突。

题目n、m、q各至10⁵，坐标和平移量绝对值至10⁸；Minkowski结果坐标至2×10⁸，位于整数几何契约内。总复杂度O(n log n+m log m+q log(n+m))，空间O(n+m)。题目保证两组均非共线且每组至少3点；内核的空集/点/线段和仍单独有测试，不能以题目保证替代退化契约。

example-136 是比赛应用，联合展示 `integer_hull`、`minkowski_sum`、`convex_contains_i64`，不计为后两者的正式非比赛模板题完成。

## 独立验证

- 最近点对和Minkowski内核测试移除classic依赖。最近点对枚举3×3网格的512个子集、反向顺序、追加重复点，独立cpp_int全点对比较；2000组随机/万亿坐标点集同时检查原编号、输入不变、默认调用和兼容入口。Minkowski和继续以所有顶点和的礼品包装凸包作独立参考，循环起点、退化和大规模都检查。
- 多边形参考选择不经过任一顶点的斜射线，用任意精度整数的严格线段相交数奇偶判定，不复用被测绕数/二分算法。网格512个子集的凸包枚举全部循环起点；161份简单边界（包括凹形）检查两种方向及平移放大到万亿范围。另测AOJ最大规模，100001顶点严格凸包与300001次二分查询。
- P4557完整程序180组小图直接对两凸包平移后的边相交/顶点包含作参考，不用Minkowski差；另有两组各100000个不同点和100000查询的最大输入。
- LC完整驱动1600组Python整数全点对枚举，500000重复/共线点，100000测试的重置和极值坐标。原P7883完整驱动另测200组点互异输入、400000点上限和8×10¹⁴答案。

全部普通与ASan/UBSan通过；打印用法原样展开验证，候选端点输出按距离证书核验，不绑定某一组最优下标。汇总证据见 `verification/polygon-applications.json`。未新增线上AC。
