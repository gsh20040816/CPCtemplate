# 维护约定

1. 覆盖目标为 kuangbin + WIDA 全量来源目录，并补中国赛站与 OI Wiki 数学。不得删除待完成条目来提高完成率。
2. 一切以可读性和赛时快速抄写为目的。禁止一行多语句及单行函数；简单算法用函数，有状态算法采用轻量 struct。新模块写入两个风格目录，各自说明下标、容量、初始化、多测重置、数值范围、复杂度和输出方案接口。
3. 至少一个独立参考算法或完整枚举；与历史实现互相吻合只能验证一致性，不能独立证明正确性。
4. 本地通过、sanitizer 通过、OJ AC 三类证据分开记录。AC 必须有提交链接和当次提交文件的 SHA-256。
5. 修改被测代码后重新回归；修改已通过 OJ 的核心逻辑时旧 AC 不能当新版本证据。
6. LaTeX 由 `tools/book.py` 引用实际源码行段。`docs/generated.tex` 是生成产物，修改 catalog 和源文件后重建。
7. 计算几何区分精确判定与浮点构造。必须列出输入范围和所有退化约定；排序比较器不得使用非传递 epsilon 等价。
8. 公开仓库不包含登录页面快照、凭据、私人联系方式或整份私人训练代码。
