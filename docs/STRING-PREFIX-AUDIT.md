# KMP、Z、两串扩展KMP与Manacher的来源对应

本文件记录916eb25批次的历史结果；后续顺序匹配与整数Manacher补全见 `docs/SEQUENCE-MATCHING.md`，当前状态以coverage.csv为准。

本次核对10个尚未映射的WIDA/kuangbin条目。核对依据是实际源代码和章节内容，而非标题相似；逐条范围记录在 `verification/string-prefix-sources.json`。其中8项标记为本地验证后的功能替代，2项保留部分覆盖。没有新增线上AC或速度排名。

## 两串扩展KMP

`exkmp(s,t)` 返回 `{z,p}`：`z[i]=LCP(t[i..],t)`，`p[i]=LCP(s[i..],t)`，0-based，z[0]=|t|。空t返回空z和|s|个0；空s只返回t的Z数组与空p。输入按字节相等比较，支持内嵌零和高位字节，不需要寻找未出现过的分隔符。字符串长度均须小于INT_MAX。

维护已经算出的匹配区间[l,r)，使r尽量大，区间里的文本等于模式前缀。若i<r，则当前位置匹配至少可复用 `min(r-i,z[i-l])`；若这个值小于r-i，模式内部已经确定下一字符不同；否则从右边界继续比较。右端点只前进，总新增比较O(|s|)，预处理模式O(|t|)，故整体O(|s|+|t|)。`i<r`同时保证 `i-l<r-l≤|t|`，所以Z下标合法；不能在区间外无条件读取 `z[i-l]`。

返回两个独立vector，共4(|s|+|t|)字节的int数据，构建后移动返回，无额外输出拷贝。输入通过const引用读取。默认4字节int、单字节char时，两串各2000万的输入加输出约200000000字节（190.7MiB）有效数据，另有string容量与运行时开销；ASan开销另计。该估算不是当前OJ内存限制的核验或内存排名。

[P5410](https://www.luogu.com.cn/problem/P5410) 要求两个数组各自的 `xor((i+1)*(长度+1))`，使用 `1LL` 先提升乘法。题面两串长度均1..20000000，字符均小写。此处用法250直接计算两串LCP，不拼接模式、分隔符和文本，因此不分配拼接串及其完整Z数组。最长乘积不超过20000000×20000001，long long足够。

## KMP的替代范围

本库 `prefix_function(s)` 返回长度n的0-based数组p，各前缀最长真border是p[i]。WIDA的 `f[0..n]` 与kuangbin的普通 `next[0..n]` 使用前缀长度下标，对j≥1映射为 `f[j]=next[j]=p[j-1]`；0位置的约定不同。库不直接输出kuangbin的优化失败表kmpNext。

`kmp_match(text,pattern)` 返回所有0-based出现起点，含重叠，模式要求非空；上游输出1-based位置的场景加1即可。原稿按模式在文本中的出现次数返回时，取结果长度即可。库在一次成功匹配后显式回退border，后续匹配保留重叠。

WIDA打印稿还列出最小周期和最小循环节：非空长度n，令d=n-p[n-1]，最小周期为d；若n%d==0，最短整串重复单元长度为d，否则为n。前者不要求周期整除串长，两种含义不能混用。这两式已通过独立逐位周期枚举验证，不需要再添加简单函数。

kuangbin §1.1还包含POJ3167 Cow Patterns：数字的相对大小与相等关系匹配，不是普通字符相等。当前KMP接口没有完成这一能力，该整章只标partial；不把普通匹配对拍拿来证明顺序匹配。

## Z的替代范围

WIDA打印稿与jiangly版本都求单串各后缀LCP。库的z_function返回长度n、z[0]=n；jiangly源码多开一个尾槽z[n]=0，必要时调用者自行补0。该尾槽不是非空后缀结果。空串返回空数组，是本库明确定义的扩展。原稿题名中的“扩展KMP”不必然包括两串操作，kuangbin §1.2的两串extend功能现在由exkmp提供。

## Manacher的替代范围

现有 `manacher(string)` 返回odd和even：odd[i]包括中心，回文长度为2*odd[i]-1；even[i]的中心在i之前，长度为2*even[i]。无需分隔符或边界哨兵，支持任意字节，n<2^30以保证整数镜像下标安全。

jiangly的插分隔符序列为 `# s[0] # s[1] ... #`，返回半径r含中心。映射为 `r[2i+1]=2*odd[i]`，`r[2i]=2*even[i]+1`（i<n），尾部分隔符r[2n]=1。kuangbin和WIDA打印稿额外放置左边界字符，将上述变换中心整体右移1；通常求最长长度为变换半径减1。库直接用两类长度最大值；全部odd/even之和是回文出现次数。

WIDA打印稿的字符串最长回文与kuangbin §1.3由现有字节版完整覆盖。jiangly的同一文件还有 `vector<int>` 重载，允许超过字节范围的整数；本库没有直接等价接口，本条只标partial，不能用强制转char替代。后续若泛化序列接口，应对完整整数域独立验证再关闭。

## 验证边界

`tests/string_prefix.py`联合验证prefix_function、kmp_match、z_function、manacher和exkmp，头文件/真实标准头抄写体各有assert/NDEBUG，普通和ASan/UBSan分别运行。参考使用逐位置LCP、枚举border/周期以及对子串逆序比较；包含全部长度0..7的三字符（a、零、高位字节）串、长度≤4的两串穷举、随机任意字节、全部256字节及百万重复串闭式结果。测试检查输入不变、重叠与空输入。

七个错误变体分别替换模式、错误截断匹配、错误复用Z、交换返回数组、漏掉重叠匹配、z[0]置零和删除偶回文半径；每个必须被独立参考拒绝。P5410三种完整程序形式各运行150份小规模随机输入及5份最大/不等长输入，最大模式包含全相等、全不相交和交错周期。生成输入未标成官方样例。字符串现有源码未改；此次补全exkmp以及来源对应，不能声称其他字符串组件或全库得到重新验证。
