# 异或行走、无向欧拉路与线性空间求交（176–179）

四份完整用法复用已有vector驱动，不改算法核心。用法176是WC2011比赛应用；177来自USACO Training Section3.3的直接欧拉路训练题，178、179来自Library Checker独立模板题。

P4151允许重复经过点和边，求的是行走的异或最大值。连通保证使`*query(1,n)`合法；一般图须先检查optional，build仅覆盖指定根的连通块。无向边通过一条树路径和环空间组合，不能用于最大异或简单路径，也不能把环基的相关性标志解释成非空行走限制。

P2731要求字典序最小顶点序列。点号直接保留1..500，run()自动从较小奇点或最小非孤立点出发，忽略编号小但孤立的点。重边必须以边ID区分；自环的两条邻接记录只消耗一次边。题面保证有解，不代表通用run无需失败检查。本题只输出vertices，edge_ids及指定起点/不排序模式需另行测试。

Library Checker题名为`intersection_of_f2_vector_spaces`；修正候选生成器原先从两个变体文件名猜出错误题号的问题，优先读取驱动开头显式注明的官方链接。题面T≤100000、输入基维数≤30且生成元独立。输出只须张成交空间且独立，不要求某种固定主元形式。Zassenhaus程序只输出second；first和空间的正确性由核心回归另外检查。64位和相关输入的验证是模板扩展范围，不归因于官方30位题目。
