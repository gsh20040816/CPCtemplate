# 精确有符号整数卷积

`convolution_i64(a,b)` 接收 signed64 系数，并返回真实整数卷积。输入为空时返回空；非空结果长度不超过 2^24。每个真实系数必须在 signed64 范围内，这属于调用前提。

分别以 167772161、469762049、1224736769 作 NTT，三者都是素数，3 都是原根，公共变换容量为 2^24。测试通过试除验证素数，并对 p-1 的不同素因子检查原根条件。

先由前两个余数重构到 [0,pq)，再加入第三个余数得到 [0,pqr)。最后选择以零为中心的代表元。三个模数的乘积远大于 2^64，因此合法 signed64 结果具有唯一代表；负系数不需要浮点舍入。中间两个模数乘积用 signed64，三模总乘积用 int128。

断言仅检查重构的中心代表是否在 signed64 范围内；若真实结果已经越界并相差模数乘积的整数倍，仍可能别名为合法小值。不能将此断言宣传为任意溢出检测。需要更大输出时应另用多精度或经过证明的更多模数。

时间为三次 NTT 卷积的 O(L log L)，L 为补到二次幂后的长度；额外空间 O(L)。模块依赖参数化 NTT，不重复抄底层蝶形代码，临时输入用移动语义传给卷积避免额外拷贝。

P3803 是无模整数乘法题，次数最多各 10^6、输入系数 0..9，因此真实系数最多 81*(10^6+1)，符合契约。它不能验证一般负系数和 signed64 极值，这些由 cpp_int 独立卷积参考覆盖。P3803 驱动已准备；线上结果及性能排名仍待验证。
