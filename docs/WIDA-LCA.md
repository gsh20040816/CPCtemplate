# WIDA 在线模板：无权 LCA

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `177db56e1ae065103835ad3125bb304cf866040b`，路径 `01 - 常用在线模板汇总/02 - 图、树、网络流/04 - LCA（无权图树上倍增解）.cpp`。它使用 `vector`，但没有包含头文件，也没有 `std::`，单独编译失败。

`work(root)` 从根做一次 DFS。根的父节点是 0，`dep[root] = dep[0] + 1`，所以根深度是 1。`lca` 先把较深的点抬到同一深度，再倍增。`clac` 用 `dep[x] + dep[y] - 2 * dep[lca]` 返回边数。单点、一条边、四点路径和一棵五节点树的全部点对，都与沿父节点走到根的结果一致。

倍增表只有 30 列。深度的对数不小于 30 时会越界，这轮没有构造那种树。`work` 没走到的点深度保持 0，也没有测。边没有权。函数名是 `clac`，不是 `calc`。

`python3 tests/wida_lca.py` 在普通 `-O2` 和 ASan/UBSan 下输出 `ok`。没有新的在线 AC，也没有新增模板。来源保持 partial。
