# 树上新增市场的支配范围

`TreeMarket`补充kuangbin 4.22.1 HDU5016来源模型。固定非负边权树上，每个顶点归属距离最近的市场；距离相同时归属编号较小的市场。只能在原来没有市场的顶点新建一个市场。本组件返回每个候选点单独新增后可支配的顶点数，原有市场点返回0。取最大值即最优数量，取到最大值的位置即候选方案；不表示同时建立多个市场的结果。

## 接口和范围

`TreeMarket tree(n)`，n≥1，点号0..n-1。调用n-1次`add(u,v,w)`建立连通树，w为非负long long，允许零权边。`solve(existing)`接受长度n的0/1标记，返回长度n的计数数组，可在同一树上更换标记重复求解。全是市场时返回全0，无原有市场时每点都可支配全树，返回全n。没有动态改边或动态维护市场的保证。

比较距离、距离和阈值使用int128。n为int，单边不超过LLONG_MAX，简单路径总长小于2^94，内部哨兵2^120足够。返回计数不超过n。构造不检查连通性或非负性，调用者必须满足树和权值前提；内部辅助方法和字段不外改。所有原树遍历保持递归，最坏深度O(n)，本地十万点长链提供512 MiB栈。

## 最近市场与点分治

多源Dijkstra按 `(距离,市场编号)` 字典序维护每个目标顶点v的原归属 `best[v]`。距离相同也可能需要用更小市场编号更新，不能只比较距离。非负权、包括零权保证字典序松弛有效。

设当前重心为c，候选点为x，目标点为v，距离c分别为dx、dv。若路径x→v经过c，则新市场获胜当且仅当：

`(dx + dv, x) < (best[v].distance, best[v].id)`，

等价于 `(dx,x) < (best[v].distance-dv,best[v].id)`。

将当前分解块所有v的右侧键排序，对每个x用upper_bound找到严格大于左侧键的数量。先统计整个分解块，再对删除c后的每个分支以同一个c距离定义减去内部配对，分支内部交给递归处理。若x、v属于不同分支或其中一个就是c，路径必过c；同分支项先抵消。每对候选/目标在首次被重心分开的层恰好保留一次，因此距离与编号规则均正确，零权也不改变证明。

每层排序和二分总O(s log s)，重心深度O(log n)，总时间O(n log² n)。Dijkstra O(n log n)。临时节点和键向量随递归分块大小几何递减，不为每点持久存储所有重心祖先，额外空间O(n)；递归栈也最坏O(n)。

## 原稿核验

固定2018PDF正文192–195页、物理194–197页已逐页目视核对。完整145行保留在 `tests/fixtures/tree_market_sources/kuangbin.inc`，含编号48空行；只去掉页眉/行号/排版缩进、拼回127行换行、规范减号。PDF SHA256为 `f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad`。

原稿使用1-based编号、全局数组、队列式最短距离松弛和树遍历。当前使用vector、显式多源Dijkstra及递归原树DFS。编号整体减一保留相对次序。原稿lower_bound按非严格右侧键计数，但原有市场ID与候选ID不同，有原有市场的合法模型里不可能出现整对键相等；当前直接写upper_bound表达严格获胜条件。原稿也不允许在现有市场点再次新建。

原程序按EOF读n，随后读n-1条带权边和n个市场标记，输出所有候选计数的最大值。`verify/api/tree_market.compact.cpp`及手册用法323复现这个来源协议；它是API/来源模型演示，不是已核验的正式题目驱动。2026-10-08 [HDU官方页面](https://acm.hdu.edu.cn/showproblem.php?pid=5016)无法读取，官方输入范围、资源限制与AC仍待核验。

原稿正常对照243组输入：240组小树，以及十万点正权链、正权星、零权链。原全局状态在同一进程多组输入间重置。另重现两项原稿边界：

- 三点链，只有点1有市场，两条边均为INF+1。原有最近市场传播被INF阻断，原稿最大支配数为1，独立枚举与当前实现为2；路径总长仍在int范围内。
- 四点链，三条边均为2^30。原稿距离累加超过int，由UBSan检出。当前距离用int128，不受此边界影响。

这些是额外来源接口边界，不宣称原题输入允许。原MAXN=100010且1-based，静态点上限100009，本批最大实跑100000，没有声称测试全部最大拓扑或无限多组时间戳。

## 验证范围

核心测试的独立Floyd全点距离直接枚举原市场归属与每个候选结果，不复用点分治或Dijkstra作为oracle。

- n≤5全部146棵标号树，分别全零权和混合0/1/2权；穷举所有市场子集并在同一对象上重复solve。
- 600棵随机树各换三组标记；另有LLONG_MAX边权的四点链，路径超过64位。
- 十万点链、星、零权链逐点校验闭式结果，再重复求解无市场和全市场。
- 普通及ASan/UBSan各头文件/最小抄写、assert/NDEBUG四种形态，每种10376小场景、320758项检查。检查不依赖assert。
- 错误编号优先级、同分支改减为加、距离阈值误加三个错误变体均被拒绝。
- API驱动/完整展开/最小抄写/NDEBUG各244组EOF输入，由独立Python任意精度树距离枚举或大树闭式答案核验。

双模式证据见 `verification/tree-market-{normal,sanitizer}.json`。不增加正式模板题覆盖，不登记在线AC或速度排名。树分治父节还有HDU5039链分治来源待补，完整目标继续。
