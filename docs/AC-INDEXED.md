# AC 序列入口、偏移与深度

本轮扩展原AhoCorasick，未另写第二份失败转移核心。`add(string)`、`count(string)`继续默认小写字母。显式双参数入口接受string或vector<int>：`add(s, offset)`、`count(s, offset)`；每个元素减offset必须在0..25。整数编码无需先转字符串，字符集也无需额外分配转换数组。双参数字符串字面量应先转成string，避免模板遍历C数组的末尾零字符。

例如整数序列使用add(vector<int>{0,1,0},0)，大写字符串使用add(string("ABA"),'A')。插入和查询必须采用一致的归一化编码；可以混用不同原始表示，只要归一化后的字符相同。减法在long long中进行，支持INT_MIN附近的负整数与INT_MAX附近的正整数。并不支持任意大字母表：归一化后仍为26种字符。

`a[u].len`记录Trie深度，根为0，创建节点时从父节点加1。`a[u].go`构建后为完整转移，`a[u].fail`为失败链接，状态数读取`a.size()`；order为不含根的BFS序。重置赋新对象。全部模式插入完后build一次，之后不能继续add。

## 空模式与兼容性

现在允许空模式，add返回根0。count的根分量恒为文本长度+1，表示所有边界的空串匹配，包括空文本的一次。非空模式的计数完全不变，重复模式仍共享终态。若原调用者需要旧版根的“扫描字符数”语义，应显式减1。旧版文档对此有不同约定，不能无声视为兼容。

ACWeighted本来已明确空模式在所有边界计次，仍直接将空权重记到根，本轮没有改动它或DynamicAC。ac_shortest仍只接受非空模式的终态与正长度，不因基础AC支持空模式就放宽该辅助函数的输入约定。

构建O(26V+L)，查询O(|text|+V)，空间O(26V)。深度和状态数须在int范围内，返回计数用long long。节点新增一个int深度字段，有相应空间常数；无需额外的字符串/整数转码缓冲区。

## 来源映射

对应WIDA固定commit cfdb12db6792eb2303798541fb5c760ed2bc618b的06B(vector新版)和06C(string新版)。上游虚点0、根1，当前只有根0，因此状态编号与size不能原样混用。其next/link/len访问对应当前go/fail/len，init对应赋新对象，work对应build。

06B的Node没有初始化根len，字符next虽然接受offset却固定减'a'；本库初始化根深度并在插入和扫描两处都使用offset，不仿效这些缺陷。06C根len初始化正确。两项经独立本地验证后标为local-tested，仍没有在线AC或排名声明。

## 验证与变更范围

独立枚举所有模式前缀，用最长后缀查表检查转移、失败链接，直接比较序列计算所有状态出现次数；检查Trie深度、空集合/空模式/空文本、重复模式、INT_MIN/INT_MAX偏移、自定义字符偏移、复制重置与百万节点链。四种核心形式在普通和ASan/UBSan中各17560组/1282271项检查。四项语义错误变体被参考答案拒绝。

新增用法265/266均为接口演示，三种完整形式各160份输入。原P5357/P3808计数回归、带权/动态AC及CF710F在线协议回归均重跑。string.hpp使20份旧展开程序的指纹发生变化，连同2份新用法共22份完整程序全部刷新普通与sanitizer记录；244份旧展开程序和230个其他核心保持不变。最短匹配辅助函数另做普通/sanitizer回归。不是全库重跑或新增线上AC。
