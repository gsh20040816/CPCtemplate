# WIDA 打印稿：图论

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `dbb3c24936d76887af097c274703c8e0bf2d0ab6`，路径 `02 - 打印稿模板汇总/03A - 图论.md`。

常见概念、单源最短路和最小生成树这三节本身没有新的可执行代码。后面各节里已经对照过的 Dijkstra、Bellman-Ford、SPFA、Floyd、Prim、Kruskal、Tarjan、带权带花树、二分图匹配、最长路、最短路径树、Stoer–Wagner、欧拉路和差分约束，这次没有改写成新模板。

平面图最短路只给了对偶图加边的四段循环。`Hash`、`add`、`s` 和 `t` 都不在这段里，单独编译失败。

二分染色的循环写成了 `if (vis[i])`。起点的颜色一开始是 0，循环一次也不会进入。三个点的三角形因此输出 `Yes`，没有报出奇环。

链式前向星使用了没有定义的 `a`、`siz`、`dis`、`d` 和 `n`。补上这些数组后，根为 1、连向 2 和 3 的树，`siz[1]` 是 3，两个孩子的 `dis` 是 1，进出栈序列长度是 6。同一张树的拓扑排序存在；`1→2→1` 不存在。`bfs` 用 `dis` 判断是否访问，却把深度写进 `d`。一条不会回到源点的环上，它不会结束。

一般图最大匹配包含自己的 `main`。三角形的匹配数是 1，两条不相交边是 2，三角形再连一个叶子也是 2。没有匹配的点按代码会输出 0。

2-SAT 从 0 编号。强制 `x` 为真时可行，答案是 1。同时强制真和假时不可行。`(x∨y)∧(¬x∨y)` 可行，唯一性扫描输出 `? 1`。唯一性扫描那段要先放进结构体，不能单独编译。

`python3 tests/wida_graphprint.py` 在普通 `-O2` 和 ASan/UBSan 下通过会结束的例子。环上的 BFS 在 2 秒时限内没有结束。没有新的在线 AC，也没有新增模板。来源保持 partial。
