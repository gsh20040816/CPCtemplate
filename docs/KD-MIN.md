# 静态二维矩形最小权与删除

`KDMin` 对固定点集建二维K-D Tree，用途是闭矩形内最小权活记录查询与按原编号删除。与 `KDRange` 的动态插入/整批取出不同，本模板不支持插入、改权或恢复；与 `KDTreeSum` 的权值求和也不是同一操作。接口尽量保持短小：批量构造、`query(low,high)`、`erase(id)`。

## 约定与不变量

`Item` 为二维 `array<long long,2> p` 和 `long long key`。返回值是原输入编号，按 `(key,编号)` 最小确定答案；无解返回-1。重复坐标和权是独立记录，重复删除幂等。`erase` 要求 `0≤id<n`。点坐标、权值、子树汇总和结构数组均只读；`build/pull/better` 与带根编号的查询是内部辅助。构造后不保留外部引用，复制对象互不影响。

所有数值只作比较，支持signed64两端，不以LLONG_MAX等合法权值充当空集哨兵。空集用编号-1表达。查询四边闭合；反向矩形直接为空。节点下标就是原输入编号，因此删除可以直接定位节点，再沿父亲向上更新最小活记录，重复坐标无需搜索或猜分支。

建树按交替坐标的中位数分割，递归深度O(log(n+1))。每个节点的固定包围盒包含建树时整棵子树，删除不会缩盒；这可能减弱剪枝，但不漏活点。每次删除只更新alive与best，后者必须忽略死点。查询不交则返回空、完全覆盖返回best，部分覆盖检查当前活点并递归两个孩子，按(key,编号)合并；因此即使所有坐标相等也正确。

按nth_element平均线性选择计，建树O(n log(n+1))；删除O(log(n+1))，查询保守最坏O(n)，空间O(n)。没有把实践中的剪枝效果冒充每次查询的对数保证。大数据本地运行不能代替指定OJ机器的时空通过证明。

## kuangbin 3.8.2 / CF44G 应用

来源为固定 kuangbin 模板印刷页111–113。已读取 [Codeforces官方题面](https://codeforces.com/problemset/problem/44/G)：靶面边界算命中，距离互异，子弹按顺序射击最近尚存靶子；n,m≤10^5，坐标在0..10^7，矩形非退化，z为1..10^7；题面资源为5秒/256MB。这里只陈述题面限制，不称已在线通过。

用法275把每颗子弹位置建为点、发射时间作为key，再按z从近到远处理靶面。矩形内最早未使用的子弹击碎当前靶子，记录答案并删除子弹。按距离归纳：更近靶子消耗掉的子弹已被删除，剩余子弹不会再被它们阻挡，因此最早进入当前靶面的剩余子弹恰是实际击中者；同一靶子只能被击中一次。没有候选则该靶子永远未被击中。

源码支持读到EOF；官方题面是单组输入，本库完整用法按单组协议。内部矩形参数由源码`xl,xr,yl,yr`转换为两点`{xl,yl},{xr,yr}`。应用输出1-based靶子编号，无命中为0，与库空查询的-1分开。

该条目是比赛应用，不计正式模板题；官方题面已核验、源码模型与题意对拍通过，但在线AC、排名、评测机资源通过情况仍未核验。3.8.2可标local-tested，3.8总目仍partial，因为3.8.3原题关系尚未解决。

## 验证范围

`tests/kd_min_probe.cpp` 对15万次查询用独立活记录扫描比对，并检查全部节点的父亲、包围盒、最小活记录不变量。涵盖空集、重复权/坐标、重复删除、单点与反向矩形、signed64极值、复制隔离；十万网格点和十万重合点按最小权反复删除，并检查全局与单点查询。

`tests/kd_min.py` 在普通与ASan/UBSan下测试header/copied各带assert/NDEBUG四种形式，五个错误变体须由答案或不变量检查拒绝。用法274每种完整形式60组；用法275每种103组，包括官方样例、独立逐发子弹模拟、十万重叠靶子和十万互不相交靶子。driver/expanded/minimal-copy分别编译运行。证据绑定实际源码、输入、输出与二进制摘要，保存在 `verification/kd-min-{normal,sanitizer}.json`。未重跑全库，也没有新增在线AC。
