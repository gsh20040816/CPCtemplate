# 树上莫队与回滚莫队

本批对应 [issue #14](https://github.com/gsh20040816/CPCtemplate/issues/14) 的两个常用缺项。只保留 vector 风格，树遍历递归，新增代码不用一行函数。静态树上莫队不包含带修改的树上莫队。

## TreeMo

先建立非空连通树 `HLD tree(n)` 并 `tree.build(root)`，然后构造 `TreeMo mo(tree)`。复用已有 LCA，避免另外抄一份倍增表。`tree` 的生命周期必须覆盖 `mo` 的全部使用，此后不能增边、重建或修改树。点号 1..n，2n 须能用 int 表示；查询数也须能用 int 表示。

`add(u,v,edge=false)` 返回从零开始的查询编号。点权包含路径两个端点；边权将每条父边映射到子节点，设 `edge=true` 排除 LCA。`run(add,del,ans,block=0)` 的增删回调接收顶点编号，答案回调接收查询编号。回调维护的统计必须初始为空，函数退出时会清空；可以重复运行。统计必须只依赖活动顶点集合，不能依赖插入顺序。回调不能修改树或查询，也不能假设查询按输入顺序执行。混合点权/边权查询要求同一套回调对每个顶点的数据解释一致；通常只选一种模式。

递归 DFS 在进点和出点时各记录一次。设进入位置 in、退出位置 out，先按 in 调整 u、v 顺序。若 LCA=u，半开区间 `[in[u],in[v]+1)` 中出现奇数次的点恰是点权路径；边权模式临时翻转 u 将其排除。否则 `[out[u],in[v]+1)` 的奇数集合是路径去掉 LCA，点权模式临时加入 LCA，边权模式不加。答案记录后再次翻转额外点，恢复欧拉区间状态。边权 u=v 得空集合。

设 N=2n，m>0，块长 B 默认 max(1,N/sqrt(m))。排序 O(m log(m+1))，移动及最终清空 O(mB+N²/B+N)，每次回调的实际代价另乘；add 查询时的 LCA 共 O(m log n)。额外空间 O(n+m)，HLD 本身 O(n)。递归深度最坏 n；比赛环境按题目栈条件运行，本机消毒器测试使用扩大的主线程栈。

用法354为 [COT2/SP10707](https://www.luogu.com.cn/problem/SP10707)：n<=40000，m<=100000，求静态路径不同点权数。读取 long long 点权、离散化，再维护频次和不同值数量。页面显示1.21s/1.46GB，RemoteJudge SPOJ；这是应用题，不是全接口正式模板题。官方样例四种构建形式都输出4、4。

## RollbackMo

`RollbackMo(n)` 支持 n>=0；`add(l,r)` 为0-based半开区间，允许空区间，返回输入编号。n及查询数须能用 int 表示并满足内存限制。`run(add,snapshot,rollback,ans,block=0)` 只需要添加位置、取快照、恢复快照和保存答案，不需要任意删除。

统计开始时为空。所有添加都必须记入可撤销历史，包括长期保留的右段；快照只能回到当前历史的祖先，撤销后不能用旧分支快照恢复版本。回调统计与插入次序无关，不修改查询。run结束回滚到初始快照，可再次运行；没有查询时不调用回调。

查询按左端点所属块、右端点递增排序。令 end 为当前左块的右边界：r<=end 的短查询先出现，从空状态直接加入整段并撤销；长查询让长期右段 `[end,r)` 只增不减，再从右往左临时加入 `[l,end)`，保存答案后只撤销临时左段。换块时撤销全部右段，因此不会污染下一块。n=0或l=r=n时也不访问数组。

m>0时默认 B=max(1,n/sqrt(m))。排序 O(m log(m+1))，添加/撤销总数 O(mB+n²/B+n)；每次添加/撤销为 O(1) 时即为总运行界。调度空间 O(m)，回调历史与统计通常 O(n)。也可自行传正整数 B。

用法355为 [P5906【模板】回滚莫队&不删除莫队](https://www.luogu.com.cn/problem/P5906)：n,m<=200000，值1..2e9，页面1s/128MB。离散化后每个值维护最左、最右位置，全局维护最远间隔。每次添加记录旧的first、last、best，回滚逐项恢复。官方样例输出1、1、6、1、6，四种构建形式均通过。

## 本地证据

`tests/mo.cpp` 为1500棵随机树各100个查询，混合点/边模式、随机根、同点路径；1500组区间各100个查询，含空数组和空区间。均用默认、1、7、100四种块长重复运行，检查每次活动集合及最终空状态。核心的header、NDEBUG和最小抄写形式分别运行。

`tests/mo.py` 对完整用法以独立 BFS 路径/逐区间扫描作真值。每题100组随机输入再加一组最大规模：COT2为40000点链和100000问，P5906为200000元素和200000问。header、NDEBUG、实际全文展开、最小抄写四种形式均通过普通及ASan/UBSan构建。消毒器最初在macOS默认栈上溢出于既有HLD递归，测试链接时扩大主线程栈至256MiB后通过，没有将DFS改成显式栈。报告保留测试输入源哈希。

这些是测试证据与算法论证，不把本地对拍、应用AC或历史账号AC混同为全库正确性保证。

三个错误变体（删除额外LCA翻转、删除短查询撤销、删除换块撤销）均被核心集合真值检查检出，见 `verification/mo-mutations.json`。
