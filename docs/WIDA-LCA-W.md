# WIDA 在线模板：有权 LCA

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `1f17e2d09d329a6416881397db9864debd40f35d`，路径 `01 - 常用在线模板汇总/02 - 图、树、网络流/04 - LCA（有权图树上倍增解）.cpp`。它使用 `vector` 和 `pair`，但没有包含头文件，也没有 `std::`，单独编译失败。

`clac` 仍是 `dep[x] + dep[y] - 2 * dep[lca]`，返回边数，不把边权加起来。`query` 返回路径上的最大边权，累加器初值是 0。非负权的单点、一条边、四点路径和五节点树，全部点对都与沿父节点走到根的边数和最大边一致。边权为 -5 的一条边，`clac` 是 1，`query` 是 0，不是 -5。

倍增表仍是 30 列。`work` 没走到的点没有测。没有新的在线 AC，也没有新增模板。

`python3 tests/wida_lca_w.py` 在普通 `-O2` 和 ASan/UBSan 下通过非负权例子，并输出负边结果 `1 0`。来源保持 partial。
