# WIDA 基姆拉尔森公式

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `618ea300f6df6dd7f8b658fc1e931726a60fcf12`，路径 `03 - jiangly模板收集/03 - 数论、几何与多项式/02 - 基姆拉尔森公式.cpp`。

它不是闭合的基姆拉尔森公式。`getDay` 从 1970 年起累加整年天数、当年已过月份和日期，再计算 `(ans + 2) % 7 + 1`。合法日期且年份不早于 1970 时，1 表示星期一，7 表示星期日。1970-01-01 得到 4，与星期四一致。闰年和每月天数与公历一致，包括 1900 不闰、2000 闰。

年份小于 1970 时循环不加年份。1969-12-31 得到 4，公历当天是星期三，对应 3。月份必须是 1 到 12，日期必须是该月真实日期；函数本身不检查。

`python3 tests/wida_kim.py` 在普通 `-O2` 和 ASan/UBSan 下各核对 44 个不早于 1970 的日期，并记录了 1969-12-31 的偏差。QOJ 提交页面没有打开，没有新的在线 AC。来源保持 partial。
