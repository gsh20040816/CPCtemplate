# WIDA 在线模板：取模类

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `93b40a4c52c2df389ca66d3cf72394610c7d1ef7`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/32 - 取模类.cpp`。它使用 `istream` 和 `assert`，但没有对应头文件，单独编译失败。

`Z` 是 `Zmod<998244353>`。3 和 5 的加减乘，以及先除再乘回去，都与整数取模一致。`Z(-1)` 是 `P - 1`，`-3` 是 `P - 3`。`P - 1` 自增变成 0，再自减回到 `P - 1`。`power(10)` 是 1024。

`operator%=` 对传入的整数取余，不是对 998244353。`Z(10) % 4` 是 2。`Z(10) % 0` 在 UBSan 下报 division by zero。`inv` 用费马小定理，断言开启时 `inv(0)` 中止。另一项模数 `1000000007` 和合数模没有覆盖。

`python3 tests/wida_modclass.py` 在普通 `-O2` 和 ASan/UBSan 下通过这些例子。没有新的在线 AC，也没有新增模板。来源保持 partial。
