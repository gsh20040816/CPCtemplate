# DC3后缀数组与来源约定

`DC3`补齐kuangbin §1.5.2的skew/DC3构造。与现有倍增`SuffixArray`、诱导排序`SAIS`并列；不以某个算法的历史AC代表其他实现，也不宣称DC3一定比它们快。

## 接口

`DC3(string)`按unsigned char比较字节，包含0和255；`DC3(vector<int>,alphabet)`要求符号位于[0,alphabet)。1≤alphabet<INT_MAX−3，长度n<INT_MAX−3。稀疏大整数须先保序离散化，外部比较排序的时间不能算作DC3的线性时间。

`sa`、`rk`、`lcp`都长n，0-based，只包括非空后缀。`rk[sa[i]]=i`；lcp[0]=0，lcp[i]对应排名i−1和i的后缀。空输入得到三个空数组。输入不被改写，用户不需要补哨兵或三倍数组。类外只需构造和读取三数组，排序辅助函数为私有。

时间、空间O(n+alphabet)，字节字符串为O(n)；递归深度O(log(n+1))。构造前要保证alphabet对应可接受的计数桶规模，不能把一个只有十个元素但最大值10^9的序列直接传alphabet=10^9再声称只需O(n)空间。

## 三类后缀如何合并

内部把所有输入符号加1，0专用于末尾填充。取起点模3为1或2的后缀，用三个稳定计数排序排好其开头三元组；相同三元组同名，名字从1开始。按“余1类在前、余2类在后”形成缩小序列，必要时递归排序。每级规模约为2/3；唯一名字时直接反排，无需递归。

当n mod3=1时，在位置n增加三元组全零的虚拟采样点。它使余1类具有与余0类对应的后继，且在采样排序中严格最小。后续生成余0类时仍需要它，但最终归并必须跳过它。漏补会丢失最后一个余0类后缀或写越界，漏跳会把空后缀混入输出。

已排序采样点p若属于余1类，则p−1属于余0类。按采样顺序收集p−1，再稳定地按首字符排序，即按“首字符、后继采样后缀排名”排序余0类。

比较采样后缀i与余0后缀j：若i mod3=1，比较字符和rank[i+1]/rank[j+1]；若i mod3=2，先比较两个字符，再比较rank[i+2]/rank[j+2]。剩余部分都已属于采样类，因此可在线性归并中完成。rank数组和原字符数组均显式扩展三格，边界读取不依赖相邻内存内容。

最后用Kasai计算LCP，遇到最小排名必须清零已知公共前缀长度；lcp按后缀排名写入，不按原起点写入。

算法出处为Kärkkäinen、Sanders的[Simple Linear Work Suffix Array Construction](https://www.cs.helsinki.fi/u/tpkarkka/publications/icalp03.pdf)。本项目按上述不变量独立写成vector版本，未把论文附录中的C数组代码直接移入新核心。

## kuangbin原片段

完整61行位于印刷14–15页（物理16–17页），本轮逐页目视核对。固定PDF SHA256：`f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad`。夹具`tests/fixtures/dc3_sources/kuangbin.cpp`保留原算法，数学减号转为ASCII，并拼回第16/44行的排版折行。

原稿没有main，测试在单独命名空间中包含其完整函数片段，提供标准头与外部数组。原MAXN=2010且所有工作数组为三倍；来源对照限定1≤n≤2000、alphabet≤256。传入原稿前把当前符号加一，m=alphabet+1，保证原稿哨兵0严格最小；调用da后原sa[0]为空后缀n，因此比较sa[1..n]、rank−1和height[1..n]。原str会被用作递归工作区，新模板不改变输入。

来源中“所有数组开三倍”的要求不能简单删除后仍使用指针偏移；新实现改成逐层vector分配，递归各层长度按比例缩小，峰值仍为O(n+alphabet)。空序列和完整字节输入属于新接口的独立验证范围，不冒称原片段已覆盖。

原§1.5.1 DA还附有反串+RMQ求最长回文的完整主程序，其来源协议尚未在本批完整复现。因此仅将§1.5.2标为local-tested，父章节继续保留partial，并明确下一步剩余的是原DA应用程序审计，而不是已经补齐的DC3算法。

## 题目与测试

用法341为[Library Checker suffixarray](https://judge.yosupo.jp/problem/suffixarray)：1..500000小写字符串，输出0-based非空后缀起点。已核对固定官方题面、长度参数和四份官方样例。用法342独立展示稠密整数输入的三数组及空输入的三空行；正式字符串题不覆盖字节0、255或空序列，不能用它代替这些接口测试。

`tests/dc3.cpp`枚举长度至14的全部二元序列、至9的全部三元序列，追加随机字节/整数和长度模3边界；共63323组序列，暴力后缀切片排序与逐字符LCP为真值，其中62816组还对照完整原片段。string与整数构造互相核对，无符号字节顺序独立覆盖。

10000/10001/10002长随机序列与使用比较排序的独立倍增算法对照；500000/500001/500002的全同序列和严格递增序列核对闭式sa/rk/lcp，覆盖深递归与无需递归分支。正式用法另有50万字符全同串、交替串闭式结果。

`python3 tests/dc3.py`与`--sanitize`覆盖普通、NDEBUG、实际展开和最小复制形式；独立复制核心也运行全套枚举及压力测试。故障变体检查输入零与哨兵混淆、未跳过虚拟点、基数排序不稳定、LCP写错下标。所有记录为本地验证，不新增线上AC、评测时间或速度排名。
