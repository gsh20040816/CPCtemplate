# 严格凸多边形的外点切线

`convex_tangents_i64(p,q)` 使用 `IntegerPlane` 的精确整数方向判定。输入须为 n≥3 的严格凸 CCW 多边形，不重复首点，边界上不保留共线顶点；循环起点任意。多边形和查询坐标绝对值均≤10^12，n≤INT_MAX/2。凸性、方向和数值范围是调用前提，不进行每次 O(n) 的验证。

返回 `optional<pair<int,int>>`。内部或边界点返回空；外点返回原输入的 `(right,left)` 下标，含义以叉积为准：
- 所有顶点 v 满足 cross(q,p[right],v)≤0
- 所有顶点 v 满足 cross(q,p[left],v)≥0
- 切线与整条边重合时，返回离 q 最近的端点

输入不改写，无预处理，单次 O(log n) 时间、O(1) 额外空间。n<3 不在契约内。散点可先调用 `integer_hull`，但得到的是新凸包的下标；原编号需要调用者自行保留映射。`SupportHull` 是利用外部支持函数构造凸包的另一接口，圆的切线也不能替代本函数。

## 可见边链与返回顺序

令 E(i)=cross(p[i],p[(i+1)%n],q)。CCW 多边形的内部在每条有向边左侧，所以 E(i)<0 的边对 q 严格可见。对外点，严格可见边构成一个非空且非整圈的循环连续链：从 q 发出的、穿过多边形的射线占据一个小于半周的角区间，其首次交点连续沿靠近 q 的边界移动。两端是支撑射线。E(i)=0 的切线边在边界端点，排除出严格可见链；不会把它误当作可见边内侧的断点。

设第一条可见边起点为 s，链后第一条不可见边起点为 t。则 E(s)<0、E(s−1)≥0，以及 E(t−1)<0、E(t)≥0。

对于 q→p[s]，后继的叉积为 E(s)<0，前驱的叉积为 −E(s−1)≤0。凸多边形的所有点都位于该顶点两条邻边形成的内角锥中，邻点的同侧性推广到所有顶点，因此 s 是 right。t 同理为 left。

若 E(s−1)=0，切线包含边 (s−1,s)。q 不能落在边上；若 q 在前驱外侧，则严格凸性会使 E(s)>0，与可见性矛盾。故 q 位于 s 外侧，s 正是最近端点。左切线的 E(t)=0 情形同理。无需浮点角度、长度比较或扰动。

如需接触面：右切线贴边当且仅当 E(right−1)=0，接触边是 (right−1,right)；左切线贴边当且仅当 E(left)=0，接触边是 (left,left+1)。下标循环取模。这是相邻点即可验证的证书，不新增返回字段。

## O(log n) 找到两种状态的种子边

固定 p0。扇形射线 p0→p1,...,p0→p[n−1] 按角度严格排序，覆盖角度小于 π。令 a=cross(p0,p1,q)，b=cross(p0,p[n−1],q)。

1. a<0、b≤0：边0可见，边n−1不可见。
2. a≥0、b>0：边n−1可见，边0不可见。
3. a<0、b>0：两条邻边都可见。二分扇形叉积从非正到正的转折，取前一条射线的下标 l。扇形 (p0,p[l],p[l+1]) 包含从 p0 背离 q 的射线，其外侧边 l 严格不可见。
4. a≥0、b≤0：边0不可见；按通常的包含判定二分扇形叉积从非负到非正的转折。对应外侧边 l 若严格可见则 q 在外，否则 q 在内部或边界，返回空。q=p0 时所有扇形叉积为0，但外侧边仍不可见，结论相同。

第三种情况的严格证明：背离 q 的射线与外侧边交于 x=p0+λ(p0−q)，λ>0。该边的有向半平面函数 f 是仿射函数，f(x)=0 且 f(p0)>0，故 f(q)=(1+1/λ)f(p0)>0。射线恰经过扇形顶点也成立。扇形角小于 π，保证所用符号转折只有一次；实现把零分别归入所需的左端状态。

得到可见 v、不可见 h 后，沿 h→v 的正向循环弧只有一次由不可见到可见的转折；沿 v→h 只有一次反向转折。分别二分，得到上述 s、t。不是直接在整个循环布尔数组上进行没有单调性的普通二分。

## 算术与资源

`IntegerPlane::cross` 在做减法前提升到 signed128。设 B=10^12，两个差的乘积至多4B²，叉积绝对值至多8B²，安全落在 signed128；乘以 ±1 也安全。本算法没有更高次乘积。不能据此把输入扩张为任意 signed64。

n≤INT_MAX/2 使循环偏移、中点和 `end-start+n` 均可用 int；输入大小必须满足此条件。所有断言只是调试诊断，NDEBUG 不会自动验证非法多边形。

## 用法和证据范围

example-240 是自定义有效输入协议的 API 演示：n m、多边形顶点、m 个查询；外点打印0-based的 right left，内部/边界打印 `-1 -1`。不是正式 OJ 题目，不验证输入的凸性和方向。

成都2025 I 的官方题解使用切线界和额外的旋转双指针计数。本接口只补前者，不能据此宣布整题完成。

算法是本库按扇形定位和可见边连续性推导的实现，并非声称逐字采用以下任一资料：
- [KIT 计算几何习题课，切线二分](https://i11www.iti.kit.edu/_media/teaching/sommer2018/compgeom/psession1.pdf)，slides38–48提供对数时间切线背景

- [成都2025官方题解](https://contest.ucup.ac/download.php?id=2567&r=1&type=attachments)，printed pp29–32给出使用场景

小规模本地测试采用独立逐边外部性和逐顶点支撑线枚举，以 Python 任意精度整数挑选最近接触点。三份十万顶点／十万查询的大规模输入采用抛物线凸包的四方向闭式答案，每个方向另对查询区间的两个端点扫描全部顶点验证支撑线；并非对每个大查询运行二次枚举。查询族关于参数是仿射的、接触下标固定，端点支撑不等式也保证中间查询的支撑性。测试与源码绑定；在线 AC、整道计数应用和其他数值范围均不在这些证据之内。
