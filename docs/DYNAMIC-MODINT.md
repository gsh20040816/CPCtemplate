# 动态模整数的适用范围

`mint<tag>` 是轻量运行时模整数。各 tag 保存独立模数，同一 tag 的所有对象共享该模数。修改模数后必须重建旧对象与容器，不能将旧规范余数解释为新模数下原整数的余数。

当前上界是 INT_MAX。加法先转 long long；两个规范余数的乘积小于 2^62。构造时先对输入取余，因而 LLONG_MIN 也不需要先取负。扩展欧几里得的系数和商乘积也处于 long long 范围内（模数限制为 int），不能擅自把 mod 改成 long long 就声称支持 64 位模数。

`try_inv` 只有 gcd(v,mod)=1 才返回值，其他情况返回 nullopt；`inv` 和除法以可逆为前提。模 1 采用零环约定：唯一的值和乘法单位元都是 0，返回逆元 0。若调用算法本身排除模 1，须在算法入口另行约束。

本地测试枚举模数 1..150 的全部余数和逆元，以穷举乘积找逆元；大模数包括 INT_MAX 及其前一个合数，以 int128 检查运算并核对 gcd/逆元证书。另测不同 tag、切模后重建、uint64 指数和 Fenwick 组合。普通与 ASan/UBSan 通过。

该组件尚无独立在线证据。已准备 P5431.mint.compact.cpp，组合 batch_units，以一次总乘积求逆完成运行时模数的批量求逆；原 long long 驱动和历史 AC 保留。Python 独立逆元/幂参考、五百万个相同分母的几何级数闭式答案均通过普通与 ASan/UBSan。

P5431 的 prime/非零前提不覆盖合数不可逆分支，该分支另由 batch_units 的小模数穷举验证。不得将原 P5431 或同文件其他数论算法的 AC 当作这个动态类型组合驱动的线上验证。
