# 二维点加、矩形加与矩形和

这两种结构分别处理稀疏点和稠密格子，统一使用0-based半开矩形 `[l,r) × [d,u)`。它们不是互换的实现，也不重新收录已经排除的一维基础题P3374。

## 稀疏预登记坐标

`Fenwick2D<T>(points)` 预登记所有未来更新坐标，权值初始为0。重复坐标去重；`add(x,y,v)`累加该点权值，负增量可表示删除；`prefix(x,y)`求两坐标严格小于x、y的点权和；`sum(l,d,r,u)`用四个前缀容斥。空矩形返回0，反向端点不合法。

`init(points)`可重新登记并清空全部权值；空点集合法。默认T为long long，要求其零值、加减以及全部Fenwick桶和、查询累加和容斥中间值均可表示。内部字段只读。值复制独立；移动后的源对象仅销毁或重新赋值。未经登记的更新违反前置条件，调试断言按完整坐标对检查，不能只验证横、纵坐标分别出现过。

所有坐标和查询端点均为long long。使用lower_bound实现严格前缀，不通过坐标减1，因此LLONG_MIN可作为点坐标，LLONG_MAX可作为上界。有限半开区间的上界也必须可表示；这个接口不能查询包含LLONG_MAX坐标的区域。若题目需要全有符号域上的闭区间，应扩大坐标类型或单独设计闭前缀，不能直接对最大值加1。

外层对横坐标做Fenwick分解，每个节点保存会落入该桶的所有纵坐标，内层再做Fenwick。构造时先按y排序全部预登记点，按这个顺序向每个外层祖先分发；每个桶自然有序，相邻去重即可，无须对每个桶分别排序。设登记输入含重复项共K个，不同点P<2^30；先去重耗时O(K log K)，随后分发耗时O(P log P)，构造峰值空间O(K+P log P)。完成构造后有效桶内容O(P log P)，单次更新和查询O(log² P)；空集单独为O(1)。反复init可能保留部分vector容量，释放全部已分配容量可重新赋值新对象。上限确保int类型的lowbit上跳不溢出。

稀疏版不是任意新坐标在线插入结构。Library Checker [Point Add Rectangle Sum](https://judge.yosupo.jp/problem/point_add_rectangle_sum)的全部操作可先读取，因此完整用法246先收集初始点及每条增加点操作的坐标，再按原操作顺序执行。预读不会使未来的权值提前生效；重复点权直接累加符合原题求和语义。N、Q≤100000，坐标/权值≤10^9，最终最多200000个点，总权≤2×10^14；使用long long。题面、verifier与参数已核对固定官方版本e64660561a995c357cdc61ddee1bde68b80528db。

## 稠密矩阵的四矩差分

`RectangleFenwick<T>(n,m)`初始化零矩阵，`add(l,d,r,u,v)`对矩形内每个格子加v；`sum`与`prefix`查询同一区间语义。单点操作使用单位矩形。空矩形和零维矩阵合法，端点必须位于`[0,n]×[0,m]`。`corner`与`bit`均为内部实现，不是直接调用接口；重新赋值一个新对象清空矩阵。

对差分D，位于(p,q)的差分值对前缀`[0,x)×[0,y)`的贡献为 `D[p,q]*(x-p)*(y-q)`。展开得 `xy*D-y*(pD)-x*(qD)+pqD`，因此每个Fenwick节点维护D、pD、qD、pqD四个矩。矩形更新在左下/右下/左上/右上四角分别加入`v,-v,-v,v`。位于x=n或y=m的差分不会影响矩阵，直接忽略；不能错误地截断到最后一格。

存储为`vector<vector<array<T,4>>>`，时间和空间初始化O((n+1)(m+1))，单次更新/查询O(log(n+1) log(m+1))。n,m<2^30确保int上跳安全，但这不是实际内存承诺：默认long long在2048×2048网格上约需128MiB四矩存储。稠密矩阵应先核对空间；不能压缩坐标后把相邻压缩格当成原来的一格，真实面积会变。

T必须支持零值、加减、取负、乘int；所有中间值均需可表示。即使最终答案很小，差分矩与展开项仍可能很大。例如signed long long的最小值不能直接作为v，因为`-v`不可表示；可换更宽T。坐标乘法始终先乘T，避免先算int型x*y。核心还使用int128大权做独立对拍，不能因此声称long long版本支持这些大权。

P4514 [上帝造题的七分钟](https://www.luogu.com.cn/problem/P4514)用法247读取`X n m`，然后读到EOF；`L`更新，**小写k**查询。其1-based闭矩形`[a,c]×[b,d]`转换为`[a-1,c)×[b-1,d)`。n,m≤2048，操作≤200000、|delta|≤500。题目背景说过32位中间值，但最终提示明确不保证中间运算范围；以最终提示为准。保守将每次矩形更新视作4个差分脉冲，容斥四个前缀各含四项，所有项绝对值总和不超过 `64*200000*500*2048² < 2.7×10^16`，所以long long足够，最终32位条件不用于缩窄内部类型。
