# 区间不同子串：kuangbin 1.7 来源审计

本节标题是“字符串 hash”，实际完整程序为 HDU4622 的区间不同非空子串计数。不能用通用滚动哈希或整串 `distinct()` 的验证代替这一应用。现有 `SuffixAutomaton` 不变，完整驱动 `verify/api/interval_substring.compact.cpp` 验证精确的等价模型，登记为手册用法325。测试入口直接包含此驱动，避免另养一份实现。来源模型覆盖状态为 local-tested；不新增算法组件或线上成绩。

## 来源和协议

固定 kuangbin 2018 PDF 正文23–24页，物理25–26页已逐页目视核对，SHA256为 `f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad`。完整63行保存在 `tests/fixtures/interval_substring_sources/kuangbin.inc`；仅删除页眉、行号及排版缩进，规范减号，拼接第54行折行。原稿版权归原作者，夹具只用于来源核对，不作为本项目原创模板。

来源协议：先读T；每组字符串s、查询数m，再读m个1-based闭区间[l,r]；逐行输出s[l..r]中不同非空子串数量。测试驱动限定非空小写字母串，合法区间1≤l≤r≤n。2026-10-08尝试读取[HDU官方题面](https://acm.hdu.edu.cn/showproblem.php?pid=4622)失败，原题字符集、资源限制和线上AC均未核实。

## 原稿算法与边界问题

原稿枚举子串长度L，按起点递增扫描，用模2^64多项式哈希记录同一哈希的上次起点p。当前起点i、终点j时，在差分表(i,j)加1、(p,j)减1。随后沿左端点递减、右端点递增累加。对查询[l,r]，每种内容由其在该区间的第一次出现贡献一次；要求等长子串哈希相等确实等价于内容相等。

HASH=10007只是链式哈希表桶数，桶冲突会比较完整64位值解决；不同内容的64位值相等则不会解决。固定SEED=13331没有无碰撞保证。本轮测试未构造64位碰撞，不把有限测试通过解释为哈希确定正确。每个L会清空表，故不同长度之间不互相合并。原表查找也没有最坏O(1)保证。

原稿第52行累加循环执行到i=0，第53行从j=i开始，因而第54行读取 `ans[0][-1]` 和 `ans[1][-1]`。输入单字符a、查询[1,1]即可由UBSan复现负下标；即使常见编译下正下标答案看起来正确，也不能当成无未定义行为的证据。

原夹具保留不改。用于算法对照的副本仅将第52行 `i >= 0` 改为 `i >= 1`，跳过不需要输出的第0行；差分写入第0行仍可保留。两种副本哈希和补丁记入收据。普通模式只编译未修正原稿，不拿其运行结果作为正确性依据；消毒器模式专门运行它复现故障。

MAXN=2010，累加会读第n+1行，因此修正负下标后仍要求n≤2008。测试包含n=2008边界；没有宣称n=2009合法。输入缓冲区本身不能代表整套程序的安全长度范围。

## 精确 SAM 适配

对每个左端点l，新建一个SAM，依次追加s[l],s[l+1],…；记录每次追加后的不同子串总数。新增状态u的贡献为 `len[u]-len[link[u]]`，累加后得到ans[l][r]。克隆状态只重分配旧状态的长度区间，不增加旧子串种类，因而不用每次扫描所有状态调用distinct()。

固定26字母表，每个左端点的完整构建总计O(n)，所有左端点O(n²)；二维答案表O(n²)，单个SAM占O(n)，每次查询O(1)。答案用long long，表采用vector。必须在更换左端点时重新构建SAM；这不是对任意区间截取一个全局SAM的状态。手册用法325提供完整读写协议；官方题面及线上核验仍待完成。

## 验证

运行 `python3 tests/interval_substring_source.py` 和 `CPC_SANITIZE=1 python3 tests/interval_substring_source.py`。穷举二元字母表长度1..8、三元字母表长度1..5，共873串，另100个随机串。所有小串枚举所有查询区间，打乱查询顺序并重复查询，共38338个答案；逐区间同时用直接子串集合与独立后缀排序减相邻LCP核对。

大数据为长度2000的同字符、周期、随机26字母串，另有2008个同字符和随后的单字符，检查静态边界及多测清空。当前SAM另测2500长度周期串和单字符，不用越界数据运行来源程序。大数据答案由独立后缀排序计算，未使用受测SAM作为oracle。

普通及ASan/UBSan模式下，修正边界的来源程序与当前头文件、完整展开版各自的assert/NDEBUG四种形式，以及手册实际展开程序、最小抄写版及其NDEBUG版均通过。漏减link长度、覆盖累计值、左端点不清空SAM三个错误变体均被独立答案拒绝。消毒器关闭本环境的LeakSanitizer，不声明泄漏检测通过。

收据见 `verification/interval-substring-source-{normal,sanitizer}.json`，源码绑定及原有文件不变检查见 `verification/interval-substring-source-checkpoint.json`。用法325已纳入总册及字符串册，按源码哈希绑定到双模式收据；local-tested只表示本地来源模型完整，不表示官方题面、资源限制或线上评测已经核验。
