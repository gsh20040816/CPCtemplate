# WIDA 17 素数测试与因式分解核验

原稿为 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的精确 blob `e744206b3a512a31c8a7ba9f2141922433c7aebb`。保存于 `tests/fixtures/wida_factor/factor.cpp`，随附原仓库 GPL-3.0 许可。外围仅补充 `i64 = long long`。

## 可复现的正确性差异

原稿 Miller–Rabin 固定使用 2、3、5、7、11、13、17、19、23 九个底数。它把以下合数判断为素数：

```
3825123056546413051 = 149491 × 747451 × 34233211
```

这不是依靠另一个 Miller–Rabin 实现判断的反例：测试用独立试除确认三个因子均为素数，用 Python 整数乘法确认乘积。该值小于有符号 64 位上界，不能把错误归因于超出 i64 范围。

原稿 factorize 随即把整个合数当作素因子返回，因此判素的取值范围也限制分解函数。当前 `Prime64::prime` 正确拒绝这个合数，`PollardRho::factor` 返回上述三个因子。普通优化与 ASan/UBSan 两种构建均复现这一差异。

本批不推定原稿九个底数的精确安全上界，也不把有限测试当作全域证明。原题可能具有更小的数据范围；完整原题尚未核验。

## 替代接口和前提

| 原稿 | 当前组件 | 说明 |
| --- | --- | --- |
| mul(a,b,m) | Mod64::mul(a,b,m) | 两者使用 128 位乘积；模数必须为正。本次原稿测试限规范化非负 i64 系数。 |
| power(a,b,m) | Mod64::power(a,b,m) | 非负指数、正模数；独立 Python pow 校验大指数、模数 1 与有符号端点。 |
| isprime(n) | Prime64::prime(n) | 当前接口为 unsigned long long，使用另一组七底数；原稿的九个小素数底数不能照搬为全 64 位保证。 |
| factorize(n) | PollardRho::factor(n) | 当前约定 n>=1，返回排序后的素因子并保留重数，1 返回空数组。递归拆分；未改为显式栈。 |

原稿使用固定多项式 x²+1 和递增初值，并批量计算 gcd；当前实现随机选取多项式常数和初值，每次尝试有迭代上限，失败则重试。本次没有测量两者的性能优势，也不承诺分解的最坏运行时间。

原稿不提供 unsigned 64 位接口。当前版在本批还检查 2^63、3^40、5^27 和 2^64-1 的分解，所有期望因子先由试除和乘积独立确认。这几个样例不等于穷举 unsigned 64 位空间。

## 验证证据和剩余范围

运行 `python3 tests/wida_factor.py`。普通优化（关闭 assert）和 ASan/UBSan 各通过 **60,987 个协议样例**，其中：

- 50,001 个 0 至 50,000 的判素样例，真值来自独立筛法。
- 10,156 个分解样例，包含 1 至 10,000、150 个随机数、试除阈值附近和素数幂；真值来自独立试除。
- 2 个上述合数误判与错误分解的明确反例检查。
- 4 个当前实现的 unsigned 范围分解样例。
- 800 个 Python 大整数模乘、模幂随机样例及 24 个端点样例。
