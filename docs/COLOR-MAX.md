# 树上翻色、改权与同色连通块最大值

`ColorMax(h, color, w)`依赖已经build的连通树HLD，点1..n，颜色0/1，两个数组均长n+1。`flip(u)`单点翻色，`set_weight(u,w)`改单点权，`query(u)`返回u所在同色连通块的最大点权。支持signed64全部权值，包括LLONG_MIN和LLONG_MAX；没有权值加减，不会用过小的有限负无穷屏蔽合法值。固定拓扑，不支持link/cut。

可以读取col、weight，不应修改内部字段或调用内部更新函数。h须比本对象长寿，构造后不能修改或重新build。1≤n≤INT_MAX/2，初始化O(n log n)，每次操作O(log²n)，空间O(n)。HLD仍为递归DFS，需足够栈空间。重链有序集合及迭代区间最大值查询不模拟树DFS。

## 维护量与正确性

每个点u的两棵multiset `light[u][c]`分别保存颜色c的每个轻儿子向下同色连通块的最大权值。每个轻儿子贡献恰好一个数，保留重复项；删除必须用find后的迭代器，不能按值删除全部相等项。

`base(u)`取本点权与同色轻儿子贡献的最大值。线段树按dfn存base，`down(u)`取从u开始沿重链向下的连续同色区间最大值：异色位置集合给出第一处颜色障碍，chain tail给出重链边界。区间内每个点的base包含它的轻子树贡献，因此恰好得到u的整个向下同色连通块。初始化反向dfn计算实际向下最大值，再建立轻儿子集合和线段树。

更新时，先记住当前重链头t的旧颜色与旧down(t)，再改变原点颜色/权值，并更新它的base叶子。此后down(t)是新贡献。若t不是根，向父亲的light删除一个旧贡献并插入新贡献，继续更新父亲的base；每轮跨一条轻边，最多O(log n)轮。更新父亲的light以后，其线段树叶子尚未刷新，所以进入下一轮时仍可读到上一条重链的旧贡献。必须在翻色前保存旧链头颜色；即使数值相同，颜色变化也不能被省略。

`top(u)`跨重链寻找整个同色连通块的最高点，方法与计数版一致，但不依赖计数版的额外数据。最高点的向下同色连通块即为全部答案，因此query返回down(top(u))。每轮multiset、有序集合和区间最大值操作O(log n)，整体O(log²n)。轻边一共n−1条以下，multiset总元素O(n)，没有每次翻转枚举全部邻边的问题。

## 来源与题面核对范围

kuangbin2018 §3.5.6标题及说明在印刷87页，完整152编号行在印刷88–91页（物理90–93页）已逐页核对。原稿为指针LCT，按颜色存虚子树multiset，维护实链前后缀最大值；新实现是固定树问题的HLD替代，不声称复现其LCT结构。原稿完整EOF main未改动；仅规范化PDF减号、拼接换行并补公共头文件。原稿为int和有限-INF哨兵，库的signed64扩展由独立验证覆盖，不能归于原稿。

[洛谷SP16580镜像](https://www.luogu.com.cn/problem/SP16580)已核对操作定义、输入顺序和两个完整样例，页面显示5秒、1.46GB。输入为n、n−1条边、n个初始颜色、n个权值、q及操作；0 u查询，1 u翻色，2 u w改权。两个样例分别输出1/5与7/5/7。驱动兼容EOF多组，与原稿一致。

镜像的输入说明存在缺失的HTML数值约束，不能据此声称已核验原题所有参数；来源模板说明n,q≤10⁵，权值边界未由正式页面确认。SPOJ原站先出现Cloudflare验证，尚未操作就变成NS_ERROR_OFFLINE加载失败。此缺口与算法本地测试分开记录，不把来源常量或网上题解当作原题限制。

## 验证

- n≤5全部标号树、全部颜色、全部根。n≤3再遍历三种权值（LLONG_MIN、LLONG_MAX、-1）的所有组合；n=4/5取六种含重复值、同值及极值的模式。逐点翻色、改权、再翻色、恢复权值，每一步检查全部点。另有20棵200点随机树各500次混合操作，共2660418状态。
- 独立BFS检查全连通块最大值、最高点、向下最大值；再次独立枚举轻儿子的向下块，核验两个multiset的完整内容与重复次数。
- 十万点链、星形、二叉树各十万次翻色并改权；链使用末端为根并检查中点断开，高度数星心反复翻转，检查全局极值修改。
- O2、NDEBUG、ASan/UBSan全部通过，oracle检查不使用会被NDEBUG禁用的assert。Mac压力测试链接器预留512MiB栈；不修改发布驱动或推断OJ栈环境。未启用LeakSanitizer。
- 完整原稿、头文件驱动、最小抄写程序在普通和消毒器构建下，与独立BFS核对102组EOF连续输入，包含两个镜像样例和100组混合操作。该来源对照的权值限制在±10⁶内，以适配原稿有限-INF；不是宣称已确认正式题域。
