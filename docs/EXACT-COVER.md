# 精确覆盖：Algorithm X 与 Dancing Links

## 选型与接口

把每个“必须恰好满足一次”的约束建成列，每种候选选择建成一行，行内记录该选择满足的列。`ExactCover(m, rows).solve()` 返回任意首个可行选择的原始 0-based 行号；`nullopt` 表示无解。有值的空向量表示空约束全集的可行解，不能用 `ans->empty()` 判断无解。

列号为 `[0,m)`，每行内部不得重复，顺序任意；重复行是不同候选，空行不参与选择但不改变后续行号。所有列都是必选列。最少选几行、所有解计数、允许重复覆盖、可选列均不是这个接口的功能。

构造时要求 `0 <= m < INT_MAX`、行数 `< INT_MAX`、`1+m+非零数 <= INT_MAX`。输入范围和行内互异是前置条件；assert 在 NDEBUG 下不提供验证。构造需要 O(行数+m+非零数) 时间，对象和临时空间 O(m+非零数)。搜索最坏指数，最少候选列只是剪枝策略，不是多项式时间保证。递归深度最多 m，调用方须提供相应栈空间。

## 不变量与恢复

0 为根节点，1..m 为列头。每个非零节点既在本行的左右环，也在所属列的上下环。`s[c]` 记录当前列的可用行数；节点携带原始行号，不通过当前链序号猜测答案。

搜索选可用行数最少的列 c；任何可行解都必须且只能选择一个含 c 的行，因此逐行枚举不漏解。选择该行后，移除其覆盖列，以及与该行冲突的候选；剩余子问题仍是精确覆盖。没有列表示所有约束已满足，有列但没有候选则该分支失败。

`cover` 向下遍历各行、向右移除其他列上的节点，保留被移除节点自己的链接。`uncover` 必须向上、向左按相反顺序复原节点和列计数，最后复原列头。失败分支弹出答案行；成功分支保留答案，但仍完整撤销所有链接修改再返回。由此成功和失败后都可重复调用 `solve()`。

节点用 vector 下标而非指针连接，完整复制对象仍有效。构造预数节点并 reserve；solve 先为至多 m 个答案行 reserve，递归内不分配内存。最终答案复制发生在链恢复之后。这里没有进行分配失败注入，不据此声称覆盖所有异常运行环境。public 实现字段及 cover/uncover/dfs 不作为用户可修改接口；移动后的源对象仅销毁或重新赋值。

## 完整用法

[洛谷 P4929](https://www.luogu.com.cn/problem/P4929) 是独立精确覆盖模板题。驱动 `verify/luogu/P4929.compact.cpp` 读取 01 矩阵，转为稀疏行，输出原 1-based 行号；没有解输出 `No Solution!`。题面限制 N,M≤500，非零数≤5000。输出按覆盖语义校验，不能比较唯一的固定答案或要求固定顺序。

数独可以把每格一个数、每行每个数、每列每个数、每宫每个数分别建成列，候选 `(r,c,v)` 对应四个约束。测试另有 4×4 数独模型，按棋盘行、列和宫独立复核；不是新增完整数独接口或线上成绩。

## 验证边界

`tests/exact_cover.py` 运行原头文件/抄写代码 × assert/NDEBUG，以独立行子集枚举判断小矩阵可解性，并语义校验返回行。每次调用后逐字段比较节点和列计数，检查重复 solve、复制和重新赋值。覆盖无列、空行、重复行、无解奇环、Knuth 回溯例、乱序列号和 500 列深递归，以及 5000 个非零的块矩阵。故意破坏成功恢复、列计数、回退答案、空解语义、原行号的变体必须被 oracle 拒绝。

三种完整程序形式（原驱动、展开依赖、最小前导抄写）分别执行，并保存源码、程序、输入、输出哈希。当前证据只代表对应源码的本地运行；线上 AC、排行榜和重复覆盖仍待后续。
