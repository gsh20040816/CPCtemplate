# 中国赛站模板需求审计

[赛题映射](contest-coverage.csv)按题记录需求、已有候选代码与缺口；[资料目录](contest-sources.json)记录来源和本轮实际检查范围。两份文件都是持续补充的工作清单，尚不是三年中国赛站的完整名录。2026 年公开场次仍需追加，不由清单缺席推断不存在相关需求。

页码统一使用 PDF 阅读器中的物理页，从 1 开始；遇到印刷页码不同，以资料目录的说明为准。引用只指向官方题解或题面，不把博客标签当成算法证据。

状态解释：

- `missing`：当前接口无法满足已识别的需求，需要新增或扩展。
- `kernel_partial`：已有基础算法可复用，但题目所需组合、参数范围或完整调用尚未验证。
- `candidate`：仅有候选组件，仍须核对完整题面、数值范围与接口适配。
- `application_verified`：完整题面、调用和本地独立参照已核对，且两套驱动有在线 AC；仅覆盖记录中实际调用的接口。
- `application_pending`：主要是题目专用建模、证明或转移。保留审计项，不为增加数量而新增堆、排序等基础模板。

除 `application_verified` 外，上述状态都不表示整题已经解决或在线通过。候选代码中即使存在某算法，仍须核对它的输入范围、目标方向、精度和复杂度。例如最小化查询不能自动当成最大化接口，给定点集的凸包也不自动提供通过优化问题寻找支撑点的过程。

下一步先补容易复用的缺失接口，再验证题目组合。特殊理论、复杂数学建模及单题构造保留为后续应用说明；不能用一句“已有 DP / 几何”关闭条目。随机哈希方案还需说明碰撞假设，不能与确定性正确性证据混写。

本轮只迁入已经重新检查的条目。此前 SOURCES.md 中其余赛站笔记保留，等资料可读并核验后再迁入。资料目录中的 `inventory_complete: false` 表示该赛站仍未完成从全部题面到实现验证的审计。

2026-09-12 已完成 2023 杭州站 A–M 共 13 题的题解主题核对，资料目录记录本地下载 SHA256。`editorial_review_complete` 仅表示题解主题清单完整；`inventory_complete` 仍为 false，完整题面、数值约束和应用验证尚未完成。K 题对应的可持久化区间加与版本拼接已新增独立模板，初次映射状态为 `kernel_partial`；后续完整驱动在 QOJ8240 双 AC，现为 `application_verified`。
