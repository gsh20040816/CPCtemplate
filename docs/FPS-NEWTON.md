# NTT缓存与Newton高半段更新

本批改善已报告的多项式性能差距。保持vector、自然顺序DFT与固定ModInt；不引入原稿的全局多项式工作数组。组件数331、完整用法450不变，用法450改为直接调用inverse_sqrt。

## NTT单位根

每个mod/primitive实例保留独立的局部static vector。roots[h+j]保存长度2h蝶形的第j个单位根。扩展时roots[2i]=roots[i]、roots[2i+1]=roots[i]乘新一层单位根；已有层不变，故大、小长度交替调用不受污染。每个蝶形省去w的递推乘法。逆变换复用正变换，再翻转下标1..n-1并乘n的逆元，输入输出仍是自然顺序。

缓存空间按历史最大变换长度计，不会随一次小调用自动缩小；同一实例不能并发扩容。卷积工作vector仍每次独立。参数化素数/原根前提、最大变换长度及空卷积约定不变。

## 级数逆元

设b是长度k的当前逆元，a截取前m≤2k项。长度2k循环卷积a*b的最高次数≤3k-2，因此回绕仅落到0..k-2，高半段准确。由于a*b低k项为1，清空低半段得到误差E在[k,2k)的系数。再乘b时，E*b最高次数≤3k-2，回绕依然只落到低半段。于是新高半段为-E*b，旧低半段保留，这正是b(2-ab) mod x^m。

两次正向变换计算a、b，一次逆向得到误差；误差一次正向与缓存的b相乘，再一次逆向，共五次长度2k变换。相比两次普通卷积，避免不需要的完整乘积，并复用b的变换。输入不足补零，多余尾项不参与；最后一轮可只取m项。支持n≤2^23，明确断言上限。

## 平方根倒数

首项取标量较小平方根的逆元。设当前b长度k，满足a*b²=1 mod x^k；Newton更新为(3b-a*b³)/2。a取前m≤2k项，a*b³最高次数≤5k-4，长度4k循环卷积的回绕仅落到0..k-4，因此[k,m)的高半段准确。高半段3b为零，直接写入-a*b³/2，低半段保留即可。每轮只需a、b的两次正变换与一次逆变换。

inverse_sqrt(a,n)对n>0且常数项为零、非二次剩余时返回nullopt；n=0返回有值空vector。n≤2^22保证4k不超过NTT容量。普通sqrt提出前导偶次零后，计算a*inverse_sqrt(a)，截断再移位；保留较小首根与未确定尾系数置零的旧约定。

## 检查

参数化NTT采用cpp_int独立DFT和朴素卷积，额外检查逆变换先调用、大小长度交替、同素数不同原根及再次返回原实例。inverse_sqrt以已知较小首根构造平方，用独立逐项逆元递推核对；长度跨越二次幂边界、调用顺序打乱，包含无解、空精度、短输入和多余尾项。普通NDEBUG与ASan/UBSan分别执行。

满容量解析数据：inverse(1-x,2^23)逐项为1；a_i=i+1、n=2^22时inverse_sqrt为1-x，sqrt逐项为1。每种模式均逐项核对，不仅抽样或比较两个相关实现。其他既有FPS导数/积分/log/exp/幂与普通商余式回归一起执行。

本批本地证据不等于新增线上AC，原稿的其他模数和容量检查另列于WIDA审计，原应用仍未核验。原稿重复调用静态缓冲残留问题仍有效。计时单独保存，不覆盖之前55倍和25倍差距的回执。
