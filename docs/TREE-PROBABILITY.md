# P3317：随机图恰为生成树的概率

题面范围经2026-10-12 Firefox页面及公式截图核实：[Luogu P3317](https://www.luogu.com.cn/problem/P3317)，2≤N≤50，概率矩阵对称、对角为0、至多两位小数；非零答案保证≥1e-4，相对误差限1e-4，1s/125MB。浏览器读取补齐了网页文本提取在小于号处截断的范围。

## 接口与模型

`tree_probability(p)`接收整数百分数矩阵，元素0..100，对称且对角为0，1≤n≤50，输入不变。每条无向边独立出现，返回恰有n−1条边且连通的概率。n=1的空图约定为1。输入域不是任意实数概率；直接传浮点矩阵或非对称矩阵不在约定内。

概率100的边是必选边。先用并查集合并；若它们成环，事件不可能，直接返回0。否则它们组成森林，缩成k个分量。其他边的缺失概率q=(100−p)/100严格为正，令权重w=p/(100−p)。任意包含必选森林的树对应缩点后的一棵多重图生成树，其概率等于所有非必选边的q之积乘树上w之积。求和即矩阵树行列式。缩点后落在同一分量内的非必选边会构成环，必须缺失，因此它们仍计入q乘积，但不能加入拉普拉斯矩阵。

若正概率边形成的图不连通，概率严格为0；通过图的连通性判定，不用浮点eps代替。否则缩点图的拉普拉斯余子式正定，每个消元主元数学上为正。先累加log(q)，再累加log(主元)，最后exp，避免先算极小缺边乘积再乘极大行列式。时间O(n³)，空间O(n²)，递归find路径压缩，不使用显式DFS栈。

百分数输入域的正权至少1/99、至多99，且n≤50；仍是浮点近似运算，不声称任意实数/任意规模精确。代码保留主元正值assert以暴露不符合约定或数值异常，不悄悄把负主元改零。long double在本机只有53位有效二进制位，不能靠类型名称假设扩展精度。题外极小概率最终仍可能下溢；正式题面非零答案下界不受影响。

P3317驱动将输入乘100后四舍五入为百分数；两位小数域的浮点读取误差远小于半个整数单位。输出固定12位，绝对舍入误差≤5e-13，对题面非零下界对应相对误差≤5e-9。这个输出格式不直接用于任意小概率。

## 独立验证

`tests/tree_probability.py`用Prüfer序列枚举每棵标号树，直接把出现边的整数p与缺失边的100−p相乘，再除以100的边数次方；以Python整数精确求和，90位Decimal转换比较。真值不使用消元或缩点公式。包含四点以内所有0/50/100三值图，500组混合百分数随机图、单点扩展，以及最大规模的树、必选森林和平行边选择、完全图、断连和必选环。

额外以解析公式验证50点50%完全图：缺边因子乘积单独会在double中下溢，完整答案仍可表示；两个99%稠密块之间只有1%桥的案例检验消元误差。共1275例，原头文件、仅抄手册代码、NDEBUG三种形式，普通和ASan/UBSan六构建均通过，当前最大相对误差约3.67e-11。完整题目驱动在两种构建下各81例，全部满足题面非零答案下界；证据及源文件哈希见 `verification/tree-probability.json`。实测误差不扩大为对所有浮点输入的形式化保证。
