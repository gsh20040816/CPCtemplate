# 十进制大指数与扩展欧拉降幂

对应附件 3.5 和 [Luogu P5091](https://www.luogu.com.cn/problem/P5091)。输入顺序是 a,m,b，指数最大值 10^20000000 本身有 20000001 位。模板用 string_view 接收非空十进制串，不拷贝指数；主程序用 string 保存输入。

调用者传入正确的 φ(m)。若 b<φ(m)，直接使用 b；否则改用 b mod φ(m)+φ(m)。仅对余数快速幂在非互质时是错误的，例如 2^3 mod 8=0，而指数 3 mod φ(8)=3 尚可，2^4 则不能降成 2^0。也不能无条件加 φ(m)：2^1 mod 8=2，加上 4 后就变成 0。

为什么足够：分解 m 为互质素数幂。对于整除 a 的素数 p，一旦 b≥φ(m)，其 p-adic 赋值足以使幂在该素数幂模数下为零；降后的指数也至少为 φ(m)。对于不整除 a 的素数幂，欧拉定理允许按该因子的 φ 周期降幂，该周期整除 φ(m)。最后由 CRT 合并得到同余。这里不要求 gcd(a,m)=1。

扫描指数时分别维护模 φ 余数 rem 和 min(b,φ) 的饱和值 cap。前导零不会改变阈值判断；不能按字符串长度直接判定“大指数”。完整 unsigned64 模数可能令 rem+φ 超过 64 位，因此最终指数以及十进制乘十都使用 uint128；乘法模运算由 Mod64::mul 负责。m=1 返回 0，b=0 按 0^0=1 约定处理。

phi 的求值独立于降幂。P5091 的 m≤10^8，可使用 euler_phi(m) 的试除版；大模数可以显式采用其 PollardRho 重载，或复用已知 φ。euler_power 只检查参数范围，不通过重新分解 m 验证用户提供的 φ 是否正确。

验证采用独立重复乘法穷举小 a/m/b，再与 cpp_int powm 比较 200 位随机指数、完整 unsigned64 边界、阈值前后及需要 65 位保存的降后指数。P5091 完整驱动用 Python pow 对拍 200 组，另验证两千万位奇偶性、最大指数的幂零化和两千万个前导零后的小指数。均为普通与 ASan/UBSan 本地结果，不记作在线 AC。
