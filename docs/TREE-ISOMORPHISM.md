# 确定性有根与无根树同构

对应 [issue #14](https://github.com/gsh20040816/CPCtemplate/issues/14)。使用轻量 `TreeIsomorphism`，通过精确子树签名实现判定，不依赖随机数或哈希碰撞假设。

## 输入与编号

邻接表 `vector<vector<int>> g` 为0-based、非空、简单无向连通树，每条无向边双向各存一次。`rooted(g,root)` 返回有根树int编号；`unrooted(g)` 返回无根树pair编号。空图、环、森林、重边或非法点号不在接口合同内；没有为了验证输入图而额外加一遍检查。

所有要比较的树必须共用同一个 `TreeIsomorphism iso`。codes驻留表只读；编号由签名首次出现顺序决定，不同对象的整数不可比较，清空后也不能与旧编号比较。返回值只编码形态，不包含顶点/边标签，不构造顶点间的对应映射。n<=INT_MAX，驻留签名数须小于INT_MAX，并符合内存限制。

## 为什么是确定性的

递归处理孩子，取得每棵子树的编号后排序，得到一个 `vector<int>` 签名。`map<vector<int>,int>` 用完整向量的字典序比较，不是只比较散列值。相同签名复用已有编号，不同签名分配新编号。

按树高归纳：叶子的空签名相同；两个非叶子根相同，当且仅当它们的孩子子树同构类多重集相同。排序签名恰好表达这个多重集，因此编号相同当且仅当有根树同构。整数编号本身不必按树形大小或字典序规范排列；只要同一驻留表中每个类有唯一编号即可。

无根树的重心集合在同构下保持，且仅有一个或两个。递归计算子树大小，以删除顶点后的最大分量不超过n/2判断重心。单重心返回(rootedCode,0)；双重心分别以两点为根对整棵树编码，再排序返回两个编号。双重心邻接表的遍历顺序不同不会改变这个pair。单点自然得到单重心结果。

如果两个无根签名相同，至少一对根编码相同，由有根树的结论立即得到无根同构；反方向由同构保持重心集合成立。此实现的正确性不依赖随机概率。

## 复杂度

S为本次调用结束时驻留签名总数。孩子排序总计O(n log(n+1))。一个长度d的签名查询map至多O(log(S+1))次比较，每次O(d+1)，对全树求和为O(n log(S+1))。无根最多三次DFS（找重心、两次根编码），常数倍不改变渐近界。

临时空间O(n)，递归深度最坏n。驻留表跨调用保存唯一签名，累计存储O(T)，T为累计编码遍历的顶点数；不声称只依赖最后一棵树的大小。为了赛时抄写，使用递归，不改为显式栈。本地macOS测试链接256MiB主线程栈，以验证十万点链。

## 完整用法与验证

用法357对应 [P5043【模板】树同构](https://www.luogu.com.cn/problem/P5043)：M,N<=50，页面1s/250MB。输入每点父亲编号，0为输入根；先建无向图，判定时忽略输入根。全部M棵树共享一个iso，用map保存每个无根签名第一次出现的树编号。官方样例四种构建输出1、1、3、1。

核心验证以独立的排序括号串为有根真值，并枚举所有根取最小括号串作为无根真值，不复用整数驻留或重心逻辑。枚举六个点以内全部1442棵有标号树，再加1000棵随机树；每棵测试所有根、重标号及邻接顺序变化，双向映射检查既无错误合并也无错误拆分。另验证100000点链和星形树。

完整用法有40组、每组50棵树，含随机树与既有树的重标号副本，独立生成父亲输入和最早同构编号。核心header/NDEBUG/最小抄写、完整用法header/NDEBUG/实际全文展开/最小抄写分别通过普通与ASan/UBSan。上述证据的范围区别于线上N<=50题域与性能排名，见 `verification/overall-kth-isomorphism-*.json`。
