# WIDA 打印稿：几何

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `29b9fa7f47c21422e31cce8f3dbb5ee857764150`，路径 `02 - 打印稿模板汇总/06A - 几何.md`。

按 4 位小数读入时，`"1.25"` 得到 12500，`"3"` 得到 30000。`fgcd(6,9)` 是 3。`(1,0)` 与 `(0,1)` 的叉积是 1，点积是 0。正文把点积也写成了叉乘符号。`(3,4)` 的欧氏距离是 5，曼哈顿距离是 7，单位向量是 `(0.6,0.8)`。

绕原点的 90 度旋转得到 `(0,-1)`，是顺时针。按弧度旋转向量是逆时针，`(1,0)` 转 90 度得到 `(0,1)`。点绕点的公式写着逆时针，同样的例子得到的却是 `(0,-1)`。3、4、5 的对角是直角。两轴交于原点。点 `(0,1)` 到 x 轴的距离是 1，投影是原点。点 `(2,1)` 到线段 `(0,0)-(1,0)` 的最近点是 `(1,0)`，距离是 \(\sqrt{2}\)。

许多函数的参数写成 `Pt`、`Lt`，模板参数 `T` 不能从调用推导。两份“点是否在线段上”签名相同，第二份还会调用自己，放在一起不能编译。线段相交对 `Line` 做结构化绑定，而 `Line` 有构造函数，不是聚合体，不能编译。三点定圆调用的 `midSegment` 同样推不出模板参数。四边形有向面积写成了 `cross(b, c, a)`，这三个名字都不存在。

三角形 `(0,0),(4,0),(0,3)` 的面积是 6。单位正方形的多边形面积是 1。边长 2 的整数正方形边界上有 8 个格点，内部有 1 个。单位圆和自己的相交面积是 \(\pi\)，相距 3 的两个单位圆是 0。点 `(2,0)` 到单位圆的最近点是 `(1,0)`。

凸包、内心、垂心、直线方程和全部立体几何这轮没有运行。
