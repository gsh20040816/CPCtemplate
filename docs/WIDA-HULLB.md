# WIDA 11B 新版静态凸包

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `8bceff9d4901e0ac952b41c47d10a19a045c56d9`，路径 `03 - jiangly模板收集/03 - 数论、几何与多项式/11B - 静态凸包（with. Point，新版）.cpp`。注释里的提交链接多了一个右括号。`Point` 使用 `i64`，文件没有定义它，单独编译失败。

`getHull` 返回上链和下链，不是一条闭合多边形。点按 x、再按 y 排序。上链在叉积 `>= 0` 时弹栈，并且同一条竖线上只保留后遇到的、也就是 y 更大的点。下链在叉积 `<= 0` 时弹栈，同一条竖线上不加入更靠上的点，所以保留 y 更小的点。空集和单点不会做空范围迭代，两条链都得到相应结果。`(3,4)` 与 `(1,0)` 的点积是 3，叉积是 -4。

`python3 tests/wida_hullb.py` 在普通 `-O2` 和 ASan/UBSan 下对照了空集、单点、竖线、共线、正方形和内部点。没有证明坐标乘积不溢出。QOJ 提交页面没有打开，没有新的在线 AC，也没有新增模板。来源保持 partial。
