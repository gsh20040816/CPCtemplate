# 一般多边形面积并：整数精确判定

`polygon_union_area(polygons)` 输入 `vector<vector<IntegerPlane::Point>>`，返回long double面积。每个输入轮廓是无洞简单多边形，可为凹多边形；不同轮廓可相交、重合、包含、共享整条边或部分边，并集可以有孔洞。顺/逆时针均可，函数转成逆时针；删除连续重复顶点及末尾重复首点。点、线段及全共线的零面积退化轮廓忽略。自交轮廓、单个输入轮廓内含洞不在接口范围，不执行昂贵的合法性检查。

本函数要求每个坐标绝对值≤10⁹，比IntegerPlane基础类型的坐标约定更严格。总顶点数V及覆盖计数必须适合int；实际比赛内存范围下通常自然成立。时间O(V²log V)，额外空间O(V)，参数按值复制、不修改调用者；并查集递归深度至多输入轮廓数。

## 边界覆盖

当前有向边p→q的左侧属于当前多边形。只要它右侧也被其他多边形覆盖，该段就在并集内部，不应积分。把当前边所在直线向右侧平移无穷小量，原来线上点视为上方点；于是精确整数判断 `(cross(p,q,c)>=0)!=(cross(p,q,d)>=0)` 给出其他边是否穿越测试线。向下穿越时覆盖数加1，向上穿越时减1。交点参数为 `cross(c,d,p)/(cross(p,q,d)-cross(p,q,c))`。

这只是符号化的单侧极限，不实际改动坐标。参数事件沿整条直线累计覆盖数，对凹多边形同样能产生多个内部区间。将每个事件参数裁到[0,1]再排序，相当于把0之前的全部变化合到起点，1之后的全部变化合到终点，因此覆盖状态仍正确。同参数事件的中间状态只对应零长度，不贡献面积。

共线反向边的内部在两侧，右侧覆盖测试已经将其去掉。共线同向边应保留一次：编号较小的其他多边形把对应重叠参数区间加入遮挡事件，因此最早编号者保留，其余删除。该规则适用于整边、部分边、不同顶点拆分以及完全相同的多边形，不依赖扰动或eps。

## 面积与精度

覆盖数为0的参数段[l,u]属于并集边界，格林公式贡献 `cross(p-origin,q-origin)*(u-l)/2`。所有原轮廓已逆时针，内部位于左侧，因此输出边界中的孔洞自然按相反方向积分；不可对单段面积取绝对值。

用包围盒相交关系建立连通块，块内共享一个原点。真正相交的多边形必然在同一组，故每组是若干完整并集分量，独立平移不改变面积。即便包围盒相交而多边形未相交，也只是把原本可分开的组并在一起，不影响正确性。此做法减少遥远分离区域的抵消，但不保证消除所有浮点误差。

令M=10⁹。差向量分量至多2M，叉积及参数分子/分母绝对值至多8M²，分式比较的单个乘积至多64M⁴=6.4×10³⁷，小于有符号128位上界约1.70×10³⁸。分母在构造时统一为正；排序采用交叉乘法比较，不转浮点。参数裁到[0,1]后，相减的两个乘积均非负且不超过同样上界，因此差仍安全。面积符号归一化所用叉积之和也在int顶点数量约束下安全。

因此输入域内的方向、交点顺序、重合边处理和覆盖拓扑判定是精确的；最终面积使用long double将有理数转换并累加，**不是精确有理数输出**。补偿求和降低但不能消除误差。某些长细、复杂遮挡或尺度悬殊模型仍需更高精度面积累加。不可把基础点类型允许的10¹²坐标直接用于这个函数，否则有理数比较乘积可能溢出。

## 验证与题目

独立参考程序使用Python Fraction：枚举所有边交点横坐标和顶点横坐标，在每个竖直条带内用奇偶配对得到各简单多边形截面，再合并区间，使用线性上下包络的梯形面积得到精确真值。它不使用被测函数的有向边覆盖事件或符号化右侧测试。

450组包含可重复矩形组合、凹L形及多凹口梳状轮廓、多边形重复/逆序、共享边、顶点接触、共线拆点、重复首尾点、孔洞、非整数交点、坐标±10⁹、随机三角形与凹多边形混合、旋转、远平移、比例缩放和分离复制。三组1000三角形使用独立解析真值：分离、重复、嵌套。头文件、NDEBUG和抄写版均通过O2及ASan/UBSan；最大观察到的缩放误差约5.24e-16，不是普遍误差保证。

完整驱动采用[P13338 三角形面积并加强版](https://www.luogu.com.cn/problem/P13338)：最多1000个非退化三角形，整数坐标绝对值≤10⁶，允许相对或绝对1e-6误差。该题只能验证三角形输入，任意凹多边形支持另由上述精确参考与证明覆盖。当前Mac锁屏，**尚未在线提交，不记录AC、不勾选issue验收项**。代码独立编写，没有复制第三方实现。
