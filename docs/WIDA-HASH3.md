# WIDA 在线模板：字符串双哈希++

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `f60132a4f225aff184d57389ca594263e50bd0be`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/35 - 字符串双哈希++.cpp`。它使用 `mt19937`、`vector` 和 `pair`，但没有头文件，单独编译失败。

模数和进制在运行时用时钟种子寻找。字符先减去 `'a'`。幂表只建到 2 时，`"ab"` 改成 `"cb"` 与非负的 64 位乘法一致。一次运行抽到的四个数是 `352224689`、`29`、`471865081`、`127`，试除确认它们都是素数。换一次运行会换一组数，不能把这次结果当成固定参数。

`Miller_rabin` 对 1、2、9、17 分别给出假、真、假、真。`findPrime(14)` 是 17。`"a0"` 里 `'0' - 'a'` 是负数，模 100 的结果停在 -49，没有拉回正余数。用进制 127、模数 `1000000007` 建 8 项幂时，`260144641 * 127` 溢出。默认长度 `1 << 21` 没有构造。

`python3 tests/wida_hash3.py` 在普通 `-O2` 和 ASan/UBSan 下通过小素数和短字符串，并记录了长幂表溢出。没有子串查询，没有新的在线 AC，也没有新增模板。来源保持 partial。
