# 浮点 FFT 与拆系数卷积

对应附件 5.2（实际 130–131 页）、5.12（实际 178–180 页），分别实现复数 FFT 整数卷积和拆系数任意模卷积。它们不调用精确 CRT 卷积；CRT 只在测试中用作独立参考。

## 接口和舍入条件

ComplexFFT(n) 建立 n 点单位根表；n 是 1..2^22 的二次幂。transform(a) 使用正指数，transform(a,true) 使用负指数并除以 n，数组长度须为 n。根表可在多次变换间复用，正逆变换共用共轭根。根由各自角度直接计算，不用长度为 n 的旋转因子连乘，避免误差随整条连乘链增长。位逆序从 i=1 开始，n=1 合法。

convolution_fft(a,b) 接受有符号 int 系数，返回 long long；空输入返回空，非空结果长度不超过 2^22。设 A、B 为最大绝对系数，要求 `A*B*sqrt(a.size()*b.size()) <= 2e12`。这上界控制两输入欧氏范数的乘积，也保证真实系数远小于 long long 上限。末尾使用 llroundl，对正负数都向最近整数舍入。

convolution_mod_fft(a,b,mod) 允许 1..INT_MAX 的模数、合数模数及任意 int 输入。先归一化到 [0,mod)，再写成三个 11 位块，因此输入负数、INT_MIN 均不依赖有符号移位。每个块至多 2047；结果长度不超过 2^19。六次正变换的结果复用，九个块对分别逆变换、舍入，再按 2048 的幂模合并；没有在浮点数里累加九路大系数。mod=1 返回全零。

三块版本比附件两块打包版常数大，但适用于本机只有 53 位有效精度的 long double，代码不需要共轭拆包推导或假定 x86 扩展精度。每个模板保持 O(N log N) 时间、O(N) 空间；第二个的明确常数是 15 次 FFT。P4245 的 100001 项输入需要 2^18 点变换，仍在此范围。

## 最坏误差，而非仅靠随机测试

以下均要求二进制浮点至少 53 位有效精度、最近舍入、无 fast-math，且计算过程中无上溢或下溢。单位根的复数绝对误差须不超过 8u，其中 u=2^-53。C++ 标准本身没有保证三角函数达到这一误差，换平台时必须核验该前提，不能仅检查 long double 类型名。

[Percival 的论文 Theorem 5.1](https://www.daemonology.net/papers/fft.pdf) 给出三次 radix-2 FFT 计算卷积的无穷范数误差界。若 N=2^l、单位根误差界为 beta，输入欧氏范数乘积为 S，则界为

`S * ((1+u)^(3l) * (1+sqrt(5)*u)^(3l+1) * (1+beta)^(3l) - 1)`。

代入本实现 beta=8u：整数接口 l<=22、S<=2e12 时，界小于 0.165161；拆系数接口的每一路 l<=19、S<=2047²*(2^18+1)，界小于 0.078378。后者用输入长度之和至多 2^19+1 推得，包含两输入长度分别为 2^18、2^18+1 的非对称边界。这是对每个输出系数的界，低于 0.5，故各自最近整数舍入正确。除以二次幂是精确缩放；模合并只用整数。上面的范数判定即使有末位舍入，也远离 0.5 边界。超过契约范围不能只用“结果离整数很近”断言正确。

模合并时每个余数、权重都小于 INT_MAX，因此乘积加当前结果小于 signed64 上限；2048 幂逐次取模，不形成 2048^4 的无界中间量。整数入口的真实系数绝对值由 Cauchy–Schwarz 控制在上述 S 内，不存在 llroundl 超范围。

## 平台核验和独立测试

tests/fft_roots.cpp 对最大 2^22 网格的全部 2097152 个半圆单位根，用 100 位十进制精度、独立高精度旋转递推逐个比较。较短二次幂网格的角度是这张表的子集，当前根生成式会计算相同的二进制角度。本机 GCC 的 long double 有效位是 53，测得最大根误差约为 3.687u，小于 8u。高精度参考的累计舍入量与这个间隔相差数十个数量级。

其余测试不靠正逆变换互相抵消错误：

- 100 位直接 DFT 核对 1、2、4、8、16、32 点正/逆变换，另做往返变换。
- 14641 组长度 0..4 的正负系数全枚举，1200 组随机整数二次卷积。
- 六个模数（含 1、偶合数、奇合数、INT_MAX）共 600 组随机输入，int128 下标对枚举；另覆盖 INT_MIN、INT_MAX 和负常数乘法。
- 一百万次、全 9 系数的闭式三角卷积。
- 100001 项集中频率的正负输入，与精确整数 CRT 卷积逐系数比较。
- 100001 项随机完整 signed-int 输入，对两个大模数与三素数 CRT 重构的非负整数卷积比较；真实系数上界低于三素数乘积。
- 拆系数接口的最大 2^19 结果容量边界：两路分别 262144、262145 项、全为 INT_MAX-1 的闭式。
- P3803、P4245 各 100 个完整随机输入与一个题目最大次数闭式；打印用法另外编译验证。

普通及 ASan/UBSan 模式各自执行；详细源码指纹、编译环境和日志摘要保存在 verification/fft-attachment.json。新实现的线上 AC、排名仍待验证。本地实测时间不替代 OJ 时限结论。

## 与附件的差异

附件 5.2 的 `(long long)(x+0.5)` 只适用于非负结果，本实现使用对称舍入；其位逆序从 i=1 开始，常数乘法没有负移位，不重复此前文本提取造成的误判。

附件 5.12 的 rev 初始化从 i=0 开始，常数乘法 bit=0 时出现负移位；本实现修复。附件直接拆原输入且只向正方向舍入，不能自然扩展负系数；本实现先归一化。两块 15 位改为三块 11 位，并明确记录 53 位平台的保守误差界。这仍是浮点拆系数算法，没有把既有精确 CRT 算法当作覆盖。
