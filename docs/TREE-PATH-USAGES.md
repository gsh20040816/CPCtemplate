QTREE2的[官方SPOJ课程页面](https://am.spoj.com/FHNW1907/problems/QTREE2/)提供完整协议与样例，[洛谷SP913](https://www.luogu.com.cn/problem/SP913)交叉确认题意与输出空行：t≤25、n≤10000、c≤100000。KTH返回路径上第k个**点的编号**，k从1开始、包含两端；DIST返回权值和。kuangbin印刷75页的“第K条边的长度”是文字错误，其后query_kth也实际返回点号。本批按正确语义实现。官方文本未给操作数上界，额外压力测试不冒称官方最大数据。

## 抄写要点与正确性

**路径点加**：HLD.path发出的闭区间无重叠且恰好覆盖路径顶点。Fenwick只保存增量差分；每段在l加x、r+1减x，前缀和恰好是查询点累计增量，再加初值。r=n时add(n+1)不进入循环。I/D都包含LCA和两端，同点更新只更新一次。每测重新构造HLD与Fenwick。

**路径边最大值**：把输入边i映射到深度较大的child[i]，父边存在dfn[child[i]]−1。HLD的edge=true排除LCA顶点所代表的路径外父边，其余区间恰好对应路径边；转换闭[l,r]到半开[l−1,r)后取各段最大值。幺元LLONG_MIN不能换成0，否则全负权失败。CHANGE是set赋值，不能add。不能直接把输入边号当子节点号，亦不能总取输入第二个端点。

**路径距离与第k点**：额外递归DFS计算根权值和d。设p=LCA(u,v)，距离为(d[u]−d[p])+(d[v]−d[p])；h.distance返回的是边数，不能代用。设a=depth[u]−depth[p]、b=depth[v]−depth[p]；前a+1个点在u至p段，跳k−1步；其余点从v回跳a+b+1−k步。这里的1不能省掉，也不能把最后一段方向当成u方向。所有根距离、中间差与最终和必须在signed64范围；例题正边长约束满足它。

HLD两次递归DFS，倍增及额外根距离DFS也保留递归。按用户要求不模拟调用栈。驱动不调整栈；本机压力验证在Darwin用链接器指定512 MiB栈，在其他平台用进程stack limit，测试记录中明确区分，不把本机栈配置说成评测机资源保证。

281预处理O(n)，每次路径加O(log²n)、点查O(logn)，空间O(n)。282预处理O(n)、边赋值O(logn)、路径最大值O(log²n)，空间O(n)。283预处理与空间O(nlogn)，查询O(logn)。这些入口为组合示例，所有涉及组件带具体章节/页码引用；不加反向联合用法引用，以免Fenwick作为跨类依赖时把整段HLD用法带入其他分册。

## 验证范围

`tests/tree_path_usages.py`使用独立BFS恢复路径，不调用HLD/LCA作为参考答案：穷尽n≤5的全部标号树（146棵）、所有有向点对，KTH穷尽路径上的每个合法k；点加后逐点核对；输入边随机排列并随机翻转端点。另有60组随机多测（每输入3棵树）、单点与空路径、负权及LLONG_MIN/LLONG_MAX的最大值、链/星压力测试。281的大链5万点、5万操作；282/283各1万点、10万操作。QTREE/QTREE2含官方样例，QTREE2逐字节验证组后空行。

普通及ASan/UBSan分别执行原驱动、展开代码、最小标准头+书中组件、最小抄写NDEBUG四种完整程序。每种形式281有70输入、282/283各71输入。六个安全错误变体分别漏掉差分右端、漏掉D负号、选错边端点、未排除LCA、把边数当权值和、逆向第k点错位；独立答案检查必须将其拒绝。两模式对应源码快照与逐输入哈希保留在`verification/tree-path-usages-{normal,sanitizer}.json`。

本批所有算法头文件保持原字节，旧280份展开程序指纹保持一致。上述证据是新增组合用法专项验证，不是重新执行全库回归、线上AC或速度排名。
