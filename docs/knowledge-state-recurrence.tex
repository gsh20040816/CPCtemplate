\section{有限状态计数到线性递推：先证明阶数，再用 BM}\label{knowledge-state-recurrence}
\index{有限状态计数}\index{Cayley--Hamilton}\index{线性递推}\index{Berlekamp--Massey}
只问极大长度 $N$ 的一个计数时，用有限状态 DP 生成少量项，再用 BM 求标量递推外推；须先有阶数上界。

\subsection{先把状态、方向和输出写清楚}
$v_n\in R^d$ 为长度 $n$ 时各状态计数的列向量，$A_{ij}$ 为从状态 $j$ 一步到状态 $i$ 的方案数（重边须累加）：
\[
v_{n+1}=Av_n,\qquad v_n=A^nv_0,\qquad a_n=u^{\mathsf T}v_n.
\]
$R$ 可为整数环或模 $m$ 的交换环；按行向量建模时整体转置。
\textbf{前提：}状态维数 $d$ 有限且固定，转移矩阵固定，更新与输出均为线性（min-plus 不算）。
固定周期可加相位状态，仿射项可加恒为 1 的坐标，阶数按扩充后的维数计。

\subsection{Cayley--Hamilton 给出阶数至多 d}
$\chi_A(t)=\det(tI-A)=t^d+q_{d-1}t^{d-1}+\cdots+q_0$，$\chi_A(A)=0$ 对交换环成立，故
\[
\boxed{a_{n+d}=-\sum_{i=0}^{d-1}q_i a_{n+i}\quad(n\ge0).}
\]
按 $a_n=\sum_{j=1}^k c_{j-1}a_{n-j}$ 约定取 $k=d$、$c_j=-q_{d-1-j}$。调用 BM 只需上界，不必算出特征多项式。

\subsection{为什么前 2d 项足以恢复这个标量序列}
在素数域 $\mathbb F_p$ 中，精确的前 $2d$ 项 $a_0,\ldots,a_{2d-1}$ 经 BM 得到的最短递推（阶 $k\le d$）对整个序列成立；
$2d-1$ 项不够。恢复的只是该 $u,v_0$ 下的标量递推，不是矩阵恒等式。
BM 返回的末尾零系数不能删除。额外项交叉检查不代替阶数证明。

\subsection{模型：不含连续子串 101 的二进制串}
状态为与禁串前缀的最长匹配 $\varepsilon,1,10$：
\[
A=\begin{pmatrix}1&0&1\\1&1&0\\0&1&0\end{pmatrix},\quad
v_0=\begin{pmatrix}1\\0\\0\end{pmatrix},\quad
u=\begin{pmatrix}1\\1\\1\end{pmatrix},\qquad
a_n=2a_{n-1}-a_{n-2}+a_{n-3}.
\]
调用链：\texttt{c=berlekamp\_massey(s,p)}，\texttt{init} 取前 \texttt{c.size()} 项，
\texttt{recurrence\_nth(init,c,N,p)}，$N$ 为 \texttt{unsigned long long} 零基下标。
样本与系数须先正规化到 $[0,p)$ 并在目标素数域内恢复；模一个素数得到的递推不保证在别的模数下有效。

\subsection{按目标选算法，并把采样成本算进去}
$e$ 为非零转移数：采样前 $2d$ 项 $O(d(e+d))$ 时间、$O(e+d)$ 空间（稠密 $O(d^3)$）；BM $O(d^2+d\log p)$ 时间、$O(d)$ 空间。
\begin{itemize}
\item 直接 DP：$O(N(e+d))$，适合 $N$ 不大或要整个前缀。
\item 矩阵幂：第~\pageref{compact-ModMatrix}~页 \texttt{ModMatrix<p>::power(A,N)}，$O(d^3\log(N+1))$ 时间、$O(d^2)$ 空间，可复用于不同初值/输出。
\item 小阶：第~\pageref{compact-recurrence_nth}~页 \texttt{recurrence\_nth(\allowbreak{}init,c,N,p)}，$O(k^2\log(N+1))$ 时间、$O(k)$ 空间。
\item 大阶：第~\pageref{compact-BostanMori}~页 \texttt{BostanMori<p,g>::recurrence(init,c,N)}，$O(k\log(k+1)\log(N+1))$ 时间、$O(k)$ 空间；
参数转换为其 \texttt{Poly}，$p$ 素数、$g$ 原根，非初值查询要求 $2k+1\le\texttt{NttConvolution<p,g>::max\_size}$。
\end{itemize}
BM 见第~\pageref{compact-berlekamp_massey}~页。两种远项接口要求初值\textbf{恰好} $k$ 项，下标为 \texttt{unsigned long long}；$k=0$ 返回 0，$N<k$ 返回初值。

\textbf{合数模数：}BM 用 $x^{p-2}$ 求逆，只支持素数模数。已知正确递推时，\texttt{recurrence\_nth} 支持
$2\le m\le\texttt{INT\_MAX}$ 的合数模数（初值和系数在 $[0,m)$）；\texttt{ModMatrix} 乘法与非负次幂也无需逆元。
求逆矩阵与 NTT 版 Bostan--Mori 不适用。
