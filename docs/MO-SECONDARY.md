# 莫队二次离线：区间异或位数配对

对应附件 4.5（实际 117–119 页）。图中的题意及完整代码与 [Luogu P4887](https://www.luogu.com.cn/problem/P4887) 一致：统计区间内 i<j 且 popcount(a[i] xor a[j])=k 的下标对。2026-09-29 核验官方题面，n,m<=100000，a_i 和 k 都小于 2^14；**k 不一定小于等于 14**。因此不可直接以 k 索引只有 15 项的数组。

## 可抄接口

`xor_hamming_pairs(a,queries,k,bits=14)` 返回按输入顺序排列的 long long 答案。数组下标 0-based，每个查询为半开区间 [l,r)，可为空，也支持空数组、无查询、重复查询。0<=bits<=20，0<=a[i]<2^bits；k<0 或 k>bits 返回全零。n、m 及所分配容器下标必须能用 int 表示。函数每次重建本地状态，可重复调用，无全局初始化依赖。P4887 驱动只减 l，不减 r。

这是静态对称配对关系的一个具体应用，不是带修改莫队，也不是可直接处理任何贡献公式的黑盒。计数按不同下标；相同值允许配成一对，而一个元素不能和自己配对。

## 二次离线推导

记 H(i,j) 为 popcount 条件是否成立，t(i)=sum(j<i) H(i,j)，P(x)=sum(i<x)t(i)。第一次从左到右扫描，在插入 a[i] 之前读取 count[a[i]]，得到 t(i)。每次插入只向与 a[i] 异或后恰有 k 个置位的值增加计数，因此插入需枚举 C=binom(bits,k) 个掩码，读取为 O(1)。

定义 S(p,i)=sum(j<p)H(i,j)，以及去掉自身的 T(p,i)=S(p,i)-[k=0 且 i<p]。莫队从旧窗口变到新窗口，先扩右、扩左，再缩右、缩左，保证移动过程中窗口合法。每次一整段端点移动拆为一次 P 的区间差及一个前缀事件：

| 移动 | 新增/移除下标段 I | P 的区间和符号 | 前缀事件 |
|---|---|---:|---|
| 扩右 R -> R' | [R,R') | + | -T(L,i) |
| 扩左 L -> L' | [L',L) | - | +T(R,i) |
| 缩右 R -> R' | [R',R) | - | +T(L,i) |
| 缩左 L -> L' | [L,L') | + | -T(R,i) |

右端贡献为 t(i)-T(L,i)，左端贡献为 T(R,i)-t(i)；段内先后加入/移除的元素由 t(i) 的严格前缀自然只计一次。事件记录 (查询编号,段左端,段右端,符号)，按前缀长度 p 分桶，不存每个单独移动，事件数最多 4m。

第二次扫描先插入 a[p-1]，再处理桶 p，count 即 S(p,·)。桶 0 也显式处理。k=0 时若 i<p，必须减一，避免左端事件含自身。每个 answer[id] 此时只是从上一莫队窗口到当前窗口的答案差，最后**按莫队顺序**累加，再按原编号输出。不可按输入编号直接累加。

## 复杂度与整数

块长取 max(1,floor(n/sqrt(m)))，m=0 在开平方前返回；蛇形右端排序。总端点移动 O(n sqrt(m)+m)，每个事件下标只需 O(1) 读取，因此总时间 O(2^bits+nC+m log(m+1)+n sqrt(m)+m)，空间 O(2^bits+n+m)。两次扫描都付出 nC，但端点移动没有再乘 C。默认 bits=14，最大 C=3432，测试包含 k=7，不能仅测试 k=0 后宣称最坏掩码分支通过。

count 至多 n，用 int；P、答案差及答案用 long long，符号乘法显式提升。n=100000 全相等且 k=0 时答案为 4999950000，超过有符号 32 位。bits=20 是明确可表示的接口上界，不承诺所有 bits/n 组合满足某个在线时限。

## 验证

- `tests/mo_secondary.cpp`：长度 0..6、值域 0..3 全部数组，每组所有半开区间打乱查询顺序，k=-1..3 与逐对枚举对拍；1500 组随机数组/查询，bits 包含 0，允许空区间与空查询。另测 bits=14/20 的值域极值及 k=0/bits/bits+1。n=m=100000 随机端点查询，k=0 全相等组合数，k=7 两种互补位值的乘积计数，检查超 int32 答案。
- `tests/mo_secondary_application.py`：150 组官方格式完整程序，以 Python 逐对异或置位数为参考；另有三个 n=m=100000 案例，覆盖 k=0、k=7、k=16383 的零答案捷径。
- `example-111`：三组打印程序测试，覆盖相等值、异或一个置位及 k 超出位宽；原题 1-based 闭区间适配。

普通和 ASan/UBSan 的源码指纹与结果见 `verification/mo-secondary.json`。这些是本地验证，没有新增在线 AC 或速度排名。附件固定数组改为 vector、signed-id 事件改成单独 sign，保留其二次离线算法；P 区间和替代端点逐个累加，查询顺序采用蛇形排序。
