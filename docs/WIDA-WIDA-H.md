# WIDA 在线模板：wida.h

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `316ac267170adf57303e93ea0e8a45f7b53ffce8`，路径 `01 - 常用在线模板汇总/01 - 初始与杂类/00 - wida.h`。完整头文件在没有 `ONLINE_JUDGE` 时包含的是 `<bits/wida.h>`。这份源文件没有安装到编译器的头文件目录里，所以那条包含仍然失败。

它在全局使用 `using namespace std`，并为 `tuple`、`pair`、顺序容器、栈、队列和堆重载了输出。空 `vector` 只打印 `[`，没有右括号。一个元素是 `[7]`，三个元素是 `[1, 2, 3]`。`pair` 是 `[4,5]`，三元 `tuple` 是 `[1,2,3]`。`string` 被排除，`"ab"` 仍按普通字符串输出。栈从栈顶打印，`1,2,3` 依次入栈得到 `S[3,2,1>`。队列是 `Q<1,2,3]`。大根堆和小根堆分别是 `[3, 2, 1]` 和 `[1, 2, 3]`。调试输出 `_(1, 2)` 是 `●1▏2▏`。

`python3 tests/wida_debug_header.py` 在普通 `-O2` 和 ASan/UBSan 下通过这些例子。没有新的在线 AC，也没有新增模板。来源保持 partial。
