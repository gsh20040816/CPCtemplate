# 二分图最大独立集与最小点覆盖方案

`independent_set(g)` 复用 `BipartiteMatching`，内部执行 `solve()`，再对 `cover()` 的左右点集分别取补集。返回左右各自的 1-based 原点号，按升序排列。短函数仅补方案转换，不另写一套流或匹配，也不改变已有 HK 核心。

## 适用范围和调用顺序

左右划分必须已知，边只连接两侧。左右相同数字表示不同顶点；空侧、孤立点、断开图、平行边均允许。目标是最大**基数**独立集，不是最大权独立集，也不是一般图最大独立集。一般图三角形的最大匹配为1、最大独立集为1，直接套“3减匹配数”会得到错误的2。

函数会更新传入对象的匹配、层次和当前弧。原有合法匹配可以保留，继续 `add` 后再调用即可；重复调用也允许。不能删除边或手改 `l/r` 后仍依赖增广恢复。调用后可立即用 `g.cover()` 读取对应最小点覆盖。两侧大小非负且小于 `INT_MAX`，全部存储须能分配。

只求数量时可写 `1LL * g.n + g.m - g.solve()`，无需抄本函数。需要具体顶点才使用返回列表；两个列表的大小相加不会混淆左右同号点。打印方案时保留两侧标识。总时间沿用 HK 的 `O((V+E)√(V+1))`，额外取补集的时间、空间均为 `O(V)`；HK 增广仍使用递归，深度最坏 `O(V)`。

## 正确性

任意图中，一个点集覆盖所有边，当且仅当其补集不包含一条完整边。故最小点覆盖的补集是最大独立集。

这里由最大匹配终止时的交错可达集合 `Z` 构造覆盖：取左侧未到达点及右侧到达点。每条边至少有一个端点被取，且每条匹配边恰有一个端点被取，覆盖大小等于匹配数。由 König 定理它是最小覆盖，因此补集有 `V-|M|` 个顶点且最优。独立集、最小覆盖和最大匹配共同给出可独立检查的最优性证书。

## 完整应用和接口用法

- `example-309`：[P3355 骑士共存](https://www.luogu.com.cn/problem/P3355)。`n≤200`。骑士每步使 `(x+y)` 奇偶翻转，未阻塞格分别编号，八种攻击位移建立两侧边；障碍格不能建成独立点。输出最大可放骑士数。题目只要求数量，用法调用方案函数展示复用，赛时仅求数量可用上述公式。
- `example-310`：通用接口演示。输入两侧大小和边表；输出最大独立集大小及左右原点号列表。允许空侧和重边。它没有在线判题，不算正式模板题。
- `example-311`：[CSES 1709 Coin Grid](https://cses.fi/problemset/task/1709/)。`n≤100`。行列为两侧，每枚硬币是一条边；删除行列就是覆盖所有边。直接调用 HK 的 `solve/cover`，输出最少操作数及 `1 行号`、`2 列号`。补齐旧匹配条目的覆盖方案应用，不需要抄独立集转换函数。

P3355 与 Coin Grid 均按应用登记，不冒充非比赛模板题。线上 AC、速度排名及线上资源结果仍未取得。

## 本地验证

`tests/independent_set_probe.cpp` 枚举左右各0..4点的所有简单二分图，对每张图用全部顶点子集直接求最大独立集，检查返回点号唯一/有序、无内部边、与cover互补，匹配互逆及匹配边实际存在。每图重复调用；另有300组随机增量重边图、独立对象复制和十万点长增广链/空侧。每种核心形式为160730次运行、10712448项检查。

`tests/independent_set.py` 对实际驱动、展开程序、仅复制声明依赖和关闭断言四种形式分别验证：309每种610个输入，310每种159个输入，311每种595个输入。骑士小棋盘独立枚举可用格子集，攻击边由绝对坐标差判定，不复用模板的黑白建图；覆盖所有1..3边长障碍配置和4/5随机棋盘。200×200空棋盘由4×2分块的骑士完美匹配给出20000上界，单色20000方案给出同值下界；另测整侧障碍和仅一格可用。硬币小方阵枚举行列点集求独立集，再得最少删除数；实际输出逐个检查操作编号、无重复以及每枚硬币被覆盖。通用接口逐边检查没有两端同时入选。

普通及ASan/UBSan分别执行16种程序形式，并以9个错误变体验证测试敏感性：遗漏求匹配、左右未取补集、遗漏末点、直接返回覆盖、错误骑士位移、将障碍当孤立点、交换独立集左右方案、交换硬币行列类型。原有匹配实现及原308个展开用法不变。本地递归栈配置512MiB；这些测试不构成线上AC或线上时间/内存通过。
