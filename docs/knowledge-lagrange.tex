\section{隐式生成函数与 Lagrange 反演}\label{knowledge-lagrange-inversion}
\index{Lagrange inversion}\index{隐式生成函数}\index{形式留数}\index{复合逆}
用于 $T=x\Phi(T)$ 只问 $T$ 或 $H(T)$ 某一项的情形；这里是\textbf{复合逆}，
不同于第~\pageref{compact-Lagrange}~页的点值插值。

\subsection{适用条件与取系数公式}
特征零域上形式幂级数，$\Phi(0)\ne0$（一般 $\mathbb Q$-代数中要求 $\Phi(0)$ 可逆），
$T(x)=x\Phi(T(x))$、$T(0)=0$ 唯一确定 $T$。对 $n\ge1$：
\[
\boxed{[x^n]H(T(x))=\frac1n[t^{n-1}]H'(t)\Phi(t)^n,}\qquad
\boxed{[x^n]T(x)^k=\frac{k}{n}[t^{n-k}]\Phi(t)^n\ (n\ge k\ge1).}
\]
边界：$[x^0]H(T)=H(0)$；$[x^n]T^0=[n=0]$；$k\ge1$、$n<k$ 时为 0。不要求解析收敛。

\subsection{模型一 按内部结点计数的满有序多叉树}
每个结点为叶子或恰有 $d\ge2$ 个有序孩子，按内部结点计数：$A=1+xA^d$，$a_0=1$，$n\ge1$ 时
\[
a_n=\frac1n\binom{dn}{n-1}=\frac1{(d-1)n+1}\binom{dn}{n}.
\]
孩子无序时不能用 $A^d$。用 \texttt{Binomial<p> c(d*n)} 须在宽类型中算 $dn$ 并保证 $dn<p$，
否则按第~\pageref{knowledge-binomial-choice}~页选组合数算法。

\subsection{模型二 带标号有根树的 EGF}
根的孩子无序：$T=x\exp T$，$r_n=n!\,[x^n]T=n^{n-1}$（$n\ge1$）；指定根时为 $n^{n-2}$（$n\ge2$）。
EGF 系数须乘回 $n!$。

\subsection{落到现有接口及模数边界}
\textbf{单个幂系数。}第~\pageref{compact-FpsPower}~页的 \texttt{FpsPower::power} 固定 $p=998244353$；
在 $1\le k\le n<p$、$L=n-k+1\le2^{22}$ 下：
\begin{lstlisting}
using F = FpsPower;
using Z = F::Z;
int l = n - k + 1;
auto q = F::power(phi, to_string(n), l);
Z answer = Z(k) * Z(n).inv() * q[n - k];
\end{lstlisting}
长度是项数（传 $n-k+1$），指数传完整十进制串。单次 $O(L\log(L+1)+\log(n+1))$、空间 $O(L)$；
对所有 $n\le N$ 逐个求为 $O(N^2\log(N+1))$。
一般 $H$：先算 $q=\Phi^n\bmod t^n$，答案为 $n^{-1}\sum_{i=1}^n iH_iq_{n-i}$。
第~\pageref{compact-FpsFunctions}~页的 \texttt{log}（首项 1）、\texttt{exp}（首项 0）可构造已知表达式，
不能解任意隐式方程；\texttt{Binomial<p> c(N)} 要求 $N<p$。
第~\pageref{compact-FpsInverse}~页的 \texttt{inverse} 是乘法逆，要求常数项非零，不能求 $f=t/\Phi(t)$ 的复合逆。

\textbf{模数。}在 $\mathbb F_p$ 中使用 $1/n$ 公式要求 $p\nmid n$，EGF 的 $1/j!$ 不能跨过 $j=p$；
否则改用无除法递推或提升精度后再整除。
