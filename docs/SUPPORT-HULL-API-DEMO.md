## 回调契约与完整调用

SupportHull 从支撑 oracle 重建严格下凸链，不是维护动态插入和任意方向查询的数据结构。点集必须固定、有限且非空；回调必须在整个点集上精确最大化 a*x+b*y，允许返回任意一个并列最大点。两端分别取最小和最大横坐标上的最低点；同一横坐标时仅留下最低点。空集由演示驱动提前处理，不调用 build。

自定义协议见 tests/fixtures/support-hull-demo/contract.json：0≤n≤2000、0≤q≤200000，点和查询方向坐标绝对值≤10^18，查询的 b≤0。先输出严格下凸链，再输出每次支撑值及字典序最小的最大点；空集输出 EMPTY。不承诺原点编号或向上方向。

演示扫描全部原点作为 oracle；链上值在限定方向下单峰，二分第一个最大顶点，覆盖支撑边、水平及零向量并列。显式点云通常直接用单调链更合适，本例重点是隐式可行集合的 oracle 适配，而非更快的显式凸包算法。

若递归进行了K次严格分裂，则回调次数为2K+1。K可能包括最终被删除的共线支撑边点，不能直接等同于最终顶点数。当前扫描回调给出O(n²)构造、O(n)存储及递归空间，查询总O(q log(max(2,n)))；需要相应递归栈。

生成方向每坐标≤2×10^18，回调点积≤4×10^36，叉积及其保守中间界≤8×10^36，均使用signed int128。查询结果绝对值≤2×10^36，故本例负数打印取反安全；它不是通用INT128_MIN打印器，也不扩大为完整signed64点域契约。
