# 矩阵树的公司容斥与消息传播应用

本批对应附件3.7引用的P4336和P4455，复用现有素数模行列式与矩阵树，不新增重复算法组件。两者登记为application用法427、428，不冒充独立模板题。正式题面：[P4336](https://www.luogu.com.cn/problem/P4336)、[P4455](https://www.luogu.com.cn/problem/P4455)。

## P4336：每家公司恰好一条边

设公司数k=n−1。允许使用公司集合S时，将各公司的边都加入多重图，以矩阵树求生成树数T(S)。不同公司即使提供相同端点，也必须作为不同边保留：题目将不同公司分配视为不同方案。

答案为Σ_S (−1)^(k−|S|) T(S)。一棵具体的公司带标记生成树若使用了公司集合C，其系数为Σ_{S⊇C}(−1)^(k−|S|)，仅C为全部公司时等于1，否则为0。生成树恰好有k条边，使用全部k家公司就等价于每家公司恰一条。n≥2时T(空集)=0，可以跳过空集。

代码固定删去最后一个顶点的行列，以Gray码枚举公司集合；相邻集合只变动一个公司，对它的每条边增减拉普拉斯贡献。行列式函数按值接收矩阵，不得move掉后面还要增删的lap。模数1000000007，2≤n≤17，每家公司内部没有重边或自环；时间O(2^(n−1)n³)，空间O(n³)，其中输入边存储占主要空间。

## P4455：沿“关注”方向走向根

输入a b表示a看到b的消息，故a选择从b转发时，父边是a→b。每个非根点恰选一个父亲，且沿父边最终到达初始发布者1，正是以1为根的内向树。因此保持输入方向，用toward_root；它与消息实际流动方向相反。若误用away_from_root，链2→1、3→2就会被错判为0。

模数10007为素数，点数至多250，时间O(n³+m)，空间O(n²)。代码按朋友关系去重并忽略自环：同一关注关系反复输入不产生新的来源选择。题面未明确给出重复关系和自环的合法性，相关测试仅验证此约定，不扩张题面保证。n=1,m=0作为空树返回1的扩展；题面的m下界与n=1相矛盾。算法统计父亲选择形成的结构，不统计时间顺序。

## 验证与边界

`tests/matrix_apps.py`直接运行完整输入输出驱动，真值不使用行列式。P4336的209组小例逐公司选边，以独立连通性判断是否成树；含空公司、不同公司相同端点、全部公司都提供完全图。n=17的完全图答案用17^15·16!，另测一个公司为空的零答案。

P4455的4265组小例逐非根点枚举朋友并沿父指针检验是否到达根，包含1–4点全部有向简单图，以及重复关系、自环的约定测试。250点完全有向图用Cayley公式250^248 mod10007校验。普通构建及ASan/UBSan结果、最大规模本机耗时和源文件哈希见 `verification/matrix-apps.json`；这些耗时不是在线排名。手册用法的展开版本另由 `tests/usage_examples.py`校验；`tests/matrix_apps_copy.py`仅拼接手册列出的ModInt、det_prime、MatrixTree必要片段和用法，普通及ASan/UBSan均通过，未依赖整份头文件的额外符号。
