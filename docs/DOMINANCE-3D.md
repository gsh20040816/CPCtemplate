# 静态三维弱偏序

`Dominance3D::count(points)` 接受 `vector<array<long long,3>>`，返回与输入顺序一致的 `vector<int>`。第 i 项是满足 j≠i 且三个坐标都不大于第 i 点的输入点数。重复坐标是不同输入位置，不会被忽略；空输入返回空，单点返回0，输入不会被修改。

完整 signed64 坐标只参与比较，不做减一、差值或变号。n≤INT_MAX/2 且分配可行是接口前提：这既让计数和组大小不溢出，也保证共享 Fenwick<int> 的 `x += x&-x` 最后一次跳出仍在有符号 int 范围内。不能只写 n≤INT_MAX 而忽略这一步。Fenwick 本身未作修改。

时间 O(n log²(n+1))，额外空间 O(n)，递归深度 O(log(n+1))。内部完成第三维压缩和所有初始化/回滚；调用者无需传 k、排序或清理。这里只提供静态、无权、三个弱不等号；动态事件、混合严格关系和加权值域要另行设计。

## 为什么必须处理平局

1. 先按完整三维字典序排序，而不只是第一维。若不同坐标的 p 逐坐标≤q，那么 p 的字典序一定在 q 之前；当第一维相等时，后两维仍保证这个方向
2. 合并完全相同的坐标，保存 multiplicity=w。来自其他组的贡献统计完成后，每个该组成员再加 w−1，恰好排除自身而保留同位置的其他输入
3. 每个组保留稳定 ID，另存每个原输入位置对应的组 ID。CDQ 的 y 归并会重排工作数组，但答案按稳定组 ID 累加，最后恢复原输入顺序

若只把重合点去重却不保留数量，或者只在排序后原位输出，都会改变接口含义。

## CDQ 不变量与证明

递归最初的字典序位置区间。每次返回时，该区间仍由相同的点组组成，已经按 y 排序，而且 Fenwick 恢复到进入前的零状态。

对左右孩子先分别完成递归；合并时按右侧 y 递增枚举。把左侧 y≤当前 y 的整段权重插入 Fenwick，再查询压缩 z 的包含端点前缀和。第一维条件已由初始字典序划分保证，其余两维分别由 y 扫描、z 查询保证。每个不同坐标的合法点对恰在唯一一个将二者分到左右孩子的递归节点被计算一次。

当前层结束前只撤销真正插入的左侧前缀，随后完成 y 归并。未插入的左点不可撤销；撤销必须使用同样的 multiplicity。临时数组只分配一次，不在每层建立新的节点容器。

这里用的是静态且彼此独立的点权，所以顺序为左递归、右递归、跨区间统计。已有 `cdq_convolution`/P4721 的递推值有依赖关系，需要左递归、转移、右递归，不能把两种时序互换，也不能把卷积模板计为三维偏序覆盖。

## 正式题与构造例子

[洛谷 P3810](https://www.luogu.com.cn/problem/P3810) 的官方标题与背景明确标注模板题：n≤100000，三个正整数坐标≤k≤200000，输出每种被支配次数的点数直方图。库压缩坐标，所以驱动读取 k 后不用于分配；库的空输入、负数与 signed64 极值属于单独 API 扩展。

自行构造的五点例子（不是官方样例）：(1,1,1) 两份，另有 (1,2,1)、(2,1,2)、(2,2,2)。原序计数为 [1,1,2,2,4]，输出直方图为 [0,2,2,0,1]。

当前读取的官方正文未暴露样例块，不把自造输入称为官方样例。线上 AC、最快排名、官方隐藏数据和独立官方判题器都不在本地验证声明中。

## 本地验证分层

核心以 Python 的双重循环、三个直接≤比较及 j≠i 为独立参考，不复制 CDQ 排序、分组或 Fenwick。覆盖小立方体全部有重复多重集、顺序打乱、相等坐标、完整 signed64 边界和随机集合；另做轴置换、严格递增坐标重标记、输入置换和复制倍数恒等式。

大实例使用链、反链、全部重合、三维整数网格及重复网格的闭式计数，并包含全宽整数坐标。头文件/最小复制及断言/NDEBUG 四种形式检查重复调用、空调用穿插和输入不变。

完整 P3810 驱动、打印展开和最小复制使用满足正式约束的独立点集与直方图校验。目标错误变体包括严格 y/z、忽略权重、漏排除自身、漏回滚、只按 x 排序和原下标错置；其中另设插入/撤销都用±1与错误散射两个更单一的错误。

普通和 ASan/UBSan 结果分别绑定实际源码、编译器、输入、输出及二进制哈希。LSan 关闭。复制语法、实际PDF检查与全套回归分别记录，不用其中一项冒充其他项。
