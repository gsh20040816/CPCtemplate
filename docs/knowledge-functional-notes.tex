\section{函数图的入环链与到达查询}\label{knowledge-functional-graph}
代码见第~\pageref{compact-FunctionalGraph}~页。
接口 0-based：题目 1-based 时构造减 1，只有跳转返回的顶点加 1；最少步数的 0 与不可达的 $-1$ 原样输出。

每个弱连通分量是一个环加若干指向环的树。入度剥离后剩下环点；反向处理剥离序列即可得到环编号、入环点和入环距离。
跳转 $k$ 步：$k$ 小于入环距离时倍增，否则先到入环点，余步对环长取模；$k$ 可达无符号 64 位上界，倍增表 $O(\log n)$ 层。
$u$ 到 $v$ 最少步数：环编号不同则不可达；$v$ 在树上时要求 $\mathrm{depth}(u)\ge\mathrm{depth}(v)$ 且跳深度差恰到 $v$；
$v$ 在环上时为 $u$ 的入环步数加环上顺向距离。不可达返回 $-1$，自身为 0。
position 只对环点有意义，树点为 $-1$。

\section{杭州 2023 H：随机事件顺序与函数图}\label{knowledge-hangzhou-h}
QOJ8237。事件 $u$ 的目标 $v=b_u$：$a_u<a_v$ 必成功，$a_u\ge a_v+w_v$ 必失败，
否则 $u$ 成功当且仅当 $v$ 更早执行且成功。确定事件的后继改为自身。
到达确定失败终点或纯依赖环（含自环）则概率为零；到达确定成功终点、入环距离 $d$ 时概率为 $1/(d+1)!$，
期望 $a_u+w_u/(d+1)!$，模 $10^9+7$。依赖不可当作独立的 $1/2$。
$\sum n\le500000$，阶乘表跨组只扩不缩；用通用函数图时 $O(n\log n)$ 时间与空间。

\section{杭州 2023 G：开放时间的单位边最短路}\label{knowledge-hangzhou-g}
\label{app:hangzhou2023g}
\index{开放时间最短路}\index{贪吃蛇}
QOJ8236。初始蛇身从头到尾编号 $0,\ldots,k-1$，第 $i\ge1$ 节所在点开放时间为 $k-i$（尾格为 1），其余为零；该限制必要且充分。
转移 $d_v=\max(d_u+1,\mathrm{open}_v)$。按距离递增处理时首次发现即最优：
候选等于 $d_u+1$ 的入 FIFO，其余入开放时间桶，每次取两者较小者；桶指针只扫到下一个 FIFO 距离。
$R=\max\mathrm{open}$，时间 $O(V+E+R)$，空间 $O(V+R)$。仅适用于所有边权为 1；一般非负权用优先队列。
答案用 unsigned long long 累加距离平方（模 $2^{64}$）。
