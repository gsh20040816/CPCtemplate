# WIDA 10 立体几何 Point

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `4acee66bdb971659f99ec1a83ff8c836d66957c8`，路径 `03 - jiangly模板收集/03 - 数论、几何与多项式/10 - 立体几何（Point）.cpp`。

坐标类型是 `double`。`i64` 只被声明，运算符没有使用它。加减、数乘和数除按分量进行。`(1,2,3)+(4,-1,2)` 是 `(5,1,5)`，`(1,2,3)-(4,-1,2)` 是 `(-3,3,1)`。点积是对应坐标相乘再相加，`(1,2,3)` 与 `(4,-1,2)` 的点积是 8。叉积按行列式展开，`i × j = k`。`(3,4,12)` 的长度是 13。`(0,3,4)` 归一化后是 `(0, 0.6, 0.8)`。

`getAng(a, b, c)` 用余弦定理求边 `c` 所对的角。`3, 4, 5` 得到直角。零向量归一化会除以 0，三个坐标都是 NaN。这不是整数精确几何，也没有覆盖共面、共线的判定。

在包含 `<complex>` 并且 `using namespace std` 的翻译单元里，`real` 会和 `std::real` 冲突。原稿单独编译没有这个问题。

`python3 tests/wida_point3d.py` 在普通 `-O2` 和 ASan/UBSan 下通过这些例子。QOJ 提交页面没有打开，没有新的在线 AC，也没有新增模板。来源保持 partial。
