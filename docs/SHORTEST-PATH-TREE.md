# 最小总边权最短路树与零权连通块

`ShortestPathTree`接受无向非负权图。它在保留源点到全部可达顶点最短距离的前提下，最小化所选树边权值之和，不能用普通最小生成树替代。断开图只覆盖源点所在连通块。

点号1..n，0<n<INT_MAX；add(u,v,w)自动加入双向邻接，返回0-based无向原边号。支持自环、重边、0≤w≤LLONG_MAX、总边数≤INT_MAX。run(s)返回可达顶点数量，包含s本身，并重置全部状态；add令valid=false，须重新run后读取结果。

成功运行后dis为int128最短距离、inf表示不可达；ids为选中无向原边号，weight为最小总边权。path(v)返回从s到v的正向无向原边号，按当前顶点判断边的使用方向。根的零边路径和不可达点都返回空，结合dis区分。pre记录父边号，根与不可达点为−1；并列任选，不承诺字典序。对象可独立复制，成员只读，zero/dfs和bel/tree为内部辅助。

## 为什么要单独处理零权块

Dijkstra先求距离。无向零边连接的两点距离相同；从可达点沿零边走，仍然可达。递归划分这些零权连通块，顺便选一棵零权生成树。

把满足dis[u]+w=dis[v]的边按u到v定向，称为紧边。不同零权块之间的紧边权值严格正，故沿紧边距离严格增加。对每个非源点块，选权最小的一条紧入边；块内选好的零权树与这些入边合并。每个非源点块必有入口：取任意最短路首次进入该块的边即可。沿所选入口反向追溯时距离严格下降，最终到达源点块，因而结果连通无环。若可达顶点有r个，内部零边共r−块数条，外部入口有块数−1条，合计r−1条。

每条选边都沿源点方向保持最短距离，所以得到最短路树。任意最短路树进入每个非源点零权块时至少使用一条紧入边，其边权至少为该块最轻入口权；其他边权非负，因此所有最短路树都有“各非源点块最轻入口之和”的下界。本构造恰好达到该下界，故总边权最小。仅逐点选最轻前驱会在零权环内互相选择，不能代替按块处理。

最后对选出的树做递归DFS确定父边，保证path与ids描述的是同一棵树。零权块DFS和树DFS最坏深度均O(n)，保持递归，不改写为模拟栈；调用方保证足够栈空间。

Dijkstra严格改善才入队，每条有向邻接至多引起一次改善，堆中条目O(m)。总时间O(n+m log(m+1))、空间O(n+m)，单次path与输出边数成正比。有限最短路径和总树权均至多(n−1)·LLONG_MAX<2^94，松弛候选至多n·LLONG_MAX，int128足够，inf=2^126不会与有限值冲突。输出所有顶点的完整路径可能需要O(n²)输出，API不保证线性打印成本。

## 来源差异与可复现反例

核对WIDA固定提交cfdb12db6792eb2303798541fb5c760ed2bc618b，`02 - 打印稿模板汇总/03A - 图论.md`的“最短路径树（SPT问题）”。该来源使用≥覆盖前驱，并以端点对map保存编号和边权；本实现保留全部原边编号，不照搬这两处行为，并额外支持最小总树权。

`verification/shortest-tree-source-counterexamples.json`记录了原流程的Python适配复现（明确不是逐字编译原C++）：

- 三角形1−2、2−3、3−1均为零边，源点1。等距覆盖使前驱形成环，来源DFS输出零条边，未覆盖另外两个可达点；正确树应有两条零边。
- 两点之间依次输入权1、权5的平行边。最短距离为1，但端点map保留第二条边的编号和权5，来源输出的方案不是最短路树。

新核心对上述范围另行验证；CF545E题面只有正权且无重边，不能凭该题通过推断零权与重边正确。

## 完整用法

用法307：[Codeforces545E](https://codeforces.com/problemset/problem/545/E)。给定连通无向正权图及源点，输出最小总树权和任选一组树边。n,m≤300000、1≤w≤10^9，原题没有自环和重边；总树权≤299999000000000，long long足够。模板原编号从0开始，输出加1。它是竞赛应用，不计正式非比赛模板题覆盖。

用法308是完整非负signed64、零权边、重边和断开图的API演示：首行输出可达数、int128总权、树边数量和原边号，随后逐点输出INF或距离与原边路径。每条无向边只调用一次add，避免误加两份。API演示同样不计正式模板题。

## 本地验证

`tests/shortest_path_tree_probe.cpp`枚举n≤4无向简单图每对点的无边/0/1/2四种状态，遍历所有源点；参考用同步Bellman-Ford求距离，再枚举全部r−1条原边子集，通过独立连通性和树上距离检查找出最小总树权，不复用Dijkstra或零权缩点。另有300组逐次加边的n≤6多重图，覆盖自环、断开图、换源点、重复运行、加边失效和复制隔离。每份核心形式24687次参考运行、451120次检查。

头文件/最小抄写×assert/NDEBUG共四种核心形式均通过普通与ASan/UBSan，并检查300000点LLONG_MAX链、300000点零权链的递归处理及完整端点路径。程序测试使用512MiB本地栈，这是Darwin本地设置，不代表在线资源限制通过。

`tests/shortest_path_tree.py`对driver、展开程序、最小依赖抄写、NDEBUG四种完整程序形式分别运行应用105份、API105份输入。包括300000点300000边正权环、星形带额外轻边（区分最短路树与MST）、300000点零权星形且源点取末尾。检查器接受任意最优方案，核验原边集合、可达点覆盖、树上最短距离与独立最优总权；API路径必须只用首行选出的树边。
