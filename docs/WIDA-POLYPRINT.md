# WIDA 打印稿：多项式

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `5ccf93566b4e7dce4235e81c670c08a32ffa863b`，路径 `02 - 打印稿模板汇总/07 - 多项式.md`。

多项式封装依赖不在这段里的 `MInt`、`power` 和 `CInv`。用一个本地的取模类型后，`(1+x)^2` 是 `1+2x+x^2`，`1+2x+3x^2` 的导数是 `2+6x`，`1+2x` 的积分是 `x+x^2`。`1+x` 的前 4 项逆元是 `1-x+x^2-x^3`。`log(1+x)` 和 `exp(x)` 的前 4 项与幂级数一致。`(1+x)^3` 是 `1+3x+3x^2+x^3`，`x^2` 截到 4 项是 `x^2`，`sqrt(1)` 是 1。空多项式相乘仍是空的。长度 128 的乘法与直接相乘一致，说明这里的 NTT 路径在这个例子上可用。

`eval` 把 `resize` 的返回值传进递归。`resize` 返回 `void`，原程序不能编译。先把结果拷出来再改长度，`1+2x+3x^2` 在 2 和 3 处是 17 和 34。

Berlekamp–Massey 这一节的标题写成了杜教筛，代码并不是杜教筛。它使用 `assert`。这份标准库的 `bits/stdc++.h` 不提供 `assert`，实例化时要另加头文件。补上头文件后，斐波那契前缀 `1,1,2,3,5,8,13,21` 得到 `1-x-x^2`。线性递推对 `x/(1-x-x^2)` 的第 10 项是 55。

快速傅里叶变换和快速数论变换都只在构造函数里做正变换，没有把乘法封装进去。构造函数还分别要求非 const 的 `vector<int>`、`Z`、`mod` 和 `LL`。手动做点值相乘再做逆变换后，`(1+2x)(3+4x)` 都是 `3+10x+8x^2`。

拉格朗日这一段求的是 `1^n+...+k^n`，不是任意点插值。它要求 `Z` 有二元 `power`、`inv`，并且能从 `long long` 减去。`n=2` 时，`k=3` 得到 14，`k=5` 得到 55。符号用了 `std::pow`，这个例子的结果仍然是整数。

常用结论里有两处笔误。广义二项式写成了 `\binom{n}{\alpha}`，卡特兰数的分母根号写成了 `n-4x`。这两节没有可执行代码。

`python3 tests/wida_polyprint.py` 在普通 `-O2` 和 ASan/UBSan 下通过上面这些例子。没有新的在线 AC，也没有新增模板。来源保持 partial。
