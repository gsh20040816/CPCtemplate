# 圆方森林与桥缩点的完整用法

使用代码165–167。核心模板未改，只有一套vector/STL码风，算法DFS保持递归。

## 题意及接口

- [P4630 铁人两项](https://www.luogu.com.cn/problem/P4630)：无向简单图可不连通，n≤100000、m≤200000。统计有序三元组(s,c,f)，存在某条经过c的简单s-f路径，三点互异。同一三元组的多条路径只算一次。`block_cut_forest`需先`run`，原点1..n，块i的方点是n+i+1。原点权-1、方点权为块大小。对不同原点s、f，树路径上各块并集恰好是可能经过的原点集合；内部割点减一次去重、端点各减一次排除。把路径权和按节点贡献累加即得答案。单个点双内指定三个不同点可安排在所需简单路径上，可由点双的两条内部点不交路径性质推出。
- [P2860 Redundant Paths G](https://www.luogu.com.cn/problem/P2860)：连通无向图，n≤5000、m≤10000，已有边/新增边均允许重边。最少新增边使任意两点间有两条边不相交路径。`bridge_component_forest`邻接项为(边双号,原桥号)，边双号1..cnt、原桥号从0开始。叶子数L给出答案ceil(L/2)，只有一个边双时L=0。此公式依赖连通前提。
- 同题另一用法调用`bridge_augmentation`得到最优补边端点，端点为原点号1..n；题目只输出方案长度。接口不修改图。调用者可以遍历结果输出方案，或自行add后run。原图非空且连通、允许新重边是接口前提。

三项都是比赛应用，不能借此增加正式模板题覆盖；P2860仅检查方案长度，完整端点与桥号由单独接口测试验证。

## 局部贡献及复杂度

P4630用两次递归遍历：sz只计原点，得到当前树原点总数C，再算节点贡献。删去u后各支的原点数为a_i，经过u的有序不同原点端点对数量为`2*sum(i<j,a_i*a_j)+2*(C-1)*(u<=n)`。父侧为C-sz[u]，子侧为sz[v]，前缀累加可线性计算两两乘积。原点作为端点的贡献不可遗漏。每个连通分量使用各自的C，孤立点贡献0。答案最大n(n-1)(n-2)，所有乘积和答案用64位有符号整数。总时间空间O(n+m)。

补边构造按DFS叶子序列对半配对；奇数个叶子复制首叶。每条桥切出的叶子集合是环形序列上的真区间，配对不可能全留在区间内，所以每条原桥均被新增边跨越。每个叶子至少需一个新边端点，ceil(L/2)为下界，构造达到下界。构造和桥树算法均O(n+m)。
