# DAG支配树：拓扑序与倍增LCA

`DagDominator` 补充 issue #11 附件中 DAG 上的专用构造。一般有向图仍使用既有 `DominatorTree`；新模板不修改其实现，也不把原有验证记录归给新程序。

## 使用约定

`DagDominator(n)`，1≤n<INT_MAX，点号1..n。`add(u,v)`允许重边；端点须在范围内，每点入度能用int表示。加边后旧结果失效，须重新build，结果数组只读。

`build(root)`首先检查全图是否无环：任何分量的环或自环都使其返回false，idom、dep、up、order同时为空。不可把false当作“从root没有可达点”，也不能使用失败前的旧结果。图仍保留在g中，可交给通用LT算法。成功后可反复换根重建。

成功时 `idom[root]=root`，不可达点idom=dep=0；其余idom为直接支配点。`order`是包括不可达点在内的全图拓扑序。根的深度为1，up[k][u]为支配树上2^k级祖先，根的祖先仍为根。`lca(u,v)`只用于已经成功构造的可达点；额外允许0表示空累积，lca(0,v)=v、lca(0,0)=0，不能把任意不可达点编号当作0使用。

时间O((n+m)log(n+1))，空间O(nlog(n+1)+m)。这里的拓扑队列是Kahn算法本身，不是把DFS改成显式栈。通用LT保留递归DFS。只要已知题目是DAG，赛时只抄DagDominator；通用题的组合示例才同时使用LT。

## 构造理由与边界

固定入口r，只对r可达的点定义支配关系。对非根可达点v，其严格支配点集合等于所有可达前驱u的支配点集合交集；v自身不属于这些前驱的支配点集合，因为图无环。前驱的支配点恰为已构造支配树上根到u的一条祖先链，这些链的交集末端就是前驱们的LCA。

按拓扑序处理时，所有可达前驱都已构造。新代码把每个已处理点沿出边贡献给后继的候选父亲，相当于扫描反图合并前驱，但省去了另一份邻接表。重边只会重复取相同的LCA，不改变结果；不可达点直接跳过。根可能有来自不可达点的入边，这些边不应修改根的自指父亲。可达点不可能有到根的入边，否则产生有向环。

例如边1→3、2→3、3→4，以1为根时，2不可达，idom[3]必须为1。把2也并入前驱LCA是错误的。另一个陷阱是只检查可达分量的环却声称“全图是DAG”；本接口明确检查全图，连不相干分量的环也会拒绝。

多入口问题应先根据题意添加虚拟根并向入口连边，随后求单入口支配树。不能在普通指定root的图中擅自向所有零入度点加边，那会改变哪些路径合法。

## 来源与题目分类

issue #11附件印刷20页给出DAG前驱LCA构造的文字说明，19页为支配关系引理，21页转入LT；本轮已逐页目视检查。该处没有可直接运行的DAG来源程序，因此没有伪造“完整原程序对照”记录。实现按上述不变量独立组织，保留原附件和OI Wiki的出处。

[OI Wiki支配树](https://oi-wiki.org/graph/dominator-tree/)也描述DAG的前驱LCA方法；页面默认入口能到达所有点。本接口显式扩展不可达分量的处理，论证里的“前驱”只指可达前驱，且严格支配的交集关系仅针对非根点，避免不带前提照搬概述。

- 用法338为纯DAG API：输入n,m,root与边，环时输出−1，否则输出idom（不可达0）。
- 用法339为[Library Checker dominatortree](https://judge.yosupo.jp/problem/dominatortree)正式模板题的组合程序。先试DAG算法，非DAG时把g移交LT；全程使用题面0-based输入输出转换，不可达输出−1。题目允许环，所以不能用纯DAG程序冒充完整解法。两条路径分别测试，不沿用旧程序的线上记录。
- 用法340为[P2597 / ZJOI2012 灾难](https://www.luogu.com.cn/problem/P2597)竞赛应用。官方图保证无环，食物向消费者连边；每行列出消费者的食物，0结束，n≤65534，输入小于1MB。给每个无食物的生产者连虚拟根n+1，它不会灭绝。生物u额外导致的灭绝数量为其支配树子树大小减一。先逆全图拓扑序向idom累加，虚拟根不向自己累加。

应用正确性也可直接按食物网拓扑序归纳：一个未被主动删除的生物存活，当且仅当至少一条从某个生产者通向它的路径没有经过被删除生物；生产者由虚拟根统一供给。因此删点后不可达与连锁灭绝等价。程序读入时按第一项是否为0区分生产者，不把暂时没处理到的消费者误当生产者。

## 验证范围

`tests/dag_dominator.cpp`枚举至6点的全部拓扑边子集，并对每个起点检查；点号打乱，避免按编号顺序的错误侥幸通过。另含随机DAG、多重边和任意含环图。独立删点BFS判定每一对支配关系；传递闭包对角线判断全图有环；据支配关系检查父亲、深度、LCA和逆拓扑累加结果。每个图在同一对象上换根重建；成功后添加自环，检查失败会清除旧结果。

20万点逆编号链检查高层倍增与任意根；正式组合程序另含20万点带自环星图，保证实际走LT回退。P2597使用逐轮灭绝的独立不动点模拟，并覆盖65534点链。头文件、NDEBUG、实际展开和手册最小复制四种用法均分别编译运行，普通和ASan/UBSan模式各一轮。

故障变体覆盖只保留最后前驱、把不可达前驱当可达、遗漏全图环拒绝、未初始化根。所有测试都是本地证据，不是线上AC或速度排名；P2597也不计入独立模板题覆盖。
