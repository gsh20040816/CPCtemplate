# 附件最大流与两种最小费用流

核对 issue #11 附件实际 26–28、37–41 页，覆盖 2.4、2.8.1、2.8.2 的实际代码。
最大流保留 Dinic；势能版保留 MinCostFlow；新增独立的 SpfaFlow，不把方法不同的变体直接归并成已覆盖。

## Dinic 与方案

附件是 BFS 分层加递归 DFS、当前弧的 Dinic，没有额外的特殊网络假设。
本库点号 1..n，边表成对存放；add 返回偶数原边号，id^1 是其残量反边。
两个不同的原有向边即使方向相反也各有自己的反边，不能合并成一个残量对。
自环同样可按这一边编号方案加入，分层增广不会沿自环前进。

flow 返回本次新增流量。限流后再调用须使用同一源汇；只有不存在增广路时，cut 才是最小割。
used/get_edge 输出方案；change_edge 只保证一对残量边一致，调用者仍需维护全图流量守恒。
构造器清空全部 vector；附件空构造器或只设置 n/m/s/t 的构造器不清 head/total，
不能把“全局对象恰好零初始化”当作局部、多测构造也安全。

当前实现一般复杂度 O(V²E)，递归深度 O(V)，未把 DFS 改为显式调用栈。
总流容量须在 long long 范围；[P3376](https://www.luogu.com.cn/problem/P3376) 单边小于 2³¹，
但最大流可以超过 int，完整驱动仍用 long long。

本次重跑 tests/flow_edges.cpp：6000 组图在增容、限流续流和全部重置后缩容时枚举所有割，
同时核对流量守恒、边界、自环、反向/平行边、最小割及 LLONG_MAX 容量。
完整 P3376 驱动另测 200 组 Python 大整数割枚举和 200 点/5000 边闭式，双模式通过。

## 势能 Dijkstra

附件 37–39 页初始 h 为零，没有 Bellman-Ford/SPFA 初始化，因而依赖原边费用非负。
这满足当前 [P3381](https://www.luogu.com.cn/problem/P3381) 的非负容量/费用约定，
不能据此宣称可直接接受任意负边。其 int 费用总和也依赖该题答案界。
现有 MinCostFlow 在全部顶点上初始化可行势，支持无负环的负边；距离和费用均用 int128。
最短路后的势只更新可达顶点，下一轮从同源点出发的可达子图不会产生负的约化费用；
重新调用先重建全局势，不能以旧的可达集合盲目复用。

最小费用流的逐边流量是最终方案，不等于按先后增广路径统计。
测试特设 1→2→3→4 的 -5 费用路径先送一单位，随后通过 3→2 反边撤销 2→3，
第二次新增费用为 +5，最终两单位总费用为 0。两版都检查该原边 used 从 1 回到 0。

## SPFA 备选

SpfaFlow 每次增广直接在残量图上用队列松弛，不使用 Dijkstra，也不把 SPFA 仅用于势初始化。
接口为构造、add、flow、used，容量 long long、距离/费用 int128。
点号 1..n；shortest 为内部函数，参数 0 仅表示把所有实际顶点以距离 0 入队。

每次 flow 开始先执行全点 SPFA，检查不可达部分在内的所有残量负环。
这是最小费用可行流的必要前提：与源汇不相连的负环也能改善费用，不能忽略。
计数 len[v]=len[u]+1 记录导致本次严格改进的路径边数；达到 n 说明存在负环，抛 invalid_argument。
不是把“某点被松弛了 n 次”误当负环。初始化检查不改变容量；拒绝后原流量仍可读取。
没有负环时，最短残量路增广保持当前流量下的最小费用性，并不会产生新的负环。
零费用环不引起严格下降，因此不会因同距离反复改写前驱。

返回的是本次新增流量及费用；limit=0 合法，但仍检查全局负环。
重复调用须保持同一源汇和合法的最小费用残量状态。初始容量非负，cost 不能等于 LLONG_MIN，
因为反边要取 -cost。要求总流≤LLONG_MAX 且 Σ(cap×|cost|)<2¹²⁰；总费用不能转换为 long long 输出，
除非题目另有更小的保证。P3381 恰好保证流量和费用均≤2³¹-1，其示例因此可直接转换。

若实际增广 A 次，时间 O((A+1)VE)，空间 O(V+E)。A 不能用点数代替，SPFA 最坏会退化；
通常优先势能 Dijkstra。这一版用于保留附件中直接易抄的队列增广算法，不承诺比势能版更快。
允许负环的任务仍应使用单独的负环费用流模板，不能禁用检查后硬跑本版。

## 独立证据

tests/spfa_flow.cpp 对 4000 个小图枚举每条原边的所有可能整数流量，用 cpp_int 求每个可行总流量的最小费用。
随机图由非负约化费用加顶点势构造，含负边、自环、平行边与零容量，保证全图无负环。
SPFA 和势能版分别与此参考比较；不仅互相比较。
逐边检查容量和反边关系、顶点守恒、方案费用；检查零限流、续流、耗尽、反向撤销。
另外验证连通及不连通的 1/2/5 边负环、LLONG_MAX 容量、长链负边、距离及总费用超过 64 位。

势能 slope 原测试的 5000 组全流量枚举和每个整数流量的插值核对也重新双模式通过，
保证曲线中间点不是只由“终点正确”间接推断。
P3381 的 flow/slope/SPFA 三个完整驱动各做 200 组独立可行流量枚举，
以及 5000 点/50000 边的 1000 次增广、逆序长链和 50000 条正容量边的 DAG（拓扑最短路独立参考）；普通及 ASan/UBSan 全部通过。
例子 127 原样展开后双模式通过，目录、用法和页码从源码生成。
报告见 verification/flow-attachment.json。均为本地验证；没有新增线上 AC，也未给 SPFA 冒用旧势能版 AC。
