# Lyndon 分解

Issue #15，函数 `lyndon`；用法372为正式模板题 P6114，用法373输出完整字节串分解。

## 接口和抄写

输入 `const string &s`，返回 `vector<int>` 右端点。因子是半开区间 `[0, ends[0])`、`[ends[i-1], ends[i])`；这个数值也是1-based闭区间右端点，P6114直接异或即可。单个函数，无需维护结构体状态，也不复制各因子子串。

按无符号字节0..255比较，支持零字节和高位字节；不解释Unicode码点。输入长度≤INT_MAX，空串返回空数组；输入不变。预留n个int，最坏空间O(n)，扫描工作空间O(1)，时间O(n)。只有少量因子时仍预留n的容量，这是为了避免最坏n个单字符时反复扩容。全相同串的分解有n个单字符；周期串的相等因子不能合并成非Lyndon串。

## 为什么正确

Lyndon因子严格小于它的每个非空真后缀，所有因子依次非递增。此分解唯一。扫描从i开始，j是待加入位置，k指向当前重复模式内的比较位置。相等时继续匹配；新字节更大时，已扫描段可作为新的Lyndon候选，k回到i；新字节更小时停止扩展。

停止时长度j-k是已确认的Lyndon因子长度，连续输出完整重复块，直到i越过k。剩下不足一块的尾部留给下一轮扫描。边界必须是i≤k：只写i<k会漏掉最后一块，甚至无法前进。输出块满足后缀最小性，下一块不会比上一块大，因此得到唯一分解。

每轮输出的总长度至少等于一块长度，未输出的扫描尾部短于一块；因此一轮扫描长度不到本轮前进长度的两倍。总前进长度为n，扫描与输出均为线性。这里没有递归或模拟DFS栈。

## 验证范围

题面和定义参考：[P6114](https://www.luogu.com.cn/problem/P6114)、[OI Wiki](https://oi-wiki.org/string/lyndon/)。P6114明确为模板题，输入小写串，1≤n≤5000001；页面时间限制300ms、内存500MB。两组官方样例分别输出3、23。

`python3 tests/lyndon.py` 与 `python3 tests/lyndon.py --sanitize` 运行头文件、NDEBUG、完整展开和最小依赖抄写版。核心穷举长度0..9的三字节字母表，共29524串；另外3000组长度≤24随机字节串。独立真值直接枚举切点，逐个比较因子与全部真后缀，再限制因子非递增，并验证解的唯一性；比较完整端点数组，不只比较异或。

长度5000001的全相同串、单个长Lyndon串和交替周期串检查每个端点。驱动另有官方样例、100组小串暴力和相同规模压力；字节API覆盖空串及高位字节。错误变体分别破坏相等比较、unsigned char比较和端点，须被检出。字节比较变体用-fsigned-char强制复现，避免测试依赖宿主默认char符号。

本地收据为 `verification/lyndon-normal.json`、`lyndon-sanitizer.json`。在线结果与性能排名另行记录；本地通过不能代替OJ AC。

实际 [AC 302332529](https://www.luogu.com.cn/record/302332529)：C++20 O2，100分、20 AC，页面总计251ms、最慢单点38ms、峰值24.75MB。当前最小抄写版与上传归档逐字节一致，SHA-256为`c60034a426878efca3b89a1dc4a68a55c272f011e463bed61c4efb84cb3e6006`。未核验速度排名；该题只覆盖非空小写字符串的端点异或。
