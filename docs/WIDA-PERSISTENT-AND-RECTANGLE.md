# WIDA 持久化来源审计与静态矩形求和

本批新增一个组件并扩充一个现有接口：322 个组件、436 份完整用法。

## 严格前驱

`PersistentWeightedIndex::last(before,after,key)` 返回计数版本差中严格小于 key 的最大位置，无结果为 -1。与已有 first 的 >=key 边界互补，不做 key-1，因此 INT_MIN/MAX 阈值合法。与 first 相同，要求每个位置的 after-before 计数非负；任意两个历史分支不自动满足这个条件。查询按 count 判断，负权或零权不会影响元素是否存在。查询 O(log(n+1))，不分配节点。用法 431 的操作 4 演示了调用方式。

WIDA 08B 原文件的精确字节及 GPL 来源保留在 tests/fixtures/wida_predecessor。普通与 ASan/UBSan 每种构建 600000 次原稿、新接口及独立直方图对照，涵盖分叉、相同版本、有效非祖先版本对与界外阈值。另测 n=INT_MAX 的稀疏值域，避免中点加法溢出。完整原题页面受安全验证限制，来源行保持 partial；不猜测 CF1864 的题号。

## 静态矩形和：两种可选方法

- 持久化前缀版本（用法 432）：预处理后可在线读取任意矩形查询；空间 O(N log N)。正式 C++20 AC：https://judge.yosupo.jp/submission/410009 ，1072 ms、101.38 MiB。
- 离线扫描线（新增用法 436）：先读完所有查询，按横坐标排序，以纵轴树状数组累加。时间 O((N+Q)log(N+Q+1))，空间 O(N+Q)。正式 C++20 AC：https://judge.yosupo.jp/submission/410016 ，258 ms、29.98 MiB。

离线函数接收点 {x,y,w} 与半开矩形 {l,d,r,u}，保持输入不变，按原询问顺序返回。允许空点集、空询问、空矩形、重合点、负权；坐标支持完整 signed64，不用端点加减。要求各点权值绝对值总和不超过 LLONG_MAX；半开上界无法表示包含 LLONG_MAX 坐标的范围。所有横坐标相同的事件都只插入 x<事件坐标的点，保证边界无歧义。

核心在每种构建通过 98798 次独立扫描比较，包含极端坐标、负权、重复调用和不改输入检查。完整驱动每种构建通过 241 组协议，另外 14 组固定版本官方数据被原 checker 接受，错误输出负对照被拒绝。准确抄录的纸面代码通过两种构建样例；线上提交 410016 与当前纸面代码仅相差两行 BEGIN/END 摘录标记注释，已逐字比较其余内容一致。

## 性能参考

官方普通离线 Fenwick 参考程序在相同机器、C++20/O2 下交替运行三轮；三组 max_random 数据中，新离线版中位耗时约为其 0.62–0.63 倍（最近一次复测）。此为本地对比，不是线上排名。

线上按时间排序的首条记录 393934 为 84 ms、C++23，其实际调用离线 Fenwick 扫描线，并使用基数排序及专门的 SIMD 输入输出。已检查相关求解器和 main，未在这一执行路径看到题目答案硬编码。258/84≈3.07，仍超过 issue #16 的 80% 差距阈值，须在 issue 中报告；编译语言、I/O 与数据布局也不同，不能将此等同于同参数算法常数对比。自身 rank out of total 未查明，不编造名次。

## 08A 的语义已核实，改写仍待完成

固定原文保存在 tests/fixtures/wida_parity_index，普通和 ASan/UBSan 各 100000 次独立直方图证书通过。在 [0,n) 的非负计数版本差、k>=0 下：

- query1 是 max(0，最大有元素的奇数位置，全部元素降序第 k 项的位置)，其中 k 为 0-based，不足的第 k 项忽略。
- query2 是奇数位置元素按降序第 k 项的 {位置，该位置总重数，扣掉更大奇数位置元素数后的剩余 k}；超过总数时为 {0,0,k-奇数位置总重数}。

原始 add 允许带符号计数增量；测试保持各历史直方图及查询版本差非负。奇偶性指原始整数位置，不是离散化编号。原题主程序仍需登录才能读取，当前没有把这段专用接口偷换成通用 kth 模板；来源保持 pending，附上已完成的原稿证据。08D 的 cntnew 分裂约束也尚未确认。
