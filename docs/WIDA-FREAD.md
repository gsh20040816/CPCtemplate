# WIDA 在线模板：fread 快读

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `1241bb963bc021da78b2d5cda62c5457c1b2c18a`，路径 `01 - 常用在线模板汇总/01 - 初始与杂类/06 - 快读（fread）.cpp`。它使用 `fread`、`EOF` 和 `putchar`，但没有头文件，单独编译失败。在这台编译器上，先包含标准头再包含原稿可以通过，`getc` 不是宏。

`Cin` 跳过非数字，把减号记成负数。输入 `  -12 0 34x` 读出 -12、0、34，`write` 再输出 `-12 0 34`，末尾没有换行。输入已经结束却还要读数字时，`getc` 一直返回 `EOF`，循环不会停。这轮用两秒超时确认它没有结束。

读入 `9999999999` 到 `int` 时，`ans * 10` 有符号溢出。`write(INT_MIN)` 执行 `x = -x`，UBSan 报不能对 -2147483648 取负。

`python3 tests/wida_fread.py` 在普通 `-O2` 和 ASan/UBSan 下通过那组正常输入，并记录了空输入和两处溢出。没有新的在线 AC，也没有新增模板。来源保持 partial。
