# 奇度诱导子图划分

目标是划分顶点：保留每组顶点之间的**全部原图边**，使组内每个点的度数为奇数。它不同于选取边的奇度生成子图，也不要求组数最少。

存在性的充要条件是每个连通分量点数为偶数，见 [A. D. Scott, On induced subgraphs with all degrees odd, Theorem 1](https://people.maths.ox.ac.uk/scott/Papers/odds2.pdf)。必要性可由握手定理逐连通分量得到；实现先用独立的递归 DFS 检查这个条件。

构造沿 DFS 后序进行。未完成分组内部除根外的点已为奇度，根为偶度；只有根还需要与尚未处理的祖先相连。若当前点连接奇数个这样的子组，将它们合并后即可封口。若子组数为偶数，且没有可继续向上连接的子组，则将它们合成新的未完成组；否则留下一个有最近祖先回边的子组向上挂接，其余合并封口。无向 DFS 不存在横叉边，未完成组的内部点没有通向未处理祖先的边，因此合并时不会漏算诱导边。偶数分量在根处不会留下未完成的奇数大小分组。

原 DFS 深度 `depth` 不改变，`level` 只记录活动根的新挂接深度。上挂时查询该根的最近严格祖先；祖先邻点预先按原 DFS 深度排序，再用二分查找。每个点后序处理一次，每条邻接边被检查常数次，排序、二分与并查集操作给出 `O((n+m) log(n+1))` 上界。输入必须为简单图；重边会改变度数的奇偶性，不能直接去重后冒充原问题。

附件在每次考虑上挂时扫描子根的全部邻点。可用以下图族检验这部分的重复开销：一条含 q 个顶点的链，每个链点各接一个叶子，再让一个公共点连向所有链点，并在链根多接一个叶子，总点数为 2q+2。按链优先的邻接顺序遍历时，公共点会被逐层上挂；直接扫描会反复遍历其 q 个邻点。新版把每次寻找最近祖先改成二分。测试包含 100000 点的这一图族。

`tests/odd_induced_partition.cpp` 不只比较某份参考代码的颜色编号，而是依据原图所有同色边重新计算每点度数。覆盖六点以内全部简单图、10000 组打乱边序的随机图、十万点链/星/反复上挂扇形图和 600 点完全图。空图返回空划分；不满足存在性条件返回 `nullopt`。这些是本地验证，不是线上 AC。
