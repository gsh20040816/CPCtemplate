# 强连通分量、删点与无向边定向的完整用法

新增161–164；核心实现不变，所有算法DFS保持递归。

- LC scc：当前SCC为Kosaraju，编号沿跨分量边递增。输入零基转一基，输出再减一，按1..cnt遍历；不能照搬TarjanSCC的逆序。固定官方仓库e64660561a995c357cdc61ddee1bde68b80528db的12组生成数据，普通与ASan/UBSan本地checker通过；错误输出负对照被拒绝。
- AOJ GRL_3_A：在已求出的BiconnectedCore上调用removal_components，以after[u]>before判割点。官方输入是连通简单图、零基编号，n/m至100000。只需割点时优先抄Lowlink，此处展示点双结果复用。该题仅验证阈值判断，不冒充完整删点数量验证。
- UVA10765：完整删点数量与排名应用，n至10000；输入m是输出名额，边表-1 -1结束，多测0 0结束。按(-after[u],u-1)排序，每组末尾空行。after为剩余总块数，不能再加before。以独立删除每个点后重新求连通块为参考，含官方样例和多组连续输入。
- CF118E：连通无向简单图强连通定向，n至100000、m至300000。先检查无桥再调用orient_edges，每条逻辑边只加一次，输出与原边号逐项对应。独立枚举删除每条边判可行性；输出用多重集合匹配全部原边，并检查正反图可达性，避免集合比较漏掉重复输出。

后二者属于应用，不计作正式模板题覆盖。官方题面链接见usage-examples.json及template-problem-reviews.json。

`tests/connectivity_usages.py`分别在普通/ASan/UBSan运行：

- SCC635次：全部512个三点有向图（含自环）、120随机重边图、50万点长链/环/分离二元环。小图独立传递闭包核对强连通等价关系；大图用闭式分组检查，且所有跨组边必须按拓扑序。不要求彼此无边的分量具有固定次序。

- UVA一次连续输入227组（225小图、官方样例、10000点长链），另测立即终止。严格比较全部文本，包括同分次序和空行；小于3点/不连通等为额外API契约检查。
