# 矩阵 Prim 与父点森林

## 接口和内存

`Prim(n)`独立使用，无其他算法依赖。点号为0..n−1，n为非负int；`add(u,v,w)`自动加无向边，重边保留最小signed64权，负权、零权、自环均允许。矩阵使用int128，`inf=2^126`独立表示缺边，因此−1、LLONG_MIN、LLONG_MAX都仍是合法边权。矩阵约16n²字节，构造和存储O(n²)；add为O(1)，run为O(n²)，应根据内存选择n，稀疏图优先Kruskal。

`run()`重建最小生成森林并返回连通块数；n>0时返回1才存在MST，空图返回0。`weight`为int128总权，`pre[v]`为父点，根为−1；非根的树边为(pre[v],v)，权为cost[pre[v]][v]。接口不保留原边编号，平行边合并后不能反推出原输入编号，需要原边方案使用Kruskal。

每次run重置全部局部距离、访问标记、父点和总权。加边后旧结果未更新，必须重新run；支持独立值复制。公开成员只读，不直接改变n/cost/pre/weight。同权方案任选，不承诺字典序。森林至多n−1条边，总权绝对值<2^94，int128足够；总权−1可以是合法答案，不能作为断连标记。

## 正确性

d[v]记录未选点v到已选集合的最小边权。每轮选择d最小的未选点：若d有限，这条最轻割边可由割性质加入一棵最优生成森林；若所有剩余d均为inf，则已完成连通块与剩余点之间没有边，任取剩余点作为新树根，并将块数加一。新根不把inf计入权和。

选定点u后只向未选点松弛，且只在严格变小时写pre。因此父点总是更早被选定的点，父点链不会成环，负自环不会被选进树。算法恰好选择每个连通块的一棵最小树；断连、负权不影响这一结论。区别于Dijkstra，这里的松弛量是单条边cost[u][v]，不是距离加边权，不能混用。

## 完整用法

[AOJ ALDS1_12_A](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=ALDS1_12_A&lang=en)正式算法练习以对称邻接矩阵输入；−1表示无边，其他费用0..2000，n≤100并保证连通。`example-316`只加上三角有效边，输出总权；题面限制下总权≤99×2000，long long转换安全。−1缺边是输入格式特例，不是Prim.add的边权限制；零权不能跳过。

`example-317`为完整接口演示，输入0-based无向signed64图，输出块数、十进制int128总权以及pre[0..n−1]。它检查森林父点方案，不计第二个正式模板题，也不输出原边编号。

## 本地验证与范围

独立参照枚举恰有n−c条边的所有子集，通过Floyd可达闭包要求与原图一致，再取最小权。穷举1..4点每条无向边的五态（缺边、−2、−1、0、3），200组随机多重图逐次加边至12条，覆盖负自环、重边和反向端点。每次检查块数、总权、矩阵不变、根数、父点边存在、父链无环和原图连通关系。验证反复run、复制后独立加入负自环、LLONG_MIN与LLONG_MAX链以及空图。

每种核心记录50282次小图/增量核验，另有3次2000点矩阵run（负权链重跑和全孤立点），总计964020项检查。header/仅抄模板各有assert和NDEBUG形式。普通及ASan/UBSan各运行12种程序形态；正式驱动实际文件/展开/最小抄写/NDEBUG各103输入，含官方样例和100点完整矩阵；接口各106输入，含2000点矩阵负链和孤点。Python对子集最优值与父点森林再次作独立核验。

7个错误变体被拒绝：最后重边覆盖最小权、只加单向边、不清空总权、丢失父点、跳过负边、错误块数、正式驱动把零权当缺边。WIDA原main另验证3个输入。全部证据为本地测试；没有新增在线AC、排名或线上资源通过。完整覆盖目标继续。
