# 负环费用流的变换与范围

`NegativeCostFlow` 对应 issue #11 附件 2.13，允许有限容量的负费用环，包括不经过源汇的环。目标先最大化不超过 `limit` 的非负源汇净流量，再最小化费用；`limit=0` 得到最小费用循环流。

把每条负费用边预先送满，将其费用计入常数项。令退流量为 y，原流量就是 cap-y；于是剩余选择变为反向、正费用的退流边。其他边保持原方向和非负费用。这个变换一一对应原图容量范围内的流量方案，初始可用残量边的费用全部非负。

预流产生的点不平衡用超级源汇修复，另加容量为 `min(total,limit)` 的汇到源辅助边。把全部负边退回就能恢复原图零流，因此需求修复总有可行解。对超级源汇求最小费用的足量流，相当于在允许净流量区间内找一个费用最小的可行方案。它的残量图不存在负环。记录辅助边流量和费用后，删除所有辅助残量边，再从原源点到汇点最短增广；从当前流量的费用最优方案出发，保持每个增广流量值的费用最优性，直到流量上限或真正最大流。

容量总和限制为 `LLONG_MAX` 以内，保证点平衡、需求总和和最终流量不溢出。费用不取 `LLONG_MIN`，以便用 long long 表示反向费用。总费用与中间费用累加用 int128；容量总和乘最大费用绝对值小于 2^126。原边流量通过是否反向登记还原，不能直接把退流边的 used 当成原流量。

该实现复用势能最短增广，是伪多项式算法。记录包括 8000 组原图整数流枚举（普通及随机流量上限）、费用与流量守恒证书、断开的负环、负自环和 signed64 极值；P7173 驱动另有 200 组枚举及题目规模上限的构造测试。均为本地普通和 ASan/UBSan 验证，不是线上 AC。

固定 Library Checker 参考的 `graph/min_cost_b_flow/info.toml` 含 `anti_ssp.cpp`，并把参考 `ssp.cpp` 标为允许 TLE；该题还要求上下界 b-flow 与对偶势能输出。本模板不能据 P7173 测试就宣称覆盖该题，完整范围需另评估费用缩放等实现。
