## 5.1 拉格朗日插值

130 页截图给出一般拉格朗日公式及朴素 O(n²)、快速 O(n log² n) 插值的说明，没有完整实现代码。现有任意点插值权重对应截图中的乘积公式；连续点接口是本库扩展，不能据此把快速插值也视为已核对。现有 Lagrange 提供任意模素数后互异横坐标、以及 0..n-1 连续点两种构造，允许 n=0 的零多项式；n<=p，p 必须为素数。查询通过前后缀积排除第 i 项，没有 query(k) 命中样本点时除零的问题。

## 5.3 NTT

131–133 页使用 998244353、原根 3，按系数长度补二次幂并求普通乘法。附件 bit=0 时仍计算 `(bit-1)` 移位，两个常数相乘会触发负移位；本库长度 1 时位逆序和蝶形循环均为空，逆变换乘 1，能够正常返回。

现有 NttConvolution 模数参数化，明确素数与原根由调用者保证；max_size 为 mod-1 的最大二次幂因子。multiply 空输入返回空，结果系数个数不超过 max_size。无需靠浮点四舍五入。测试移除 classic 实现，同时保留 cpp_int 定义式 DFT、朴素整数卷积、素性/原根阶核验、逆变换及三角形大规模参考，覆盖七个素数域，包括 mod=2 与大于 2^30 的模数。

Library Checker 卷积驱动另以 Python 朴素乘法、最大长度常数卷积、长短不等、零多项式核对。本批共用驱动脚本还执行 AND/XOR 变换回归；这不自动代表附件 5.10 已核对。模板源码未改，原有线上记录不重写。

## 5.4 CDQ 分治卷积

134–136 页标题虽叫“分治 FFT”，代码实际用 NTT。原题为 [P4721](https://www.luogu.com.cn/problem/P4721)，2026-09-29 核验，n<=100000。新增 `cdq_convolution<mod=998244353,primitive=3>(kernel,initial)`，精确返回

`f[i] = initial[i] + sum(j<i) f[j]*kernel[i-j]`。

两个输入是等长的 vector<ModInt<mod>>；kernel[0] 必须为零。允许空输入、单项输入和任意 initial，原题取 initial[0]=1，其余为零。不是流式追加接口，也没有非线性叶子回调。模数和原根条件同 NttConvolution。

每个半开区间 [l,r) 先递归解定 [l,m)，把这段 f 与 kernel[0..r-l) 卷积，仅取下标 m-l..r-l-1 加到右半；再递归 [m,r)。任意依赖 j<i 在分治树中恰有一个最小节点把 j、i 分到左右两半，因此每份贡献恰好加入一次。必须先解左、再做跨界卷积、最后解右；不能先把两个孩子都求完再卷积。

根层普通卷积的结果长度为 n+floor(n/2)-1，其余层更短，因此非空输入要求该值<=NTT::max_size；n=1 不做变换。系数下标用 i-l，是因为 kernel 把零次项也保留了，不能照搬附件去掉 kernel[0] 后的 i-l-1。递推为下三角系统，无论 initial 或 kernel 是否可逆都不需对角求逆。虽然题目也能通过 F=1/(1-G) 求逆解决，本入口执行的是 CDQ 本身。

每层总卷积成本 O(n log(n+1))，共 O(log(n+1)) 层，时间 O(n log²(n+1))；沿递归路径保留的乘积长度为几何级数，额外空间 O(n)，递归深度 O(log n)。初始参数按值传入，原调用者数组不变。

tests/cdq_convolution.cpp：六个素数域的 2400 组任意 initial 和 kernel，用独立整数二次递推；空/单项、小模数变换容量边界，以及 20 万项全一核/间隔七的稀疏核闭式参考。P4721 完整驱动 150 随机组、四个 10 万项零核/全一核/几何核/稀疏核；打印例 example-115 另行编译验证。普通/ASan/UBSan 记录在 verification/polynomial-attachment-base.json。没有新增在线 AC。

## 5.2 的剩余缺口

附件 130–131 页实际是 complex<double> FFT，不是 NTT。其正向加 0.5 再向零截断的输出方式不适合负系数，例如真实系数 -1 会被输出为 0。截图中的 FFT 位逆序循环从 i=1 到 total-1，常数乘法时循环为空，不存在负移位；文本提取遗漏了上界的 -1，必须以截图为准。浮点误差随数据幅值和变换长度变化，不能只凭整数答案处于 long long 范围就承诺舍入正确。

当前 convolution_i64 是三模 NTT + CRT 的精确路线。它可以用于整数卷积题，但不视为补齐了浮点 FFT；本批没有用 P3803 的已有证据替代 FFT 误差验证。保留 5.2 未实现状态继续处理。
