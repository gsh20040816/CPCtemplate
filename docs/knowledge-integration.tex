前提：定积分存在，采样点有定义；先按间断、尖峰、振荡分段，端点奇异须变量变换，不能只减小 eps。
\[
S(a,b)=\frac{b-a}{6}\bigl(f(a)+4f(m)+f(b)\bigr),\qquad
\int_a^bf-S(a,b)=-\frac{(b-a)^5}{2880}f^{(4)}(\xi),
\]
对至多三次多项式精确。$S_2=S(a,m)+S(m,b)$，$\delta=S_2-S(a,b)$，误差指标 $|\delta|/15$，修正值 $S_2+\delta/15$；
递归时误差预算对半分。error 是指标之和，\texttt{met} 不是实际误差证书；光滑函数也可能被初始五点漏采样。

eps 为正的绝对容差；depth=0 仍做根的五点比较；limit 为回调次数上限。
深度耗尽、容差下溢、预算不足、四分点与端点重合或非有限值都令 \texttt{met=false}，此时 value 不可直接输出（可能为 NaN）。
零长度不调用函数，反向区间取负。
