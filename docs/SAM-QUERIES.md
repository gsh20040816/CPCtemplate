# 后缀自动机的字典序查询与最长公共子串

后续指定状态在线扩展与直接Trie边接口见 `docs/SAM-BUILD.md`；本文件中未提供接口的说法属于此前批次，当前范围以新文档和coverage.csv为准。

新增SAMLex与sam_lcs，复用现有单串SuffixAutomaton或已build的GeneralSAM。两组件为泛型，没有固定算法依赖；用法中必须先抄选定的自动机实现。单串与广义SAM源码均未修改。本批不提供任意父状态在线扩展，也不宣称所有上游SAM例题已完成。

## 加权字典序查询

`SAMLex index(sam)`默认每个非根状态权重为1，查询不同非空子串。`SAMLex index(sam,sam.counts())`使用单串endpos出现次数，重复出现的相同串在序列中占连续多项。一般构造可传长度等于状态数的非负long long权重w：每条到达u的不同字符串均拥有w[u]份。根权重强制为0，空串不参与排名。广义SAM没有自动提供文档频率或出现次数，不能把默认权重当成这些统计。

sum[u]表示在已经到达u后，当前串及全部后续扩展的总权重，递推为w[u]+Σsum[v]，只沿非空转移计算。SAM转移使最大长度严格增加，故按len降序DP即可；用长度桶排序，无递归栈或模拟DFS。计数超过LLONG_MAX时截断到该值。加法写为sum[u]+=min(sum[v],LLONG_MAX-sum[u])，不先计算可能溢出的和。

每个非空子串在确定性SAM中对应从根出发的唯一标号路径；同一状态可以由多个不同串到达，因此不能把路径当成状态去重。短串在其所有扩展之前，先消耗当前状态权重，再依指定字母序枚举下一条边。子树权重小于k时整体跳过，否则沿该边继续。对于所有1≤k≤LLONG_MAX，若真实块大小超过上限，k必在该块内；只有块大小小于k时才需要减去它，而这时保存的计数是精确的。因此饱和不会改变支持范围内的查询答案，但sum[0]本身不再承诺超过上限时的精确总数。

`kth(k,alphabet)`返回optional<string>，k≤0或不足返回nullopt。alphabet默认a..z；自定义时须是26个字母的排列，不能重复、遗漏或含其他字符。构建O(26V+L)、额外O(V+L)；每次查询O(26×输出长度)，另分配输出串。重复查询不重建DP。

索引只保存对sam的const引用。sam必须比索引活得久，且在使用索引期间不得extend、add、build、赋值、移动或外部改写状态。不要从临时SAM构造索引。需要更新自动机时先结束旧索引使用，再建新索引；weight、sum公开用于读取，不支持手动修改维护。接口没有增加生命周期管理框架，以保证抄写简洁。

[P3975](https://www.luogu.com.cn/problem/P3975)的n≤500000、t=0/1、k≤10^9，驱动253据t选择默认权重或counts，失败打印-1。这是竞赛应用，未算作正式模板题覆盖。当前时间/内存限制未核验。

## 最长公共子串

`sam_lcs(sam,t)`返回t中的{起点,长度}，均0-based；多解取t中最早起点，无非空答案返回{0,0}。输入只能是a..z，t可空且长度<INT_MAX。对单串SAM是两串LCS；对GeneralSAM是与任一已加入文档的LCS，不是所有文档的交集。要输出实际子串，用t.substr(start,length)。不返回第一串或源文档坐标。

扫描维护当前文本前缀的最长可接受后缀，其状态为p、实际长度为length，满足len[link[p]]<length≤len[p]。若当前字符无法转移，沿后缀链接回退并令length=len[p]；若能转移，长度增加1；根也无转移时清零。每次成功至多增加1，回退使实际长度严格减少，因此扫描O(|t|)，额外O(1)空间。只在长度严格增大时改答案，保证相同最大长度取最早位置。两个参数只读。

[SPOJ LCS的洛谷题面](https://www.luogu.com.cn/problem/SP1811)指定恰好两行、每行最多250000小写字符，输出长度。驱动254使用getline保留空行，并处理CRLF。SPOJ原站本轮返回403，已读可访问的完整转载题面；不以此声称已读取原站样例或资源限制。该用法保守归入应用，线上AC待完成。

用法255直接展示GeneralSAM的文档并集、自定义字母序与LCS位置。输入文档和查询文本为非空token；n=0合法。它是API演示，没有被冒充OJ模板题。

## 上游核对与剩余缺口

WIDA固定cfdb12db6792eb2303798541fb5c760ed2bc618b的04A/04B文件均支持extend(parent,c)任意状态扩展；新版另有字符偏移和状态访问方法。本库单串SAM只有extend(c)，GeneralSAM只允许先收集文档再统一build。当前验证能证明两种对应构建场景的语言与查询正确，不能证明任意状态在线扩展接口等价。上游0号是虚点、1号是根，本库0号是根且go中的0表示无转移；状态编号不能直接照搬。两库的状态数与最长串长须可用int表示、数组须能分配。两个来源条目均由pending转为partial，缺口明确保留。

kuangbin2018稿的1.6/1.6.1/1.6.2实际包含基本构造、CodeChef TSUBSTR、CF204E。本批实现了子串路径DP、任意字母序和权重查询，但TSUBSTR还需要从输入树直接构造，不能把展开所有根叶路径当成同复杂度替代。其排名包括空串，本库排除空串：题目第1项是空串，其余调用kth(k-1)；其总数等于非空总数加1，饱和边界需另外处理。CF204E按至少k份文档出现的子串给每份文档计数，和单串occ或默认不同子串数都不同。这三个来源条目保持partial，不能关闭。

来源快照哈希与逐条状态见verification/sam-queries-sources.json。本批五项是范围核对后的部分映射，不是五个完整覆盖。

## 独立验证

`tests/sam_queries.py`对头文件与真实标准头抄写体分别运行assert/NDEBUG，普通和ASan/UBSan两模式各2591组、510427检查。参考枚举全部子串，分别构造集合、多重集、任意权重有序列表；权重总量用int128计算，涵盖0与LLONG_MAX附近值，独立验证饱和排名。对LCS枚举查询串的每个子串并在源集合中查找，核对最早位置。

覆盖全部长度≤7二字母单串与长度≤5查询、全部长度≤3双文档组合、重复文档/空文档集合、800份随机单串和任意字母序、500000长全等串与250000长LCS闭式结果。检查源自动机状态不变及出现次数不变。7个语义错误变体分别破坏空串权重、重数、排名边界、字母序、饱和上限、LCS回退长度与平局位置；必须由参考拒绝，崩溃不算成功。

完整程序的原驱动、展开版、最小依赖抄写体各运行：253为170份，254为166份，255为100份。最大输入除全等串外包含a后接499999个b，产生接近2n个SAM状态，验证克隆密集情况下的长度排序DP与两种计数口径。无新在线AC或速度排名证据；原有225核心和252用法正文未改，本批不是全库重新回归。
