# 边权修改动态树直径

本批尚未完成线上提交，不能标作 OJ AC。代码和本地测试已准备；目标为 issue #15 的 LibreOJ3163，强制在线驱动依据 [CEOI2019 官方英文题面](https://static.oj.uz/problem/25e3211db5386a934022e12dfa2cbd1e/statement/3fcf1f887b1fd60449dda224dc92b81cba9807b438de72ed782653882d7e1adb/statement_en.pdf)。2026-10-11已在Firefox读取LOJ3163：6000ms、1024MiB；强制在线解码、n/q≤100000、w≤2×10^13以及两份样例与现有驱动和测试一致。登录请求目前显示处理中，尚无线上提交回执。

`DynamicDiameter(n)` 要求 n≥1。`add(u,v,w)` 添加非负权无向边并返回从 0 开始的边编号；输入必须恰好构成一棵树。`build(root=1)` 预处理，可换根重建。`update(id,w)` 设置原边的新权值，`diameter()` 返回最长路径长度（单点树为 0）。不支持 link/cut 或负权。内部字段除只读外不要直接改写；新增边后必须重新 build。复制结构相互独立。只提供长度，不提供端点。

始终要求全部边权之和不超过 LLONG_MAX/4，以保证深度的两倍、合并候选和懒标记计算安全。题目 n≤100000、每条边小于2×10^13，满足该界。DFS 使用递归，深链须给足原生调用栈。

递归进入顶点时记录它的根距离，每处理完一个孩子再记录当前点，得到长 2n-1 的欧拉序。顶点子树对应从首次出现到最后一次出现的闭区间。修改父边权值只需将这个区间的所有根距离同时加上变化量；必须保留孩子返回父亲的记录，不能改成只记录首次访问。

设序列根距离为 d。两次出现位置 i≤k 的 LCA 对应区间最浅点；在非负边权下，也是区间根距离最小值。因此直径为 max(d[i]-2d[j]+d[k])，i≤j≤k。允许下标相同，叶子答案为0，支持零权。

线段树维护五个最大值：high=d[i]、low=-2d[i]、left=d[i]-2d[j]、right=-2d[i]+d[j]（i≤j），以及 best=d[i]-2d[j]+d[k]（i≤j≤k）。合并时枚举表达式完全在一个孩子、或在相邻两项之间跨孩子。区间统一加Δ时，五项依次增加 Δ、-2Δ、-Δ、-Δ、0，故可懒更新。建树O(n)，更新O(log n)，查询O(1)，空间O(n)。

本地核心测试：10588棵n≤5的带权标号树，逐根重建，每条边先改为4再清零；1500组随机树各最多80次修改，独立全点对路径枚举真值。另覆盖复制、换根、重建、接近安全上界的权值。核心O2及ASan/UBSan通过。正式驱动的两个官方样例、150组各60次强制在线随机修改分别检查头文件/NDEBUG/完整展开。

Linux原生大栈压力覆盖十万点、十万次修改的链、星形和换根星形；初始权值取题目上界减一，更新交替清零和恢复，以独立总和/两条最大边公式检查。漏返回欧拉记录、懒标记符号错误、漏跨区间候选三种变体均被独立真值检出。证据在 verification/dynamic-diameter-*.json。
