\section{带修莫队：时间轴与区间状态}\label{knowledge-mo-time}
\index{带修莫队}
离线记录每个单点修改的下标、修改前值和修改后值；同一位置的旧值取上次修改后的数组。
离散化须纳入全部初值与修改后值。询问时间 $t$ 表示前 $t$ 次修改已执行。
维护 $(l,r,t)$ 与半开区间 $[l,r)$；前进写 after、回退写 before，
修改点在当前区间内时先删旧贡献、改值、再加新贡献。
run 结束后状态停在最后一条询问，再次调用须重置。
左块、右块、时间三关键字排序（蛇形），时间为真实修改次数。块长 $B$、询问 $Q$、修改 $U$ 时移动量
\[
O\left(QB+\frac{n^2}{B}+U\min\left(Q,(\lfloor n/B\rfloor+1)^2\right)\right),
\]
另加 $O(Q\log Q)$ 排序、$O(Q)$ 空间；同阶时 $B\approx n^{2/3}$，总 $O(n^{5/3})$。
需区分左右端增删时应拆分回调。
