# 模板代码依赖页码与章节（issue #13）

200个算法条目检查正文中的具名模板引用，提取128条直接依赖；正文在算法前标出依赖名称、当前PDF页码和章节，三者可点击。所有198份完整用法的所需模板也逐项给出链接。不手写页码，LaTeX依据最终章节标签解析；总册指向总册，分册指向本册主条目或跨类依赖附录。

同一头文件包含多个算法，不等于抄写该片段必须抄全部定义。因此提取基于打印代码正文而非头文件include。删除注释和字符串后，以完整标识符匹配目录项；继承关系亦纳入。例如Prime64需要Mod64，FpsPower经FpsFunctions间接需要FpsInverse、NttConvolution、ModInt。每个组件只列直接依赖，继续点击即可查询传递依赖，verification/template-dependencies.json同时保留完整闭包。

泛型类型或配置函数由调用者提供，不伪造一个固定算法依赖。例如batch_units的Z只需规定的乘法与try_inv接口，不把mint强制为唯一实现；用法198具体调用mint，故其所需模板会链接mint与batch_units。标准库vector、optional等不重复列作算法模板，接口和类型约束仍在条目说明中。

运行 `python3 tests/template_dependencies.py`，核验全部算法依赖、198份用法的requires、继承和泛型反例、六册本地依赖的传递闭包以及标签存在。它不是算法正确性测试。来源目录仍未全量迁移，不能把这些200个当前条目的依赖索引视为上游713条目已完成。

运行 `build/tools-env/bin/python tools/dependency_pdf_audit.py`，读取最终八册的PDF注释和命名目的地，核验976组名称/页码/章节引用的PDF目标均存在，目标物理页与最后一轮aux及PDF页偏移一致；每个目标的实际链接数至少为三倍引用组数。引用组数仅取依赖引用，PDF链接计数也包含额外目录链接；本检查不逐一匹配链接矩形与源引用，不能据此声称每个矩形都已点击验证。
