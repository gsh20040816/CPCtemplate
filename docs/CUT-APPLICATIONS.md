# 闭合集、最小树形图与全局割：完整用法

本批补 issue #12 的三个缺项，核心 `maximum_closure.hpp`、`flow.hpp`、`graph_advanced.hpp` 与提交 `7a9922f` 相同。代码只维护 vector 版本；Dinic 的增广仍递归。新增 example-148/149/150 与三个实际输入输出驱动，没有用应用题替代正式模板题计数。

## P2762：闭合集与方案

已核对 [P2762 当前题面](https://www.luogu.com.cn/problem/P2762)：实验和仪器各至50，正的赞助/费用小于2³¹，每个实验后面的依赖个数不固定。题面特别说明 Windows CRLF 输入。用 getline 取一行，再用 istringstream 分解，行尾回车和连续空白自然跳过。实验没有依赖时仍是一行，不能继续从下一实验行读仪器。第一行 m/n 用流读完后，先消费剩余行尾。

构造 m+n 个点：实验1..m取正权，仪器m+1..m+n取负费用；选实验i必须选仪器j，故添加依赖(i,m+j)。返回 selected 中≤m的点输出为实验，其余减m输出为仪器。空集也合法，前两行即使为空也要输出两个换行。依赖共享的仪器只计费一次；不能给每条依赖单独扣一次费用。赞助总额至50·(2³¹−1)，必须用long long，不能累加在int里。

该问题是网络流建模应用；本批保留 application 分类。输出可不唯一，测试检查编号范围和重复项、所有依赖、选点真实收益及最优值，不要求与某组示例的编号完全一致。

## P4716：给定根的最小树形图

已核对 [P4716 当前题面](https://www.luogu.com.cn/problem/P4716)，标题明确为模板题。n≤100、m≤10000、正边权≤10⁶。读入顶点和根减一，调用 Arborescence::solve；有值时输出费用，否则输出-1。这是从根沿有向边能到达全部顶点的外向树形图。不能只检查每个非根点都有入边，因为选出的入边可能形成与根隔离的环。

这里总费用≤99·10⁶，能安全把128位结果转long long；该转换不扩展为核心所有输入的通用打印方案。核心也允许负权，用 optional 区分合法费用-1和无解；本题正权不会混淆。n=1时空树费用0，自环不参与。当前接口仅返回费用，不提供选边恢复。

## P5632：无向全局最小割

已核对 [P5632 当前题面](https://www.luogu.com.cn/problem/P5632)，标题明确为模板题。n≤600、输入连通、正权、总边权≤10⁹。无向边在对称矩阵中两边累加，自环不影响割而跳过。StoerWagner::solve 返回最小割权及一侧原顶点编号，核心编号为0-based；此题只打印费用，side 可供需要割方案的题直接使用。矩阵按值传入，后续核对方案仍可用原矩阵。不能把s-t最小割和这里自由选择两侧的全局割混为一谈。

核心要求至少两个点、非负权，时间O(n³)、空间O(n²)。题面未给明确单点下界；单点不存在两侧均非空的割，驱动额外约定为0，不把它称为该非平凡割定义的结果。断图、重边和自环的适配也额外测试，单独记录，不据此改写当前题面的连通性要求。

## 验证范围

`tests/cut_applications.py` 编译并执行三份完整驱动，普通和ASan/UBSan均通过。

- P2762：660组。2×2的依赖与两种正权全部组合；400随机；50×50无依赖、全部依赖、共享仪器及逐项分离模型，最大总收益超过32位。参考先枚举实验子集、计算仪器并集，极小规模另枚举实验/仪器两份子集交叉核验。LF/CRLF交替并含制表符和尾部空格；空方案的空输出行保留。六个错误方案负对照均拒绝。
- P4716：355组。350份独立入边组合枚举与根可达性检查，100点/10000边的连续缩环、三个不同根、最大边权与隔离根；答案分别由独立枚举或构造族闭式解给出。
- P5632：891组题面范围输入。所有至4点、边为无/权1/权2的连通图，以及240随机连通图，穷举所有非平凡割作参考；600点完全图、链、星形、两个稠密块之间的单桥，以及总权10⁹的边界。另有三组单点/断图/重边自环扩展。
