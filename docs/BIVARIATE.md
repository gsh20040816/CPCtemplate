# 二维NTT与二元逆级数

WIDA12A末尾的dft/idft(vector<vector<int>>)以及inv不是方阵求逆，而是二维变换和二元形式级数逆。精确原稿blob c493616c750062b41d1daf07028ee21047ae155a保存为tests/fixtures/wida_poly_variants/12A.cpp。本批新增Ntt2D、BivariateInverse，合计333组件、453份完整用法。

## 接口与约定

Ntt2D<mod,primitive>复用参数化NTT，Matrix为vector<vector<Z>>；a[i][j]是x^i y^j系数。transform先逐行、再逐列变换；自然顺序输入输出，逆变换在每一维各除该维长度。输入必须非空矩形，两维均为合法二次幂。multiply返回两维分别做长度和减一的普通卷积；任一维为空返回空矩阵。这不是矩阵乘法。两维分别补零，无一维展平时相邻行混叠的问题。

BivariateInverse::inverse(a,n,m)固定998244353，返回模(x^n,y^m)的n×m项，要求a[0][0]非零。输入允许不等长行，缺系数当零、多余系数忽略。目标精度正整数；n=1可用一维求逆到m≤2^23，n>1时n≤2^23且2m-1≤2^23。单维算术上界不等于实际能分配对应二维面积；复杂度O(nm(log(n+1)+log(m+1)))，工作空间O(nm)。缓存按NttConvolution约定保留历史单位根。

## 正确性依据

在系数环F_p[y]/(y^m)中，a的第0行有逆当且仅当a[0][0]非零。一维FpsInverse先得到该行。假定b已满足ab=1 mod x^k，Newton式b(2-ab)将精度提高到2k。

a只取前min(n,2k)行，b仅k行，两者每行截到m列。高度2k的循环卷积中，x次数最高3k-2，回绕只污染低k行，因此高半段误差E准确。宽度为不小于2m-1的二次幂，使y方向第一次乘法没有回绕。清掉低k行及y次数≥m的列后，E*b第二次乘法同样只回绕到低k行；其高半段取负便是新增逆元系数。保留旧低半段，最后一轮可截到任意n。共五次二维变换，并复用b的频域值。

初版使用完整b(2-ab)乘积，需要高度4k、宽度至少3m-2。官方形状出现明显性能差距后，改为上述高半段算法；初版源代码、完整纸面程序及测量记录保留于verification/bivariate-initial.json。

## 验证

普通NDEBUG与ASan/UBSan各95577项独立检查：三个模数的直接二维DFT、四重循环普通卷积、三角依赖顺序的二维逆元递推、非方形与单维退化、空卷积、负输入转换、非二次幂目标、短/长/不等长输入及多次调用。两份API准确纸面和头文件驱动，每种构建分别100组Python整数真值。

另用1/(1-x-y)的系数C(i+j,i)，由独立Pascal递推产生1024×1024真值。本库与原稿C=1024的实现各在普通/消毒器下逐项核对1048576个系数。本库还正确处理常数级数；原稿Poly(2)*Poly(3)普通运行打印6，但消毒器报shift exponent -1 is negative，定位到长度1的dft位逆序表。原稿这一边界不能作为已定义行为的正确性证据。

tests/bivariate_official.py按固定blob清单获取官方源码，检查每个生成输入的官方SHA-256，再检查官方参考程序输出的SHA-256，最后逐项核对本库准确纸面程序。包含500000×1、1×500000、窄长矩形与接近方形。正式用法、API示例与原稿对照分别存档；不把本地官方数据通过写成线上AC。

WIDA12A继续partial：本批只深入核验其二维尾部和一维常数乘法反例，一维主体另见docs/WIDA-RAW-POLY.md，其普通数值结果与UB反例分别记录；原Codeforces应用和全面容量仍未完成逐项审计。12B与两份12D的后续局部审查分别见WIDA-Z-POLY.md、WIDA-POLY-MULTIPLY.md和WIDA-MINT-POLY.md，仍不按相同名称视为全部完成。
