# 实数高斯消元：数值模型与误差边界

`GaussReal::solve(a,n,eps)` 与精确模域消元分开。输入是m行、n+1列的增广矩阵；返回近似一致性consistent、数值rank、自由变量取零的特解particular，以及每个自由变量对应的一条kernel方向。它按值接收矩阵，不修改调用者原矩阵。

## 具体做了什么

1. eps由调用者显式传入，必须有限且0<eps<1
2. 对每个有非零系数的输入行，除以该行系数最大绝对值；右端项也除以同一个数，但不参与选取这个尺度
3. 按列扫描，从剩余行中选当前列绝对值最大的主元。若最大值≤eps，把所有活动行的这一列明确置零并跳过
4. 选中主元后归一化，再对其他每一个非零消元因子更新。不能仅因因子小于eps就跳过：小系数乘大右端值仍可造成显著变化
5. 剩余行的右端项绝对值>eps时，报告数值不相容；否则将这些右端项视为零，读取特解及自由方向

原本全零系数的行不做缩放，右端项以原尺度和eps比较；n=0亦使用这个约定。例如零变量方程0=eps/2按该数值规则判相容，虽然它作为精确实数等式并不成立。m=0时特解全零、自由方向为标准坐标向量；m=n=0返回空的相容解。

结果描述的是最终数值消元模型，包括舍入、被丢弃的小系数和被视为零的小右端项。它不构成原问题精确秩、精确无解、精确零空间或某个经证明很近的原始矩阵的证书。相容且rank==n仅表示本次数值判定得到唯一特解；rank<n不能直接当成无解。

## 为什么要显式清空跳过的列

精确域消元跳过的活动列本来就是零；浮点阈值跳过的列可能只是很小。若保持这些旧值，又只更新当前主元右侧的列，后续归一化和行消元会漏掉对它们的变换，读出的自由方向便不对应宣称的消元结果。

本接口把这一步作为明确的数值近似：跳过时将活动行该列置零。于是活动行之前的主元列和已跳过列均为存储意义的零；后续仅更新当前主元右侧及右端项是自洽的。已经确定的主元行中，自由列系数仍被保留，并用于自由方向。

kernel不是正交归一基。不能承诺任意大的线性组合代回原方程都有eps量级残差；各方向的近似误差会随组合系数放大。

## 尺度、有限值与平台

- 0≤n<INT_MAX，m≤INT_MAX，每行恰有n+1项；除此之外还要满足可用内存和时间预算
- 输入及全部中间加减乘除必须有限且可表示。有限输入不保证归一化b/s、主元除法或消元乘积有限；调试assert可发现部分违反，NDEBUG不提供运行时拒绝保证
- long double的有效精度取决于平台，不能默认必然比double多位；禁止fast-math等破坏正常浮点语义的优化
- eps作用在系数行归一化之后的消元过程中，不是对原矩阵每个位置统一定义的相对误差。全零系数行保留原右端尺度
- 非零行的适当缩放可以改善量纲问题，但不能消除病态性、消元增长或列尺度差异，也不等于强秩揭示分解
- 不同平台精度、舍入和运算收缩可能改变临界值附近的分类。没有通用的“把eps调小就一定正确”规则

主消元通常需要O(mn min(m,n))次运算，另有输入扫描和初始化；工作空间O(m(n+1)+n)，自由方向输出另占O(n(n−rank))空间和至少同阶时间。空矩阵等退化情形不能忽略这项输出成本。

## 原方程残差只是一项诊断

保留原始A、b，检查候选x的残差Ax−b；例如逐行比较

|A_i x−b_i| / (sum_j |A_ij| |x_j| + |b_i|)。

分子分母均为零时取零。诊断计算本身也要避免溢出和抵消；必要时用更高精度重算。小残差表示对输入方程有较好的后向符合程度，不代表解的前向相对误差小，更不认证精确秩。病态矩阵可以同时有很小残差和很大解误差。

[LAPACK 误差分析说明](https://netlib.org/lapack/lug/node75.html)区分误差、扰动和条件数；本短模板没有LAPACK级条件数估计或误差界。

## 用法与题目覆盖

用法233是明确的自定义数值协议，不是官方题目：输出数值状态、特解与自由方向，适合演示调用和核对小系统。连续两个正面等待时间的两状态系统给出E0=6、E1=4；过程是否吸收、期望是否有限仍由概率模型证明，不由矩阵残差替代。

[Luogu P3389](https://www.luogu.com.cn/problem/P3389)是相关正式题目。当前题面有整数系数界、解值界和舍入安全边界，但没有条件数或数值秩分离保证。本轮不把有限本地样本当作全合法输入域证明，不登记新线上AC，也不把此API演示计为正式模板题用法。

实际采用时，先利用问题结构、量级与误差要求判断数值法是否合适。精确整数/有理数可解性或合数模方程另选算法；不要把浮点阈值替代精确代数条件。
