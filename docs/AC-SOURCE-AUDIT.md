# AC 自动机来源审计与模式编号存在性

本批没有改动任何已有算法核心，只补充P3808完整用法262，并核对WIDA打印稿、三个jiangly收集版本和kuangbin1.4的实际接口。名称相同不表示功能齐全。

## 两种计数

已有AhoCorasick::count返回每个Trie状态代表串在文本中的出现次数，允许重叠。重复模式串共享终态，但每次add返回值都应保存：例如模式a、a、aa、b，文本aaaa，出现次数是4、4、3、0，而出现过的输入编号数为3。

P3808要求后一种。用法262逐输入编号累加cnt[end[i]]>0，因此重复模式分别贡献1，一个编号出现多次仍只算1。[官方题面](https://www.luogu.com.cn/problem/P3808)已明确不同编号就算不同模式，n、总模式长、文本长上限均为1000000。已有用法70/P5357继续逐编号输出出现次数；其官方限制为模式数和总模式长200000、文本长2000000。两个完整程序均有本批独立回归，尚无本批新增在线AC或排名。

WIDA打印稿与kuangbin的HDU2222例子都以破坏终态标记的方式计算第一次query时出现过的模式编号数。我们通过count与保存的终态列表得到相同首查询输出，查询不修改自动机，可以重复使用。重置使用赋新AhoCorasick对象；无需固定数组清零、手动节点池或debug包装。若确实需要旧代码跨多个query累计“仅报告此前没命中过的编号”，应另外保存seen编号标记，本用法不冒充该破坏式接口。HDU当前官网题面不可访问，原题输入/资源未重新核验；对应功能以正式P3808模板题及原来源代码语义核对。

## 扩展版本与后续补齐

WIDA固定commit cfdb12db6792eb2303798541fb5c760ed2bc618b的06A旧版构造接收模式串及整数权重，在BFS中将终态权沿fail累加，query只扫描文本便得到所有匹配的权重和。当前核心返回每个模式的次数，虽然外部可加权求和，但每次还需扫状态/模式，不能宣称同一接口或相同O(text)查询成本。首轮该行记partial。后续已新增ACWeighted和DynamicAC，并以CF710F完整在线应用及独立本地验证补齐，现改为local-tested；空串兼容与验证边界见[带权AC说明](AC-WEIGHTED.md)。其全局节点池回收仅是存储实现，可由vector对象生命周期替代。

06B接受0..25整数vector，也可通过自定义offset从字符串转换，公开next、link、len、size，init重新置空。06C使用小写字符串入口，同样公开Trie深度len。现有a[u].go/fail、a.size()、赋新对象已覆盖相应转移、fail、大小及重置，但没有保存Trie深度，也没有整数/offset入口；现有add明确拒绝空模式，而来源add空串会返回根。这些差异必须显式补齐或约定后才能关闭来源项，二者继续partial。

上游编号是虚点0、根1；本库只有根0，不能直接照搬上游下标或包含虚点的size。06B还存在两个需要避免照抄的问题：Node构造没有初始化根len，字符版next声明了offset却实际固定减'a'。这些是固定源码的缺陷，不构成我们需要保留的语义。06C初始化len=0，情况不同。

## 首轮核心边界（后续变更见下）

仅小写非空模式；所有模式登记完后build恰好一次。允许空模式集合和空查询文本，但不允许空模式串。count可重复调用，返回数组索引0统计扫描的字符数，不是空串应有的|text|+1次匹配。因此根不能当作空模式终态解释。公开order为不含根的BFS顺序，fail父状态先于孩子；构建后go已补齐失败转移，不能再当成原始Trie边，也不能继续add。

构建O(26V)，每次count为O(|text|+V)，状态容量由vector管理，现有实现保持不变。本批不擅自增加过度封装或把BFS改成DFS。

## 验证范围

每种核心形式26770组、2692012项检查。对所有短二字母模式单/双组合及三模式样例，显式构造所有前缀字符串集合，用最长后缀查表独立验证每个状态的26条完整转移和fail；对所有状态代表串直接枚举出现次数，对模式输入编号用string::find判断存在性，覆盖重复、嵌套、未出现、空集合、空文本和重复查询。另检查复制、赋新对象后的重建、只读查询以及1000000层Trie链。

头文件/标准头抄写体各assert/NDEBUG在普通与ASan/UBSan两模式通过；五个语义mutant破坏根队列、fail、补全转移、文本记次和fail汇总，须由独立参考拒绝，崩溃不算正确检测。P5357和P3808各185份输入，每题三种完整程序形式、两种模式，包括各自最大合法模式数/总长/文本长及重复模式。精确记录程序与源码摘要，不以此前AC代替当前测试。
