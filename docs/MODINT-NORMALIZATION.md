# 固定模整数的规范化与回归

ModInt保留原有接口：模数为1..INT_MAX的编译期整数，构造接收完整signed64，pow接收非负signed64指数，合数模数的求逆仅对单位存在。公开v必须始终在[0,mod)；直接写入v时由调用者维持这一条件。

## 修改及边界依据

构造只做一次余数，再对负数加模数。加法用long long承接两个规范余数之和，最多减一次模数；减法之差处于[-(mod-1),mod-1]，int不会溢出，负时加一次模数。乘法最大为(INT_MAX-1)^2，小于LLONG_MAX，直接将一次long long余数写入结果。运算不再通过构造函数重复规范化。模1时仍全部为0，单位求逆返回0，与原契约一致。

展开原来的一行函数和幂循环，每行一个语句；没有引入额外原始构造接口，也不改用Montgomery。手册在完整方法之间拆成三页，维持连续源码行号。

## 核验范围

静态模整数既有测试分别检查完整头文件、仅cassert/optional/utility的最小抄写类，以及NDEBUG版本；涵盖模1..150穷举、合数不可逆、signed64构造边界、大模数逆元证书、别名操作与非法模数编译拒绝。普通和ASan/UBSan均通过，期间受检源码与手册哈希不变。证据为verification/modint-normalization-normal.json及sanitizer.json。

另对模整数与Fenwick组合、FPS逆/log/exp、除法/平方根及幂执行普通和消毒器回归，包括131072、200000、500000项的解析结果、十万位指数等既有检查。小规模WIDA12C独立对照与210组平方根倒数协议也重新执行；原稿重复调用错误仍如实保留。详见verification/modint-normalization-core.json与相关FPS回执。

这是本地回归，不新增线上AC，不把源码改动后的驱动当作原历史提交。

57份受影响的准确纸面完整程序在普通和ASan/UBSan模式全部通过，450条当前程序记录保持有效。包含number_theory兼容头间接带入的依赖；五份原由专用脚本管理的Fibonacci周期/任意模卷积用法也补入中央样例测试。该样例检查不替代其独立算法验证。
