# 二维静态矩形最值

`StaticRMQ2D<T,Cmp>` 补齐 kuangbin 3.2.2 的二维静态RMQ；一维位掩码版本仍独立保留，两者不能互相替代。预处理矩阵后，矩形查询返回最优位置，默认less求最小、greater求最大。

## 约定和代价

构造复制矩形矩阵，所有行必须等长。`query(x1,y1,x2,y2)` 使用0-based半开矩形 `[x1,x2)×[y1,y2)`，要求两维非空且完全在矩阵内，返回 `(row,col)`。最优值用 `rmq.a[row][col]` 读取；并列时按行号再列号取最小。空矩阵和零列矩阵可构造，不可查询；零列时复制与校验外层行数组仍需O(n)时间和空间。所有成员约定只读，重新赋值新对象可重建；不支持在线修改。

比较器必须稳定严格弱序、const可调用；支持有状态比较器及可复制记录。没有数值哨兵、没有元素算术，signed64最小/最大值都合法；浮点NaN不可用。n,m和n*m均不超过INT_MAX/2且内存可分配；这些约束使扁平位置和位移偏移的int运算安全。

非空矩阵的时间与空间均为 `O(nm log(n+1) log(m+1))` 预处理，查询 `O(1)`，假设元素复制/比较O(1)。为方便抄写，每个幂次层对都开完整n*m个int位置数组；合法起点之外的格子不用于查询。305×305矩阵有9×9层，仅索引数据即93025×81×4字节，约28.7MiB，还需原矩阵与vector开销。调用者必须按真实维度计算空间；不把它宣传成二维线性空间RMQ。

## 正确性

`st[k][l][x*m+y]` 表示左上角(x,y)、大小 `2^k×2^l` 矩形的最优原位置。基础层按行优先编号；若k>0，合并上下两个(k-1,l)矩形，否则合并左右两个(0,l-1)矩形。合并时先按比较器择优，再按较小扁平编号破平局，对应行列字典序。

对任意非空查询矩形，取不超过其高/宽的最大2次幂，以四个角放置四个这样的矩形。每维两个区间之并覆盖完整原区间，笛卡尔积的四块因而覆盖全部格子。它们可能重叠，但“最优值及最小原编号”的合并幂等，不会因重叠重复计数或改变选择。查询只合并四个预存位置；最多6次元素比较。

## kuangbin 3.2.2 源码模型

固定来源印刷页57–58提供二维最大值ST表以及一个使用程序：读到EOF，每组矩阵与询问；询问给1-based闭端点，行端点和列端点分别可逆序；输出最大值，以及该值是否至少在四角之一出现（yes/no）。用法280保留这个行为，转换为半开矩形，演示尺寸1..305，元素扩展为signed64。

必须比较四个角的值，不能只检查返回位置是否在四角：并列最大值可能先出现在内部，另一个同值角仍应输出yes。用法279另外演示最左/最上最小与最大位置。

## 验证

`tests/static_rmq_2d_probe.cpp` 穷举至3×3二值矩阵，对每个非空矩形逐格扫描，核对最小/最大位置；另覆盖单行、单列、2次幂边界、矩形长宽不等、全相等、signed64极值和空构造。大矩阵305×305使用有状态比较器和记录载荷，核对20万次解析查询、实际表格单元数及常数比较次数。

`tests/static_rmq_2d.py` 在普通和ASan/UBSan下验证header/copied各assert/NDEBUG四种形式。五个错误变体分别破坏平局、纵向合并、横向合并、下侧覆盖和右侧覆盖，必须由独立答案拒绝。完整用法分别编译driver/expanded/minimal-copy：279每份62组，280每份61组（随机每组含三个EOF数据集，另有305×305矩阵十万询问）。输入、输出、源码和二进制摘要保存在 `verification/static-rmq-2d-{normal,sanitizer}.json`。
