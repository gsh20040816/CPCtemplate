# 最小面积包围矩形

`minimum_rectangle(p)` 输入严格逆时针凸包，返回`pair(area,box)`，box为四个RealPlane::Point构成的array。非退化时四角逆时针，不指定首角，并列最优时不指定方向。空集返回零面积及四个原点占位；点重复四次；线段返回a,b,b,a。输入不变。不能传任意散点、顺时针轮廓、重复首点、零长边或共线中间顶点；n须能用int表示，实数输入和中间运算须有限可表示。

## 算法与数值边界

最优矩形至少一边与凸包边共线；参见[CGAL最小包围矩形文档](https://doc.cgal.org/Manual/3.1/doc_html/cgal_manual/Optimisation_ref/Function_min_rectangle_2.html)。固定底边e，用三个指针分别维护沿e投影最大/最小、垂直e高度最大顶点。初始边直接扫描全体顶点，随后沿凸包同向推进；同投影时推进到末端，跨过平行支撑边。精确比较下三个指针总推进O(n)，时间O(n)、额外空间O(1)。每轮steps<n用于防止异常平坦比较无限循环；浮点误判时保护不能修复结果，最坏可退化O(n²)。

设底边起点a、d=e·e，l/r为最小/最大投影，h为最大叉积。面积=(r−l)h/d，底部两角=a+el/d及a+er/d，另两角统一加perp(e)h/d；得到逆时针四角。面积选择与坐标恢复均用long double，不使用eps分类、扰动或不满足严格弱序的排序。

任意近退化实数、极薄形状和巨大平移仍受浮点精度影响。接口并不承诺精确拓扑或任意范围误差上界；面积与角点的误差必须分别检查。返回四角不是面积数值的附属证明，测试必须检查矩形垂直性、逆时针方向及包含输入点。

## P3187适配

[题面](https://www.luogu.com.cn/problem/P3187)给3≤n≤50000，坐标[0,10]且至多五位小数、不用科学计数法；最优面积≥0.1。要求面积误差/max(1,S)<1e−4，点在矩形内或距矩形<1e−4，四角逆时针。题面未要求从最低顶点开始。

驱动先读取long double，乘10⁵并llroundl恢复0..10⁶定点整数，精确integer_hull构造凸包，再转实数作卡壳。正常二进制double及long double精度下，解析/乘法误差远小于半个整数；此转换只能用于题目声明的五位小数输入，不能照搬到任意实数。整数差与两项乘积和绝对值至多2·10¹²，53位及以上二进制有效位即可精确表示，所以该题卡壳的dot/cross支撑比较精确；面积乘除和角点恢复仍舍入。面积除10¹⁰，坐标除10⁵，输出10位小数。整体O(nlog n)时间、O(n)空间。
