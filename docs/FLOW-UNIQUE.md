# 最大流的边流量方案是否唯一

`flow_unique(const Dinic &g)`返回当前最大流的原边流量向量是否唯一。先用固定且不同的源汇完整求最大流；容量为非负long long整数、最大流值可表示。函数只读g，代表方案仍由`used(id)`读取；不返回另一组流量。重边分别计量，允许自环、零容量、断连图，并将独立环流计入方案。

“唯一”不是最小割唯一，也不是把流拆成若干条路径的拆分方式唯一。例如只有一条s→t边时流量唯一；s→x→t两边容量相等时，最大流也唯一，但可以在两条不同边处取最小割。相反，图外有一个正容量自环，即使s→t部分完全固定，整份流量向量仍不唯一。

## 判据和证明

建立所有正残量弧的有向图，求SCC。对每个SCC，计顶点数v和内部正容量原边数e；同一原边的正、反残量合计只算一条，正容量自环算一条，零容量边不算。存在e≥v的SCC即多解，否则唯一。

两个相同源汇流值的可行流之差保持所有点流量守恒；将正差沿正残量弧、负差沿反残量弧表示，得到残量图中的非零循环流，可以分解为有向环。只有同一原边的一对正反残量构成的往返不会改变原边流量，不能据“残量图存在有向环”直接判多解。

若某SCC内部无向多重图是树，则每条无向边都是桥；SCC的强连通性迫使桥的两个残量方向都存在。任意循环流在这条桥两向的净值必须为0，因此不能改变任何原边流量。SCC缩点图无环，跨SCC边也不能承载流量差。所有SCC均为树或孤点时，原边流量唯一。

反之，某SCC内部无向多重图有环。如果其中存在只有一个正残量方向的原边，由强连通性可以补一条返回路径，形成包含它的简单有向环；其反向残量不存在，所以这个环不是同一原边的往返，沿环至少增广一单位得到不同的整数流。若所有内部原边都双向有正残量，则任选一个无向环并定向即可；重边形成的二边环和自环也有效。SCC内部忽略方向后连通，因此“有无向环”等价于e≥v。无需求桥，也无需对每条边另跑最大流。

时间O(n+m)，额外空间O(n+m)，Tarjan仍为递归DFS，最坏栈深O(n)。代码中的`left`先存各分量顶点数，再按内部原边扣减，首次减至0即可判多解。
