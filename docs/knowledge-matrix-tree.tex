\section{带权矩阵树定理与方向约定}\label{knowledge-matrix-tree-weighted}
结果为所有生成树的边权乘积之和；无权计数令边权为 1。
重边是不同选择，自环不属于任何生成树，单点为 1。
零权、负权按代数运算处理，结果为零不能作为连通性判定。

无向边 $uv$ 权 $w$：$L_{uu},L_{vv}$ 各加 $w$，$L_{uv},L_{vu}$ 各减 $w$；删除 root 行列求行列式，与 root 无关。
内向树形图（每点沿边走到根）：边 $u\to v$ 贡献 $L_{uu}\mathrel{+}=w$、$L_{uv}\mathrel{-}=w$，删根行列。
外向树形图先反转所有边再用同一构造。
只构造 $(n-1)\times(n-1)$ 余子式，时间 $O(n^3+m)$、额外空间 $O(n^2)$；
恒等式不需要除法，模数须为素数只是模逆元消元的要求。

\section{任意正模数的矩阵树计数}\label{knowledge-matrix-tree-mod}
实现见第~\ref{compact-MatrixTreeMod}~节（第~\pageref{compact-MatrixTreeMod}~页）。
沿用第~\ref{knowledge-matrix-tree-weighted}~节的三种构造，行列式改用欧几里得消元
（第~\ref{compact-determinant_mod}~节，第~\pageref{compact-determinant_mod}~页）。
接口 \texttt{MatrixTreeMod::count}，边权和正模数均为 signed 64 位；
时间 $O(n^3\log(m+1)+|E|)$、空间 $O(n^2)$，$m$ 为模数。
边权先正规化到 $[0,m)$，矩阵加减先扩展到 128 位再取模；重边权和不能先累加到普通整数。
单点返回 $1\bmod m$，模 1 返回零；返回零不代表没有生成树。
