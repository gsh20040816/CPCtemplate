# WIDA 打印稿：树上问题

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `40c98911328d95e41e3645a8f32ccb774c0cbd32`，路径 `02 - 打印稿模板汇总/02 - 树上问题.md`。

无权直径和以前核过的在线模板一样。单点是 0，一条边是 1，四点路径是 3，星是 2。端点写进 `st` 和 `ed` 后没有返回。森林里从 1 出发只能看到直径 1。

带权封装要先调用 `dfs`、`dfs1` 和 `dfs2`，`getCenter` 自己不会调用。权为 1 的四点路径，半径是 2，中心是编号较小的 2。直径公式多加了 1，得到 4，实际边权和是 3。一条权为 5 的边，半径是 5，直径被算成 6。`getCog` 把 `vis` 开成 `n`，点号是 `1..n`。打开库断言后，访问 `vis[n]` 会中止。普通 ASan 没有抓住这次 `vector<bool>` 越界。

点分治片段使用 `n`、`ver`、`q` 和 `ans`，单独编译失败。`MaxTree` 写成浮点 `1e18`，类型却是 `int`。

树链剖分 LCA 和无权倍增，在小树上与沿父节点走到根的结果一致。根深度是 1。有权倍增的 `clac` 仍是边数。`query` 返回路径最大边权，初值是 0。路径权 3、9、4 时，`query(4,2)` 是 9，`query(2,2)` 是 0。

路径交要调用方提供全局的 `lca`、`clac` 和 `dep`。五点路径上，`1..5` 与 `2..4` 的交有 3 个点，`1..2` 与 `4..5` 没有交。

启发式合并使用没有定义的 `color` 和 `LL`。补上之后，根颜色 1、两个孩子颜色 1 和 2，答案是 1、1、2。`cnt` 按下标当颜色，长度只有 `n+1`。

`python3 tests/wida_treeprint.py` 在普通 `-O2` 和 ASan/UBSan 下通过上面这些能单独运行的例子。没有新的在线 AC，也没有新增模板。来源保持 partial。
