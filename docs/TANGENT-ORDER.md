# 公切线的精确切点次序

AOJ [CGL_7_F](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=CGL_7_F) 要求输出圆外点到圆的两个切点；[CGL_7_G](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=CGL_7_G) 要求输出第一圆的全部公切点。两题均为整数坐标±1000、半径1..1000，每行一个点，按x/y字典序，误差<1e-5。F保证点严格在圆外，G保证两圆不同，允许同心不等圆，零条公切线时完全无输出。

F可以直接用CircleTangents::from_point，取line.b。其非零分类间隙由整数性保证：d²-r²至少为1，d≤sqrt(8e6)，所以d-r>2e-4，默认1e-12相对容差不会合并两条切线。两切点同横坐标仅发生圆心与给定点连线水平，此时构造中的横坐标计算相同。最终按普通字典序排序。

G存在跨内外切线的精确同横坐标情形：第一圆(0,0,3)、第二圆(5,5,4)的切点包括(1.8,-2.4)和(1.8,2.4)。已有浮点算法在本机产生横坐标1.7999999999999998和1.7999999999999985，raw float排序会把正y放在负y之前。误差极小也无法满足点的输出次序。

新增IntegerTangents，独立声明Tangent/Result，只依赖IntegerPlane、RealPlane，无需额外抄写浮点公切线算法。输入坐标绝对值与半径≤10000，半径可为0；整数判别式精确判断条数，用两个平方根的精确符号比较排序，最后构造浮点坐标。返回的line.a顺序已确定，不要再排序浮点值；它不承诺第二圆切点有序。数学公式和int128的中间值界见书册「公切线：切点次序也需要精确判定」。内部比较函数仅用于这些参数范围。

同心同半径返回infinite（含两个相同点圆），同心不等为空；异心两点圆一条线。side为1/−1分别是外/内公切线，两个点圆为0。用normal和a定义直线：dot(normal,x-a)=0；相切时a=b仍可定义直线。精确的是分类和次序，输出坐标与单位法向仍有浮点舍入。

## 独立验证

- tests/integer_tangents.cpp：cpp_int确定条数，100位精度atan2/acos/cos/sin构造独立切点参考；小网格穷举、零半径、平移、交换、反射、缩放、AOJ及1e4范围、上限组合。共4644组；9261单根式、10000双根式随机符号及10000精确抵消，普通与ASan/UBSan均运行。
- tests/tangent_applications.py：404组F、995组G，80位角度参考；五个官方G样例对应的0..4条情况、同横坐标反例、近切以及随机输入。精确检查输出行数和每行两坐标，六个负例拒绝顺序错误、缺点、多点、NaN、Inf、超误差。依赖mpmath。
- 参考排序仅在高精度oracle中以1e-50绝对阈值识别横坐标的数学等号，模板没有此操作。不同切点横坐标差为r/q倍的代数整数A+B√C+E√F。此数次数至多4，全部共轭绝对值<4e9；若非零，代数范数为非零整数，因此绝对值≥(4e9)^−3，除以q≤8e8后仍>1e-40。1e-50识别阈值远小于此下界，80/100位计算误差也远小于该阈值。
- 浮点旧核心的任意精度接触点/直线证书、点圆、极端尺度回归也重新通过。旧classic仅从固定提交1a9fa3e91d7dff58915341040be069611370054c临时读取，主库仍仅vector版。
