# 带势并查集：差值方向、矛盾和数值边界

`PotentialDSU<T>` 维护若干未知量之间的精确加法差值。它是独立组件，不改变普通并查集的根挂接方向、返回值或可撤销并查集。

## 先固定方向

- `merge(u,v,w)` 加入 `potential[u] - potential[v] = w`
- 返回 true 表示这条约束与已接受的约束相容，包括重复的相容约束；不是“刚刚连通两个分量”
- 返回 false 表示矛盾，该约束不被接受；既有关系不变，但查根可能进行路径压缩，不能要求内部数组逐字节不变
- `diff(u,v)` 返回同方向的差 `potential[u] - potential[v]`；不同连通分量返回 `nullopt`
- 0、负数都是合法差值，不能用数值0或−1作为通用核心的“不知道”标记
- 0-based点号。n≥0，n=0仅能构造空结构；find/merge/diff/size的所有点号必须合法

示例：接受 p0−p1=3、p1−p2=5 后，diff(0,2)=8，diff(2,0)=−8。再次加入p0−p2=8返回true；加入9返回false，随后查询仍是8。

## 合并式的推导

内部 `d[u] = potential[u] - potential[fa[u]]`，根的d为零。路径压缩先保存旧父亲p，递归使d[p]成为p到根的差，再令d[u]+=d[p]。不能先覆盖父亲再从新的根读取旧父边信息。

查根后令a=root(u)、b=root(v)，du和dv分别为u、v到各自根的差。

p[u]−p[v]=w，故 p[b]−p[a]=du−dv−w。

当b挂到a时，把这个值写入d[b]。按大小合并若交换a和b，根间差也必须取反。已经同根时，只比较du−dv是否等于w，不能把矛盾边写入任何“额外关系”。

按大小合并保证压缩前父链深度O(log n)，路径压缩后摊还O(α(n))次群运算；空间O(n)。若T自身的加减复制不是O(1)，实际成本还要乘其成本。本实现使用递归find，不需要把任意n点输入图的最长链当作父链深度。

## T的合同

T必须提供T(0)、精确的加法、减法、相等比较和正常的值语义，所表示的运算形成加法交换群。普通整数差和模整数差是典型用法；不声称支持任意非交换群，也不以浮点近似相等维护严格的等价关系。

- long long版本要求每次中间加减都不溢出，而不只是最终答案落在范围内
- 一个易检查的充分条件：若每条输入约束满足|w|≤W，则 `(2n+1)W≤LLONG_MAX` 足以保守约束本实现的中间差；检查此乘积时必须先扩大计算类型。理由是每个已接受生成森林中的简单路径最多n−1条输入边，各个到根偏移与根间偏移都由这些路径给出；计算du−dv−w时，用各项绝对值的和界住中间值
- 这只是充分条件，实际合法数据可以更宽；不能反过来把超过该条件视为一定溢出
- 模整数不需要除法或逆元，所以合数模数也能使用；模数须在构造对应DSU之前设定，并保持到该tag的所有相关实例销毁后
- 模1的测试验证零群运算和结构连通性；未连接的两个点仍返回nullopt。它不承诺推导“零群里任意两个量在逻辑上都相等”这种额外结论
- 仓库中的动态mint提供所需的相等比较，可直接组合；静态ModInt目前未提供这个比较接口，不能直接替换后声称可编译

## 正式题目与用法232

[Library Checker Unionfind with Potential](https://judge.yosupo.jp/problem/unionfind_with_potential) 的正式题面是a_u≡a_v+x，查询a_u−a_v，方向与本核心完全一致。旧讨论中的相反记法不是最终题面的合同。

N,Q均为1..200000，点号0..N−1，0≤x<998244353。用法232组合PotentialDSU与mint，将模数设置为998244353；约束操作输出是否相容，查询已知时输出规范模剩余，否则输出−1。−1只作为正式题目适配层的未知标记，核心仍使用optional。

## 验证边界

独立参考维护全部已接受约束图，用BFS求差。核心对每个状态检查所有点对的optional和值、分量大小及根偏移；覆盖短约束序列穷举、随机整数/合数模约束、负值、零值、自环、重复、矛盾、不同大小根交换、接近充分界的大整数及动态模tag隔离。另有200000点平衡合并与顺序连接。

完整驱动按直接包含、登记展开、实际抄写三个形式验证。小输入由独立BFS给出答案；两份N=Q=200000输入用预先指定的p[i]=17i给出已知关系，并保留孤立点、相容重复与矛盾拒绝。输入尺寸达到正式上界不等于覆盖所有最坏性能分布。

五个故意错误版本分别破坏根偏移符号、交换取反、压缩累加、矛盾拒绝和未知optional，必须被真实断言拒绝。普通和ASan/UBSan报告分别绑定代码、编译器、二进制及实际输入输出摘要；抄写语法检查、局部性能和本地通过均不等于线上AC或全套回归通过。
