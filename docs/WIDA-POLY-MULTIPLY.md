# WIDA 12D 乘法与平移幂和核验

本批核对 hh2048/XCPC 固定树 cfdb12db6792eb2303798541fb5c760ed2bc618b 中两份不同的12D，不能按同名文件合并覆盖。原稿以精确字节和上游GPL-3.0许可保存在 tests/fixtures/wida_poly_variants。当前334组件、454份完整用法。

## 独立多项式乘法原稿

精确blob 4c51d1709859104bb84e086e0d6d275691b6f81f，包含power、dft、idft、mul。模数固定998244353，31具有恰好2^23阶：31^(2^23)=1，31^(2^22)=-1，因此分层根表在该模数下正确。它不是任意素数原根接口。

原稿蝶形及逆变换使用C++有符号余数；输出可以为负，但归一化后对应正确模系数。逆变换的(1-P)/n是n逆元的一种负代表，因为n整除P-1。蝶形输入及乘积余数绝对值小于P，u+v和u-v仍在int范围内。

mul在结果长度小于128时走朴素分支，常数乘法因此不调用dft。直接dft长度1却计算(i&1)<<(-1)，是未定义行为。单空数组与长度3数组相乘返回两个零，而双空数组会请求超大vector并抛length_error；这些不符合本库约定。本库NttConvolution支持长度1变换，任一空输入的普通乘法返回空，结果统一为[0,P)系数。

独立检查覆盖直接O(n²) DFT、逆变换、大小交替调用、127/128分支边界、正负系数和极值系数。普通及ASan/UBSan各96813项小规模检查，另各3项空输入行为检查。原稿与现库均以长度2^22和2^22+1的全1数组相乘，逐项核对长度2^23的三角形系数，各模式各8388609项检查。长度1直接变换的消毒器失败单独列为预期反例，不作为算法通过。

原稿注释指向QOJ350298；本轮网页工具无法读取该提交，因此未确认原题协议、提交源码完整性或新线上AC。此行保留partial，局部函数核验不能代替原应用核验。

## MInt版本尾部get(n,m)

精确blob f2063c0206f44f664a04090a48f9dea4c3054879的尾部并非另一种乘法封装。奇数m追加(x+m)^n；偶数m把前半段与平移m/2后的前半段相加。因此返回：

F(x)=Σ(k=1..m)(x+k)^n。

新函数shifted_power_sum(n,m)直接给出从常数项开始的n+1个系数。模数998244353，0≤n≤2^22-1，m支持完整uint64。m=0返回全零，n=0返回{m mod P}。例n=2,m=3返回{14,12,3}。

令H(t)=Σ(k=1..m)exp(kt)，则

H(t)=(exp((m+1)t)-exp(t))/(exp(t)-1)。

先将分子分母同时除t，分母常数为1；构造A_i=((m+1)^(i+1)-1)/(i+1)!、B_i=1/(i+1)!，做一次级数求逆与卷积得到H。最后F_i=n!/i!·H_(n-i)。n+1<P，所需阶乘均可逆。所有幂次数小于P-1，完整P项块的幂和为0，包括零次幂的P=0，因此可先把m取模；代码在模域里加1，不计算可能溢出的uint64 m+1。

时间O(n log(n+1))，工作空间O(n)，另有NTT历史单位根缓存。结果长度的两倍减一不得超过2^23；这里的限度来自完整卷积，而非声称内存对所有比赛都足够。依赖FpsInverse及其NTT和ModInt依赖。原稿get使用倍增与平移，最坏还带log(m+1)因子；新实现不复制其递归代码。n=0、m mod P=0和1直接返回常数、零多项式或二项式系数，避免简单退化输入的NTT开销。

验证包括普通及ASan/UBSan各52607项独立二项式展开、原稿对照、随机64位差分恒等式与完整周期检查；n=2^22-1、m=2时各核对4194304个独立二项式递推系数（(x+1)^n+(x+2)^n）。准确纸面程序与头文件驱动各模式分别105组Python大整数真值，包括uint64最大值。用法454另有集中样例检查。

MInt版本仍为partial：这里只核验尾部get的数学意义及小规模原稿行为，并验证本库替代函数；BM与有理级数系数已另行补充核验，见docs/WIDA-MINT-RECURRENCE.md；其他MInt、Poly、Comb成员和两份原题应用未完成审查。没有为新函数伪造正式模板题候选，线上验证和排名仍待补充。
