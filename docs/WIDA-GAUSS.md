# WIDA 16 旧版高斯消元核验

核验对象为 hh2048/XCPC 的精确 blob `f45eaa851860a615f3ad9801df134bea93ec898a`，所属树为 `cfdb12db6792eb2303798541fb5c760ed2bc618b`。原始字节保存在 `tests/fixtures/wida_gauss/gauss.cpp`，随附原仓库 GPL-3.0 许可。测试仅在外围补充原稿依赖的素数 P 和 power，不修改原稿。

## 原稿实际包含的内容

| 原稿操作 | 当前替代 | 前提与接口差异 |
| --- | --- | --- |
| 整数 gauss(a,b) | GaussMod<p>::solve(a,n) | 原稿要求素数域上的可逆方阵；当前版接收增广矩阵，返回一致性、系数矩阵秩、特解和齐次空间基，支持长方阵与奇异矩阵。空方程组也须显式提供变量数 n。 |
| double gauss(a,b) | GaussReal::solve(a,n,eps) | 原稿完全不选主元；当前版先按系数行缩放，再做部分选主元，返回的是受 eps 影响的数值分类，不能视为精确秩判定。 |
| 多项式 operator* | NttConvolution / PolynomialDivision 的卷积依赖 | 原稿是朴素二重循环，系数须规范化到 [0,P)。当前快速多项式组件的模数、变换长度约束仍须遵守，不是任意素数下的直接替换。 |
| 多项式 operator% | PolynomialDivision::divide | 原稿要求非空且最高项非零的除式，余式保留至多 deg(B) 个系数；当前版同时返回商和余式，并删除尾零。 |

模数消元寻找主元时没有检查行号上界。输入 A=[[0]]、b=[0] 时，ASan 确认 heap-buffer-overflow。不能用此原稿判断无解或多解。

浮点原稿对 A=[[0,1],[1,0]]、b=[2,3] 直接除以零，产生非有限结果；当前版得到 (3,2)。这说明原稿连“可逆方阵”这一前提也不足，还要求消元过程每一步的对角主元非零，并需另行考虑数值稳定性。

## 本地验证

`tests/wida_gauss.py` 校验原始 Git blob，然后分别以普通优化构建和 ASan/UBSan 构建运行 `tests/wida_gauss.cpp`。两种构建各通过 **35,741 项断言检查**，不是 35,741 道题或在线提交。

- 穷举 F2 上 0 至 3 行、0 至 3 个变量，以及 F3 上 0 至 2 行、0 至 2 个变量的所有增广矩阵。独立枚举全部变量赋值，检查解是否存在、齐次解数量推出的秩，以及返回特解与基所生成的整个解集。原稿只在其中可逆方阵上参与比较。
- 150 组严格对角占优实数方程，构造整数真解，分别检查原稿和当前模板；另有上述必须换行的反例。这些测试不保证任意病态矩阵的精度。
- 250 组多项式，独立按二重循环构造 A=QB+R，检查原稿乘法、取模以及当前模板的商与余式。模数为 998244353，包含常数除式；比较余式时明确处理尾零表示差异。
- 原稿奇异矩阵的越界在独立子进程中作为预期失败保存，未混入通过项数。

结果、诊断日志和输入源码 SHA-256 见 `verification/wida-gauss.json`。脚本可用 `python3 tests/wida_gauss.py` 重跑。
