\section{组合计数}\label{knowledge-counting-identities}\index{inclusion-exclusion}\index{Catalan}\index{Stirling numbers}
容斥：$|\bigcup A_i|=\sum_{\emptyset\ne S}(-1)^{|S|+1}|\bigcap_{i\in S}A_i|$。
二项式反演：若 $b_n=\sum_{k=0}^{n}\binom nk a_k$，则
$a_n=\sum_{k=0}^{n}(-1)^{n-k}\binom nk b_k$。
\[
\sum_k\binom ak\binom b{n-k}=\binom{a+b}n,\qquad
C_n=\binom{2n}n-\binom{2n}{n+1}.
\]
差分形式的 Catalan 公式避免在模数下除以 $n+1$。
斯特林数见第~\pageref{knowledge-stirling-definitions}~页。

\section{生成函数与递推}\label{knowledge-generating-recurrence}\index{generating functions}\index{Berlekamp-Massey}
OGF 乘法对应普通卷积；EGF $\sum a_nx^n/n!$ 乘法对应 $c_n=\sum_k\binom nk a_kb_{n-k}$。
求逆要求常数项可逆；$\log A$ 要求 $A(0)=1$，$\exp A$ 要求 $A(0)=0$；有限域积分要求 $i$ 不被特征整除。
\[
B_{\rm new}=B(2-AB)\pmod{x^{2m}},\qquad
(\log A)'=A'/A.
\]
BM 外推未来项前须另知序列有不超过相应阶数的线性递推（如由矩阵转移、有限状态得到阶数上界）。

\section{线性代数与生成树}\label{knowledge-matrix-span}\index{rank}\index{Matrix Tree theorem}
域上一致方程组的解集为特解加零空间，零空间维数为未知数个数减秩。
浮点秩依赖阈值；模素数消元精确；合数模数下不可随意除以非零元。
无向图 Laplacian 对角为度数、非对角为负的边重数，删去同一行列的行列式为生成树数；

\section{模线性方程组：工厂工期}\label{knowledge-widget-gauss}\index{Widget Factory}\index{模高斯消元}
POJ2947：星期一为 0、星期日为 6，产品 $j$ 在记录 $i$ 中出现 $a_{ij}$ 次（重复累加），
\[
\sum_j a_{ij}x_j\equiv \operatorname{finish}_i-\operatorname{start}_i+1\pmod7.
\]
用第~\pageref{compact-GaussMod}~页的模高斯消元，模 7，增广矩阵 $m\times(n+1)$。
先判 \texttt{consistent}（假则无解），再看秩小于 $n$ 为多解，否则特解中小于 3 的分量加 7。
合数模数不能直接套用此消元。

\section{数值算法与几何}\label{knowledge-numerical-boundaries}\index{numerical stability}
排序必须是严格弱序，不能以“差小于 eps 则相等”作比较器。
叉积与行列式易抵消；整数题优先精确整数判定。
自适应积分要求函数足够规则，奇点、间断、强振荡先分段。
三分要求单峰（整数域最后枚举剩余区间）；二分答案要求判定单调。

\section{线性递推：系数方向与外推条件}\label{knowledge-recurrence-direction}
\index{线性递推}
约定 $a_i=\sum_{j=1}^{k}c_{j-1}a_{i-j}$，初值 $a_0,\ldots,a_{k-1}$，特征多项式
\[
F(x)=x^k-c_0x^{k-1}-c_1x^{k-2}-\cdots-c_{k-1}.
\]
若 $x^n\bmod F(x)=\sum_{i=0}^{k-1}r_ix^i$，则 $a_n=\sum_{i=0}^{k-1}r_ia_i$。
BM 要求素数模数；已知阶数至多 $d$ 时至少给出前 $2d$ 项。
系数末尾的零不能删除，否则改变递推开始适用的位置。
BM 加特征多项式求余求第 $m$ 项：时间 $O(nk+k^2\log m)$，空间 $O(n+k)$。
