- 本次审计时 P1226、P1177、P3374 均无独立源码、驱动或候选提交记录。因此实际删除源码/驱动/算法条目数均为 0；明确退出独立扩展计划的基础题为 3，不宣称删除了不存在的条目。
- 原 Fenwick 条目包含 kth，保留同一实现、符号和依赖链接，标题改为“树状数组第 k 小与组合依赖”；add/sum/query 仍是 kth 与模整数等组合所需的接口，不拆掉其前提。
- 本次审计时算法条目为 200，用法为 198，本次清理不改变数量。来源覆盖账本、待归并条目及 OJ 归档不变，不把停止基础题扩展记为实现完成或新 AC。二维树状数组、动态第 k 小等未列入本次排除。
- `python3 tests/basic_template_scope.py` 检查三项精确排除、近似题号/高级用途/DSU 保留及当前候选一致性；已有依赖审计继续覆盖完整目录。

## 码风落实

- 短且清楚的条件语句、循环可合并；复杂分支、多级嵌套、状态传播继续展开。
- 相邻且关系明确的更新允许逗号表达式，不能引入难辨的求值顺序或副作用。
- 优先小写短名；现有公开类型名在对应模板验证时逐项迁移，不增加只为改名的代理封装。
- 只保留 STL/vector 版。递归 DFS 不变；需要状态的算法仍可用轻量 struct。
- 第一次调整先核对格式化前后 C++ token，再检查 LaTeX/PDF；纯排版变化不产生新的 AC 记录。

第一轮已允许短 if/循环同排，183 个头文件与驱动的 token 保持一致，总行数 11897 → 10987。函数体和复杂控制流仍展开，公开类型名未在此次排版操作中更改。基础题范围现按上述最新确认执行。

DSU 最新依据：[用户指定实现](https://github.com/gsh20040816/CPCtemplate/issues/2#issuecomment-5646284816)。已采用 find/same/merge/size/groups、fa/sz 与路径减半；不再沿用原有按大小合并的复杂度描述。
