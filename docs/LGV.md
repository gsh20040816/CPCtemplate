# LGV 路径行列式的语义

对应附件 3.4；[OI Wiki LGV 引理](https://oi-wiki.org/graph/lgv/) 给出有向无环图上的带权路径族恒等式。

令 M[i][j] 是 sources[i] 到 sinks[j] 的所有路径的边权乘积之和。当前函数先对整张图作拓扑排序，对每个起点沿拓扑序 DP，最后计算 det(M)。平行边按独立路径选择累计，允许模意义下的负权和零权，零长度路径权为 1。图中任何部分存在有向环都会返回 nullopt，不能把失败用模数值 -1 混在结果中。

将行列式按排列展开后，可看作所有路径族按终点排列符号加权。相交路径族在首次公共顶点交换尾部，边权乘积不变，排列符号翻转，因此成对抵消。剩下的正是顶点不交的路径族，仍携带该排列的符号。端点序列各自必须无重复，两个序列之间可以重叠；公共端点也算路径顶点，不能被两条路径同时占用。

特别注意：只有证明非恒等终点排列的无交路径族不可能存在时，行列式才直接等于指定配对的普通计数。例：仅有边 0→3、1→2，起点 [0,1]、终点 [2,3]。实际有一个交换配对的无交路径族，行列式是 -1，而不是 +1。将终点排序、取绝对值或认为负模值为失败，都破坏语义。模意义下的零也不能证明路径族不存在。

函数返回的是单个模行列式，不返回路径方案。若题目中的路径数已有组合数公式，可直接构造小矩阵调用 det_prime，无需显式建立大 DAG；当前 DAG 接口不能据此声称覆盖所有 LGV 应用题。

验证完全枚举小 DAG 的每一条路径、终点排列和顶点不交路径组合，直接计算带符号权值和，不使用另一个行列式程序当作唯一判据。覆盖 3000 个随机重标号 DAG、重边、负权、零权、重合端点、空族、循环拒绝和 100000 点链。示例属于本地接口用法，不计非比赛模板题覆盖。
