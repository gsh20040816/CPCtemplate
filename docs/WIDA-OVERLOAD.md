# WIDA 在线模板：基础函数重载

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `5fce17a4572dd6d7803e711f7d80362c8e862284`，路径 `01 - 常用在线模板汇总/01 - 初始与杂类/02 - 基础函数重载.cpp`。`mypow` 的默认模数 `MOD` 没有定义，`mylcm` 调用的 `__gcd` 在这份编译器里只存在于 `std`。单独编译失败。`assert` 也没有包含 `<cassert>`。

补上 `MOD` 和 `std::__gcd` 后，`mypow(2,10)` 是 1024，`mypow(2,10,1000)` 是 24。`mylcm(4,6)` 是 12，`mylcm(0,5)` 是 0。`Log2` 对 1、2、3、8 给出 0、1、1、3。`Log2(-1)` 看成位模式，结果是 31，不是数学对数。`ceiledLog2(1,3,5)` 是 0、2、3。`floor` 和 `ceil` 对 `5/2`、`-5/2` 分别给出 2、-3 和 3、-2。

`mypow(100000,2)` 在取模之前做有符号乘法，UBSan 报 `100000 * 100000` 溢出。`Log2(0)` 把 0 传给 `__builtin_clz`，这不是合法参数。负指数没有跑，右移可能停不下来。

`python3 tests/wida_overload.py` 在普通 `-O2` 和 ASan/UBSan 下通过小整数例子，并记录了这两处边界。没有新的在线 AC，也没有新增模板。来源保持 partial。
