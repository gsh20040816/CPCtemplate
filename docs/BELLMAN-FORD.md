# Bellman–Ford：三态距离与原边方案

`BellmanFord(n)`使用1-based点号，0<n<INT_MAX。`add(u,v,w)`返回0-based原边编号，允许自环、重边和完整signed64权值，总边数≤INT_MAX。加边使旧结果失效，必须重新run。

`run(s)`检查从s可达的负环，返回true表示不存在；s=0时将全部点距离初始化为0，等价于超级源点，可检查任意连通部分的负环。每次run清空先前距离、前驱、负环标记与方案。

运行后按如下次序读取结果：

- dis[v]==inf：不可达。
- neg[v]：存在起点可达负环且负环能到v，答案为负无穷；内部dis标签不是答案。
- 否则dis[v]是int128有限最短距离。

`path(v)`返回有限最短路的正向原边编号。不可达、负无穷和零边路径均返回空，结合上述状态区分。`cycle`为空表示无相关负环，否则返回一条负环的正向原边编号。通过e[id]读取端点和权值。run(0)的有限值是任意起点出发到该点的最小距离，允许零边路径，不是某个指定单源的距离。

## 正确性与数值范围

每轮扫描全部边，仅从有限标签松弛。第k轮结束后，至少包含所有不超过k条边路径的最优值；无可达负环时，最短路可取简单路径，至多n−1条边。提前一轮没有改动即可结束。

第n轮仍改动的点受可达负环影响。从全部这些点沿出边BFS传播，得到恰好所有负无穷点。即使负环到后继的边权极大、后继在第n轮没有再次降低，也须传播，不能只标记第n轮被更新的点。此处是图上的BFS队列，不是模拟递归DFS。

取第n轮最后改动的点，沿前驱走n步进入前驱环，再按前驱边收集至起点，最后反转成正向顺序。有限点的前驱链给出等权最短路；接口始终保留原始边号，重边也能无歧义核验。

标签使用int128，inf为2^126。最多nm次更新，每次更新给其所代表的有限游走追加一条边，因此游走长度不超过nm；n,m的int上界和signed64边权使绝对值严格小于2^125。不可达哨兵不参与松弛，无需饱和截断，也不会把长负环截断成错误的有限答案。调用方打印或参与后续运算时不能无条件转long long。

时间O(nm+n+m)、空间O(n+m)，path输出耗时O(路径长度)。字段及内部状态只读，支持普通独立拷贝。

## 来源差异与完整用法

kuangbin4.1.3印刷131–132页未在松弛前跳过不可达点。WIDA固定提交cfdb12db6792eb2303798541fb5c760ed2bc618b的`02 - 打印稿模板汇总/03A - 图论.md`同样缺少不可达保护，并在输出时固定把源点写成0，即使源点已受负环影响。新模板以三态距离避免这些问题。两项Bellman–Ford来源记为local-tested；独立SPFA条目保持原状态。

用法293为正式模板题[AOJ GRL_1_B](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=GRL_1_B)，将0-based输入转为1-based，只在起点可达负环时输出NEGATIVE CYCLE；不可达点输出INF。其官方规模与边权确保有限距离可转long long。

用法294为[CSES1197](https://cses.fi/problemset/task/1197/)应用，run(0)查全图负环，输出闭合顶点序列。用法295为API演示，输出各点三态距离、原边路径与负环；保留int128打印。
