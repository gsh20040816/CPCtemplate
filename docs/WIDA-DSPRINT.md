# WIDA 打印稿：数据结构

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `8dbb0e73c1a81acf14fb8d143b06b088a1762749`，路径 `02 - 打印稿模板汇总/08 - 数据结构.md`。

并查集把 1 和 2 合并后，点数是 2，边数是 1。再把 1 和 1 合并会记成自环，边数变成 2。单点树状数组对 1 加 3、对 3 加 4，区间和是 7。区间加的树状数组把 1 到 3 都加 5，2 到 3 的和是 10。区间最值把位置 1、2 设成 4 和 9，最大值是 9。排名树状数组插入 3 和 5 后，5 的排名是 2，排名 1 的数是 3。逆序对那段把 `add` 和 `rangeAsk` 写成了省略号，不能编译。

简单离散化把 `3,1,3` 收成 `1,3`，下标是 0 和 1。封装版额外放了一个最大值哨兵，`operator[]` 用的是 `upper_bound`，所以 1 和 3 的返回值是 1 和 2，`Get(0)` 才是 1。它使用 `assert`，这份 `bits/stdc++.h` 不提供这个名字。

ST 表对 `5,1,4,2` 的区间 `[2,4]` 最大值是 4，`[1,3]` 最小值是 1。分数比较 `1/2 < 2/3` 成立。加法写成了 `const` 参数再调用非 const 的 `+=`，不能编译。

区间加、区间最小值的线段树，初始 `1,2,3` 的和是 6、最小值是 1。懒标记的空值是 -1，整段加 5 时会把 -1 加进标记。之后再读位置 1，得到 4，不是 6。

珂朵莉树先 `split(r + 1)` 再 `split(l)`。后一次拆分会使前一个迭代器失效，给 `[1,5]` 赋值 `[2,3]` 时程序中止。`kth` 在没找到时也没有返回值。

`vector` 按顺序插入 3 和 1 后，3 的排名是 2，排名 1 的值是 1。pbds 那段把 `#include` 和 `cin` 放在一起，原文不能编译。把语句放进 `main` 后，同样的询问得到 2。普通莫队的 `add` 和 `del` 是空函数，所以询问答案保持 0。

区间赋值、区间取模只是片段。区间乘加、异或、拆位、树链剖分、取模类、大整数和带修莫队例题这轮没有运行。二维树状数组、小波矩阵、主席树、KD 树、线性 RMQ 和线性基之前已经有库内对照，这次没有改写成新模板。

`python3 tests/wida_dsprint.py` 在普通 `-O2` 和 ASan/UBSan 下通过上面这些会结束的例子。没有新的在线 AC，也没有新增模板。来源保持 partial。
