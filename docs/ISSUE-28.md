# 代码前的问题描述与核心思路（issue 28）

每个模板节现在按以下顺序排印：

1. **问题描述**（解决具体问题的算法，144 个）或 **功能**（通用数据结构与底层组件，99 个）：题目模型与所求结果，或支持的操作及输入输出；不附会 OJ 题。
2. **核心思路**：代码实际采用的状态、不变量与步骤，变量名用打印代码中的名字。
3. 可选的“思路中的情况 → 代码中的处理 → 行”对照表（35 个分支或阶段较多的模板）。行号由 `tools/book.py` 按 `find` 子串在打印代码中唯一定位后计算，与清单行号一致，代码改动后不会悄悄错位（找不到或不唯一时生成失败）。
4. 代码依赖、**接口契约**（原 catalog 说明，保留宽度、计数类型、边界、复杂度等全部约定），然后才是代码与模板题用法。

数据在 [template-intros.json](template-intros.json)，按 catalog 顺序覆盖全部 243 个模板；总册与各分册由同一数据生成，呈现一致。`Mo` 的长契约沿用原来排在调度代码之后的版式，问题与思路仍在代码之前。

## 样例：`grid_cycle`

按 issue 给出的方案，在代码前加入题意（含 2×2 全空网格答案 1 的小例）与按行扫描轮廓、插头编号、何时允许闭环的思路；对照表把“遇到 *、无插头、单插头、不同路径合并、同一路径闭环、重编号、换行左移”对应到实际分支行号。原先放在代码之后的“轮廓与不变量”“转移与去重”两段已并入思路与契约，契约中重复的状态编码描述改为不变量与编号上限；代码后只保留“数值与验证”。分页的续页标题也写明该页对应的分支。

样例覆盖的类型：插头 DP（问题＋对照表）、区间 DP（`knuth_interval_dp`）、分组 DP（`monotone_dp_layer`）、图上计数（`MatrixTreeMod`）、树状数组与 NTT 卷积（组件）、斯特林数四种行列求解（简述后指向紧邻的推导）。

## 其余章节

其余 233 个模板按分册分 7 批起草，每批逐个对照打印代码撰写，脚本校验字段、长度、LaTeX 文本模式字符与 `find` 唯一性，合并后人工抽查。已有清楚推导的知识节（斯特林数、四边形不等式等）只写一句并指向上文，不重复推导。

分割成多页的代码在首段前按其行数预留空间，避免引言把首段挤过页后又被强制换页留下空白页。
