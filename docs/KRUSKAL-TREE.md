# Kruskal重构森林

Issue #15。组件 `KruskalTree`，用法370 P4768、371阈值分量API。只保留vector封装，复用dsu；使用时先抄依赖，再抄该结构体。

## 模型与不变量

原点0-based，无向边可重、可自环、可断连。按边权升序或降序扫描；每次连接两个不同分量，创建一个新点，以两棵已有分量树为儿子，记录该次边权。DSU在原点上按大小合并，top记录当前分量对应的重构节点；不用将深度可能为n的重构树直接当并查集父链。

升序时，重构路径上的内部点权单调不减；对阈值w保留权≤w的边，所有符合阈值的Kruskal合并恰好构成该子图的连通分量。降序同理改为≥。严格版本排除等于w的合并。二进制倍增找到最高合法祖先，其子树叶点恰是原点所在分量。同权的多次合并不能只跳一次，必须爬完所有合法祖先。

叶点权不代表任何边，不使用LLONG_MIN/LLONG_MAX作叶点或根的权哨兵；只查看真实父点。这样完整signed64端点也可用，严格查询直接比较而不将w加减1。

父点编号总大于子点，聚合时按n..k-1扫描即可，这是构建顺序形成的拓扑序，不是用显式栈模拟DFS。需要枚举子树时仍可递归。断连时保留多个根，不添加带伪边权的超级根。

build重置全部结果，允许切换方向和重复构建；新加边后必须重建。所有输出成员只读，不支持用户直接改e/ch/up。范围、复杂度和接口细节见catalog同源正文。

## P4768映射

先在原图以长度跑1号点Dijkstra；汽车可达分量由海拔严格大于p的边构成，故用降序重构树且strict=true。能在任意可达点下车，答案是该分量中到1号点的最短距离最小值。边长正数，最短路有简单路径见证，按题面上限(n-1)*10000<2e9；解码和距离均用long long，避免中间加法越界。

n=1、m=0和q=0正常处理；每组重新构造组件，last从0开始。Dijkstra为1-based，重构树为0-based，读边和查询处转换一次。P4768为竞赛应用，不能因为题目常用于练习就把它标成独立正式模板题。

## 验证

`python3 tests/kruskal_tree.py`，加`--sanitize`使用ASan/UBSan。

核心3000组随机森林：n=0..9，重边、自环、负值及LLONG_MIN/MAX；升序/降序/重建三次，严格和非严格阈值都与直接边扩张真值比较完整叶点集合。验证父子、根数、互不相交及复制后加边；20万点链逐个检查阈值分量大小。

两份驱动均验证头文件、NDEBUG、完整展开、最小依赖抄写。P4768用100个小图Floyd + 显式阈值连通块作为独立真值，覆盖强制在线；额外三组同输入复位和最大n=200000,m=400000,q=400000压力。API覆盖100个小图及空图。三个错误变体分别破坏strict、方向和DSU到树根映射，须被测试检出。
