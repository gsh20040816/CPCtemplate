# 简单无向图四元环计数

Issue #15；`count_four_cycles(n,edges)`，用法378为U367189的1-based题面适配，用法379为0-based接口。当前提供本地验证，线上提交尚未完成，不能勾选issue完成项。

## 定义与接口

输入n≥0、点0..n-1、m≤INT_MAX，edges中每条无向边仅出现一次，不允许自环和重边，函数不自动去重。允许空图、孤立点、断连；不改动输入，多次调用互不影响。返回long long。

计四个互异顶点及四条边构成的环，按边集区分，不计起点和方向。不要求诱导子图恰好只有四条边，因此有弦的环仍然计数，K4的答案是3。与四点团、四个点集合数量、有向菱形计数都不同。

## 正确性

按(度数,编号)为全部点建立严格全序；每个环恰有一个最大点u，对面点为w，两侧点v1、v2。枚举u-v-w，要求v和w都小于u。处理第二条路径时，把它与已经经过其他中间点的cnt[w]条路径配对；简单图保证每个中间点只贡献一次，因此两条路径组成四个不同点的合法环。每个环仅在最大点u、第二个中间点被访问时计一次，无需最后再除以2或4。

同度点必须用编号打破并列。每轮u结束后仅清空实际访问过的cnt位置；不能漏清，也不能每轮清空整个n数组，否则大量孤立点时会退化至O(n²)。touched只在cnt首次由0变为1时加入，所有访问总数受二步路径枚举数控制。

## 复杂度与数值范围

每条边只从较大点u向较小点v展开，遍历deg(v)个邻点，总工作量为各边两端较小度数之和。设阈值B=√(2m)：较小度数≤B的边总计≤mB；两个端点度数都>B时，这样的点不足B个，每个点只需为至多B个较大邻点展开，合计≤2mB。因此时间O(n+m√m)，空间O(n+m)，不排序、无需递归。若只按编号定序，星形图可退化为二次复杂度，不能沿用上述界。

cnt[w]≤n-2≤INT_MAX，所以用int即可；ans必须long long。每个四元环有两对对边，任意一对无公共端点的边至多形成两个四元环，所以总环数≤C(m,2)。m≤INT_MAX时该值<2^61，返回类型安全；不把中间累计放进int。

## 证据与限制

`python3 tests/four_cycles.py`，加`--sanitize`运行ASan/UBSan。独立真值逐一枚举四点组合的三个环序，不依赖度数排序或二步路径。枚举n≤6全部33868个简单图，3000组随机图及重编号、端点翻转、边序打乱、不修改输入、补孤立点。压力样例包括K632、K2,99998、K400,500、10万点星形及全孤立点；前几个计数超过32位。三种错误变体分别删除同度编号排序、漏清cnt、把答案缩成int，要求均被检测。

两份驱动验证头文件、NDEBUG、完整展开及最小抄写四种形式；用法包含151组随机图、K4和大规模稀疏图，零基接口另测空图。线上AC、运行时间和速度排名尚无证据，不从本地通过推断。
