# 动态点分树：最近活动点

固定连通非负权树，0-based 点号。`CentroidNearest(n)` 后用 `add(u,v,w=1)` 加 n−1 条边，`build()` 清空活动集；随后 `set(u,on)` 幂等设置，`query(u)` 返回最近的 `(距离, 点号)`，距离相同时选最小点号。没有活动点返回 `nullopt`，距离 `LLONG_MAX` 是合法答案。`active[u]` 只读，可以用 `set(u,!active[u])` 翻转。其余字段、辅助函数均为实现细节，不供外部修改。

每个点记录其所有重心祖先以及原树距离。重心 c 的 `bag[c]` 存储分治块中活动点的 `(dist(c,v),v)`。启用和停用只影响这个点的 O(log n) 个祖先；键包含原点号，删除一个同距离点不会删掉其他点。点分治结构只依赖拓扑，可以在原树上重复 `build()`，清空路径记录和所有活动状态；建树后不能改变边。正常对象支持值复制，复制后修改互不影响；移动后的源对象仅销毁或重新赋值。

查询 u 遍历其重心祖先 c，用 `dist(u,c) + bag[c].begin()->first` 更新答案。非负边权保证该和不小于真正的 `dist(u,v)`。对最优活动点 v，取 u、v 在点分树上的最近公共祖先 c：两点在 c 的不同分治分支中，或有一个就是 c，所以 c 在 u 到 v 的原树路径上。于是对应候选恰能达到真正最优距离。按 `(距离,点号)` 比较，并在每个 bag 中同样排序，可保证最小点号见证：若更小编号的候选有同样的绕路距离，它的实际距离不会更大，故它本身也是合法最优点。

要求所有原树简单路径和能用有符号64位表示，边权非负。即使满足这个条件，绕过重心的候选距离仍可能溢出，例如三点链的两条边权分别为 `LLONG_MAX` 和0，查询端点自身会产生 `2*LLONG_MAX` 的绕路。代码在相加前检查并跳过这类候选；最优点对应的路径重心给出的候选不溢出，因此不会漏解。不能用 `LLONG_MAX` 表示无答案，也不能把检查中的 `>` 写为 `>=`。

构造时间、空间均 O(n log n)，单次启停 O(log² n)，单次查询 O(log n)。使用标准 `set`，最坏所有活动点时会有 O(n log n) 个树节点，其实际内存常数高于连续数组。DFS 全部递归，原树链上的递归深度可达 n；本地最大规模测试增加原生栈，不改写为显式栈。

## QTREE5 与来源边界

用法245完整对应 [SPOJ QTREE5](https://www.spoj.com/problems/QTREE5/)（[洛谷 SP2939 镜像](https://www.luogu.com.cn/problem/SP2939)）：N、Q≤100000，单位边，初始全黑；0翻色，1查询最近白点距离，无白点输出−1。白点映射为活动点，输出只用返回对的距离。原站来源标为“XunYunbo, modified from ZJOI07”，因此作为应用用法登记，不视为独立非比赛模板题。

已逐段核对 kuangbin 2018 §3.5.4（打印页82–84）的题目与代码。原文中文题意误写“最远”，但源码用 `min` 和 `multiset.begin()`，与官方最近白点题意一致。原实现使用 LCT/虚子树 multiset；本组件用固定拓扑点分树替代，覆盖同一 QTREE5 功能，**不声称复刻 LCT 维护方法或支持动态拓扑**。加权距离、同距最小点号是本库扩展，单独做本地验证，不借用单位边题成绩。点分树分类参见 [OI Wiki 动态点分治](https://oi-wiki.org/graph/dynamic-tree-divide/)。

## 独立验证

`tests/centroid_nearest.py` 编译头文件/仅标准头抄写两种核心，各有 assert 与 NDEBUG 版本。探针对 n≤6 的所有标号树、每个活动子集，以及单位权/全零权/混合权三种赋权逐点核对；参考使用原树 BFS 距离后扫描活动集，不依赖任何重心记录。另含随机加权树、重复设置、复制前后独立性、重建清空、同距离点删除、空集、最大合法距离和溢出绕路。

核心还测试 n=100000 的链、星和二叉树的全开/全关、自查询与单一根活动点。完整源驱动、展开程序、最小标准头抄写三个版本分别运行官方样例、180组随机单位树输入，以及3种 N=Q=100000 结构；大输入参考按原树结构直接计算到少量活动点的距离。

错误删除全部同距离点、忽略停用、错误点号平局、重建保留活动点、把最大距离当哨兵的变体必须被独立参考拒绝；删除溢出防护必须被参考或 UBSan 拒绝。普通、ASan/UBSan证据分别保存；本地通过不等于线上AC或全库回归。未新增线上提交。
