# 正则二分图完美匹配

`regular_matching(g, seed)` 接收从左侧出发的邻接表，两侧顶点均为0..n-1，每点度数恰好为同一个正整数d。重边必须按重数重复存储。返回左侧各点对应的右点，输入不变；空图返回空。非空零度图、两侧度数不相等或非正则输入不适用，不能用于一般二分图。函数仅求一个完美匹配，不计算完整边染色或所有匹配。内部匹配数组初值为-1，避免将右点0误判为空。

每轮从所有未匹配左点中均匀随机选起点，均匀抽取当前左点邻接表的一项。若到达已匹配右点，就沿其匹配边到下一个左点；若到达未匹配右点，翻转路径。`path`记录当前无环交替路径，`pos`记录路径中位置；遇到旧左点便删除末尾形成的环。它是游走路径，不是用显式栈模拟DFS。翻转从末尾开始，用左点原匹配作为下一步要重新分配的右点；每次成功恰好增加一条匹配。

这里保留所有邻接项，包括通向当前匹配右点的项；它们形成可立即消掉的自环。不能把重边去重再均匀抽邻点，那样不再是按原边均匀抽样，会破坏下面的平衡性证明。

算法思路参考 [Goel、Kapralov、Khanna 的原论文](https://theory.epfl.ch/kapralov/papers/match-linear.pdf)，本版对所有原边采样，以下直接证明含自环的版本：剩余k个未匹配左点时，把每对已匹配点收缩，所有原边定向左→右；另加s到每个未匹配左点的d条边、每个未匹配右点到t的d条边。识别s=t后，各点入度等于出度，s度数kd，总出度(n+2k)d。包含s的强连通分量没有出边，平稳分布与出度成正比，所以从s出发返回s的期望步数不超过n/k+2。这个回路给出一次成功的交替游走，去环不增加时间。

每次尝试最多4(floor(n/k)+2)步，失败则清空路径、重新随机选择未匹配起点，匹配本身不变。由Markov不等式，每次独立尝试的成功概率至少1/2。单次增广期望O(1+n/k)，求和得到O(n log(n+1))期望游走工作量。加上度数检查与读取，总期望O(nd+n log(n+1))，额外空间O(n)，输入空间O(nd)。这是独立均匀随机模型的期望界；固定mt19937_64种子没有确定性最坏耗时保证。随机性影响运行时间和选择哪一个正确方案，不以概率猜测答案，也不会在重试耗尽时返回残缺匹配。

[QOJ265](https://qoj.ac/problem/265)明确允许重边，nd≤2000000，3秒、2048MB。驱动将输入1-based转成0-based，输出反向转换；使用时钟种子，核心测试用固定种子复现。已用CCF_NOI获得 [QOJ265满分](https://qoj.ac/submission/3150703)，页面显示1391ms、152212kb。排名未核验。

本地验证检查每份返回结果确为0..n-1的排列，且每一对都在原图中；这种证书检查直接验证整个答案，不依赖另一个匹配实现。穷举n≤3、重数0..2的96个非空正则邻接矩阵，各20个种子；3000组由随机排列并集生成的正则多重图，各4个种子，涵盖大量重边和打乱邻接顺序。大图覆盖nd=2000000的d=1、2、20、2000，循环邻接、平行边分量及高度重复的循环连接，各3个种子。本机时间仅作压力测试记录，不是OJ排名。
