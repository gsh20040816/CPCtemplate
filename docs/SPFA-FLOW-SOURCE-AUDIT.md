# kuangbin SPFA费用流来源核验

已逐页核对固定2018原稿正文169–170页（物理171–172页），PDF SHA256为`f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad`。78行完整片段保存在`tests/fixtures/spfa_sources/kuangbin.inc`；去掉行号、页眉和排版缩进，拼回第46行的版面折行，并把Unicode减号/波浪号规范为ASCII，执行语句不变。该片段没有main；测试在独立namespace中原样编译。

## 接口对应

| 原稿 | 当前SpfaFlow | 约定 |
|---|---|---|
| `init(n)` | `SpfaFlow g(n)` | 原点号0..n−1，当前1..n；重建清空所有边与流量 |
| `addedge(u,v,cap,cost)` | `id=g.add(u,v,cap,cost)` | 两个方向相反的原边仍各有残量反边；自环/重边保留 |
| 原偶数边`edge[id].flow` | `g.used(id)` | 当前add返回原边编号；反边编号都是id^1 |
| `minCostMaxflow(s,t,cost)`返回int流量，通过引用输出int费用 | `g.flow(s,t,limit)`返回pair<long long,int128> | 都返回本次增加的流量与费用，均不把上次结果重新计入；当前支持限流 |
| `edge[id].cap-edge[id].flow` | `g.e[id].cap` | 两种残量存储不同，不能把cap变量直接互换 |

重复调用必须保持同一源汇和合法最小费用残量状态。原函数每次令引用cost=0，但不清除边流量；耗尽后再次调用返回0并写cost=0。当前也是增量接口，之前若仅送一部分，可以继续。原稿没有限流参数，不伪造原稿限流测试。

两版都逐次求残量最短路并增广。原稿以头插链表遍历，当前vector顺序遍历，因此平局时允许不同逐边方案；测试比较最大流、最小费用及独立方案证书，不要求选择完全相同。

## 前提与边界

两版等价范围要求初始残量图全局无负费用环、s与t不同。原稿没有负环检测，从源点可达的负环可能导致队列不断松弛；不实际无限运行此输入。与源点不连通的负环则被原稿忽略：1→4容量1费用0，2→3容量1费用−1、3→2容量1费用0，原稿得到(1,0)，枚举允许环流的最优答案是(1,−1)。当前SpfaFlow在变更容量前检查全局残量负环并抛invalid_argument，明确拒绝这个输入；不能把拒绝说成求出了含负环的答案。含负环模型须用单独的负环费用流组件。

原稿声明最大费用可通过费用取反求得。这个转换在代数上成立，但仍须满足取反后无负环（原模型无正费用环），并避免取负溢出；不能对任意有向图直接照用。本测试在DAG上同时核验原费用与取反费用，保证两种符号均满足前提。

原MAXN=10000支持0-based至多10000点；MAXM=100000容纳反边，故至多50000条原边。原容量、费用、距离、流量和费用和均为int；当前容量/流量long long，距离/费用int128，数值合同保持[FLOW-ATTACHMENT](FLOW-ATTACHMENT.md)不变。

原INF=0x3f3f3f3f不只是容量分批的哨兵，也是最短路上界：仅一条容量1、费用恰等于INF的边，原稿因严格松弛条件输出0流，当前正确输出1流和INF费用；这个问题不需要任何整数溢出。另用UBSan分别重现原费用50000乘流量50000的int乘法溢出，以及cost=INT_MIN时反边取负溢出。它们是来源合同的限制，不冒充某个官方题目的合法输入，也不是当前模板失败。

跨实现正常案例使用n≤10000、原边≤50000、|cost|≤100，容量非负且总容量≤100000、Σ(cap×|cost|)≤10000000；简单最短路的绝对值小于INF，流量及中间费用也安全。原稿本身不检查这些边界。大容量与超64位距离测试仅传给当前实现。

若增广A次，SPFA最坏时间O((A+1)VE)，空间O(V+E)。不声称SPFA快于势能Dijkstra，不因本地通过给线上速度榜赋值。

## 验证证据

`tests/spfa_source_audit.cpp`以逐边枚举所有整数流量为独立参照，按守恒条件求每一个可行总流量的最低费用。覆盖三点无自环有向图的729种0/1费用组合、800组以顶点势加非负约化费用生成的图、125种DAG及费用取反图；包含负边、自环、平行/反向原边、零容量与零费用环。原稿跑满后检查每条边、容量和守恒，当前逐单位限流检查所有中间最优值并检查续流耗尽。专门的反边撤销例子验证最终撤销先前的2→3流量。

另覆盖10000点负边链及50000条原边的精确数组容量边界。当前单独覆盖LLONG_MAX流量、总费用与最短距离超过64位，以及连通/不连通负环的拒绝且容量不变。检查函数不依赖assert，因此NDEBUG不会移除参照核验。

普通和ASan/UBSan各编译头文件/最小抄写、assert/NDEBUG四种核心形态，每种1782组正常等价图、406268项检查（检查数含独立边界案例）。used符号错误、不增加反向残量、漏掉全图负环检查三个错误变体均被拒绝。两种来源算术溢出单独登记为预期失败。

报告为`verification/spfa-source-audit-normal.json`和`verification/spfa-source-audit-sanitizer.json`。本批映射kuangbin4.17.1到现有SpfaFlow；zkw及费用流父节继续待完成。没有新增组件、手册用法、正式题目、在线AC或排名；既有P3381/SPFA用法与PDF不变。
