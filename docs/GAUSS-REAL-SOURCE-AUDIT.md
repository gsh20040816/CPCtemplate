## 返回值不能按原注释用于一般系统

原稿使用double、固定绝对eps=1e-9，a保存系数，x起初为右端项。每轮行号和列号同时递增，选当前列最大绝对值主元；主元小于eps时立即返回0，否则归一化并对其他行消元。行或列耗尽后直接返回1，没有检查剩余矛盾行，也不跳过自由列。

因此“返回0无解、1有解”并非一般奇异/矩形方程组的正确合同。下面反例均直接执行未修复原稿：

| 系统 | 原稿返回 | 精确结论 |
|---|---:|---|
| x+y=2，2x+2y=4 | 0 | 有解，秩1，一维自由度 |
| x=0，x=1 | 1 | 无解，系数秩1 |
| 0x+y=1 | 0 | 有解，第一列是自由列 |
| 1e-10 x=1e-10 | 0 | 唯一解x=1，绝对阈值丢弃了主元 |

在方阵且每步主元足够大、算术误差可接受的前提下，原稿可作为唯一解消元过程；仍不能把它当作任意尺度实矩阵的可解性认证。测试中438个非奇异小方阵全部通过精确解对照，不把有问题的泛化注释扩大成“所有原稿场景都错误”。

## 独立小系统核验

`tests/gauss_real_source.py`穷举m,n∈{1,2}、所有增广项∈{-1,0,1}的846个系统，另加上表4个定向反例，共850组连续输入。Python Fraction消元独立求精确秩、一致性、自由变量取零的特解，以及按自由列顺序排列的零空间基。

普通及ASan/UBSan两种模式下，分别运行assert/NDEBUG探针。原稿与当前GaussReal在同一探针内接收相同矩阵。每种形式均观察到原稿返回值与精确一致性不符158次：109次假阴性、49次假阳性。这里统计的是固定测试集上的事实，不是实际比赛输入发生率。

当前GaussReal以eps=1e-12调用，对这850组的分类、系数秩、特解和零空间基均通过参考核验；浮点向量与Fraction参考用1e-12绝对容差比较。删掉原稿右端项归一化的突变，在标量方程-x=1上以解值错误被拒绝。LSan关闭。

探针用命名空间隔离原稿全局变量，并在纳入原稿后取消eps宏；不修改原消元函数。每组重新填入矩阵和右端项，未提供的x槽位清零。只测试正行数、正变量数的小尺寸，不借此放宽来源数组容量。

## 对应现有模板的范围

来源需求由现有 `GaussReal`（用法233）对应：跳过数值零列、检查剩余右端项、返回数值秩/特解/零空间基。原32行来源覆盖项从pending改为local-tested，不新增重复组件、正式模板题或线上AC。

GaussReal有行尺度归一化和显式eps，其数值模型不同于原稿绝对eps规则。上述小型精确参考只证明受测矩阵上的结果，不能把浮点阈值提升为原矩阵精确秩证明。病态、舍入、尺度和非有限中间值的使用限制继续以 [数值合同](GAUSS-REAL.md) 为准。本轮不改核心代码、用法或任何PDF；旧验证收据保持历史原样。
