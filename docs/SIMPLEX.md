# 两阶段单纯形

`Simplex(A,b,c)` 求 `max c·x`，约束为 `Ax≤b`、`x≥0`。A有m行n列，b长m，c长n，均用long double，所有输入必须为有限数且运算中不能溢出。构造后只调用一次 `solve()`；需要修改模型或再次求解时重新构造。返回 `status` 为 `optimal / infeasible / unbounded`。只有optimal时 `value` 和长度为n的 `x` 有效，其他状态不提供证书。内部表、变量编号以及pivot/improve属于实现细节，不是可自行修改的接口。

下标从0开始，允许负右端、冗余约束、重复约束、等式拆成两条不等式，以及n=0或m=0。非负变量本身不需要另加约束。自由变量需自行写成两个非负变量之差；最小化目标先取反，所得目标值再取反。返回的方案按照原变量顺序恢复。

## 算法与正确性范围

字典第i行是 `基本变量 = RHS - sum(d[i][j] * 非基本变量)`。目标行采用同一符号约定，负约化系数意味着增加对应非基本变量会改善目标。正列系数限制该变量的增加量，用最小比值选出基行；没有正系数行即得到保持可行并使目标无限增长的射线。换基同时更新所有约束及两个目标行，始终保持它们表示同一等式系统。

初始化给所有约束加入同一个人工变量t，系数为-1，即基本变量为b-Ax+t。若最小b为负，令该行的t入基使所有基本变量非负。第一阶段最大化-t，目标不超过0；最优值为负意味着t无法消去，原问题不可行。达到0时将仍在基内的t换出，全零冗余行可留下；第二阶段不允许t再入基。原目标行始终参加换基，因此无需重新恢复目标系数。最终所有非基本变量取0，从基本变量的RHS恢复解。

按变量编号最小的负约化系数入基；最小比值并列时按基本变量编号选出基。在精确算术下这是Bland规则，可避免退化循环，但最坏换基次数仍可能指数级。一次换基时间及表空间均为O((m+1)(n+1))，初始化也为该量级，不能写成总时间O(n³)。

实现采用long double和绝对eps=1e-12。浮点“并列”不同于精确并列，故不声称任意病态输入下均能正确分类、收敛或精确满足约束。特别是极小系数可能被视为零、尺度悬殊可能导致消去误差、近不可行模型可能落入容差区间。应先合理缩放模型，并以原始A、b、c核对x非负、Ax≤b与c·x。固定eps不是误差上界，单纯减小eps也不能替代有理数精确算法；线上AC不能消除这些限制。

## 验证

本地2720组：1086组有界最优、1310组无解、324组无界。独立Python Fraction判定枚举约束与非负边界的交点，不运行单纯形；可行域处于非负正交象限，不含直线，因此非空时有顶点。判断无界独立检查 `Ad≤0,d≥0,c·d≥1` 的可行性。覆盖零变量/零约束、所有小一维二约束组合、随机至三维模型、负右端、重复约束、等式、Beale退化循环反例，以及两个100×100已知真值模型。最后两个大例使用数学真值，不做顶点枚举。

头文件、NDEBUG和完整抄写版均通过O2与ASan/UBSan，除分类与目标值，还验证每个返回方案的原约束与目标。P13337四个官方样例另外用完整驱动执行，印刷用法也分别执行O2及ASan/UBSan。报告见 `verification/simplex-local.json` 和 `verification/usage-examples.json`。

正式题为[P13337](https://www.luogu.com.cn/problem/P13337)：n,m≤100，整数系数绝对值≤100，保证随机数据，3秒/512MB，允许1e-6绝对或相对误差。当前代码实际[AC R302627451](https://www.luogu.com.cn/record/302627451)，30个测试点，单点最大45ms；页面顶部汇总时间/内存与各点值不一致，两者均原样归档，不据此夸大性能。实际提交源已归档，排名未核查。
