# 圆覆盖重数面积

`circle_coverage_area(vector<RealPlane::Circle> a)` 返回长度为原圆数n+1的数组。第k项是恰好被k个闭圆盘覆盖的面积（1≤k≤n），第0项只是0占位，不表示无界的未覆盖平面。圆心、半径均为long double；半径非负，输入及中间运算须有限可表示，n≤INT_MAX−2。按值传参，不改调用者输入。允许同圆、零半径、包含、内外切、多个连通块和孔洞。O(n²log n)时间，O(n)额外空间，并查集使用递归路径压缩，最深O(n)。

## 正确性不变量

沿当前圆逆时针走，一段不经过交点的弧左侧包含当前圆，右侧不含当前圆；其他圆的覆盖数不变。左侧计数为k时，这段弧恰是至少k重覆盖区域的正向边界。因此按count分别累积格林积分得到至少k次的面积B[k]，最后按k递增作B[k]−B[k+1]得到恰好k次面积。不能倒序原地差分，也不能对单弧取绝对值：孔洞边界方向必须保留。

m个完全相同的圆有相同边界；对其中第t个圆只把先前t−1个同圆计入覆盖数。若外部另有q个圆覆盖该弧，m份边界依次计入q+1至q+m层，每个阈值恰好一次。这是形式上的分层，不移动圆，也不去重。零半径圆没有面积，内部删除它们但保留返回数组原长度。

跨0的角区间拆开，事件严格按原值排序；同角事件之间没有面积，处理次序不影响积分。严格相交图每个连通块独立平移原点，各阈值区域的闭合边界积分不变。两圆交角使用缩放Heron乘积与atan2；每层补偿累加，整圆直接算πr²。

## 数值约定

浮点关系判断不是精确谓词。近退化分类、尺度差异、输入舍入和相邻阈值面积相减仍可能损失精度，尤其小面积可能有微小负误差。核心不取绝对值、不强制截零；提交驱动只在最后三位小数显示时用max(0,area)避免负零。这不修复分类错误。不存在由这些测试推出的任意实数无条件正确性或误差保证。
