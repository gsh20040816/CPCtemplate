# 有资源上限的自适应 Simpson

`AdaptiveSimpson::integrate(f,a,b,eps,depth=20,limit=100000)` 返回 `value,error,evaluations,met`。这是局部估计驱动的数值工具，不是严格误差包络算法。

## 使用合同

- `a,b,eps` 为 long double，端点有限、eps 有限且严格为正；eps 是绝对容差，不是相对容差。depth 为 0..60，limit 为非负 int
- f 接收 long double，须在采样点（包括端点）有确定的有限函数值；异常直接传播。允许只统计调用次数的副作用，不能让返回值依赖调用顺序
- 零长度区间返回 `{0,0,0,true}`，不调用 f；参数检查先于此分支。反向区间交换端点，最后只对 value 变号
- 非空区间至少需要三次求值形成初始 Simpson；limit<3 不求值，返回 NaN、无穷 error、0、false
- depth=0 仍允许根区间的五点比较，但不向下细分。最多递归 depth 次；已采样端点/中点传给孩子，每个被细化的区间只追加两次调用
- `met=true` 仅表示本次浮点运算中的局部估计条件满足，且汇总 error 不超过对应预算。它不是实际积分误差不超过 eps 的保证，甚至光滑函数也会混叠
- error 是叶区间 `abs(S_left+S_right-S_parent)/15` 的非负和，估计的是细分后、未修正 Simpson 的主导误差；它不是修正结果 value 的严格误差上界
- 仍未满足当前估计条件时，深度耗尽或容差二分下溢会返回当前修正估计及有限误差指标，但 met=false。求值预算耗尽、坐标停滞或非有限中间结果时，保留当前粗估计并给 error=∞、met=false；若初始估计尚不可用，value=NaN
- 两个孩子的结果相加后再次检查 error≤tol，防止极小次正规容差二分向上舍入后，子预算之和超过父预算而仍误报满足
- 有限端点/函数值不保证中间加减乘法有限。实现会拒绝这些算术失败，即使真实积分本来可表示；不启用 fast-math，不承诺非标准浮点陷阱环境

必须先检查 met，再决定是否采用数值。失败时调用方应分析函数、拆分已知困难区间、变换变量或合理增加资源；不能把强制停止值当作精度已满足。

固定字长运算及函数调用次数为 O(evaluations)，栈 O(depth+1)。这不约束 f 本身的计算耗时，也不是给任意函数保证一个固定误差下的复杂度。

## 为什么是 15，以及为什么仍不保证误差

单段 Simpson 为 `(b-a)*(f(a)+4*f(mid)+f(b))/6`。在具有连续四阶导数的条件下，其误差公式见 [NIST DLMF 3.5(ii)](https://dlmf.nist.gov/3.5#ii)。二分后的主导误差在足够规则的渐近区间约缩为原来的 1/16，因此使用差值除以 15 估计，并作 Richardson 修正。

反例取 `[x(x-1/4)(x-1/2)(x-3/4)(x-1)]²` 于 [0,1]。初始五个样本全为0，程序立即返回 value=error=0、met=true；但它是非负、非零的光滑多项式，积分严格为正。测试用精确有理数展开提供其正积分证书。多取固定层数只能改变潜在漏采样点，不能让有限采样获得任意函数的严格保证。

分段、周期/振荡频率分析和奇点变换是建模责任。被积函数在端点无定义时，不能直接交给本闭型采样接口。可积分性与某个递归停止条件是两回事。

- WIDA 锁定版本的 jiangly Simpson 文件使用 double、固定 EPS 与特定全局 integrand，重复计算样本，无资源/停滞状态。本实现保留标准估计与修正思想，改为独立 callable；没有移植原应用函数或继承原提交 AC
- [OI Wiki 固定版本](https://github.com/OI-wiki/OI-wiki/blob/bc070e827180fbd75c2e27a16c1212f1d671d949/docs/math/numerical/integral.md)还介绍等距复合 Simpson，且自适应示例强制至少13层。本接口不实现这种最小深度策略，也不声称整页所有算法已完成。该页普通积分小节所示五次长度误差是单段公式，不要误套成任意步长的复合误差
- kuangbin §2.15 正文46页的13行完整原稿已按锁定PDF逐行核对，并与当前实现完成双模式数值对照。其可调用积分模型登记为local-tested；原稿无资源停止保护，也无严格误差保证。来源、调用计数及光滑函数漏采样反例见 [来源核验](SIMPSON-SOURCE-AUDIT.md)
