# 凸多边形裁剪与面积重心

两个接口均依赖 RealPlane，采用 vector，直接函数封装。原输入不变，n 须能用 int 表示；坐标和所有中间运算须有限可表示。没有 eps、随机扰动或显式 DFS 栈。

## 裁剪

`convex_cut(p,a,b)` 保留有向直线 a→b 的左侧闭半平面，要求 a≠b。p 按凸多边形边界顺序给出，顺/逆时针均可，允许共线中间点。空集、点、线段亦支持。输出继承输入方向，可能保留共线点或重复边界点，不保证严格凸包，不能直接传给 minimum_rectangle。

逐边考察端点有向叉积 s、t。保留 s≥0 的端点；严格异号时加入 u+(v−u)s/(s−t)。对凸多边形，半平面相交仍凸，保留下来的边界段按原序相连就是交集边界。过顶点和沿边时不另求交。时间与输出空间 O(n)。任意实数近退化符号可能舍入错误，这不是精确拓扑接口。

[AOJ CGL_4_C 官方题面](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=CGL_4_C&lang=en)规定 n,q≤100，坐标为 [-10000,10000] 内整数，凸多边形逆时针且允许共线顶点。每次查询独立裁剪原多边形，输出左侧面积，绝对误差小于 1e−5。初始侧向叉积绝对值不超过 8·10⁸，在至少 53 位有效二进制精度下精确；求交和面积积分仍浮点舍入。驱动采用相对首点的三角扇与补偿求和，输出 12 位小数。

## 面积重心

`polygon_centroid(p)` 返回 optional<Point>。均匀密度简单多边形可凹、可顺时针。少于三点或计算有向面积恰为零返回 nullopt；这是接口语义，不用原点作为失败占位。不是顶点均值或边界线重心，不用于自交、多环带孔输入。

相对首点建立三角扇。每个有向三角形二倍面积 s=cross(a,b)，相对重心为 (a+b)/3。累积 s 与 s(a+b)，用总一阶矩除以三倍总有向面积，再加回首点。凹多边形的外部三角区域按符号抵消，反转方向同时反转分子分母，结果不变。三个和分别补偿求和，O(n) 时间、O(1) 额外空间。

浮点补偿不能修复几何误判。近共线输入的面积零判定仍有舍入风险，巨大平移会损失最后输出坐标的绝对精度。本机 long double 为 53 位有效精度、8 字节，并非 80 位扩展精度；10¹² 附近可表示坐标间距约 10⁻⁴。测试容差明确依赖实际机器 epsilon，不能把远平移测试通过理解为仍有 1e−9 绝对精度。

## 验证与来源范围

`tests/polygon_tools.py` 共 5072 组，头文件/NDEBUG/手册抄写版各 O2 与 ASan/UBSan 六种构建通过。裁剪参考用 Fraction 精确隐式直线 Cramer 求交，取保留顶点与线段交点集合的凸包；与生产代码逐边插入不同。检查极点、边界归属及面积。重心参考按顶点 x 坐标分竖条，配对内部区间，对面积、x 一阶矩和 y 一阶矩精确积分，不共享三角扇公式。

覆盖空集、点、线段、共线、过顶点/沿边、反向切割、顺时针、多种凹形、10¹² 平移、1/1024 和 1/10¹² 缩放，以及 10 万边界点解析压力。坐标容差为 1e−9·span+2·epsilon·max_abs_coordinate+1e−30，记录实际 digits=53。这只是所列样例的验证范围，不是任意实数误差定理。

`tests/polygon_tools_driver.py` 另测 182 组正式 AOJ 协议、8983 次查询，包括官方样例、有界随机整数和 n=q=100 共线边界压力；每次查询均针对原多边形。面积使用 Fraction 真值，断言绝对误差小于 1e−6，比题目要求更严格。O2 和 ASan/UBSan 均通过，最大观察绝对面积误差约 8.98e−8。另测重心示例的三角形、凹 L 形、共线和空集。此示例是 API 用法，不计在线题。
