## 矩阵求逆：完整来源对应

原稿固定mod=1000000007，容量400，输入输出均1-based，维护[A|I]。每列选一个最大数值的非零主元，同时交换整个增广行；用主元逆元消去其他行，最后逐行归一化。素数域中无需按数值大小选主元，任意非零主元即可；不能把这个选法解释为实数数值稳定性处理。

当前 `matrix_inverse` 返回optional且按值保留输入，使用vector和ModInt，固定模数由驱动选择。它先归一化每个主元行，再消去其他行，数学语义等价；与原稿不同，每轮只计算一次逆元，原稿在其他行循环中重复计算。没有为了复现来源再提供数组版本。

205组完整输入，对原稿和当前P4783驱动分别执行。200组1–5阶矩阵以置换展开行列式独立判断是否可逆；返回逆矩阵同时验证AB=I与BA=I。另检查1、2、5、40、400阶逆序置换矩阵，逆矩阵就是自身，覆盖行交换与最大容量。普通和ASan/UBSan共四种构建通过。新增证据不替代既有F2/F3穷举、稠密矩阵和Library Checker官方本地数据证据，也没有新增线上AC。

3.6及3.6.1可记local-tested；范围仅附件的素数模方阵求逆，不扩大为合数模逆矩阵。

## 矩阵树：核心通过，整节仍部分完成

原稿对有向边u→v写L[v][v]+=w、L[u][v]-=w，去掉根1的行列。当前P6178传root=0、away_from_root，余子式是原稿的转置，行列式相同。opt=0为无向图。两者都计算边权乘积之和，模数1000000007；相同端点的重边分别贡献，自环贡献抵消。
