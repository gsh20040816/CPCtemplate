# 有符号权 DAG 最长路

`DagLongest`补齐WIDA打印稿“最长路（topsort+DP算法）”，不由《糖果》的0/1差分约束应用代替。点号1..n，0<n<INT_MAX；add返回0-based原边号，重边各自保留，权值支持完整signed64，边数≤INT_MAX。

run(s)求从s到每点的最长路径；run(0)允许从任意点开始，包含零边路径，故每点答案至少0。不能把run(0)用于“必须至少走一条边”的问题。run每次重建入度、清空拓扑序和前驱，支持改源点、加边后重跑和对象独立复制。

返回false表示整张图有环，即使该环从s不可达也拒绝；valid=false，此时dis/pre/ord全部不得作为结果读取。它不是求一般有环图最长简单路的算法。返回true时，ord是全图拓扑序，dis[v]==−inf表示不可达，其余为int128距离。path(v)给出正向原边号，并列任选，不承诺字典序；不可达和零边路径均为空，须结合dis区分。add清除valid。成员只读，不手改。

## 正确性与整数范围

拓扑队列起初包含全部零入度点，而不是只放s。每条边都减少终点入度，即使起点从s不可达；否则一个不可达前驱会阻止本来可达的点出队。ord同时保存队列与最终拓扑序，不是把DFS改写成显式模拟栈。

处理u时，其全部前驱已经处理，所有到u的路径最后一条边都已参与比较，故dis[u]为最长距离。仅当dis[u]有限时向后松弛，避免对负哨兵加一个正数制造虚假可达；负权路径同样有效。每个新前驱都处于更早的拓扑位置，恢复路径必然终止。若处理点数不足n，剩余图每个点仍有前驱，沿前驱必遇环；若图有环，环上点不可能被完整消去，故判环充要。

每条边只扫描常数次，run时间与总存储O(n+m)，path时间和输出空间O(路径边数)。一条有限路径至多n−1边，绝对值<(n·2^63)<2^94，所以int128与inf=2^126足够。禁止无条件把通用结果转为long long。分别输出所有点的完整路径最坏需要O(n²)输出，API演示不承诺线性总打印时间。

WIDA固定提交cfdb12db6792eb2303798541fb5c760ed2bc618b、`02 - 打印稿模板汇总/03A - 图论.md`中的该小节使用有限负哨兵，未过滤不可达状态便做加法，并消耗原入度；本实现补上不可达保护、每次重新建入度与全图判环。核心保持轻量结构体，不扩展为通用图框架。[OI Wiki拓扑排序](https://oi-wiki.org/graph/topo/)用于分类参照；这一条按“拓扑排序的最长路应用”登记，不表示该整页内容全部覆盖。

## 三份完整调用

- 用法301：[P1807](https://www.luogu.com.cn/problem/P1807)，求1到n的有符号权DAG最长路。n≤1500、m≤50000、|w|≤100000，所以有限结果绝对值≤149900000，可以转long long。只比较−inf判断不可达，不能以结果<0判断。n=1时零边路径答案0。题目输出−1可能同时表示不可达或合法的−1距离，这是题面约定，模板内部不混淆。
- 用法302：[CSES1680](https://cses.fi/problemset/task/1680/)，每边权设1，以最长路边数加1得到城市数。恢复原边号后输出起点1和每条边的终点，任意最优路线都接受。n≤100000、m≤200000。题目保证DAG，因此两份题目程序直接run(1)；不能据此省略任意输入场景的返回值检查。
- 用法303：完整signed64输入与int128打印，演示s=0、整图有环失败、不可达和正向原边方案。没有把接口演示登记为正式模板题。

P1807与CSES1680当前作为应用证据登记，未核验为正式非比赛模板题，也没有新增在线AC或最快提交排名。

## 本地验证

`tests/dag_longest_probe.cpp`对n≤3每个有序点对枚举无边/−1/0/+1，含自环，遍历全部指定源点和s=0；再枚举n=4的全部24个顶点排列及4096种向前边状态，对每图运行5个源点。参考独立使用递归三色判环与所有路径枚举，不复用拓扑DP。

另有300组逐次加边，每步验证返回边号、结果失效、切换源点和复制隔离；完整signed64两端、十万点反向负权链和s=0零边路径。头文件/抄写×assert/NDEBUG四种核心形式每种1548079次运行、13086298次检查，两种运行模式均通过。

`tests/dag_longest.py`运行driver、展开程序、最小依赖抄写和NDEBUG四种完整程序形式，每种P1807 108份、CSES1680 107份、API 172份输入。小图独立枚举所有路径；P1807包含1500点50000边负权链，CSES包含100000点200000边链，API包含100000点星形完整输出；最长链完整方案由核心测试覆盖，以免逐点打印路径产生不必要的二次输出。路线检查器校验原边连续性、端点、不重复点和独立最优值，允许并列的不同方案。

八个核心错误变体（不可达哨兵加法、错误起点、零初值、只从源点入队、漏判环、权值取反、不清拓扑序、路径逆序）和三个调用错误变体（把负数当不可达、城市数少1、输出错误端点）均被独立参考拒绝。普通与ASan/UBSan运行报告记录源码前后快照、编译命令、输出与二进制哈希。它们证明这一批本地测试通过，不代表在线资源通过或全库运行回归。
