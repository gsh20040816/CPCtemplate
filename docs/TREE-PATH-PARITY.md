复用现有 `HLD` 和 `lazy_segtree`，不增加专用重链DP组件。完整用法 `verify/api/tree_path_parity.compact.cpp` 对应手册324，保留名字到点号、输入边编号、多组数据与查询输出。树和两种组件都保持vector及递归实现。

## 路径奇偶与子树翻转

固定根1，令p[u]为根到u路径上所有边属性的异或。u到v路径异或为p[u] xor p[v]，因为根到LCA的公共部分出现两次而抵消。若全树p=0有zero个点、p=1有one个点，则无向奇路径数量为zero*one；原稿输出ans*2，故对应有向端点对数量2*zero*one。自路径异或为0，不计入。

翻转边(u,v)只会改变较深端点x的全部子孙的根路径异或。用HLD找父子关系和DFS序，子树闭区间[dfn[x],dfn[x]+siz[x]-1]转为lazy_segtree的0-based半开区间[dfn[x]-1,dfn[x]-1+siz[x])。线段树状态是零/一计数，合并分量相加，翻转交换两者，标签合成用异或而不是或。查询只读全树状态；不需要对u-v路径分段。

初始化先把每条边的值挂在其较深端点，按h.rk的先序顺序从父点累积异或。不能按原点号递增累积，因为父点编号未必更小；测试打乱边输入顺序与方向。重复翻同一条边两次恢复原状，修改不是赋值。

树上预处理O(n)，每次翻边O(log n)、查询O(1)，空间O(n)。名字用map映射，输入处理另需字符串比较和O(log n)字典查找。递归深度最坏O(n)，测试提供512 MiB栈。要求n≥1、输入为连通树，初始边位只能0/1、名字唯一且边端点名字存在、修改边号1..n-1合法。结果用long long，`2LL`在乘法之前提升；十万点时可超过32位。

测试 `tests/tree_path_parity.py` 直接从每个起点遍历原树累积边异或，统计所有有向终点；不把2*zero*one实现当成唯一oracle。普通及ASan/UBSan分别运行驱动、完整展开、最小抄写及NDEBUG四种形态。

n≤5的146棵标号树按Gray码走遍所有边位状态，混入同一边重复翻转；另180棵随机树各120操作，打乱边号和端点方向，名字字典序与点号顺序相反。326组在同一进程运行，检查多测重置及精确输出格式。三万和十万点链/星各做413操作，单次切边闭式答案及多条边同时翻转后的独立扫描交叉核验，每份大树后追加单点树。

漏乘2、半开区间少取末端、翻转标签误用或这三个错误变体都由独立答案拒绝。最小抄写显式包含cassert，不依赖bits/stdc++.h间接提供assert。来源243行程序对同一小图输入以及三万点链/星单独对照；不在越过来源数组界的十万点输入上运行原稿。
