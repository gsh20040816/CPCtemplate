# Kruskal：最小生成森林与原边方案

## 接口与复制顺序

先抄 `dsu`，再抄 `Kruskal`。构造 `Kruskal(n)`，顶点为0..n−1，允许n=0；`add(u,v,w)`加入一条无向signed64边，返回从0开始的原边号。允许负权、零权、自环和重复边。`run()`返回原图连通块数，同时重建`weight`（int128最小生成森林总权）和`ids`（所选原边号）。n>0时返回1才表示存在MST；n=0返回0、总权0和空方案。

原边表`e`保持插入顺序。排序仅作用于局部编号数组，同权按编号排序，输出顺序为(权值,编号)升序；重复运行结果稳定。加边后旧结果尚未更新，必须重新`run`再读取；不提供隐式增量维护。成员只读，不直接修改n/e；支持独立值复制。

普通`dsu`不改：仍以`fa[y]=x`合并、路径折半。Kruskal内部先找两根，比较`sz`后将较大根放在前；它只是调用处选择参数顺序，不把全库并查集改成按大小合并。构造O(1)，add均摊O(1)，run为O(n+m log(m+1)+m α(n+1))，总空间O(n+m)。n、m不超过INT_MAX且内存可分配，森林最多n−1条边，总权绝对值小于2^94；完整signed64权用int128累加，不减法比较权值，也不对LLONG_MIN取负。

## 正确性与断连合同

按非降权处理原边。已经同属一个选中森林连通块的边产生环（自环也在此列），必须跳过；否则当前边是跨越某个森林块割的最轻可用边，由割性质可加入某棵最优生成森林。逐次合并后没有环，且任一原图连通块最终不能残留两个未连接的森林块：否则原图跨块边处理时必会合并。因此每个原图连通块恰取一棵最小树，返回块数与`ids.size()==n−cnt`一致。负权不改变割性质，不能为了避负权而跳过边。

不以总权−1作为失败信号。两点一条权−1边是合法MST，与断开的两点不同；当前接口分别返回块数1和2。最大、最小signed64边均可选取，总权允许超出long long。

## 三份来源核对

kuangbin 2018正文134–135页（物理136–137页）已视觉核对。`tests/fixtures/kruskal_sources/kuangbin.inc`去掉PDF行号/页眉，将Unicode减号规范为ASCII；可执行语句、固定数组上限、int权重和并查集逻辑未修改。原片段排序会改变edge数组，返回−1表示断连，且合法负权树也可能返回−1。新实现保留原边编号与输入顺序，独立返回块数，并将累加扩成int128。

WIDA固定提交`cfdb12db6792eb2303798541fb5c760ed2bc618b`：

- `01 - 常用在线模板汇总/02 - 图、树、网络流/07 - MST (Kruskal).cpp`。
- `02 - 打印稿模板汇总/03A - 图论.md`的“（稠密图）Kruskal算法”。该标题按原稿登记；边排序算法不以稠密图为适用前提。

两份片段使用优先队列、int权重和int总和，最后均为`assert(cnt < n - 1)`。已分别编译原片段重现：两点一条权7边在断言启用时异常退出；两点无边却正常返回0。定义NDEBUG后，前者返回7，后者仍返回0，没有提供断连判定。这里是连通性断言方向错误，不能用“关闭断言后数值一致”宣称原片段正确。

数值对拍仅在共同的小整数域内，显式关闭这两处来源断言；独立的原样编译进程保留assert/NDEBUG两种配置记录。原优先队列还会被kruskal耗尽，再调用会得到0；当前模板每次从未消耗的边表重建。测试记录该差异，不把来源承诺扩大为可重跑接口。两份WIDA源体未重写成新模板，它们仅用于来源审计。

本批只关闭以上三条具体Kruskal来源映射。Prim与父节等其他条目仍未据此关闭。

## 正式模板题与演示

[洛谷P3366](https://www.luogu.com.cn/problem/P3366)是正式模板题：输入无向图，连通输出MST总权，否则输出orz；n≤5000、m≤200000、边权1..10000。`example-314`输入点号减一，调用run后判断块数。题面限制下总权不超过4999×10000，可安全转long long。

`example-315`是接口演示：输入0-based无向signed64图，输出块数、精确int128总权、选边数、原边编号。打印代码包含负数与零的十进制输出。它覆盖生成森林方案接口，不算第二道正式模板题。

## 本地验证

独立参照枚举恰有n−c条边的所有子集，用Floyd可达闭包比较原图连通关系，再最小化边权总和；不以另一个Kruskal作为唯一参照。穷举1..4点简单无向图，每条边五态（不存在、−2、−1、0、3）；另有200组随机多重图，每次加边后重跑至12条边，包含负自环、重边及换方向。逐项检查原边号、唯一性、原输入不变、连通块、总权、选边数量与顺序，以及反复run和复制后独立添加自环。

每个核心形态记录50282次小图/增量核验，另有两次大图run，共1165530项检查。header/仅抄dsu及Kruskal两种形式分别启用和关闭assert。额外覆盖20万点、40万边的反向链及负自环，精确总权小于long long最小值。LLONG_MAX正权链也检验超过64位的正总权，空图/孤点/断连均独立覆盖。

普通及ASan/UBSan分别运行12种程序形态。正式驱动实际文件/展开/最小抄写/NDEBUG各102个输入，含5000点200000边；接口演示各105个输入，含200000点400000边。驱动输出再由Python独立子集枚举和连通性证书检查，7个错误变体（反向权序、不清空总权、不清空方案、跳过负边、错误原边号、错误块数、忽略断连）被拒绝。两份WIDA原样程序另各运行断言开关×连通/断连，共8项可复现行为。

这些是本地测试与有限边界证据，不构成在线AC、在线排名或线上资源通过声明。全库覆盖目标继续推进。
