# 附件线性递推核对

对应 issue #11 的 5.13，实际 PDF 180–186 页，公式、代码和页间衔接均已查看截图。附件算法为 Bostan–Mori，并不是仅凭标题就可以用二次复杂度的特征多项式取余代替的大阶递推。

## 分式系数与递推转换

对于初值 a[0..k-1] 和系数 c[0..k-1]，约定从 i=k 开始

`a[i] = c[0]*a[i-1] + ... + c[k-1]*a[i-k]`。

令 `Q(x)=1-c[0]x-...-c[k-1]x^k`，`P=(A_initial*Q) mod x^k`，则无限序列生成函数为 P/Q。原因是 Q*A 的所有 k 次及以上系数均由递推抵消，低次系数只使用已给初值。

附件第 182 页的解释把分母常数项写成 0，不能直接照搬。第 185–186 页代码实际先建 F=sum(c[i-1]*x^i)，计算 G=(F*A_initial) mod x^k，再把 F[0] 改为 -1，调用 coefficient(G-A_initial,F,n)。此处分子、分母同时是上述 P、Q 的相反数，比例不变，因此末尾代码的符号是自洽的。

本库 BostanMori::coefficient(p,q,n) 每轮乘 q(-x)。分母 q(x)q(-x) 的奇数次系数为零；若 n 偶，则保留分子偶数项，否则保留奇数项，分母总保留偶数项，再令 n 除以 2。n=0 时答案为 p[0]/q[0]。这个恒等式也适用于特征 2；测试包含模 2。q[0] 非零是必要前提，每轮新常数项是旧常数项的平方。

分子允许为空或次数不小于分母，不先做多项式除法也成立。若抽取后分子为空，答案为零。设 d=max(p.size(),q.size())，每轮两次卷积的完整结果长度至多 2d-1，压缩后长度不增长；现有入口检查这个长度不超过参数化 NTT 的容量。递推入口的分母长度 k+1，所以非初值查询检查 2k+1 不超容量。

使用 0-based 下标和完整 unsigned long long 范围，支持 n=0、n<k、k=0 的全零约定。时间 O(d log(d+1) log(n+1))，额外空间 O(d)；参数化 NTT 的素数和原根前提保持不变。

## 三个不同接口

- BostanMori::recurrence：大阶递推，用 NTT 加速；适合附件 P4723 的 k=32000 和 LC 的 d=100000。
- recurrence_nth：直接求 x^n 对特征多项式的余式，O(k² log(n+1))，适合小阶；模数允许合数。没有把它的速度当作大阶模板验证。
- berlekamp_massey：从有限前缀恢复最短递推，要求素数模数；全零或空序列返回空系数。只有已知无限序列阶数至多 d 并给出至少 2d 项时，才能据此前缀可靠外推。附件 5.13 没有这一步，本次保留相关回归，不将其冒充附件的主算法。

## 仍未完成的浮点拆系数 FFT

附件 5.12（实际 178–180 页）使用 complex<long double>、2^15 拆分、共轭分离两路实变换，再重组四个分量。它与精确 CRT 卷积是不同算法，仍保留实现缺口。

位逆序初始化从 i=0 开始，两个常数多项式时 bit=0 会出现移位数 -1；Make_Int 只做加 0.5 后向零截断，输入负系数又未先归一化，不能直接扩展到负数。long double 的实际精度也依平台变化，不能只凭类型名称宣称误差小于半个整数。后续实现须单独核定舍入、平台精度、变换长度与系数边界。
