# 边双缩点的定向应用

example-227 直接使用 EdgeCompression 的 size 和 edges，解决 [Codeforces 732F Tourist Reform](https://codeforces.com/problemset/problem/732/F)。它是应用题，不是正式缩点模板题，也不表示线上AC。当前207个算法、227份用法：154个正式模板题本地用法、43个仅应用、7个仅API、3个待补。inside 的行为仍由原独立组件测试覆盖，不因本应用而虚增覆盖。

## 题意和调用顺序

官方输入是连通无向简单图，2≤n≤400000、1≤m≤400000，无自环和重边。为每条边选方向，最大化各顶点可达顶点数的最小值，计入起点自身。输出最优值和按原输入编号排列的m条有向边；合法最优定向不唯一。官方限制4秒、256MB，局部测量不能证明评测通过。

把原边按同一顺序加入 BiconnectedCore 和 Lowlink，逻辑边编号必须一致。先 core.run()，然后构造 EdgeCompression；compressed.n 是块数。选 size 最大的块为根，用 orient_edges(graph) 定向所有原边，无需 graph.run()。按 compressed.edges 同时添加两向缩点邻接，再遍历根树；桥的原编号用于覆写 direction 中该项，将其从子块指向父块。压缩边原有端点顺序没有父子含义。

原图连通是这份适配器的必要输入前提，不把一个全局最大块的做法扩展成非连通图解法。核心支持的自环、重边等更宽输入只作分开的API验证，不能记作官方题域。

## 最优性

设最大边双块含K个顶点。任意定向的凝聚DAG有汇强连通分量；无向桥不可能包含在强连通分量内部，因此该汇分量至多位于一个边双块内，顶点数≤K。汇分量中的顶点不能到达外部，故任何定向的最小可达数≤K。

DFS树边向下、非树边向祖先定向，在每个去桥后的块内得到强连通定向。将桥全部朝最大块定向后，每个顶点都可沿缩点树到达最大块的全部K个顶点；根块没有出桥，只能到达自身K个顶点。因此最小可达数恰好K，达到上界。

总时间和空间O(n+m)。BiconnectedCore 还构造点双块，实际内存必须包含这部分；不能只估计缩点数组。既有核心DFS、染色和定向递归深度都可能O(n)，各阶段依次执行。新适配器以vector遍历缩点树，不替换原递归核心。
