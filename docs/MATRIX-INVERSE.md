# 素数模矩阵求逆

对应 issue #11 附件 3.6/3.6.1（实际 82–84 页）的 Gauss-Jordan 矩阵求逆。当前函数使用 vector 和 ModInt，保留原矩阵，返回 optional 以区分奇异矩阵；不重复维护另一套数组码风。

每轮选取当前列的非零主元，同时交换原矩阵和结果矩阵的对应行。主元行归一化后消去其他行该列元素。此前处理的列已为单位阵列，后续行操作保持它们不变；右侧记录同样的可逆初等行操作。结束时左侧为 I，因此右侧 B 满足 BA=I；方阵在域上左逆等于右逆。找不到主元时剩余子矩阵首列为零，矩阵秩不足，返回 nullopt。

模数必须为素数，这是使用非零主元模逆元的前提。该算法不能直接用于任意合数模数，例如模 6 的矩阵 [[2,3],[3,2]] 可逆，却没有可作单位的首列元素。不要通过仅把模数换成合数来使用本函数。

复杂度为 O(n³+n log mod)，额外空间 O(n²)。每轮只计算一次逆元；不是对每个单位向量分别做一次完整消元。空矩阵按通常约定可逆，返回含值的空矩阵；P4783 与 Library Checker 的输入均为正阶。

验证：F2 的全部 3×3 矩阵、F3 的全部 2×2 矩阵；1000 组至 6 阶矩阵用置换展开行列式独立判定可逆性。对每个返回结果以 int128 独立计算 AB 和 BA，均须为 I。另由可逆初等行操作构造 400 阶稠密矩阵并制造奇异变体。P4783 驱动用 Pascal 矩阵和符号二项式逆矩阵的恒等式检查至 400 阶输入和行交换，不依赖被测消元生成答案。普通与 ASan/UBSan 均运行。

Library Checker 的 inverse_matrix 使用固定参考版本生成的全套官方本地数据和 checker，结果单独记录；不等同于在线 AC 或在线速度排名。模 2 的大规模位集求逆由下面的独立函数提供，不用逐元素立方算法冒充覆盖。


## 模 2 按机器字消元

matrix_inverse_mod2 将 [A|I] 每行存为 vector<uint64_t>，按位异或执行行加法；F2 的非零主元只能为 1，无须除法。只从主元所在机器字开始异或是安全的：主元行在此前已处理列均为 0，即使首个机器字同时包含更早的列，也不会改变它们。左侧 A 与右侧 I 共用一行存储，因此任意 n 下的边界跨字都被保留；不要求 n 为 64 的倍数。

验证用非零核向量穷举独立判定全部 65536 个 4 阶矩阵的可逆性，再用逐元素的模 2 乘法检查左右逆。测试包含 n=31/32/33、63/64/65、127/128/129 的可逆稠密矩阵与重复行奇异变体，覆盖主元字、左右矩阵交界和输出尾字；大规模验证由固定 Library Checker inverse_matrix_mod_2 官方本地数据提供。
