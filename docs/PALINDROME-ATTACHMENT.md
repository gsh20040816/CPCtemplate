# 附件 Manacher 与回文自动机

核对 issue #11 附件实际 4–5、14–15 页（1.1.1、1.1.2、1.6）。保留现有函数和 vector 回文树；
两份 Manacher 的区别是数组/字符串存储、标记字符及输出长度/子串，不重复收录同义核心。

## 半径、区间和标记字符

本库 `manacher(s)` 返回 0-based odd/even：

- odd[i] 包含中心，最长奇回文闭区间 `[i-odd[i]+1, i+odd[i]-1]`，长度 `2*odd[i]-1`。
- even[i] 的中心在 i 前，最长偶回文闭区间 `[i-even[i], i+even[i]-1]`，长度 `2*even[i]`；半径零表示空。
- 非空子串 `[l,r]` 是否回文：奇数长度比较 odd[(l+r)/2]≥(r-l+2)/2，偶数比较 even[(l+r+1)/2]≥(r-l+1)/2。
- 回文出现总数为所有 odd 与 even 之和，应用 long long 累加；不是不同回文字符串个数。

附件数组版先插入分隔符，用 @/# 封住两端，pi 不含变换后的中心，最大 pi 直接等于原串最大长度。
字符串版 p 包含中心，最大原串长度为 p-1，起点为 (center-p)/2。
这些换算不能套到本库的 odd/even 上。恢复本库最长串时按上述区间保存 start/len，再调用 s.substr。
相同长度时可自定最左优先，不要求排序或再建自动机。

附件哨兵写法依赖输入字符集：数组的两端标记必须不与输入混淆；
string 版以 $ 为左哨兵，使用 `operator[](size())` 的零字符终止比较，
在小写字母输入下可以成立，不能笼统说该读取越界。
若把该函数推广到含 $ 或零字节的任意字符串，则不再具备此边界保证。
本库对左右边界显式检查，支持任意字节字符串和空串，不需要选择未使用字符。
API 按字节比较，不是 Unicode 字素；int 索引约定 n<2^30，保证镜像位置等中间加法不溢出。

[Luogu P3805](https://www.luogu.com.cn/problem/P3805) 当前 n≤11000000，仅小写英文，输出最大回文长度。
新增完整程序从两类半径取最大值；既有 Library Checker 输出所有中心长度的用法保留。

## PAM 的三个计数含义

附件中的 cnt 是该节点代表的回文串的非空回文后缀数量，递推为 `cnt[v]=cnt[fail[v]]+1`；
它对应本库 suffixes，不是该字符串在原串中的出现次数。
[Luogu P5496](https://www.luogu.com.cn/problem/P5496) 每个字符先按上一次答案解码，
再 add，输出 `t[last].suffixes`。n≤500000；完整程序也核对回车结尾。

本库根 0 长度 0，根 1 长度 -1，真实节点从 2 开始；内部序列前置 -1，和小写字母编码 0..25 不冲突。
-1 长度根保证 get_fail 最终可以停止。fail 指向最长真回文后缀，创建编号小于当前节点。
每次插入最多创建一个不同回文串节点，因此倒序按 fail 累加可以统计出现次数。

hits 只记录“当前最长回文后缀命中”的次数；occurrences 返回其副本再汇总，不改 hits。
重复调用不会累加污染，查询后继续追加也安全。total 为各位置 suffixes 之和，最大 n(n+1)/2，必须用 long long。
end 保存首次创建节点时的右端点，可用 end-len+1 还原一个代表串；distinct 不含两个根。
清空使用重新赋值 PalindromicTree()；本库只接受小写字母，不能把 Manacher 的任意字节契约迁移过来。
