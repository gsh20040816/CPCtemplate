# SPFA 与差分约束的完整调用

`Spfa`是FIFO队列松弛实现；最坏复杂度O(nm+n+m)，空间O(n+m)，不能把经验上的少量入队当成近线性保证。点号1..n，0<n<INT_MAX；允许重边、自环及完整signed64权值，总边数≤INT_MAX。

`add(u,v,w)`返回0-based原边号并清除valid。`run(s)`只检查从s可达的负环，`run(0)`把所有点距离初始化为0以检查全图。二者不能混用。每次run重新初始化距离、前驱、队列和临时标记，普通对象拷贝互相独立。

- 返回true：valid=true，dis[v]==inf表示不可达；其余为int128有限最短距离。path(v)返回正向原边编号，不可达和零边路径都返回空，须结合dis区分。
- 返回false：valid=false；算法提前停止，所有dis/pre均未完成，不可读作最短路，也不可调用path。要保留负环方案或分类每个点是否为负无穷，使用已有BellmanFord。

字段e/g/dis/pre/valid仅供读取，不手改。run(0)的有限距离是任意起点到该点的最小距离，允许零边路径，并非固定单源距离。

## 队列与负环判定

in只表示当前在队列里；出队时必须清零，随后距离改进可以重新入队。已经入队的点仍须更新距离、前驱和len，仅去重入队动作。严格松弛条件防止零环反复入队。

len[v]=len[u]+1维护当前标签所代表的历史游走边数。它不是入队次数，也不是当前pre链的长度。当长度达到n，这条历史游走含重复顶点。该顶点再次被严格松弛时，标签比先前经过该点时更小，所以所绕的闭合段为负，且由已入队的有限点延伸，必从所选起点可达。因此立即返回false。没有相关负环时，有限最短路可取简单路径，队列最终停止。

FIFO队列可按轮分层计费，每轮各点至多处理一次；最坏仍需线性数量的轮，每轮扫描至多全部出边。不能把DFS模拟栈或栈式松弛代替此FIFO实现并沿用相同界。

停止前所有标签代表的游走最多n条边，绝对值≤n·2^63<2^94。int128计算和inf=2^126均安全；只有实际入队的有限点被松弛，不会把不可达哨兵当作距离参与运算。打印通用结果不能无条件转long long，API用法保留int128打印。

kuangbin4.1.4印刷132–133页使用FIFO队列并统计入队次数。这里改为严格松弛游走长度；两个计数不能混为一谈。WIDA固定提交cfdb12db6792eb2303798541fb5c760ed2bc618b的图论稿中，队列SPFA未提供负环中止，并在逐点输出时写成d[n]；本实现补判负环并按目标点读取。队列版来源与Bellman–Ford来源分别登记。

## 全图差分约束

对每条x_v−x_u≤w建u→v权w。任何解沿一个有向环求和都要求0≤环权，因此负环意味着无解。反过来，全点初始化0相当于添加超级源点到每点的零边；没有负环时，最短距离满足dis[v]≤dis[u]+w，所以dis本身就是一个可行解。无需强制某个原变量为0，也无需真的增设一个节点。

用法296对应正式模板[洛谷P3385](https://www.luogu.com.cn/problem/P3385)，只问顶点1可达负环。每条输入记录w≥0加双向边，w<0仅加单向边，m不是最终边数。T组数据每次新建对象。

用法297对应正式模板[洛谷P5960](https://www.luogu.com.cn/problem/P5960)，输入x_u−x_v≤w故建v→u。必须run(0)，否则漏掉与顶点1无关的矛盾。n,m≤5000、|w|≤10000时，输出距离绝对值小于5×10^7，符合题目要求的int范围。检查器直接代入全部原不等式，不要求某个固定解。

WIDA“差分约束”小节的文字称SPFA，而代码实际按全部边执行Bellman–Ford扫描，并给所有点有限初值。新用法保留原不等式方向，明确使用全零超级源点初始化。没有把两个实现名称混为同一个算法。

用法298对应[洛谷P1993](https://www.luogu.com.cn/problem/P1993)：至少多c转换为b−a≤−c，至多多c转换为a−b≤c，相等加入两条0边。可行解能整体平移到非负，不能凭“作物数量”自行增加一个上界。它是竞赛应用，不计新增正式模板覆盖。299独立演示有限路径和负环时整体失效的API约定。

## 十万规模的0/1约束：糖果

用法300对应[洛谷P3275](https://www.luogu.com.cn/problem/P3275)，使用已有递归TarjanSCC，核心未修改。把关系写成x_v≥x_u+w，边权只有0或1。等号双向0；a<b建a→b权1；a≥b建b→a权0；a>b建b→a权1；a≤b建a→b权0。

强连通分量内若有权1边，沿其终点回起点的路径权非负，构成正权环，要求一个变量严格大于自己，无解。否则每个分量内部全为0边，两两可达使所有变量相等，可以缩为一点。

TarjanSCC编号按逆拓扑顺序生成，因此从cnt到1处理分量。初值1保证每人至少一颗；沿边用dis[v]=max(dis[v],dis[u]+w)递推。任何可行解都至少满足从任意点出发的每条路径下界，故得到逐点最小值，累加即总量最小。必须按原顶点累加，同一分量多人不能只计一次。

时间和空间O(n+k)，DFS仍为递归。路径上至多n−1条权1边，单点糖果≤n；总量可能达到n(n+1)/2，n=100000时超过signed32，故用long long求和。该应用仅覆盖非负0/1约束，不能据此宣布WIDA任意有符号权DAG最长路模板完成。
