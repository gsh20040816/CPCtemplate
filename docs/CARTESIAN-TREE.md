# 笛卡尔树（本地验证中，书册与线上待完成）

`cartesian_tree(a)` 返回轻量 `CartesianTree {root,left,right}`。点号0..n-1，不存在的孩子或空树根为-1；中序遍历恰为原数组下标顺序，按值为小根堆。相等值时较小下标优先，即每个区间以最左最小值为根。输入不修改。n须能用int表示，元素的 `<` 须构成严格弱序；浮点NaN不在输入域内。

核心只用比较，无数值加减，因此支持LLONG_MIN、LLONG_MAX。比较视为O(1)时，时间O(n)、返回数组与构造辅助空间各O(n)。单调栈维护当前树最右侧的路径，是构造算法本身，不模拟DFS。

插入新的最右点i时，弹出右侧路径上所有比a[i]大的节点。最后一个弹出的节点代表整个被提升为i左子树的部分；如果栈仍非空，则i取代剩余栈顶原来的右孩子。未弹出的路径保持堆序，被弹出的部分值均大于a[i]且下标较小，故BST顺序与小根堆性质同时保留。相等值不弹，保证左侧优先。每点只入栈一次、出栈至多一次。

[P5854正式题面](https://www.luogu.com.cn/problem/P5854)给1..n的排列，n≤10^7。驱动将0-based孩子转成1-based（不存在为0），再输出两个异或校验和。乘法用long long：i*(child+1)最多约10^14。当前题面还提示GCC15.1在特定编译选项下可能有编译器bug，建议C++14（GCC9）提交；本核心无C++17/20依赖。

本地独立真值通过逐区间寻找最左最小值、递归建左右子树获得，直接比较root及完整左右孩子数组。枚举n≤9的三值数组，覆盖空数组、全等、相等值隔开；再加1000个随机数组与极端64位值，共30525组。头文件/NDEBUG/抄写形式分别以O2和ASan/UBSan运行。正式驱动另以50组随机排列校验两个异或结果。千万级递增、递减、全等数组以已知链形逐节点校验，不能把本地耗时当作OJ耗时或排名。
