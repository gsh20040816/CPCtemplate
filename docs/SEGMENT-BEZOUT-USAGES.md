# 区间加求和与最小 Bézout 系数的正式用法

本批分别给既有 LazySeg、extended_gcd 补正式模板题用法；没有改核心，也没有新增线上 AC 或速度排名。

## P3372：初始化和整数范围要如实说明

[官方题面](https://www.luogu.com.cn/problem/P3372)当前限定初值、增量严格为正，1≤n,m≤100000，任意时刻全序列和不超过 2×10¹⁸。闭区间保持 1-based；值、增量和输出均用 long long。

LazySeg(n) 只建零数组，没有专门的线性 build。example-220 用 n 次单点 add 装入初值，初始化 O(n log n)，之后每次操作 O(log n)，空间 O(n)。不能把原驱动的初始化成本写成 O(n)。

由于正式域所有值和增量为正，每个节点区间和与延迟增量贡献都不超过全数组和，2×10¹⁸ 位于 signed long long 范围内。本例的安全论证不外推到无限大小、负数相消或非法区间；更宽的接口测试应另外说明。

`tests/lazy_segment_usage.py` 为完整驱动、实际登记程序和仅抄 LazySeg 的最小程序各验证 18 份输入，普通及 ASan/UBSan 合计 108 次执行。小数组逐元素修改并枚举所有询问区间；检查非2次幂长度、嵌套与连续积累延迟标记。最大 n=m=100000 的构造使用独立标量/数组参考，还精确达到 2×10¹⁸ 后用子区间查询迫使下传。仅使用正式正数域，官方样例输出 11、8、20。

## NTL_1_E：不仅是任意一组 Bézout 系数

[官方题面](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=NTL_1_E)规定 1≤a,b≤10⁹，输出 ax+by=gcd(a,b) 的整数解，先最小化 |x|+|y|，若最小解并列再选 x≤y。后一个条件不是对所有输入都强制要求。例如 a=3,b=2 的最优解为 (1,−1)，不能交换输出。

example-221 直接调用现有递归 extended_gcd，用 __int128_t 接收系数，再转 long long 输出。它在此正整数域已满足题目的选择条件，不需要另写修正算法：

1. 令 g=gcd(a,b)，A=a/g，B=b/g。A,B>1 时，标准欧几里得最后一个非零余数为1，前一个至少为2，故最后商 Q≥2
2. 相邻余数的 Bézout 系数逐坐标符号交替，终止零余数的系数为 (±B,∓A)。递推因此给出 B=|s|+Q|x|、A=|t|+Q|y|，所以 |x|≤B/2、|y|≤A/2。初始 A<B 时首个零商只交换角色
3. 其他解均为 (x+kB,y−kA)。其1范数至少为 |k|(A+B)−(|x|+|y|)，非零整数 k 不能更小。并列要求两项同时达到半界；那不能满足 Ax+By=1，因此非平凡情形最小解唯一
4. A=1<B 时返回 (1,0)，B=1<A 时返回 (0,1)，都唯一最优。A=B=1 即 a=b 时，返回 (0,1)，在两个范数为1的解中符合次级条件

系数在非平凡情形绝对值不超过5×10⁸，退化整除情形只用0和1，所以转 long long 安全。复杂度 O(log(min(a,b)+1))。这些论证限定本题正输入，不把负数或零输入的符号约定混入正式用法。

`tests/bezout_minimum_usage.py` 独立枚举小范围有符号系数，并用精确模逆元与凸分段端点候选核对大数最小性；含两组官方样例、相等/整除/换序/Fibonacci和10⁹边界。只在并列最小值时检查 x≤y。最终每种形态、每种模式1431组，共8586次执行通过；其中625组直接枚举有符号系数，全部用例还用独立精确端点参考核对。

证据分别位于 `verification/lazy-segment-{normal,sanitizer}.json` 和 `verification/bezout-minimum-{normal,sanitizer}.json`。最终测试使用默认 PIE、默认 ASan quarantine，仅因环境 ptrace 限制关闭 LSan；源码、登记、编译器及夹具指纹绑定具体版本，不代表新的全库回归或在线提交。
