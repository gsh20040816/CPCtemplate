# 整数三维凸包的重心与表面距离

先构造 `Hull3D<long long> h(points)`，再构造 `Hull3DMetrics m(h)`。凸包须在 m 使用期间保持存活且不修改。整数点及 plane_distance 的查询点各坐标绝对值≤10⁹；不接受浮点输入。

- `centroid()`：均匀**体积**重心，返回 optional<array<long double,3>>。维数不足3时为空，不混用点平均或面重心。
- `clearance()`：体积重心到凸包表面的最短距离，低维为空。不是可自由移动球心的最大内切球半径。
- `plane_distance(p,i)`：整数点到第 i 个三角面所在**无限平面**的距离，不是到有界三角形的距离。i 必须为有效 faces 下标；共面二维凸包的三角面也可用。
- `planes()`：每个几何平面的一张代表三角面的下标。三维为真实多边形面数；二维为1；点、线、空集为0。三角面数量直接读取 `h.faces.size()`。

构造O(F+n)，重心O(n)，clearance O(nF)，planes O(F²)，额外空间O(n+F)；F为三角面数，n为去重后点数。对HDU4273的n≤100足够；不把O(nF)接口宣称为线性测量。可只抄所需方法，normal_length为距离接口依赖。mass、total为实现字段，不供修改。

## 数值与正确性

取凸包上的p[0]为公共四面体顶点。每个外向三角面与p[0]组成六倍体积v≥0的四面体，内部互不相交并覆盖凸包。体积重心是四顶点平均，所以给四顶点各累加v作为mass，总质量total=4Σv。顶点质量全部非负且用128位精确累加。坐标界M=10⁹时Σv≤48M³，total≤192M³，远小于2¹²⁷；每个中间量同样有界。不会把四次或六次坐标乘积塞入128位：先转long double再乘。

重心各坐标减去该轴最小输入坐标，非负加权求和后再平移回来；结果是近似值，接近零的重心不保证相对误差。对一个外向面，d(p)=-orient(a,b,c,p)是非负仿射函数。因此重心平面距离等于Σmass[p]d(p)/(total·|normal|)。代码直接计算此式，不对近似重心做可能严重抵消的点积。每个d和叉积先用整数精确计算，浮点阶段只有非负求和、乘除和范数。最近舍入、无fast-math时，其相对误差随n·机器精度增长；不是任意规模的无条件精确实数结果。

凸多面体是面半空间的交。以内部重心为球心，能包含于凸包的最大球半径就是最小面平面距离；取得最小时接触点必在面域中，否则球会先越过其他半空间。这说明clearance确实等于到表面的距离。对任意外部查询点不成立，因此plane_distance明确只返回无限平面距离。

planes逐个比较代表面，使用三个顶点的精确共面行列式；不会用eps合并相近但不同的平面。

## 源码覆盖与验证

完整阅读 kuangbin 7.4.1 的246行（印刷243–248页，物理245–250页），并渲染逐页核对。原始程序只补标准头文件、还原Unicode减号及编号行折行，不修改算法。原版、当前驱动、最小抄写版各在O2及ASan/UBSan运行102组EOF数据，包括两组官方样例及100组所有点均为极点的整数矩曲线多面体，三位小数逐行一致。

`tests/hull3d_metrics.py`的509组真值以独立支撑平面枚举、面内二维凸包和相对原点的**有符号**精确有理矩积分构造，与实现的非负顶点质量路径不同。核对维数、重心、距离、代表平面集合和整数查询点距离；包含立方体所有子集、随机点、重复点、平移到±10⁹、大尺度、行列式1的极薄四面体及低维输入。头文件、NDEBUG、实际抄写版的O2和ASan/UBSan全部通过。
