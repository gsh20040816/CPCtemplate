# WIDA 在线模板：并查集

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `8314323d9e6a125effbb87e64a409d70142f48b1`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/24 - DSU.cpp`。它使用 `vector` 和 `iota`，但没有头文件，单独编译失败。`DSU(n)` 包含 `0..n`。

`get` 做路径折半，不是完全压缩。`merge` 按根的编号把较小的挂到较大的下面，不是按块大小合并。注释里的「设 x 是 y 的祖先」在交换之后并不成立。`p` 记录的是块大小，查询前会先找到根。

把 `(1,2)`、`(2,3)`、`(4,5)`、`(3,5)`、`(1,5)` 依次合并后，1 到 5 在同一块，大小是 5。重复合并返回假。0 单独成块，大小是 1。`DSU(0)` 只有点 0，`same` 为真，大小是 1。越界下标没有调用。

`python3 tests/wida_dsu.py` 在普通 `-O2` 和 ASan/UBSan 下与独立的父节点数组一致。没有新的在线 AC，也没有新增模板。来源保持 partial。
