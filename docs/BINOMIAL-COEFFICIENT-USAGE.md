# Binomial 与 ModInt 的联合用法

[P1313官方题面](https://www.luogu.com.cn/problem/P1313)要求计算(by+ax)^k的一项系数模10007；k至多1000，n+m=k。这是历史比赛应用，不能登记为独立模板题。

## 为什么这组接口适用

二项式展开得到系数C(k,n)·a^n·b^m。驱动先构造 `Binomial<10007>(k)`，再直接调用 `choose(k,n)`；a、b分别通过显式 `ModInt<10007>` 构造器归一化，然后调用pow并相乘。

10007可由试除到100验证为素数，且k<10007，阶乘表中没有零因子，满足本版阶乘逆元的前提。不能把这个示例外推到任意合数模数或k达到模数的情况。构表O(k)，两次幂O(log(n+1)+log(m+1))，存储O(k)。

零次幂在此按空乘积取1。尤其k=0时唯一项的系数为1，即使a=b=0也如此；这来自形式多项式的解释，不是在讨论实分析中不定式的一般取值。正指数的零底数则贡献0。

## 只算真实的直接调用

example-216以Binomial为主条目，ModInt作为联合覆盖项。main明确构造ModInt并调用pow、乘法，不能仅因Binomial内部用了ModInt就声称演示了它。联合调用检查支持显式模板实例调用，并拒绝仅在别名、注释或字符串中提及类型。

ModInt还出现在数据结构、图论的跨类依赖附录中。因此分册生成器对联合使用页的引用继续纳入其主条目Binomial，保证页码引用闭合。这是手册的引用闭包，不反向声称ModInt算法依赖Binomial；唯一主分类仍在数学册，不增加算法条目。新增检查包含缺失主条目的负对照。
