# 历史版本与集合所有权

本批补充 `PersistentDSU` 和 `MergeSplitTree`，接口分别对应 [P3402 可持久化并查集](https://www.luogu.com.cn/problem/P3402) 与 [P5494 线段树分裂](https://www.luogu.com.cn/problem/P5494)。题面操作和数据范围已核对；当前记录为本地验证，未取得在线 AC，也未核验实时评测机时间／内存限制。两者作为 OI Wiki 补充功能收录，不凭名称认定已替代 kuangbin 或 WIDA 的未映射条目。

## 可持久化并查集

`PersistentDSU(n)` 初始只有版本0，点为0..n-1，n>0。`merge(ver,x,y)` 从任意旧版本建立一个新版本，返回连续的新版本号；即使已经连通仍建立新版本，但不分配线段树节点。`copy(ver)` 只复制版本根。`find(ver,x)` 返回代表元，`same` 判断连通，`size` 返回集合大小。查询无副作用，不分配节点。

稀疏可持久化线段树记录每个点的父亲，根记录负集合大小。空节点的所有叶子隐含为-1，因此构造不必建满树。父亲0是合法顶点，不能用0表示并查集根。每次成功合并，路径复制两个叶子：小集合代表元挂到大集合代表元，再累加大集合大小。等大时第一根挂到第二根。`set` 先复制节点到局部变量，递归时仅保存编号，避免vector扩容使引用失效。中间一次更新的根可以不登记为公开版本。

正确性由版本归纳得到：修改只写新节点，因此历史叶子和历史连通关系不变；新版本只改变一棵并查集树的根父亲与另一根的大小，连通关系恰是原划分合并这两个块。按大小挂接使任意点的深度每增加1，其所在集合大小至少翻倍，深度≤floor(log2 n)。每跳父亲通过线段树查叶子需O(log(n+1))，故find/same/size/merge为O(log²(n+1))，copy均摊O(1)，成功合并新增O(log(n+1))节点。若共U次成功合并、V个版本，空间O(1+V+U log(n+1))；vector增长的摊销计入整体分配成本，单次扩容可能超过对数时间。

这是独立可持久化组件，**不改变普通dsu的固定挂接方向与路径减半**。可持久化版不做路径压缩，代表元也不承诺等于调用中的第二个点；只在等大时固定上述方向。`root`、`t`、`n`只读，`get/set`是内部函数，不能直接修改共享根。节点和版本数量须适合int索引并可分配。完整对象值复制后独立；移动后的源对象仅重新赋值或销毁。

P3402每个操作都算一个版本，查询也必须复制前一版本，回退操作复制指定版本k；k=0合法。驱动明确使版本号等于操作号，点减1，不添加异或。数据n≤100000、m≤200000。

算法背景对应 [OI Wiki 可持久化线段树](https://oi-wiki.org/ds/persistent-seg/)的可持久化并查集扩展。本实现使用负大小叶子、稀疏初态与公开版本号，自行编写。

## 线段树合并与分裂

`MergeSplitTree(n)` 建空集合0，或传入长度n的 `vector<long long>` 作为集合0中各值的重数。n>0，固定值域[0,n)，所有重数非负。公开接口只接收集合号，禁止拷贝裸根制造两个所有者。

- `add(s,x,delta)` 增减重数，结果不能为负；delta=0直接返回。
- `sum(s,l,r)` 查询半开值域[l,r)，允许空区间。
- `kth(s,k)` 按重数查询1-based秩，返回0-based值；k≤0或超过总重数返回-1。
- `split(s,l,r)` 从s移走区间到一个新集合，返回新集合号；即使移走的是空集也新增编号。
- `merge(dst,src)` 将src消耗并入不同的dst，src随后为空，核心允许这个空集合再次使用。没有持久化与根克隆接口。

每个活节点恰属于一个集合根；每个空闲节点恰出现于回收池一次；0号节点始终为零，不入回收池。计数均为long long，每个集合的总重数须≤LLONG_MAX，节点和集合数量须适合int索引。增量可负，但结果必须合法，负增量检查用 `delta >= -old_count`，不对delta取负，避免LLONG_MIN取负溢出。正更新与合并在总量处检查溢出；所有子树非负，因此总量上限足以约束中间求和。断言关闭后由调用者保证这些前提，不提供失败后的恢复协议。

分裂递归对无交区间保留原根，对全包含区间直接转移原根，只有两条边界路径可能同时保留和提取内容。递归先取得左右两组编号，再写回保留节点；保留内容为空则回收，提取内容非空则分配新父节点。先回收再分配允许立即复用空节点。部分区间分裂最多O(log(n+1))步和新增节点。无论分配是否触发vector增长，递归边界间均无节点引用或指针。

合并遇到一个空根直接转移另一根；两个根都非空时，分别合并左右孩子，回收被消耗的父节点。因此合并**不保证单次O(log n)**，两棵稠密重叠树可耗时O(n)。每次两个非空根的递归恰回收一个节点，整批合并的工作量可摊到创建过的节点：从初始构造开始，总计O(N0+(A+S)log(n+1)+M)，其中N0为初始活节点数，A为点修改次数，S为分裂次数，M为合并次数；节点回收后重建仍算一次创建。若复制了整个对象，复制所得活节点另计为该对象初始资源。

数组构造O(n)，单点修改、区间和、第k小为O(log(n+1))，递归深度O(log(n+1))。回收池使节点内存随历史峰值活节点数增长，集合根表仍随所有分裂次数增长，空集合号不删除。`n/t/root/free`只读；make/release/pull/build/add_node/meld/cut/query/select为内部实现。只复制整个对象才能得到独立副本。

P5494外部集合1映射内部0，值x映射x-1，闭区间[x,y]转换为[x-1,y)。操作2的参数顺序是“重数x、值q”，不是相反。原题合并后保证不再操作被消耗集合；测试驱动遵守此约束，来源集合重用只在核心扩展测试中进行。题面n,m≤200000，初始每项≤m，总重数可达4×10^10，不能用int。原题k≤200000；核心超过此秩的测试不能冒充原题合法输入。

背景见 [OI Wiki 线段树合并与分裂](https://oi-wiki.org/ds/seg-merge-split/)。实现按值域分裂，不按重数秩分裂；不存在整数域动态扩张或负计数顺序统计。

## 验证

`tests/ownership.py` 使用独立的历史分量标签数组和每集合重数数组。普通与ASan/UBSan各运行头文件／抄写体 × assert／NDEBUG四种形式。测试旧节点逐字段不变、只读查询、冗余合并无分配、平衡深度、父亲0、对象复制；穷举n≤5每位置0..2重数及所有半开分裂区间，随机交错正负增量、分裂和合并，逐节点审计独占性、子树和、零号节点与回收池，验证LLONG_MAX及反复回收的峰值。

七个语义错误变体分别破坏历史节点、集合大小、按大小平衡、来源根清空、分裂边界、第k小相等分支、回收登记，均必须由参考模型或结构不变量检测拒绝。两份完整题目程序各以原驱动、依赖展开、标准头最小抄写三种形式运行随机数据与最大规模输入；没有把自制输入标为官方样例。这些证据不构成线上AC、速度榜、全库重新验证或LeakSanitizer结果。
