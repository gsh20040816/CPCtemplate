# 长链剖分与常数时间 K 级祖先

Issue #15；`LongChain`，用法376为P5903，用法377展示任意根、k=0和越根查询。

## 接口与抄写约定

`LongChain(n)`，1≤n<INT_MAX，点号1..n；add加入无向边，调用者保证全部边恰好组成一棵树，不支持森林、自环、重边和环。build(root=1)重建，根深度为1；kth(u,k)返回k级祖先，k为非负int，k=0返回自身，越根返回0。支持换根重建、重复build和值复制；查询前必须build，加边后重新build。成员只读，dfs1/dfs2是内部辅助函数。

两次DFS均递归，不模拟调用栈。son按子树高度选长儿子；len包含当前点，不能换成重链剖分的子树大小。链顶t的down[t]从t向下，up[t][0]=t，向上越根后填0。k=0先返回，不能直接计算0的最高位。

## 正确性与复杂度

设查询从x向上k步，先跳p=不超过k的最大2的幂到u，剩余r=k-p<p。因为x是u下方距离p的后代，u的子树高度至少p+1。设t为u所在长链顶，d=dep[u]-dep[t]；长链顶的高度等于长链长度，且至少d+p+1。因此r≤d时，down[t][d-r]是目标；r>d时，up[t][r-d]也是有效表项。先检查是否越根，保证合法查询不用依赖不存在的祖先。

每个点仅属于一条长链，链长之和为n，故up/down各存n个int，另有O(n)个vector外壳。倍增表O(n log n)，预处理O(n log n)，递归栈最深O(n)。查询仅一次最高位计算、一次倍增跳跃和一次数组访问，在32位字长模型下O(1)。线上AC不是复杂度证明：P5903题面明确不保证卡掉更慢方法。

## 验证

`python3 tests/long_chain.py`，加`--sanitize`执行ASan/UBSan。独立BFS获取父亲，逐级爬父亲作为真值；枚举n≤6全部1442棵标号树、每个根、每个点、0..n+1和INT_MAX；3000组乱序编号随机树验证复制、换根和重建，额外扫帚树区分高度与大小选儿子。核对链表长度之和、链顶、父子转移、全部高度和深度。

两份驱动各验证头文件、NDEBUG、完整展开、最小依赖抄写；P5903官方样例及150组强制在线随机数据，API检查150组完整边界数据。三个错误变体破坏k=0、up下标、down下标，均被检测。

`tests/long_chain_large.py`在原生Linux运行，栈软限制设为512MiB，递归源代码保持原样。50万点链（含反向换根）、星形树、完全二叉树在O2和ASan/UBSan均通过；三种树各500万次询问以独立树形公式核验。Ryzen 7 9700X、GCC16.2.1测得O2三组0.36/0.19/0.36秒，峰值RSS166036/132840/115472KiB；这些是本地端到端测量，不是线上速度排名。macOS默认栈限制不足以代替比赛环境的深递归测试。

实际 [AC 302333606](https://www.luogu.com.cn/record/302333606)：C++20 O2，100分、10 AC，页面总计7.13s，最慢1.51s，峰值143.54MB。秒级显示有舍入，保留原显示，不伪造精确毫秒。提交源归档与当前最小抄写版字节一致。线上覆盖题目合法祖先查询，单点、越根、复制及换根重建的更广接口由本地测试覆盖；未核验速度排名。
