# 三元环枚举

来自 issue #11 附件的 2.9 节（目录写 40 页，实际 PDF 第 42–43 页）；使用独立整理的 vector 与回调接口。edges 为无自环、无重边的简单无向图，0-based，每条边只给一次；回调顺序是度数/编号次序，不保证点号升序。

按 (degree,id) 总序定向后，一个三角形恰有一个最小顶点 u；另外两点 v,w 满足 u→v、u→w、v→w，因此用邻点标记可恰好访问一次。出度不超过 O(√m)：低度点直接受度数限制，高度点的更高度邻点总数由度数和 2m 限制。总成本 O(n+m√m)，另加回调成本；不保存所有三角形。输入合法性约定避免为去重引入额外排序。

tests/triangles.cpp 穷举所有不超过 6 点的简单图，以三重枚举集合验证完整性/唯一性，并测试边方向和次序变化、完全图、20 万点星形图和完全二分图。普通及 ASan/UBSan 通过。

Library Checker enumerate_triangles 驱动累计点权乘积；已阅读固定官方 task.md 与 info.toml，约束 n,m≤100000、点权小于 998244353。17 组官方本地测试在普通及消毒器模式均通过，检查器负例控制通过；报告见 verification/triangles-official*.json。这不是在线 AC 或 OJ 排名。
