# WIDA 在线模板：DSU++

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `3b7ab7bf61d1cbf4653f794b87198463c72fa405`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/24 - DSU++.cpp`。它使用 `vector` 和 `iota`，但没有头文件，单独编译失败。`DSU(n)` 包含 `0..n`。

合并规则和普通版本一样，按根的编号把较小的挂到较大的下面。`E` 统计调用 `merge` 的次数，重复边也算。`F` 只在两个端点是同一个点时置位，所以它表示自环，不表示一般的环。

先连 `(1,2)`、`(2,3)`、`(1,3)`。这是一个三角形，块大小是 3，边数是 3，`F` 为假。再调用 `(4,4)` 和 `(3,4)`，自环标记并进大连通块，1 和 4 的 `F` 都为真，边数变成 6，块大小是 4。点 0 和点 5 仍单独成块。最后再调用一次 `(1,2)`，返回假，但边数仍增加。

`python3 tests/wida_dsu2.py` 在普通 `-O2` 和 ASan/UBSan 下与独立的父节点数组一致。越界下标没有调用。没有新的在线 AC，也没有新增模板。来源保持 partial。
