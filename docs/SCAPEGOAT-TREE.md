# 替罪羊树与附件核对

`ScapegoatTree` 对应 issue #11 附件 4.4/4.4.1，实际 113–117 页。独立 vector 节点池、递归插入/删除、递归中序收集与中点重建。相同键只占一个节点，用 count 记录副本数；不使用随机数。

## 接口

默认空树。insert(x) 插入一个副本；erase(x) 删除一个副本，返回是否存在。size() 为总副本数，less(x) 为严格小于 x 的副本数，less(x,true) 为小于等于；rank(x)=less(x)+1，即使 x 不存在也定义。kth(k) 要求 1<=k<=size()。prev/next 是严格前驱/后继，没有答案时返回 nullopt。键可为完整 long long，没有 +/-inf 哨兵，也不使用 x-1 或 x+1。

元素总数与累计分配节点数均要求小于 INT_MAX，避免 size、下标或最大排名 n+1 溢出。a、root、以及带节点编号的重载和辅助函数属于内部状态；不要从外部改写。直接赋值 ScapegoatTree() 可重置整个对象。

## 三种计数与重建

每个节点维护 size（子树副本总数）、nodes（物理节点数）、live（count>0 的不同键数）。count 降为零的节点是墓碑，仍可有左右子树。size 支持排名与第 k 小；nodes 用于平衡；live 用于决定是否清理墓碑，三者不能混用。

每次更新回溯时，先 pull。满足以下两条则保留子树，否则重建：

- 任意孩子的 nodes 不超过本子树 nodes 的 3/4。
- 本子树 live 至少为 nodes 的一半。

条件用 64 位整数交叉相乘，不用浮点阈值。collect 递归按中序只输出活节点编号，build 按中点连接这些原有节点，保留各自 count。中序严格升序、计数不变，所以重建不改变集合；新子树没有墓碑且按节点数均衡。不把结果节点列表当作 DFS 执行栈。删除最后一个元素时返回空根 0。

每次更新后递归检查沿途所有祖先，因此最终整棵树都满足两个条件。沿任意路径，nodes 每层至少缩小到原来的 3/4；又因根的 nodes<=2*live，令 d 为当前不同键数，查询最坏 O(log(d+2))。中点重建后到再次显著失衡或超过一半删除之间，必须累计与子树规模成比例的结构变化，可将线性重建费用分摊给这段变化；在更新路径每层记账得到更新摊还对数界。触发大子树重建的单次更新仍可能 O(d+1)，不能写成最坏对数。

内存按累计分配节点数 K 计 O(K)，不是当前集合大小。重建复用活节点、不另分配树节点，但清除的墓碑不回收到节点池；反复删光再插入仍增长节点池。临时中序列表 O(d+1)，递归深度对数。大批重复值只增加 count，不为每个副本创建节点。

## 与附件的边界差异

附件 Rank 遇到空子树返回 0，仅在找到相等键时加 1；例如只插入 1 后询问 rank(2) 会得到 1，正确值应为 2。当前实现统一先数严格较小元素再加 1。P3369 明确允许排名查询键不存在。

附件用有限 +/-inf 表示缺失邻居和重建哨兵，限制了完整键范围；当前使用 optional 表示邻居缺失，重建直接返回根编号。附件重建另外分配新节点；当前复用活节点。附件删除后不做墓碑比例清理；当前删除回溯也执行重建检查，避免查询高度仅依赖历史插入规模。

## 验证与正式用法

tests/scapegoat_tree.cpp：60 万次插删，独立排序 vector 检查大小、rank、less、kth 和严格前驱后继；有 LLONG_MIN/LLONG_MAX、缺失删除、空树及重复值。递归核验 BST 的严格顺序、三个计数、3/4 平衡和 1/2 有效比例。20 万不同键的升序插入、隔位删除、逆序删光、降序重插与大批相同键验证规模和重建；初次构造后确认节点池仅 n+1 项。

tests/scapegoat_application.py：201 个 P3369 完整程序，Python bisect 排序表作参考；规模例 10 万次操作，含删除半数、查询不存在的大键排名和最后一个第 k 小。使用例 example-110 单独打印替罪羊树主程序；三个打印案例同时覆盖普通操作和缺失键排名。

普通与 ASan/UBSan 的结果及指纹见 verification/scapegoat-tree.json。没有新增在线 AC，不能使用 OrderedTreap/Splay 的历史 AC 代替这个实现。来源：[P3369 题面](https://www.luogu.com.cn/problem/P3369)、[OI Wiki 分类入口](https://oi-wiki.org/ds/sgt/)，具体覆盖以本页接口与证据为准。
