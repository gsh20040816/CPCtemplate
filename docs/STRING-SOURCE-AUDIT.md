## Manacher：覆盖功能，不继承哨兵限制

两份原稿各用3582例非空小写串验证最长回文长度：三字符表长度1–7的穷举、300例随机串、长度1000的全同与交替串。真值独立枚举中心并逐字符比较，vector原稿返回值还检查确为原串中的回文子串。普通优化构建和ASan/UBSan加标准库下标断言均通过。

原稿没有声明可接受任意字节；不能把小写域通过扩大成任意字符串正确：数组版单字符 `@` 触发负下标，vector版单字符 `$` 触发string下标断言。脚本保留这两例作为预期失败诊断。读取 `string[size()]` 本身合法，问题是哨兵碰撞后继续扩展到合法范围之外，不能笼统把终止零字符的读取说成越界。

当前 `manacher` 返回奇偶半径、显式检查边界，不选哨兵，支持空序列及任意字节。最长长度为所有 `2*odd[i]-1` 和 `2*even[i]` 的最大值（空序列为0）；需要原稿vector接口的子串时，记录对应中心及起点后取substr即可，平局可按起点选择。此次重新执行现有测试，19531个含哨兵/零/高位字节的穷举串、2000例任意字节串逐子串核对回文谓词和总数，以及百万等字符串的每个半径闭式，普通/检查构建均通过。不新增重复组件。

第一份原稿输入为非空小写串，初始桶1–26；3582例以直接排序后缀、逐字符LCP的Python真值检查全部sa、rk、height。第二份输入为非空正整数序列，编码1–n；13391例包括小字母表穷举、所有选定分隔阈值、300例随机和长周期边界，同样核对三数组。普通及ASan/UBSan构建均通过。

第二份中 `save_total_map` 以上的符号参与排序，但不进入LCP。真值在任意一端遇到此类符号时停止。当前 `SuffixArray` 保留普通LCP，已有 `SUFFIX-ATTACHMENT.md` 的remain截断适配：

`height[k] = min(lcp[k], remain[sa[k-1]], remain[sa[k]])`。

新增 `tests/string_source_current.cpp` 用当前核心及这一适配，执行同样13391例独立真值，两个构建均通过。还重新执行现有后缀数组测试，覆盖任意字节、整数编码、重建、LCP区间最小值、百万周期串和1500例重复分隔符。原稿1-based到当前0-based映射只改变下标，不改变非空后缀集合。当前允许空输入是接口扩展，不冒充原稿空输入已验证。
