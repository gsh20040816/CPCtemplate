# WIDA 在线模板：高精度大整数

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `0ea72a039abf01bd3654e3d8e57019a01c580e13`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/33 - 高精度大整数类.cpp`。它使用 `vector`，但没有头文件，单独编译失败。每个数位是 9 个十进制位。

两个 30 位正数的和、差、Karatsuba 积、商和余数，以及乘 7、除 7、模 7，都与 Python 整数一致。`gcd(12,18)` 是 6，`lcm` 是 36。字符串 `"-0"` 读入后变成 0，但 `-bigint(0)` 打印成 `-0`，并且它比 0 小。

`check` 按值接收个位数，只改符号，不把除数或乘数改成正数。`12 * -3` 打印 `--36`，`12 / -5` 打印 `--2`。`12 % -5` 仍是 2。`-12 / 5` 是 -2，`-12 % 5` 是 -2，余数符号跟着被除数，不是 Python 的非负余数。`LLONG_MIN` 取负时 UBSan 报 negation。除以 0 会访问空数组的末位，这轮没有跑。

`python3 tests/wida_bigint.py` 在普通 `-O2` 和 ASan/UBSan 下通过正数例子，并记录了负零、负除数和最小值。没有新的在线 AC，也没有新增模板。来源保持 partial。
