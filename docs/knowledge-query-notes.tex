\section{线段树维护单调栈：双向扫描与接雨水}\label{knowledge-seg-stack}
\texttt{MonotoneStackSeg} 每段存 $F_0,F_1$：从左、从右扫描的运行最大值减原值之和。
外部高度 $x\ge$ 段最大值时贡献 $x\cdot len-sum$；否则按扫描顺序孩子 $A,B$：
$x\ge\max A$ 递归 $B$，否则递归 $A$ 并加 $F_{parent}-F_A$。单段扫描 $O(\log n)$，
区间修改及任意子区间扫描最坏 $O(\log^2(n+1))$，建树 $O(n)$。
雨水体积（$M$ 为全局最大值）根上 $O(1)$：
\[
\sum_i\bigl(\min(L_i,R_i)-a_i\bigr)
=F_0+F_1-\bigl(nM-\sum_i a_i\bigr).
\]
负高度可用；所有中间量须在 long long 内。

\section{动态 K-D Tree：矩形和与重建边界}\label{knowledge-kdt-sum}
\texttt{KDTreeSum} 按深度交替坐标轴，重复坐标累加权值，孩子过重（超过 $3/4$）时 \texttt{nth\_element} 重建。
树高 $O(\log(d+1))$，矩形查询最坏 $O(d)$；插入摊还 $O(\log^2(d+1))$。
矩形闭边界；绝对权值和及中间量须在 long long 内。零权保留节点，负权不影响剪枝。

\section{CDQ 卷积递推：贡献只跨越一次}\label{knowledge-cdq-conv}
\texttt{cdq\_convolution} 求
\[
f_i=b_i+\sum_{j<i}f_j g_{i-j},\qquad g_0=0.
\]
半开区间 $[l,r)$：先递归左半 $[l,m)$，再与 $g_{0\ldots r-l-1}$ 卷积加入右半，最后递归右半；顺序不可改。
根层卷积长度 $n+\lfloor n/2\rfloor-1$ 须不超过 NTT 最大二次幂容量。
时间 $O(n\log^2(n+1))$，额外空间 $O(n)$。

\section{SPFA 费用流与残量方案}\label{knowledge-spfa-cost}
SPFA 版允许负边，\textbf{不允许负环}：每次调用先全点零距离入队检查（含不可达负环），发现即抛异常。
最终方案按原边编号查询 used；flow 返回本次新增流量与费用，重复调用须同源汇。
容量 long long，距离与费用 int128；费用不能为 LLONG\_MIN，总流不超过 long long，
且 $\sum cap\,|cost|<2^{120}$。增广 $A$ 次为 $O((A+1)VE)$；通常优先势能 Dijkstra。

\section{2-SAT 编号方向与双连通定义}\label{knowledge-twosat-bcc}
TwoSAT 的 add(x,a,y,b) 表示 $(x=a)\lor(y=b)$；强制值 add(x,a,x,a)，
蕴含 $(x=a)\Rightarrow(y=b)$ 写 add(x,!a,y,b)。
Kosaraju 拓扑编号下真文字分量编号更大时取真；换 SCC 实现须检查不等号。
solve 仅成功时读 ans，$O(n+m)$，不保证字典序最小。

点双：连通且无割点；桥两端成块，孤立点单独成块，割点可属多块；自环不产生点双、不标桥。
每条无向边只 add 一次；lowlink 只跳过父边编号，不跳过重边。
BiconnectedCore 点号 $1\ldots n$、边号从零；blocks 为点双顶点集，bridge 为桥标记，
bel 为 $1\ldots cnt$ 的边双号（不承诺拓扑方向）。不连通时圆方图与桥缩点均为森林。

removal\_components 返回原块数 before 与删点后总块数 after；割点即 after[u]>before。
连通无向图能强连通定向当且仅当无桥：DFS 树边向下、非树边向祖先。

圆方森林原点 $1\ldots n$，第 $i$ 个点双（从零）对应方点 $n+i+1$。
原点权 $-1$、方点权为块大小时，$s,f$ 间圆方树路径权和为可作中间点的顶点数。
所在树原点数 $C$，删 $u$ 后各支原点数 $a_i$，有序端点对经过 $u$ 的次数为
$2\sum_{i<j}a_i a_j+2(C-1)[u\le n]$；sz 仅计原点，用 long long，总 $O(n+m)$。

桥森林邻接项为（边双号，原桥号）。连通图有 $L$ 个叶子边双时，补成边双连通至少且恰需 $\lceil L/2\rceil$ 条边：
DFS 序收集叶子，奇数补首叶，前后半段配对；仅一个边双不加边；非连通森林不适用。
