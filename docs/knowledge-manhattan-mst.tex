\section{曼哈顿最小生成树：闭锥扫描与平局割证明}\label{knowledge-manhattan-mst}
\index{Manhattan MST}\index{minimum spanning tree}
接口见第~\ref{compact-ManhattanMST}~节（第~\pageref{compact-ManhattanMST}~页）。
边权 $d(p,q)=|p_x-q_x|+|p_y-q_y|$。每点只保留四个向右闭锥中的最近邻，再对候选边 Kruskal；
候选图含至少一棵 MST，但不含所有最优边，禁边等额外约束不能套用。

单方向锥 $q_x-p_x\ge q_y-p_y\ge0$：按 $(x+y,\text{原编号})$ 排序，活动点以 $-y$ 为 map 键，
首个满足条件者即最近邻，找到后删除。四轮坐标 $(x,y),(y,x),(-y,x),(x,-y)$。
总时间 $O(n\log n)$，空间 $O(n)$。重复坐标是不同顶点，按编号生成零权链。

输入为 signed 64 位，先转 signed 128 位再做和差；单边最大 $2^{65}-2$。
返回 0 基编号与 128 位总权；空集与单点返回 0 和空边集。
