# 整数矩形面积并

## 范围与调用

`rectangle_union_area(rect)` 输入 `vector<array<long long,4>>`，每项依次为左、下、右、上。端点必须有序；空输入与零面积矩形合法，退化矩形忽略。坐标限制为 `[-10^18,10^18]`，结果是精确 `__int128`。每次调用独立，不修改输入。

Library Checker 的 [Area of Union of Rectangles](https://judge.yosupo.jp/problem/area_of_union_of_rectangles) 输入至多 500000 个矩形，坐标在 `[0,10^9]`，所以面积至多 `10^18`，配套驱动可安全转成 `long long` 输出。一般输入不可照搬这个窄化。2026-09-30 通过官方 task.md 核对输入顺序和严格端点约束；规模常量来自仓库已固定版本的 inventory。

## 为什么维护的是面积并

按横坐标扫描，把每个矩形拆成一次加入、一次移除。离散化后的纵坐标叶子代表相邻坐标之间的半开区间，不是一个坐标点。扫描宽度乘当前覆盖长度，就是上一条竖线到当前竖线之间的面积。

`cover[p]` 仅累计完全覆盖节点 p 的事件；不把它下传。非零时该节点全部覆盖，长度为 `y[r]-y[l]`；为零时恢复孩子的覆盖长度和。孩子仍记录局部覆盖，因此外层矩形移除后内部矩形不会消失。每个移除与此前加入使用同一离散区间和分解，同横坐标先移除也不会让计数变负；相邻同横坐标事件之间宽度为零，不会多算面积。

坐标差与总纵向长度至多 `2*10^18`，可存入有符号 64 位。先转 `__int128` 再乘宽度，最终面积不超过 `4*10^36`。整体 O(n log(n+1)) 时间、O(n) 空间，递归深度 O(log(n+1))。索引还要求 n≤(INT_MAX-8)/8，实际更受内存限制。

## 验证与限制

- 核心：46656 组小网格矩形三元组穷举；4000 组独立单位格集合 oracle，并检查乱序、平移和输入不变
- 边界：空集、零面积、重复、包含、相接、同横坐标事件，以及面积超过 signed64 的极端坐标
- 规模：三组 n=500000，分别为离散小矩形、嵌套和全部重复
- 完整驱动：180 组独立单位格 oracle 和同样三组最大规模输入
- 普通和 ASan/UBSan 的精确执行记录见 verification/rectangle-union.json；LeakSanitizer 关闭
