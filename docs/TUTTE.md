# Tutte 多项式求值（验证中）

本批核心、头文件/NDEBUG/抄写形式和题面用法已经通过本地O2与ASan/UBSan检查，尚未线上提交或PDF集成。不能标为完整完成或AC。

`tutte(adj,x,y)`：简单无向图，n≤21，点号0..n-1，adj[u]是邻居位掩码；输入须对称、无自环、无越界位。返回模998244353的Tutte多项式在(x,y)处的值，要求0≤x,y<998244353。支持断连图、孤立点、空图（值1），不支持重边或自环。不修改输入。连通分量搜索保持递归。

[QOJ45正式题面](https://qoj.ac/problem/45)给出边子集定义：每个边集A贡献(x-1)^(k(A)-k(E))·(y-1)^(k(A)+|A|-n)。算法按连通分量乘积计算。下面固定一个连通分量，不会除以x-1或y-1，因此x=1、y=1无须对输入作扰动。

令c[S]为顶点集S上所有连通生成子图的(y-1)^(边数-|S|+1)之和。取S的最小顶点r，删去r后，剩余边集唯一分成若干非空连通块T。每个T内部贡献c[T]，且至少选一条r到T的边。若这些候选边有h条，按额外环数计权，连接部分贡献：

sum(k=1..h) C(h,k)(y-1)^(k-1) = 1+y+...+y^(h-1)。

h=0时为0。右边用递推直接计算，y=1时自然得到h。于是c[S]为S去掉r之后所有集合划分上，块权c[T]乘以该等比和的乘积之和。r从大到小处理时，所有T的最小点大于r，对应c[T]已经求出。

集合划分通过快速子集指数计算：将块权a[T]按|T|放入次数层，进行子集zeta变换；在每个集合处求截断普通形式幂级数exp，再做Mobius逆变换并取|S|次项。逆变换只留下各块并集恰为S的项，次数=|S|排除重叠，exp中的1/k!抵消块的排列次序。普通exp递推用g[i]=(sum(j·f[j]·g[i-j],j=1..i))/i；1≤i≤20，在本模数下均可逆。

最后固定整个连通分量的顶点0所在块。对不含0的集合，用块权(x-1)c[T]再做一次子集指数得到p。答案是sum(c[V\S]·p[S], S⊆V\{0})。每个边集恰好产生一次集合划分，其他块各产生一个x-1，因而正好是定义中的k(A)-1。x=1时可直接返回c[V]。

每次子集指数O(k²2^k)时间、O(k2^k)空间；所有最小根分批处理的维数依次减小，因此总时间O(n²2^n)，峰值空间O(n2^n)，不是O(3^n)的所有子集划分枚举。断连分量各自处理并相乘，最大分量决定指数规模。

当前证据：n≤4的76个简单图在x/y∈{0,1,2,模数-1}的16种组合均与独立边子集枚举一致；500个随机图再比较随机模值、(1,1)、(0,0)。题面七组取值全部通过。21点完全图、树、环使用T(2,2)=2^m、生成树数量、树的x^(n-1)、环的y+x+...+x^(n-1)做独立公式核验。完全图任意(x,y)的压力项只记录运行结果，没有独立真值，不能把它描述为正确性检查。

Linux GCC16的21点九组压力中，八组有独立公式核验，完全图任意模值一组仅测性能；单次约1.27–1.98秒，整个压力进程峰值内存见 verification/tutte-large.json。三个错误变体（等比和初值、Mobius符号、连通分量乘积）均被独立定义真值检出。本机及Linux耗时不代表OJ排名。
