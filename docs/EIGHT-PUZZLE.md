# 八数码：反向搜索与最短方案

`EightPuzzle`固定解决3×3、目标123456780的八数码。构造一次供多组询问使用；输入为0..8的合法排列，0为空格。`solve`返回可解标记和空格移动方向u/d/l/r，目标为空路径，无解返回false。不承诺字典序最小，不扩展到十五数码。

## 来源和差异

完整核对kuangbin 2018 PDF 5.2/5.2.1的89行，印刷209–211页，物理211–213页全部渲染查看。固定PDF SHA256为f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad。只恢复行号、页眉、Unicode减号和标准头文件。原全局`move`与C++11后的std::move重名，因此原版用C++98编译，不修改原标识符或算法。

原版没有在入队时标记目标，目标后来被两步回路再次访问，其路径从空串变成`ud`。全部9!排列核对确认：只有目标状态的原路径不是最短；其余可达路径合法且最短，无解分类正确。HDU1043只要求任意合法方案，因此这个差异不证明原程序在该题WA；当前模板明确保证最短，初始化parent[root]=root，目标保持空路径。

原版对百万槽位存string并在队列节点复制整条路径。当前用9!个前驱编号和单步字符，BFS队列只保存棋盘。预处理发现新状态b时，parent[b]为距目标近一步的a，step[b]为刚才扩展动作的反向。查询沿parent输出动作，无需反转整条字符串。数组为vector，不压行，不增加通用搜索框架。

康托编号用混合进制Horner形式，等价于每位“右边较小元素个数×剩余阶乘”之和，范围0..9!−1。合法排列与编号双射。反向状态图是无向单位边图，首次BFS发现给最短距离；跟随parent严格下降，因此终止且最短。构造O(9!·9²)时间，含队列O(9!·9)空间；固定9格时查询O(9²+路径长)。目标可达集合181440个，最远31步。

## 全域验证

`tests/eight_puzzle.cpp`使用独立4位编码的uint64棋盘和12条无向网格边构造参考BFS，不使用康托编号或生产版方向数组。枚举全部362880排列，检查：编号无重无漏、可达性与参考表及忽略空格的逆序对奇偶一致、每条动作合法、最终到达目标、长度等于参考最短距离。距离0只有1个状态、距离31有2个状态，并保存完整距离直方图。

`tests/eight_puzzle_source.py`把所有排列组成EOF输入，分别运行完整原版、当前驱动、展开版、仅书册必要代码的最小抄写版、NDEBUG版，在O2和ASan/UBSan下逐条重放输出，原版仅允许上述一个已定位的最短路差异。未把样例特定路径字符串当成唯一答案。方向未反转、编号进制错误、无解返回空方案、水平跨行四种错误实现由同一全域检查拒绝。

example-413给出HDU完整读入输出。书册代码、依赖和main的拼接也须可独立编译；输入文件不完整或含重复数不属于接口契约。
