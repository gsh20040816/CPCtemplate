# 通用懒标记的作用契约

`op` 满足结合律，`e()` 为双侧单位元。`mapping(f,s)` 将标记作用于摘要；`composition(f,g)` 表示先执行 g 再执行 f。

必须满足：

- `mapping(id(),s) == s`。
- `mapping(f,op(a,b)) == op(mapping(f,a),mapping(f,b))`。
- `mapping(composition(f,g),s) == mapping(f,mapping(g,s))`。
- 标记复合满足结合律，`id()` 为单位元（至少在实际节点上的作用等价）。

每个节点的摘要已经包含自己的标记作用，子节点尚未包含该作用。因此追加 f 时，摘要立即执行 mapping，待下传标记更新为 composition(f,old)。下传后父标记重置为 id；点设置先下传路径，再清除叶子的旧标记。

区间和需保存长度：单位元为 `{0,0}`，真实叶子为 `{value,1}`。仅用 `lazy_segtree(n)` 会得到 n 个单位元，不自动把长度变成 1；应通过数组构造。当前实现不需要 F 提供相等比较。

查询和边界搜索会下传，不能标为 const。父摘要无需重新合并，因为下传保持 op 的结果。左右搜索分别按 `op(prefix,node)` 和 `op(node,suffix)` 合并；要求判定在指定扩展方向单调，且对单位元为真。

本地证据包括仿射向量、赋值字符串的非交换顺序、独立左右扫描和 50 万叶上复合标记；普通和 ASan/UBSan 通过。标准区间仿射驱动也以独立模数数组验证；该驱动只调用构造/apply/prod，线上尚未提交。全部接口不能仅凭同文件内一个应用通过就视作在线验证完成。

固定版本的 19 组官方区间仿射数据也已通过普通及 ASan/UBSan 的官方 checker；详见 [官方测试流程](OFFICIAL-TESTS.md)。这是本地结果，未记入在线 AC。

## 区间修改后的边界搜索

新增 `tests/lazy_binary_search.cpp` 把标记表示为布尔值到布尔值的函数，统一覆盖恒等、翻转、置零与置一。直接按函数复合生成新标记，参考数组逐点执行；这能检查翻转与赋值顺序，避免只测可交换修改。

对长度不超过 5 的全部位串，枚举两种连续作用及第二次作用的所有区间，任何查询前都保留两次待下传修改；随后以独立扫描核对每个位置的包含端点前驱、后继和单点值。较大随机区间修改另覆盖非二次幂长度。

50 万位置上反复整段清零、设置单个随机位置后，从两端搜索。记录 op 调用次数，单次不超过 8 倍树高；这是所测场景的退化回归检查，不是用有限测试替代复杂度证明。普通及 ASan/UBSan 日志位于 verification/lazy-binary-search-*.txt。
