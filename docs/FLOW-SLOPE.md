# 最小费用流的费用曲线

`slope(s,t,limit)` 返回本次调用的 `(新增流量,新增费用)` 折点，从 `(0,0)` 开始，终点对应本次实际增广量。连续相同边际费用的增广会合并，相邻折点之间线性插值给出每个整数流量对应的最小新增费用。费用为有符号 int128。

`flow` 与 `slope` 使用相同增广核心；普通 `flow` 不分配折点数组，保持原来的额外空间规模。slope 另需 O(折点数) 空间。内部 run 方法不作为用户接口。

负费用边允许，但调用开始时残量网络必须无负环；与原 flow 一样先用全点 Bellman-Ford 初始化势能。沿最短残量路增广后，边际费用等于 h[t]-h[s]。反边增广可以撤销早先路径的流，不能通过只考虑原正向边来计算费用曲线。

重复调用必须保持同一源汇，且此前状态为合法的最小费用流。每次返回的坐标以此次调用为原点，若需要整条历史曲线，应加上之前累计流量和费用，再处理边界处相同斜率。传 limit=0 或无增广路时只返回 `(0,0)`。其他容量、负环和 int128 总费用范围约束沿用原模板。

本地测试枚举小网络每条边的流，按每个可行流量取费用最小值，再逐个整数点核对折点插值。随机成本由非负约化成本和顶点势构造，允许负边、自环、平行边，同时保证无负环。另验证连续相同斜率、限流与续流、超 64 位费用以及负环拒绝；普通和 ASan/UBSan 通过。

P3381.slope.compact.cpp 只输出最后一个折点，完整驱动以独立边流枚举验证通过。它不能作为中间折点全覆盖的证据；新接口尚无线上 AC，旧 flow 的提交快照不改写。
