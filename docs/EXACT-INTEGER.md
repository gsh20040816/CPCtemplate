# 精确整数行列式与生成树计数

本批新增 `determinant_exact<Z>` 和 `MatrixTreeExact<Z>`，补齐 kuangbin §4.15 的不取模计数缺口。保持单一 vector 码风，消元是一个函数，矩阵树只作轻量包装。三份使用代码分别是任意整数矩阵、带权三方向矩阵树、原稿布尔邻接来源协议，均为 API / 来源模型，不是新增线上 AC。

## 接口与证明

`determinant_exact(a)` 接受方阵副本，不改变调用者。空行列式定义为1。每步在当前列寻找非零主元，交换行并记录符号；不存在则行列式为0。`Z` 必须提供精确有符号整数运算，推荐 `boost::multiprecision::cpp_int`。固定宽度类型仅在所有中间乘积和差均可表示时可用，不能只检查最终答案。行列式可以为负，不能取绝对值。

设当前已选主元对应的非零前缀子式为 D，前一前缀子式为 d，空子式为1。当前尾块元素是该前缀的加边子式。Sylvester 子式恒等式给出下一尾块：

`next[i][j] = (current[i][j] * pivot - current[i][k] * current[k][j]) / previous_pivot`。

分子严格是 previous_pivot 的整数倍，因此无需有理数或浮点误差阈值。当前剩余行的交换不改变先前前缀，只改变当前排列符号；末项是置换后完整行列式。分子要先完整计算，消去列的值须在该行所有尾块更新后再清零。保存 pivot/value 用具体 Z，避免 Boost 延迟表达式引用随后变化的存储。

`MatrixTreeExact<Z>::count(n,edges,root,kind)` 使用0-based顶点、三元组边；无向边添加两条弧，朝根模式用出度拉普拉斯，离根模式先反向所有弧。删根行列后调用精确行列式。矩阵树恒等式是权变量上的多项式恒等式，因此也允许负权和零权。重边独立，自环没有贡献，单点空树权为1。负权可能抵消，所以答案0不证明没有生成树。原稿布尔邻接适配器另外去重，不能混同核心重边语义。

复杂度为 O(n³) 次大整数运算和 O(n²) 个整数工作对象；矩阵树构造另需 O(m+n²)。这不是常数位宽时间、空间界，实际成本取决于中间位数。维数需小于 INT_MAX，矩阵树还要求 n≥1 和合法根。

## 验证

运行 `python3 tests/exact_integer.py` 与 `python3 tests/exact_integer.py --sanitize`。测试直接使用排列定义与选边枚举，不以另一份消元为正确性参考。覆盖0..3阶所有三值矩阵、4..7阶随机矩阵、巨大Vandermonde及行交换；枚举至5点简单无向图和至3点简单有向图、各根方向，追加有符号大整数重边/自环与闭式大图。来源协议追加重复、反向边、自环，保留布尔语义。

程序形态包括头文件驱动、NDEBUG、实际书中生成的完整用法、仅抄所需模板和明确额外头文件的版本。原稿两段独立运行并记录预期差异；五个故障变体检查换行符号、整除分母、提前清零、根方向与来源去重。

Boost为额外环境依赖，不属于标准库；使用页与Infra明确列出头文件，并在抄写检查中显式带入。参考 [Boost cpp_int官方文档](https://www.boost.org/doc/libs/latest/libs/multiprecision/doc/html/boost_multiprecision/tut/ints/cpp_int.html)；[Bareiss的NASA记录](https://ntrs.nasa.gov/citations/19680000292)确认整数保持消元用途，本文恒等式论证独立写出，未声称读取不可访问的AMS原论文。
