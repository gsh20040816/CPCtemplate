# 三维最长链与来源语义

`Chain3D` 是带依赖顺序的三维最长链 DP，不是 `Dominance3D` 的静态前缀计数。代码位于 `src/compact/chain_3d.hpp`；用法272输出全部每点状态及一条方案，用法273只演示 kuangbin 3.8.3 的源码模型。

## 明确的两种关系

- `strict=true`：链相邻点的三个坐标都严格递增。相同 x 的点组成不可互转的一组，重复坐标记录是不同的长度1候选。
- `strict=false`：三个坐标不减，并固定按 `(x,y,z,原输入编号)` 排序的顺序。重复坐标按输入编号串联，不计算这些重合点的所有排列。该规范顺序消除了弱关系的环。

每个原输入位置是一个点的身份；坐标相同也不合并。`length/count` 表示最长长度与模方案数；`len/ways/parent` 按原编号对齐。`path()` 返回一条最长链，不承诺整条路径字典序最小，只在并列时选较小终点或直接前驱。空输入长度0，有1条空链（模mod）；计数为0不代表不可达，尤其 `mod=1` 时所有计数都是0。

接口支持完整 signed64 坐标，只做比较和压缩，没有坐标减法、乘法或人为无穷哨兵。模数为正int；相加前提升到long long。`n≤INT_MAX/2` 且内存可分配，避免树状数组上跳时int溢出。公开结果成员约定只读；构造不修改输入、不保存输入引用。

## 递推正确性

先按三维字典序与原编号确定拓扑顺序。严格模式按相同x分组，弱模式每点一组；任意合法前驱必位于更早组。CDQ对组区间执行“求左半→左向右转移→求右半”。在任一合法前驱与后继首次分离的唯一递归节点上完成一次跨半贡献，因此不会漏转或重复计数；调用右递归前，它已有左半所有可用贡献。

跨半转移按y排序；严格模式只插入 `y_u<y_v`，弱模式允许相等。z压缩后的树状数组分别查询严格前缀或闭前缀。状态合并选较大长度，等长相加方案数，并记录较小终点编号。树状数组查询区间互不相交，每个前驱只贡献一次。查询无正长度才判不可达，不能用模计数为零作判断。

本层转移结束后清空所有本层实际更新过的树状数组路径，然后才执行右递归。最大值加计数没有逆元，不能用减法撤销。左右临时点表在右递归之前离开作用域，因此即使x组大小极不均衡，也不会在递归链上重复保留大型点表。时间 `O(n log²(n+1))`，额外空间 `O(n)`，递归深度 `O(log(n+1))`。

## kuangbin 3.8.3 的差异

固定来源 `build/source-audit/kuangbin.pdf` 印刷页114–115：文字写三个严格小于，但代码字典序扫描、立即更新，查询y与z均为小于等于；重合点可依次接长。源码模数是 `1<<30`。本库分别测试上述两种模型；用法273明确采用源码的弱关系、非空点集、多组输入，只输出长度和模计数。

尝试读取官方题面 `https://acm.hdu.edu.cn/showproblem.php?pid=4742` 未取得内容。原题严格性、重复点语义、完整协议和资源限制均未确认，来源表保留partial；没有新增在线AC、排名或正式模板题覆盖。不能把“本地验证源码模型”写成“HDU4742已通过”。

## 本地验证

`tests/chain_3d_probe.cpp` 使用独立二次方DAG DP核对每点长度、模计数、前驱和全局方案；另对小点集穷举所有点子集构成的链。穷举至4点的二值三维坐标序列，随机signed64极值、重复点、模1/2/3/17/2^30/INT_MAX；严格模式还检查轴轮换、保序坐标映射及输入重排。每份核心验证15362个小案例，并检查十万点长链、反链、全重合、多层重复与偏斜x分组的解析答案。

`tests/chain_3d.py` 在普通与ASan/UBSan模式下分别编译头文件/复制版、assert/NDEBUG四种核心形式。六个错误变体（右半过早求解、取消x分组、错误y边界、错误z边界、不清空树状数组、把模零当不可达）均须由答案检查拒绝，不能以崩溃算通过。用法272与273分别在driver/expanded/minimal-copy三种完整形式验证100与96组输入。源、输入、输出与二进制摘要记录于 `verification/chain-3d-{normal,sanitizer}.json`。
