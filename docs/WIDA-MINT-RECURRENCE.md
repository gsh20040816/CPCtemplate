# WIDA MInt：BM与有理级数系数核验

使用tests/fixtures/wida_poly_variants/12D-mint.cpp的精确原稿（blob f2063c0206f44f664a04090a48f9dea4c3054879）。保留原字节，不通过修补原稿掩盖失败。许可和上游路径见该目录README与LICENSE。本批补原稿功能映射及验证，不新增重复实现，仍334组件、454份完整用法。

## 两种BM不能混淆

berlekampMassey(s)是Berlekamp–Massey，用有限序列推导最短线性递推。原稿返回q={1,-c1,...,-ck}；现库berlekamp_massey返回{c1,...,ck}，满足s_i=Σ_j c_j s_(i-j)。不能直接交换返回值。全零或空序列原稿返回{1}，现库返回空递推。

linearRecurrence(p,q,n)实际求有理级数p(x)/q(x)的第n项，使用Bostan–Mori消去奇次项；其p并不是初值数组。现库BostanMori::coefficient对应这一输入；BostanMori::recurrence才接受初值与递推系数。

原稿公开函数没有检查以下重要前提：q.size()=k+1且k≥1、q[0]非零、p恰有k项（不足须补零）、n为非负signed64、各次卷积长度可处理。q允许末项为零，但仍按传入长度决定迭代空间。原稿函数只更新p的前k项，不是支持任意次数分子的通用接口。

## 独立检查

- 对模2、长度0..10的全部序列，模3、长度0..7的全部序列，逐一用高斯消元判断每个候选阶数的线性方程组是否有解。由最早可解阶数验证原稿与现库BM的最短阶数，再检查各自返回系数确实满足全部适用位置；不要求欠定情形两份系数完全相同。
- 另250组模998244353随机短序列，同样独立核对最短阶数。
- 移位脉冲周期序列的阶数1、2、127、128、129、1024检查返回完整系数。其前2k项在k-1和2k-1位置为1，其余为0；前k个移位约束形成反对角单位矩阵，最短阶数为k，递推为s_i=s_(i-k)。
- 有理级数使用q[0]可不为1的独立系数递推；阶数包括1..15随机以及127、128、129、257，覆盖原稿朴素/NTT乘法分支。核对第0、1、2、7、31、64、129、511、1025项。
- 独立斐波那契快速倍增核对大下标，包括signed64最大值和uint64最大值；原稿只核对signed64范围，现库BostanMori与recurrence_nth核对uint64范围。另30组随机几何级数通过整数模幂核验。

普通NDEBUG与ASan/UBSan各60980项正常检查通过。参考tests/wida_mint_recurrence.cpp和verification/wida-mint-recurrence.json。测试仅覆盖所列模数、阶数和规模，不声称全部容量或全套MInt/Poly成员都已完成。

## 原稿边界反例

常数分母q={1}、p={2}、n=1，真实答案为0，但原稿返回2；现库BostanMori::coefficient返回0，空分子对uint64最大下标也返回0。这是原稿未支持k=0，不能据此将其正常k≥1算法判错。

短分子p={1}、q={1,1,1}、n=1未补齐至k=2，原稿ASan实际报heap-buffer-overflow，单独作为预期反例记录；正常用法应先补零。现库coefficient本身接受短分子，不要求用户补齐。当前反例分支只在消毒器下运行，不把普通构建的未定义行为当作参考答案。

## Comb增量表补充核验

另补Comb与现库Binomial的合法域检查：独立Pascal三角形逐项核对上标0..512全部组合数，包含负下标和k>n返回0；阶乘表继续扩至4096，逐项检查阶乘连乘值、阶乘与逆阶乘乘积、i乘inv(i)，再缩小init请求确认表不退缩。原稿inv(0)返回0，是哨兵而不是0的数学逆元。

补充后本测试普通NDEBUG与ASan/UBSan各337978项正常检查通过，原稿反例仍单独保留。Comb只是小于模数的阶乘法：fac(m)、invfac(m)、inv(m)请求必须处于合法域，init内部把预处理上限截至P-1不会使超过P的查询合法。接近模数的内存规模未实际测试，不声称完整容量或任意上标支持；大上标应按条件选择Lucas等其他模板。组合数部分已从未核验推进到上述局部核验，其他MInt/Poly成员与原应用继续待核验。
