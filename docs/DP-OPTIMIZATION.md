# 三种 DP 优化的使用条件

## 单调斜率凸包

`MonotoneHull` 求最小值，直线按斜率非增加入，查询横坐标非减。两种单调性均是接口前提，不能把任意操作顺序传入。`query` 返回 int128 值与调用方编号；值相同时保留最早加入的直线，编号不参与比较。

同斜率只保留较小截距；截距也相同保留旧线。三条严格降斜率直线按相邻交点次序判冗余，使用整数交叉乘法，不进行浮点除法。若两交点重合，中间直线在任何位置都不会严格更优，删除它仍保留最早的并列最优。查询仅在后一条严格更优时移动指针，维护该并列约定。

系数、截距和查询坐标绝对值均不超过 10^18；先提升 int128 再相减，差的绝对值至多 2×10^18，交叉乘法至多 4×10^36，低于有符号 int128 上界。求值也在范围内。不能无条件窄化返回值。总加线数须小于 INT_MAX；vector 保留失效前缀，空间按历史加线数计算。

P2365 任务安排使用前缀时间 T、前缀系数 C。将每次启动时间对其后所有任务的影响在分批时结算，得到

`dp[i] = T[i]*C[i] + s*C[n] + min_{j<i}(dp[j] - (T[i]+s)*C[j])`。

加入斜率 -C[j]、截距 dp[j]，查询 T[i]+s。题目正系数和正时间保证两个方向；最多 5000 个任务、t/f<=100、s<=50，以单任务分批的费用粗界 3.75×10^11 保证窄化安全。独立测试枚举所有分批方案并直接计算完成时刻，避免仅用同一递推式对拍。

## 分治决策单调性

`monotone_dp_layer(prev,first,cost,opt)` 计算一层非空连续分组。代价函数接收闭区间，决策 j 表示上一组结束位置，因此最后一组为 [j+1,i]。处理第 g 层时 first=g；最小并列决策必须关于 i 非减。调用方负责证明，本函数不会验证这一性质。

中点枚举允许决策并取最小最优 j，左半答案只搜索不超过 j 的决策，右半只搜索不小于 j 的决策。每层总枚举 O(n)，递归深度 O(log n)，故代价查询 O(1) 时一层 O(n log n)。所有有限 prev、区间代价和候选和严格落在 (-LLONG_MAX/4, LLONG_MAX/4)，不存在状态用该上界表示；prev[first-1] 必须可达，保证每个要求计算的终点至少有一个合法候选。

CF321E 的组内代价为区间内无序点对非负权之和。对 a<=b<=c<=d，

`cost(a,c)+cost(b,d) <= cost(a,d)+cost(b,c)`，

右边比左边多出的恰为 [a,b-1] 与 [c+1,d] 间非负点对权。由此可用交换两个交叉决策的标准比较，得到取最小并列决策时的单调性。二维前缀和常数时间查询；矩阵对称、对角零，矩形总和除以二。输入字符读取兼容空格分隔或紧排单个数字。

## WQS：至多 k 个不相邻位置

`wqs_independent_set` 专门求路径上至多 k 个不相邻位置的最大权和，允许负权和空选；不将该函数包装为适用于所有 DP 的二分器。

把第 i 个位置视为路径上的第 i 条边，不相邻位置集合恰好对应匹配。令 F(c) 为恰选 c 条边的最优权和。取大小分别为 c-1、c+1 的两个最优匹配，其对称差由交替路径组成；至少存在两条使后者多一条边的路径，交换其中一条，得到两个大小同为 c 的匹配，且总权重不变。因此 2F(c)>=F(c-1)+F(c+1)，F 离散凹。

每选一个位置扣除整数 penalty，用 pair(惩罚后权和,数量) 取最大；并列时保留更多数量。罚值增加时最优数量不增。若罚0的最优数量不超过 k，原问题已解；否则 k 位于 F 的非下降部分。二分“最优数量仍至少 k”的最大非负整数罚值，此值是相邻整数最优值的差，k 在惩罚目标的最优平台上，故 `best_penalized + penalty*k` 恢复 F(k)。数量跳过 k 时仍成立，不强求某次 DP 恰好返回 k。

罚值上界 max(0,max(a))：超过最大单点权时所有非空集合的惩罚后值为负。若边界罚值仍返回至少 k 个，k 本身也在零值平台上，公式不变。k=0、空数组直接返回0；k超过独立集最大规模时罚0分支处理。

要求 n<INT_MAX，n×max|a[i]|<=LLONG_MAX/4，调用方以宽类型检查，排除 LLONG_MIN；所有 DP 候选与答案恢复的 long long 运算在界内。P1484 的 n<=300000、|a[i]|<=10^6 满足条件。时间 O(n log(W+2))，额外空间 O(1)，不返回选择方案。

## 验证范围

核心测试包含3000条交替加线/查询随机操作流、系数边界、500个随机非负对称矩阵的所有分组层与最小决策、1200个路径数组的全子集枚举和所有 k。完整用法分别使用全分批枚举、二次分组 DP、全合法子集枚举；每份100个小例和1个最大规模压力。头文件、NDEBUG、实际展开、最小抄写、ASan/UBSan 分别记录；线上判题与本地证据分开归档。

## 邮局补充应用与远程评测状态

CF321E 在本次提交时返回“Codeforces RemoteJudge 暂不可用”，未产生记录。因此增加 P4767 的独立完整用法，不把拒绝提交记为通过。

P4767 先排序坐标，将每个邮局服务范围分成连续区间（最近站点归属的边界可在排序线上单调划分），每组放在中位数。对区间 [a,r]，向左增加一个点的边际为 cost(a-1,r)-cost(a,r)=x[floor((a+r)/2)]-x[a-1]。右端扩大时中位数下标不减，因此该边际不减；累加左端增加的边际即得 cost(a,c)+cost(b,d)<=cost(a,d)+cost(b,c)。依然适用最小最优决策非减的分治层。

代价由排序坐标和前缀和 O(1) 计算。完整程序另以枚举所有邮局位置集合、直接求每个村庄最近距离作独立真值，覆盖未排序输入和重复坐标；最大规模测试为3000个等距村庄、300个邮局，答案7500。
