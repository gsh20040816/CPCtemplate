# 有符号高精度整数

`BigInteger` 使用 vector<int> 存储低位在前的 10⁹ 进制绝对值，sign 为 ±1。零只有一种表示：空 vector、sign=1。实现独立编写，不依赖 Boost，不使用浮点乘法。成员公开是为了方便赛时抄写，不应直接修改 d/sign 破坏不变量。

## 接口与边界

- `BigInteger(long long x=0)` 支持全部 signed64 输入，包括 LLONG_MIN；先转无符号求绝对值，避免有符号取负溢出。
- `BigInteger(string)` 接收至少一个十进制数字，可有单个前导 +/− 和任意前导零。空串、只有符号、其他字符不在契约内。用 string 读输入，不在结构体中重复实现流运算符。
- `str()` 输出规范化十进制；`cmp(b)` 返回 −1/0/1，`abs_cmp(b)` 只比较绝对值。
- 一元负号与 `+ - *` 返回新数，操作数保持不变；默认复制、赋值和自赋值可用。
- `divmod(int b)` 一次返回 pair<商,余数>，要求非零 signed32 除数，含 INT_MIN。商向零截断；a=q·b+r，|r|<|b|，r 与 a 同号或为零。不是 Python 的向下取整除法。
- `pow(unsigned int e)` 为非负整数幂，约定 0⁰=1；没有负指数。指数很大时结果可能无法存储，调用者须控制输出规模。

十进制串长度、所有中间分节数和两个操作数分节数之和须小于 INT_MAX 并留进位空间。内存须足够。以 n,m 表示分节数，解析/输出为线性，加减比较 O(n+m)，朴素乘法 O(nm+n+m)，小整数除法 O(n)，结果空间 O(n+m)。幂有 O(log(e+1)) 次乘法，但位数增长必须单独计算，不能声称固定字长 O(log e)。不提供大整数除大整数；不适合直接用于要求 NTT 复杂度的百万位乘法。

## 算术正确性

同号相加逐节维护进位，单步至多 2B−1<2³¹，B=10⁹。异号相加先比较绝对值，以较大减较小；逐节借位，最后清除高位零并规范化零符号，避免负零及负数链式运算错误。

乘法每个低位积当场归一化，单步 d[i]·b[j]+c[i+j]+carry≤B²−1<10¹⁸，signed64 安全。每轮行末的进位位置此前未被更高行写入，直接写入；随后统一 trim。一个操作数为零时，临时零分节也统一清除。

除法从高到低维护余数 rem，取下一节时 rem·B+d[i]≤|b|·B−1≤2³¹·10⁹−1<2⁶³。先用 signed64 得到 |INT_MIN|，再做绝对值长除法；最后恢复商和余数符号，余数绝对值严格小于 2³¹，能用 int 表示。快速幂维持 r·aᵉ 等于原始幂，并省去指数耗尽后的最后一次无用平方。

## 原稿审计与能力对应

固定 kuangbin PDF SHA256：f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad。8.1 全部 70 行与 8.2 全部 266 行在物理251–257页（印刷249–255页）目视核对，提取后只还原 PDF 的减号并补标准头文件，以 C++17 编译原稿。

8.1 仅有非负数加乘、构造与输出；8.2 增加比较、减法、除 int、模 int 和非负整数幂，最后是 HDU1134 的 C0..C100 程序。标题“完全高精度”不意味着有大整数除大整数、开方、Karatsuba 或 NTT。这两条来源范围由当前接口覆盖；OI Wiki 高精度整页仍 partial，其大整数竖式除法、Karatsuba 等需另行实现/审计。

原稿有效域内：8.1 的 1400 组加乘、8.2 的 4641 组算术，以及完整 Catalan 程序 101 个值，均在 O2 与 ASan/UBSan 对照 Python 任意精度真值通过。原稿比较/减法仅测不相等的规范化非负操作数，除数≤9999，避免把已知 UB 混进通过统计。负差只验证单次输出，不认为它能继续可靠参与算术。

另行复现七类原稿问题：相等比较先访问 a[-1]；除法与取模在大 int 除数下中间乘法溢出；(1−10001)+1 错成 −10001；自赋值清零；同一对象先读10000再读1残留高位，10000+b 错成20001；operator<< 无视目标流，写到 cout/printf。当前采用独立符号、vector 默认复制和 string I/O，分别消除这些问题。原稿数组还有固定容量限制，本实现改为动态存储但仍受上述尺寸/内存条件约束。

## 测试与用法

`tests/big_integer.py`：24065 组 Python int 精确对照，头文件/NDEBUG/实际抄写版各 O2 与 ASan/UBSan 六种构建通过。另有丢失商符号、丢失乘法进位、借位错误、负零四个故障变体，均被测试检出。含符号四组合、规范化前导零、逐节进借位、零乘法、负数运算链、LLONG_MIN、INT_MIN 除数、0/±1 的 UINT_MAX 次幂、10 万位线性操作及 5000×5000 位乘法。检查表示不变量、操作数不变、复制与自赋值。
