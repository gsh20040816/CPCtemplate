# 树分块与在线路径去重

`TreeBlockDistinct` 使用静态树的关键点路径位集，支持强制在线查询闭路径颜色种数。仅保留 vector 版本，递归 DFS，无哈希误差。点为 1..n，颜色可取任意 signed64 整数；调用方保证输入恰是一棵树。

- `add(u,v)` 加无向边。
- `build(values, B=512, root=1)`：values 长 n+1，忽略下标 0；从零构建，可换颜色、块长和根。
- `query(u,v)`：返回闭路径不同颜色数。修改树或颜色后须重新构建。内部成员构建后只读。

按残余子树大小选关键点：子树残余达到 B 时标记该点并向父亲返回 0；最后补上根。每个自然选出的关键点消耗至少 B 个之前未消耗的点，故 K≤floor(n/B)+1。连续 B 个非关键祖先会使最高点残余至少 B，所以每点距离最近关键祖先严格小于 B。

从每个关键点出发递归遍历全树，维护当前路径的颜色计数和位集；遇到关键点就存下位集。重复颜色不能在回溯一次后直接清位，必须等计数归零。

查询在 LCA=p 处分成两条祖先链。若 u 到 p 不足 B 步，直接枚举；否则令 x 位于 p 下方 B-1 层，取 a=near[u]、b=near[x]。因为 x 到 b 不足 B 步，b 不会高于 p；a 位于 b 下方或与它重合。合并 a..b 的预存位集，再枚举 u..a 和 b..p 的短边界，最后补 p。直接使用 near[p] 可能混入查询路径之外的颜色，禁止这样替换。

设 C 为不同颜色数，W=ceil(C/64)。预处理 O(n log n+Kn+K²W)，空间 O(n log n+K²W+n)，查询 O(B+W+log n)。n=40000、B=512 时 K≤79，位集有效数据至多 31,205,000 字节，另有 vector 和倍增等开销。B 太小会产生平方级关键点表；不是任意块长都能满足内存限制。递归栈按竞赛环境提供足够空间。

验证包括 1442 棵 n≤6 标号树、1500 棵随机树、多块长/根/复制/重建、signed64 极值及位集字边界。头文件、NDEBUG 和抄写形式通过 O2 与 ASan/UBSan；官方样例与 100 组独立 BFS 路径真值生成的强制在线数据通过。越过 LCA、重复颜色错误清位、漏 LCA 三种错误变体均被检出。

Linux GCC16 扩大原生调用栈后，四万点、十万查询的异色链、周期颜色链、星形和二叉树均通过独立公式核验；测试程序保留于 `tests/tree_block_distinct_large.cpp`，不把本机耗时当作 OJ 排名。
