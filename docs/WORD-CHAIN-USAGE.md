# 最小字典序单词链的实际用法

来源为 [UVA 10441 Catenyms 官方题面](https://onlinejudge.org/external/104/10441.pdf)。每组有 3..1000 个互不相同的小写单词，长度 1..20；每个单词恰用一次，前词尾字母等于后词首字母，输出字典序最小的点分隔词链，无解输出 `***`。

example-217 复用输入输出格式兼容的 `verify/poj/2337.compact.cpp`，并只打印其 main。这是比赛应用，不计独立模板题覆盖；复用驱动不代表重新核实了 POJ 题面或获得新线上 AC。

## 复制和调用

依次复制 `DirectedEuler`、`word_chain`，再复制使用代码和标准头文件。返回的 optional 有值时，元素是原输入的 0-based 单词编号；按编号取出原词，词间输出点，末尾不加点。无值输出失败标记。

`word_chain` 先按完整单词排序，再关闭底层欧拉路的终点排序。若改成按终点字母排序，不能保证最小单词序列。非回路起点由度数决定，回路从最小出现的首字母开始。输出中点的字典序早于小写字母，因此前缀单词的比较与实际点分隔字符串一致。

若 n 是词数、L 是字符总数，核心做 O(n log n) 次字符串比较和 O(L+n) 其余工作，辅助空间及递归栈 O(n)。本题单词长至多 20；不要把字符串比较误写成任意长度下无条件 O(1)。

## 官方域与更宽接口分开

接口支持重复词、空输入和更大规模，但这些不在本题范围。原有核心与完整驱动测试中保留相关扩展用例，不把重复 1000 次的相同单词当作“1000 个不同单词”的官方最大规模测试。

新增 `tests/word_chain_distinct_application.py` 专测官方域：

- 官方两组样例，预期输出独立由所有排列验证
- 1020 组不同单词的小集合，枚举每一个排列，筛选首尾连续者，对实际点分隔输出取最小值；含前缀、长度 1/20、a/z 端点、已知有解链和输入乱序
- 1000 个不同的长度 20 自环词，应排序输出
- 999 个不同自环词加字典序更小的 `ab`；`ab` 必须留在最后，防止贪心提前走入死路
- 两个互不连通的平衡分量，共 1000 个不同单词，应失败

全部输入都先验证词数、互异性、字符和长度条件。分别测试完整驱动、仅复制两个组件的最小程序以及精确登记的打印程序，使用普通和 ASan/UBSan 模式；LSan 在该环境不支持 ptrace，明确关闭，不代表内存泄漏检查通过。源码、编译器、输入及输出指纹保存在相应 verification 记录中。

两种模式均通过：每种形态每种模式 1025 组题目输入（分 3 次进程调用），总计 6150 组执行。各项测试前后指纹一致；打印程序与登记源码匹配。

没有改核心或既有驱动，也没有新线上提交、AC 或速度排名。
