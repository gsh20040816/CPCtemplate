# 转置卷积与滑动点积

用法455直接复用NttConvolution，不新增一套Poly类。设a有n项、b有m项，均从常数项开始排列，目标为

c_i = Σ(j=0..m-1) a_(i+j) b_j，i=0..n-1。

超出a范围的系数按0处理，因此保留右端不完整窗口，输出恰好n项。例如a={1,2,3}、b={4,5}，得到{14,23,12}。它不是普通多项式乘积，也不等于只保留完整窗口的匹配结果。

反转b得到r_j=b_(m-1-j)，普通卷积d=a*r满足

d_(i+m-1) = Σ_j a_(i+j)b_j = c_i。

所以只需反转b、调用multiply，再删除前m-1项。不要反转a，也不要再反转结果。若只需完整窗口且n≥m，最后将结果截为n-m+1项；n<m时完整窗口不存在，但本例仍按零补齐定义输出n项。

空输入沿用WIDA mulT及本库普通卷积的约定：任一数组为空则返回空，而不是n个零。调用代码只在卷积非空时删除前缀，避免m=0造成负偏移。非空时n+m-1≤2^23，底层模998244353。输入可为signed64，ModInt先归一化，结果为[0,998244353)。这份用法没有改变底层NTT容量或模数要求。

令L为不小于n+m-1的最小二次幂，时间O(L log L)，空间O(L)，另有NTT历史单位根缓存。反转与删除前缀均线性，总复杂度不变。手册依赖索引指向ModInt和NttConvolution，使用部分只有一份main，便于按需抄写。

验证由tests/transposed_usage.py运行头文件驱动及准确纸面程序，每份都在普通NDEBUG、ASan/UBSan下检查110组独立真值。覆盖空数组、signed64端点、单项/长数组、127/128附近长度、不等长随机系数，以及131072×65537全1输入的解析重叠计数。Python小规模真值直接逐项点积，没有复用NTT或反转卷积实现。用法455另通过集中样例检查。证据见verification/transposed-usage.json和verification/usage-examples.json。

这是API用法，不冒充正式模板题，也没有新线上AC。WIDA12B的mulT接口局部映射和手册用法已补齐；原文件仍因原应用、其他容量和线上排名等缺口保留partial。
