# WIDA 在线模板：字符串双哈希

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `d755a66281a887e40454ae6ead94ed611a58e677`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/35 - 字符串双哈希.cpp`。它使用 `pair` 和 `vector`，但没有头文件，单独编译失败。

两套参数是模数 `1000000007`、进制 127，以及模数 `1000000009`、进制 131。幂表只建到 2 时，`"ab"` 的两套哈希与 64 位乘法一致，改成 `"cb"` 也一致。空串是 `(0, 0)`。

幂是用 `int` 先相乘再取模。建到 8 项时，`260144641 * 127` 超过有符号 32 位，UBSan 报 signed integer overflow。默认构造长度是 `1 << 21`，这轮没有计时，也没有把它当成可用的默认表。

`python3 tests/wida_hash2.py` 在普通 `-O2` 和 ASan/UBSan 下通过短字符串，并记录了长幂表的溢出。没有子串查询，没有新的在线 AC，也没有新增模板。来源保持 partial。
