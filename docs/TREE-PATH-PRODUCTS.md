# 固定树上的动态路径乘积总和

`TreePathProducts<mod>` 补充 issue #11 附件实际 105–109 页“爱莲说”的 LCT 变体。输入树和点权均为 0-based；`set(u,w)` 修改点权，`query(u)` 返回从 u 到所有终点的路径点权乘积之和，包括单点路径。构造要求非空无向树，边双向存储，顶点和权值数量相同。不会检查环或错误邻接表。

与普通路径异或 LCT 的不同之处是虚子树贡献，以及辅助链的正反两个方向；不能用普通 LinkCutTree 的测试或 AC 证明这个变体。树拓扑固定，不提供 link/cut。辅助函数与 a 数组仅供内部使用，尤其 make_root 接收内部 1-based 点号，不能从外部直接调用。

若所有顶点独立以 w 的概率保留，那么查询值也可解释为包含 u 的保留连通块大小的无条件期望：对每个终点 v，连通需要唯一路径上的点全部保留；对指示变量使用期望线性性即可。无需将结果除以 w[u]，w[u]=0 时结果为 0。模板本身仅计算代数式，不要求点权具有概率意义。

## 不变量

每条辅助链维护整链点权积 P、从首端进入的总贡献 L、从尾端进入的总贡献 R。每个点的 virt 是其所有虚儿子子树贡献之和。对左右辅助子树 l,r：

- P = P_l * w * P_r。
- L = L_l + P_l * w * (1 + virt + L_r)。
- R = R_r + P_r * w * (1 + virt + R_l)。

空节点 P=1，L=R=0。上述式子是按路径的终点所在位置分类：终点在左段、当前点/虚子树、右段。反向聚合同理。因此整体反转必须交换 L 和 R，同时交换左右儿子。权值为零或模数为合数时不变量仍成立，因为没有求逆。

访问路径时把旧右链移入 virt，把新右链移出 virt；只改右儿子而不调整 virt 会丢掉原树子树。旧右链的父指针仍是路径父亲，不能清零。修改点权前先换根至该点，旧贡献已沿访问路径正确更新，随后修改和 pull。查询同样换根，返回 L。

构造递归后序把所有边初始化为虚边，O(n)；每次操作摊还 O(log n)，不是最坏 O(log n)。递归建树与 splay 前祖先下传的最坏深度都是 O(n)，没有显式 DFS 栈。空间 O(n)。mod > 1，运算约束沿用 ModInt；输入点权可以是零或负数。

## 证据与范围

`tests/tree_path_products.cpp` 对 998244353 和合数 8 共 2000 棵随机树做修改、查询，以独立 DFS 显式累乘每条唯一路径作参考。另有 20 万点链和星形，验证全 1、修改为零、恢复、两端反复换根。

`tests/tree_path_products_application.py` 对完整主程序做 150 棵树、15000 次操作的 Python 路径枚举。主程序保留附件的 1-based 输入和参数 x，显式转换为 0-based 顶点与权值 1-x；零、一、负权对应的模参数均覆盖。

普通与 ASan/UBSan 检查、当前源 SHA-256 见 `verification/tree-path-products.json`。example-108 是本地应用，未核验原题外部地址，不计入正式模板题覆盖，也不声称线上 AC。使用程序的两个直接执行案例另见 `verification/usage-examples.json`。

## 普通 LCT 的附件核对

附件 4.2.1（实际 100–105 页）是 P3690 路径异或：单点修改、拒绝成环的 link、仅删除相邻点之间真实边的 cut、连通路径查询。当前 `LinkCutTree` 对外点号是 1..n，与这里的新类不同。query 仅允许连通点；相同点查询其自身权值。当前 cut 在 make_root(x)、access(y) 后检查 y 的左儿子为 x 且 x 无右儿子，等价于暴露路径上只有两个顶点；不会把非相邻的路径当作一条边删除。is_root 判断辅助树的父子连接，而不是简单判断 fa=0。

`tests/trees.cpp` 已移除 classic 依赖，仍保留独立 BFS 森林、排序向量与序列向量参考；本次普通和 ASan/UBSan 均通过。普通 LCT 部分为 300 组动态森林，每组 500 次操作，含重连、删不存在的边、自环、两端查询和换根；另有 20 万点链。`tests/lct_application.py` 对 P3690 完整程序做 200 组、10 万次操作，合法查询的连通性由独立图模型保证，两种模式均通过。此范围没有新增线上 AC；来源代码中的 Splay 祖先标记下传与图 DFS 是不同操作，本次不改已有 LinkCutTree 源。
