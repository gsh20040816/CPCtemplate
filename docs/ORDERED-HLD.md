# 有向路径：HLD 与非交换聚合

现有 `HLD::path` 保持原语义：回调区间覆盖路径，但顺序只适合和、最值、异或等可交换聚合。新增 `path_ordered(u,v,work,edge=false)` 专门输出真实 u→v 顺序，使用同一棵静态树和既有递归重链剖分，不新增组件计数。

## 区间合同

- 调用 build(root) 后使用，点号1..n；图必须是非空连通无环树
- work(l,r,rev) 的 l≤r，为dfn数组的1-based闭区间
- rev=false按l,l+1,…,r访问；rev=true按r,r−1,…,l访问
- 回调之间的先后次序也是路径顺序，不能先把区间排序，也不能统一按左端点拼接
- 点模式包含两端和LCA；u=v只回调一次单点
- edge=true只去掉LCA的位置；把每条父边存到较深端点后，回调序列正好对应经过的边。u=v不回调
- 边模式不会自动求逆算子。若一条边两个方向对应不同操作，要分别维护正反聚合，并利用rev选择正确方向
- 重选根后build会重排dfn；所有依赖这个顺序的线段树都须重建

u侧每次取一个上行链段并立即输出；v侧取出的段是从终点向上剥离，先保存。两端进入同链后输出中间段，最后倒序遍历v侧保存的段，段内仍按dfn正向。跳过LCA只发生在中间段，不能把每个链头都跳过。

每越过一条轻边，向上看到的子树大小至少翻倍，所以每侧O(log n)段。此接口额外存储O(log n)段；若回调对每段做O(log n)线段树查询，总计O(log² n)。递归DFS不变，最坏链的栈需求是独立限制，不能因路径查询只存O(log n)段就忽略建树递归深度。

## 正向和反向是两个聚合

令区间A在区间B前面。正向复合是 F_B∘F_A，反向复合是 R_A∘R_B。仿射函数(a,b)表示x↦ax+b，先f后g的参数为(a_g a_f, a_g b_f+b_g)。仿射函数复合中的斜率乘积可交换，截距组合不可交换。

用法231的S为四元组：正向(a,b)、反向(a,b)。拼接时分别按上述次序计算。叶子的两个方向相同；单位元都是x↦x。点修改要同时更新两个方向。

“反向遍历原函数序列”不是“把复合函数求逆”，即使每个函数都可逆也不能混淆。一般接口也能承载零乘数，但官方题面斜率非零；验证中把零乘数单独列为额外扩展。

## 正式题目与索引转换

[Library Checker Vertex Set Path Composite](https://judge.yosupo.jp/problem/vertex_set_path_composite)：N,Q≤200000，模998244353；题面1≤a,c<mod，0≤b,d,x<mod。静态树、单点函数赋值、按u→v依次代入（含两端）。

题目点号从0开始，调用HLD前加1；HLD的闭区间[l,r]变成segtree的半开[l−1,r)。回调查询一段后，直接把当前x送入所选方向的聚合函数。long long的乘加上界小于mod²+mod，远小于signed64上界。

官方题面、参数和校验器按既有固定上游版本核对，旧动态树同名类题不自动归入此实现。新接口没有link/cut，不扩张到动态树。

## 验证范围

独立BFS建父树后重建实际路径序列，比较回调展开结果，不排序抹掉方向。包括1..6点全部带标号树、所有根与点对、边模式、打乱邻接顺序、随机换号树、15点多链证书和200000点链/星/二叉树，保留换根后重复build。核心完整头与最小标准头各执行同一检查。

完整程序分别验证直接驱动、登记展开、实际抄写组件三个形式。小输入按路径逐个应用函数；最大链、星、二叉树各N=Q=200000，用独立闭式或最多三步代入参考。故意错误的链内方向、v侧缓冲顺序、LCA边模式和仿射组合顺序均有负控。

新功能的最终普通/ASan/UBSan证据另列；不把旧P3384的AC转移给新接口，不把局部性能、语法审计或最大链在增大栈后的通过等同于线上AC。旧path、DFS和相关用法需单独保持回归。
