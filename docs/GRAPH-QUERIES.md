# 删边、改点权与连通块第k大

用法289把已有`dsu`与`MergeSplitTree`组合为完整[UVA1479 Graph and Queries](https://onlinejudge.org/external/14/1479.pdf)程序。它是竞赛应用，不能据此增加正式模板题覆盖。

官方约束：n≤20000、m≤60000，权值在[−10^6,10^6]；每条边至多删除一次，Q操作1..200000次，C操作至多200000次。k可为任意signed32，非法k的答案为0。多组输入以0 0结束，各组操作以E结束；输出`Case i: 平均值`，保留六位小数。平均值分母包含非法k的查询次数。

## 离线恢复与接口组合

按正序读取所有操作，C操作同时交换当前值与新值：数组a记录最终权值，操作记录保存这一次修改前的旧权值。收集全部初值和所有新值做离散化，重复值共用一个坐标，其频数仍累计。

处理最终图：每个点对应一个线段树集合，频数总和为1；只合并没有被删除的边。`split(0,0,0)`把空区间分裂为新空集合，连续创建后集合号恰为0..n−1，无需手改root。此处split不是在分裂图的连通块。

倒序执行时，D恢复边；C从所属连通块中删除目前权值的一个频数，恢复旧值并加入一个频数；Q只查询，不改变点权。合并前先取并查集根u,v，若不同，调用`t.merge(u,v)`消费v的集合，再调用`d.merge(u,v)`。普通dsu固定执行fa[v]=u，两个操作方向必须一致。没有把普通并查集改为按大小合并。

k为第k大，线段树kth为1-based第k小，转换为`(long long)component_size-k+1`。必须先转long long再减：k=INT_MIN时int中间结果会溢出。kth返回−1时贡献0，其余通过离散值表还原权值。查询总和绝对值至多2×10^11，用long long累加，最后才做浮点除法；不用逐次平均。官方至少一个Q，因此count不会为0。

线段树的合并按相同值域递归，每次同时存在的节点合并都会回收一个槽；所有合并的总成本可由已分配节点数计费。若U为不同初值/新值数，权值更新与kth各O(log U)，所有线段树工作可按O((n+C+Q)log U+m+D)估计，另加并查集和离散化成本。节点回收复用，活跃树内的频数总和始终n，空间O(n log U+m+C+Q+U)。这不是在线评测机时间/内存通过证明。

## 与原稿的关系

kuangbin3.4.2印刷67–72页以可合并的Splay集合维护相同的删边/改点权/连通块第k大模型。本用法改用已有可合并频数线段树，保留应用行为；不声称新实现了Splay任意根合并接口。来源3.4.2与3.4父项因此保留partial：应用行为有了独立证据，但原稿的可合并Splay算法仍待补齐。已读取UVA官方两页PDF，操作、非法k、重复点权、平均值和两组样例与源稿对应。HDU3726原页面没有独立核验，不能推断HDU资源限制下通过。

## 独立验证

`tests/graph_queries.py`在正序图上用BFS重新计算查询点所在连通块，排序实际顶点权值，独立核对倒序算法。100份输入各含3组随机数据，包含负权、重复权、平行边、自环、重复改同点、删边后修改、INT_MIN/INT_MAX及非法k；自环与平行边是本地扩展边界。

另有官方两组样例和三个大输入：60000次删边+200000次改权+200000次查询的满规模；20000点链逐次拆开及逆序恢复；始终连通时连续200000次改权和200000次查询。大输入答案由结构不变量直接给出，未使用被测数据结构作为参考。

完整driver/expanded/minimal-copy/minimal-NDEBUG四种形式在普通及ASan/UBSan下各执行104份输入。额外在完整展开程序中仅插入每次Q的输出记录，逐项核对逆序答案，避免平均值把错误互相抵消；最终平均值用Python精确Fraction验证到半个最末小数位。五种错误变体必须被独立结果拒绝：第k大方向错误、记录了新值、仍连接被删边、漏恢复旧值、把负答案取绝对值。
