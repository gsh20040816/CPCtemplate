## 状态与独立推导

以下是本次审计使用的最小割推导。令 g/h 为累计生长/采摘，b 为最低需求。建立源到各生长组容量g、各生长组到允许放置的实际节点无限容量、实际节点到覆盖它的采摘组无限容量、实际节点到汇容量b、采摘组到汇容量h的网络。满流需求为总b+总h。达到需求后，多余生长可随意留在允许节点；先全部生长、再采摘便能避免负数，故该流模型与原题可行性等价。

以割掉所有生长边的总g为基准，子树贡献有四类。状态0选择该节点生长组留在源侧，于是全部子树节点和采摘组均须在源侧，并要求父节点也在源侧；所有子孙生长边均可保留，因此减去子树总g。状态1把当前实际节点留在汇侧，但允许后代源侧节点，需支付当前h；不能让直接孩子采用要求父节点源侧的状态0。状态2把当前实际节点留在源侧，但割掉当前生长边，支付b+h，孩子任意。状态3让整个子树在汇侧，额外贡献为0。

状态1允许没有后代源侧节点而仍支付h，状态2允许未被任何生长组使用的源侧实际节点。这些仍是合法割，不会产生低于最小割的虚假答案；非负b/h保证保留这些冗余状态无害。由此得到：

```
F0(u) = b[u] + h[u] - g[u] + sum F0(v)
F1(u) = h[u] + sum min(F1(v), F2(v), 0)
F2(u) = b[u] + h[u] + sum min(F0(v), F1(v), F2(v), 0)
F3(u) = 0
```

最大流等于总g加根的四状态最小值。根的F0恰为总b+总h-总g，因此健康当且仅当根F0等于根四状态最小值。根无父节点，不额外引入父亲约束。

## 动态维护与数值边界

实链按从上到下的顺序相乘。第四维固定0，把常数项表达为仿射min-plus转移；空链为单位矩阵。虚子树分别累计F0、min(F1,F2,0)、min(F0,F1,F2,0)。access中先将旧右子链转虚，再移除新右子链的旧贡献，保存当前旧聚合后才更新局部矩阵。最后将修改点splay到辅助树根，其聚合覆盖整棵固定树。没有反转或其他懒标记，不需要空的push/pushAll。

总b加历次事件数限制为10^15，所有参数非负。任意矩阵有限项是对应簇内每点b/h/g的系数为0或±1的割代价，绝对值由该簇参数总量界定；合法相邻簇相乘不会重复计入同一节点。虚子树暂时转入再扣出只产生常数倍该界的中间量，远小于2^60。不可达项相加前显式跳过，避免INF与负数相加后变成伪有限值。

初建O(n)，add摊还O(log n)，healthy为O(1)，空间O(n)，矩阵维度固定。初建递归深度最坏n，遵守项目的竞赛栈约定。公开接口为构造、add、healthy；内部矩阵、节点数组和辅助函数不应由调用者直接修改。只判定可行性，不输出流或事件分配。
