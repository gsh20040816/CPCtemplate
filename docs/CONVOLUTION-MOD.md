# 精确任意模数卷积

`convolution_mod(a,b,mod)`把已有三模NTT方法封装成可直接组合的函数。目标模数为1..INT_MAX，可以是合数，也可以与NTT素数相同；输入为完整signed int系数，输出标准代表[0,mod)。任一数组为空则返回空；非空结果长度不超过2^24。普通传参不修改调用者数组，也可显式move移交输入以节省复制。

本库已有[固定模1000000007的Garner组合用法](GARNER-CONVOLUTION.md)，不是此前完全没有精确模卷积。本函数将负数归一化，并预先计算固定三个素数之间的逆元，避免逐系数调用通用Garner时重复求逆；不修改既有Garner、浮点拆分或signed64卷积代码。没有用线上成绩声明速度优越性。

## 为什么能准确恢复

先把输入系数分别归一化到[0,mod)。这是必要步骤：未经目标模数归一化的负数，直接在三个NTT素数下求余并重构非负CRT代表，不一定对应目标模数下的负数结果。

选择p=167772161、q=469762049、r=1224736769，共同支持长度2^24，均以3为原根。令输入长度n,m且n+m−1≤2^24，每项真实非负整数系数最多含min(n,m)≤2^23个乘积，因此

`C[k] ≤ 2^23 × (INT_MAX−1)^2 = 38685626155610539586224128`

严格小于

`p q r = 96525171769480128904560641`。

所以CRT最小非负代表就是原整数系数，不是某个模周期别名，随后对目标模数取余正确。这个上界只依赖公开长度与模数契约，不要求调用者另外估计系数能否装入long long。

先以p,q恢复v=x+p·t，0≤v<pq；再求u使v+pq·u满足模r余数。v和两个模乘中间量均在signed64内，最终值用int128；不能先窄化到long long。最大系数甚至小于CRT乘积一半，所以在此精确契约内选择中心代表与非负代表等价，但没有必要增加中心化分支。测试中的这个变体保留为等价变体，不伪称已检出错误。

目标mod不参与任何逆元计算，故可以为1、合数或三个NTT素数之一；所有逆元只发生在固定的互素素数之间。mod=1直接返回正确长度的零数组。

## 代价与抄写

依赖`ModInt`、`NttConvolution`。`convolution_prime`只是此代码块内部使用的三模转换辅助，调用者通常只调用`convolution_mod`。参数按值接收便于就地归一化，三个NTT依次执行，并保留三份结果；输出复用第一份余数数组。

总时间O(L log L)、空间O(L)，L为不小于n+m−1的最小二次幂。2^24是代数变换容量，不是承诺该长度一定满足题目内存或时限。测试没有跑满2^24的内存容量；长规模闭式测试覆盖2^18前后及正式P4245最大次数。

与`convolution_i64`的区别是输出语义：后者输出有符号整数并要求真实系数在signed64内，本函数输出目标模数代表。与`convolution_mod_fft`的区别是完全不使用浮点数，不需要误差估计前提；它们保留为不同实现，历史提交结果不互相转移。

## 用法与测试

用法345为[洛谷P4245任意模数多项式乘法](https://www.luogu.com.cn/problem/P4245)独立三模驱动。官方协议为次数1≤n,m≤100000，系数0..10^9，模数2..1000000009，输出n+m+1项。此次读取官方题面和边界；没有把生成测试说成官方样例，没有新增线上AC或速度排名。

用法346单独演示空数组、负数、INT_MIN/MAX、模数1和INT_MAX等接口扩展，多组直到EOF，空结果仍输出一行。扩展不是P4245的正式输入域。

`tests/convolution_mod.cpp`直接用int128计算有符号乘积并逐项取模，不使用其他卷积作为真值。核心20103组包括长度0..3、值−2/0/1的全部数组对与11种模数、2500组随机/极值输入、131072长度附近全−1数组的闭式结果；后一类归一化后的真实系数远超signed64。检查输入保持不变，并覆盖move调用。

`tests/convolution_mod.py`运行普通、NDEBUG、真实最小抄写核心和四种完整用法形式（头文件、NDEBUG、展开、抄写），普通及ASan/UBSan分别执行。正式驱动82例包括两组最大次数闭式输入，扩展驱动163例。三个有效故障变体破坏第三素数、CRT逆元和负数归一化，必须由错误结果而非崩溃检出；一个中心化等价变体明确记录为等价。报告位于`verification/convolution-mod-normal.json`和`verification/convolution-mod-sanitizer.json`。
