# 固定编号的区间翻转 Splay

`SequenceSplay`用轻量vector节点池维护初始原编号0..n−1的排列。元素的原编号永久不变，当前位置随翻转改变；实际值由调用方用原编号索引自己的数组，重复值不会被合并。

- `SequenceSplay(n)`：允许空序列，0≤n≤INT_MAX−3，需有足够内存。
- `reverse(l,r)`：翻转当前0-based半开区间，空区间合法。
- `pos(id)`：原编号id目前在哪个0-based位置；要求0≤id<n。
- `at(k)`：当前位置k放的是哪个原编号；要求0≤k<n。
- `order()`：按当前顺序返回全部原编号；空序列返回空vector。

建树O(n)，pos/at/reverse均摊O(log(n+1))，单次最坏O(n)，order为O(n)，空间O(n)。本组件不提供插删和数值聚合；这些需求使用现有SequenceTreap等组件。a/root/n与辅助函数仅供实现内部使用，不直接修改或单独调用。普通值拷贝完全独立；重新初始化用新建对象赋值。

建树、祖先下传、遍历均为递归；顺序伸展可制造深度O(n)的树，调用方保证栈空间。测试给Darwin程序指定512MiB栈，不代表在线评测资源已验证。

## 哨兵与下传

内部节点1与n+2是首尾哨兵，真实元素id对应节点id+2。内部子树大小含哨兵，pos把目标伸展到根后取左子树大小减1；at先选内部第k+1个，再伸展到根，返回节点编号减2。两种接口均会改变树形，但不改变序列。

reverse先把内部秩l的左边界伸展到根，再把内部秩r+1的右边界伸展为其右儿子；右儿子的左子树恰好是[l,r)。反转只交换该子树的左右儿子并翻转懒标记，大小不变，因此不用重算祖先大小。空区间先返回，避免两个边界选择重合。

按原编号访问不能假定祖先的翻转标记已经下传。splay之前递归到根，再从上到下push，使每次旋转的左右方向对应当前序列。只在目标节点push会在嵌套翻转后得到错误位置。普通zig/zig-zig/zig-zag旋转维护父子关系与大小，祖先下传的工作量与此次访问路径长度同阶，保持伸展树均摊界。实现不使用显式DFS栈。

## 模板题与来源

[洛谷P3391](https://www.luogu.com.cn/problem/P3391)是正式区间翻转模板题，n,m≤100000。用法286把输入1-based闭区间转换为reverse(l−1,r)，最终原编号加1即题目要求的序列值。它验证翻转与输出，不独自证明pos接口。

[洛谷P3165排序机械臂](https://www.luogu.com.cn/problem/P3165)是竞赛应用，n≤100000、高度≤10^7。用法287先按(高度,原编号)排序；第i步通过pos找到目标元素，输出其1-based位置，然后翻转[i,p+1)。不能把当前位置当成相同高度的并列依据，稳定性必须由初始原编号决定。用法288独立展示pos、at、order和空序列约定。

kuangbin3.4.1印刷64–67页的HDU1890源稿同样按(值,初始位置)选取元素，查询当前位置后翻转。新实现保留该操作模型，改为vector节点编号和递归祖先下传。原HDU页面仍不可读取；源稿的EOF/零终止多组协议没有冒充P3165协议，P3165驱动仅处理它自己的单组输入。不存在HDU1890线上通过声明。

## 验证

`tests/sequence_splay_probe.cpp`枚举n≤7所有排列，并枚举每个0-based半开区间（含空区间）；独立vector反转核对结果、原编号的位置与按位置返回的编号。对子树大小、父指针、每个节点恰访问一次的检查在深拷贝上运行，避免先把被测树的懒标记全部下传后才测pos。另有150组随机操作、复制隔离、十万点顺序伸展后的递归遍历、连续循环移位与全区间反转。

每种核心形式共204706小案例、9963716次小规模核验，加十万规模后共10663716次核验。普通及ASan/UBSan各执行头文件/抄写×assert/NDEBUG四种形式；六个错误变体被独立答案拒绝：漏祖先下传、漏翻转、漏懒标记、位置哨兵偏移、原编号哨兵偏移、右端点偏移。

完整driver/expanded/minimal-copy三种形式分别执行83份P3391输入、103份P3165输入、70份API输入，两种模式均通过。大输入包括n=m=100000及n=100000的升序、降序、全相等排序机械臂；随机重复值通过稳定排序和vector模拟独立核对。

证据见`verification/sequence-splay-{normal,sanitizer}.json`。本地通过不等于在线AC或速度排名，也不是全库运行回归；历史组件与历史用法应字节保持不变。
