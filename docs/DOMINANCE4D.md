# 四维偏序

`Dominance4D::count(p, strict=false)` 返回每个输入点被多少其他输入点支配，结果与输入顺序一致。默认要求四维均小于等于；`strict=true` 要求四维全部严格小于。排除自身，重复点仍按输入次数计数。支持空输入及完整 signed64 坐标，不修改输入；点数不超过 INT_MAX/2。每点答案用 int，汇总应使用 long long。

每点拆成更新和查询事件。先按第一维排序，再进行外层 CDQ；每个更新与查询在唯一一个左右分离的递归节点计数。该节点只取左侧更新与右侧查询，按第二维排序后做内层 CDQ。内层合并按第三维扫描，用 Fenwick 查询第四维前缀；插入过的更新必须全部回滚。

弱偏序在第一、二维同坐标时将更新排在查询之前，第三维扫描允许相等，第四维查询当前秩。严格偏序将同坐标查询排在更新之前，第三维仅允许严格小于，第四维查询秩减一。坐标不做加减，不会在 signed64 极值处溢出。弱模式最后减去自身的一次贡献，严格模式没有自身贡献。

内层每层合并维持第三维有序；外层事件始终保留第一维顺序，不能用内层排序结果覆盖它。单个外层节点耗时 O(k log²(k+1))，总时间 O(n log³(n+1))，辅助空间 O(n)，递归深度 O(log(n+1))。保留递归实现。

本地验证穷举四维布尔网格的 65536 个子集，并检查 5000 组随机多重集及打乱顺序后的副本；独立 O(n²) 真值覆盖两种模式、相等坐标、重复点和 signed64 极值。头文件、NDEBUG、展开和抄写用法通过 O2 与 ASan/UBSan。两个官方样例及 100 组随机驱动通过；十万点链、反链、重复点使用公式检查，随机数据另与已验证的三维偏序归约比较。事件同值顺序、第四维前缀、回滚、自身扣除四种错误变体均被检出。
