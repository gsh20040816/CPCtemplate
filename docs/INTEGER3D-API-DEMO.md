## 明确的协议与几何含义

选择0≤Q≤200000，每次输入a、b、c、d四个整数点，每个坐标在[-10^9,10^9]。输出：

1. orient(a,b,c,d)：有向六倍四面体体积，精确有符号整数
2. collinear(a,b,c)：0或1
3. on_segment(d,a,b)：0或1，包含端点和a=b的退化线段

重复点、共线和所有退化都允许。orient为0表示仿射相关，不能据此声称前三点唯一确定了一个平面。几何体积为abs(orient)/6这个有理数，不能丢掉余数作整数除法。本演示没有三维凸包构造。

[SPOJ TETRAHED](https://www.spoj.com/SPOJ/problems/TETRAHED/)仍只是潜在应用。官方URL的索引文本描述五点中四点构成四面体、另一点在其中，但没有明确重复点、唯一解及边界约定；实时页面未能读取。不能因此把“返回第一个候选点”的本地诊断程序发布成已核验的判题解法。本例的约束和样例全部明确为自定义。

## 算术边界

设点坐标绝对值≤B，则点差每分量≤2B；两个点差的叉积每分量≤8B²；点差点积≤12B²；orientation及其部分和的保守界≤48B³。B=10^9时均在有符号128位范围内，但点积已可能超过有符号64位，不得缩窄输出。

这一保证只覆盖规定点域产生的运算，不覆盖任意公开Vector值或反复嵌套组合。两个合法orientation相乘仍可溢出128位，比较符号应分别与0比较。diff的先提升后相减也不代表其他方法支持完整signed64坐标域。

驱动使用无符号模转换得到十进制打印的绝对值，不用浮点格式化或不安全的最小负数取反。独立抽取实际打印lambda检查0、±1、signed int128最小/最大值和±8×10^27；这些打印边界不扩大点坐标契约。
