# 有向图最小平均权环

Issue #15；minimum_mean_cycle。用法380适配P3199实数输入，用法381输出整数权精确分数。实现、本地验证和实际线上AC均已完成。

## 模型与接口

n≥0且n<INT_MAX，点0..n-1，edges为tuple<int,int,T>。有向图可以断连、有负权、自环和重边。最小化环的总权除以边数，不是最小总权环；自环的均值就是自身边权。无环返回nullopt，空图也返回nullopt。其他情况返回pair<分子,正分母>，不约分，不提供环方案。输入不变，重复调用独立。

T为有符号至多64位整数时，内部W=int128，完整支持LLONG_MIN/MAX；不是先做long long加减再提升。n<2^31、|w|≤2^63，长度n的行走和绝对值≤n*2^63；分子差和分母交叉乘积绝对值<2^126，int128安全。分母1..n，分子可为负，按精确分数比较。

实数T需支持值语义、基本运算。禁止NaN/Inf，要求2n²max|w|<2^118；这是避免范围溢出的条件，不是精度保证。普通double/long double有舍入，尤其不能假设所有平台long double精度相同。P3199驱动使用GCC __float128（113位有效二进制精度）做核心运算，long double仅用于标准流读入和最终输出转换。在|w|≤10^7下，即使long double只有53位有效精度，单次输入转换绝对误差也小于10^-9；最小环均值对每条边的扰动是1-Lipschitz，输入误差不会因环长累积为n倍。最终转换误差同阶，仍需区分数值误差与8位小数格式化舍入。任意长度小数仍可能舍入，恰在八位小数舍入边界附近不能声称十进制逐位绝对保证；整数或有明确缩放界的小数需要绝对精确时，应先做精确整数缩放。

## 两遍Karp与全图初始化

令Fk(v)为从任意点出发、恰好k条边、终止于v的最小权行走；F0(v)=0。每层从前一层转移，next必须先清成无穷大，不能原地松弛或沿用d，否则就变成“至多k条边”。第一遍滚动计算Fn，保存last；第二遍重算F0..Fn-1并逐点取max_k (Fn(v)-Fk(v))/(n-k)，最终对点取min。不存在长度n行走的点跳过。

原始Karp定理常表述为强连通图固定源。这里全点F0=0的推广无需强连通：把每条边减去最小平均值μ，所有环非负且存在零环。每个点的任意起点最短行走都能去掉非负环，故其最优值π由长度<n的简单路径取得，Fn(v)≥π(v)，每点的max比值≥0。选择到零环的最短行走并无限重复零环；其前缀都是相应终点的最短行走（否则替换前缀将改善整条到零环的最短路），长度n的前缀终点满足Fn=π，全部比值≤0且至少一个为0。故全局min为0。恢复μ后，每个比值同时增加μ，得到公式。无环图最长行走至多n-1条边，因此所有Fn无穷大，返回nullopt。

滚动重算避免保存n²个权值；时间O(n(n+m))，额外空间O(n)，输入空间O(m)。不将一般稀疏/空图的n²项省略成O(nm)。不调用DFS、负环启发式或二分。只返回值，不能随意把取得最优的分子差解释成某个真实环的权和。

## 验证与题面

独立真值递归枚举简单有向环（不是模拟DFS栈），枚举三点每条有向边无/-3/+7共19683图、四点固定混合权的全部65536图；3000随机重边、自环、断连及补孤立点，检查signed64极值、3000点10000边公式压力。实数用Python Fraction从十进制精确建立真值，覆盖正负消去和八位舍入；两份驱动各测头文件/NDEBUG/完整展开/最小抄写，分别O2及ASan/UBSan。

[P3199](https://www.luogu.com.cn/problem/P3199)：2≤n≤3000、1≤m≤10000、|w|≤10^7，实数权，无自环，保证有圈且有一个点可达所有点；5s/512MB，输出小数点后8位。两个样例分别11/3与-3。本函数支持更广的断连/无环/整数权范围，不能只用这一题AC证明全部接口。

原始来源：[Karp 1977 Berkeley技术报告](https://www2.eecs.berkeley.edu/Pubs/TechRpts/1977/29121.html)，后发表于Discrete Mathematics 23 (1978), 309–311。这里的两遍滚动、全点初始化与整数精确比较由上述约定及证明给出。

环境兼容记录：首次提交302334514因洛谷没有Boost头文件而编译失败，0ms/0B不能当算法运行时间。改用GCC内建__float128，无需quadmath链接库；不使用其非标准输入输出函数。
