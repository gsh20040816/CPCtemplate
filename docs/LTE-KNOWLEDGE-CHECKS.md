# 升幂引理知识补充与检查

`knowledge-lte.tex` 新增一节初等整数素因子赋值与 LTE：奇素数差/和式、素数 2 的指数奇偶分支、公因子约去、零差排除、简短证明和整除条件的转化。主分类为固定 OI 导航的“数学 / 数论 / 升幂引理”，独立起页；现有知识分类增至五份文件、16 个带标签节，其余历史附录仍不宣称已全量分类。

条件参照 [OI Wiki 升幂引理](https://oi-wiki.org/math/number-theory/lift-the-exponent/)，正文组织与证明说明为原创。术语限于整数的素因子重数，不把这一节称为完整 p 进数理论。它没有增加算法条目、OJ 用法、AC 或排名；数学覆盖表仍保留完整来源页范围待审的限制。

运行：`python3 tests/lte_knowledge.py`。默认报告写到 build；发布证据在 `verification/lte-knowledge.json`，绑定测试和正文哈希。

检查使用 Python 任意精度整数，直接构造幂、相加减，再反复除素数求实际重数：

- a、b 遍历 1..24，n 遍历 1..18，素数遍历 2..43，逐项筛选前提后核对各式
- 对不同/相同公共估值两分支，分别验证和、差的因子剥离
- x、y 遍历 1..64，检查乘积与相加估值、不等估值必取等
- 明确拒绝对 0 求有限估值；检查遗漏单位条件、整除条件、奇数指数、误用素数 2 和合数底数等反例
- 逐个测试更小正指数，独立验证最小指数应用；正文的 2^6·3^2 整除 7^n−1 在 n=1..144 验证恰当且仅当 24 整除 n

这些有限枚举是回归证据，不代替正文证明，也不是 C++、sanitizer 或线上判题检查。阶乘的 Legendre 赋值、素数幂开根的单位条件分别链接已有模板，避免重复实现或混淆适用条件。
