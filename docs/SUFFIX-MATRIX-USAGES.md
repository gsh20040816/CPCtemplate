# 平方串与矩阵树用法（186–188）

## 平方串应用

[洛谷 P1117](https://www.luogu.com.cn/problem/P1117) 是 NOI2016 比赛题，统计所有子串的 AABB 拆分，A、B非空，允许相等，不同位置与长度分别计数。T为1至10，每组小写串最长30000。本批为已有 square_counts 添加完整调用代码；它属于应用覆盖，尚未找到独立模板题，不能计作正式模板题覆盖。

正向 SuffixLCP 与反向 SuffixLCP 来自同一原串及其反转。start[i]表示起始于字符i的平方串数量，finish[i]表示结束于字符i的数量。按两段之间的分界点乘积求和，每个合法拆分唯一对应一个分界点及左右两个平方串，故不会重复或遗漏。半长不同也分别计数；long long可容纳本题答案。模板本身不修改，main只负责构造、反转和累加。

打印程序由 tests/square_usages.py 在普通及ASan/UBSan模式分别验证5983个串，共599次进程调用：所有长度1至10的2046个二进制串，长度1至7的3279个三进制串，500个随机串，148个周期边界串；最后一份输入含10组长度30000的串。短串参照直接枚举起点、A长度、B长度后比较原字符片段；最大规模用周期内字母互异的串，半长必须是周期的倍数，再按A/B长度组合直接求和。两模式完整输入输出指纹相同。

旧核心回归移除了已删除classic版本依赖，保留vector版本所有长度0至7的三字母表序列（含字节0/127/255）、150个随机序列、稀疏大字母表、含零字节字符串、源对象重置后的查询、空后缀和空子串。直接扫描验证所有LCP/LCS与所有半开子串比较，逐字符判断平方串起止数组；20万长度周期串另检查10万组查询及全部位置计数。核心两模式均通过。LCS在此指最长公共后缀，不是最长公共子序列。

## 矩阵树正式模板题

[Library Checker Counting Spanning Trees (Undirected)](https://judge.yosupo.jp/problem/counting_spanning_tree_undirected) 为独立生成树计数模板题。已核对官方task.md与info.toml：1≤n≤500、0≤m≤500000、0起点号，允许自环和重边，结果模998244353。每条原边以权1加入；自环不构成树，重边分别贡献选择。删去任意根的拉普拉斯行列，取行列式即树数量；n=1的空树计1，断连计0。

用法187使用MatrixTreeMod与determinant_mod，展示支持任意正模数的已有接口。该接口无需除以模逆元，支持合数，复杂度O(n³ log mod)。固定质数时也可使用已有更快的MatrixTree版本。这里root=0只是删行列位置，不要求无向树另有方向。

固定上游commit e64660561a995c357cdc61ddee1bde68b80528db，完整生成22组输入和参考输出（4样例、10小图、5随机、3最大规模），普通与ASan/UBSan均通过官方checker；故意错误输出被拒绝。执行时间、输入输出、checker、元信息和程序指纹均归档。它是本地官方数据验证，不能当成线上AC或OJ全提交速度排名。

MatrixTreeMod核心回归也迁到当前vector版，移除外部Boost依赖，使用int128安全乘法逐步取模。独立枚举边集合并检查连通性/各点度数，不用第二份行列式或拉普拉斯算法。300个随机小图在所有根、三种方向和六种模数（含1、合数与LLONG_MAX）上验证；另测LLONG_MIN/LLONG_MAX权重、自环和重边。160点完整图以Cayley公式验证大权重及合数模数，两模式均通过。

## 有向矩阵树正式用法

用法188补充[Library Checker Counting Spanning Trees (Directed)](https://judge.yosupo.jp/problem/counting_spanning_tree_directed)，同样n≤500、m≤500000，指定根r为0起。官方要求从根能到达所有顶点，必须使用away_from_root，等价每个非根点一个入边、根无入边；toward_root解决所有点能到达根的相反方向，不能混用。自环和重边约定不变。独立核心测试已覆盖所有根和三种方向；打印用法增加非零根、方向颠倒无解、单点与重边边界。

上游同一固定commit的全部22组有向数据也执行普通和ASan/UBSan两模式，官方checker接受所有输出并拒绝故意错误输出。两题合计44组官方生成数据、88次完整程序执行，均使用打印用法的精确程序文本。tools/official_cases.py新增可选--usage参数，强制所选用法属于指定驱动，并在报告中绑定其程序指纹；不带参数时保持既有独立驱动执行方式。
