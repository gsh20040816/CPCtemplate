# WIDA 在线模板：立体几何

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `ae89fba9d6351b6356331ee586ec17c6a626b6e0`，路径 `01 - 常用在线模板汇总/03 - 数论、几何/23 - 立体几何.cpp`。结构体叫 `Point3`，后面的函数却使用没有定义的 `ld` 和 `P3`。单独编译失败。

测试在命名空间里补上 `using ld = long double` 和 `using P3 = Point3`。`i × j` 是 `(0,0,1)`，长度是 1。`(1,2,3)` 与 `(4,-5,6)` 的点积是 12。`(3,4,12)` 到原点的距离是 13。平面 `(0,0,0),(1,0,0),(0,1,0)` 的法向量是 `(0,0,1)`。

两个点的 `operator*` 是逐分量相乘，`(2,3,4)*(5,6,7)` 得到 `(10,18,28)`，不是叉积，也不是点积。零向量单位化的结果不是有限数。`Line3` 和 `Plane` 只有成员，没有别的运算。

`python3 tests/wida_solid.py` 在普通 `-O2` 和 ASan/UBSan 下通过这些例子。没有新的在线 AC，也没有新增模板。来源保持 partial。
