# WIDA 欧拉筛

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `0bd397ab79b5ae363938682c46d3274167a621d0`，路径 `03 - jiangly模板收集/03 - 数论、几何与多项式/03 - 欧拉筛.cpp`。两份 `sieve` 和两套全局数组同名，整份文件不能一起编译。

前一份只求 `minp` 和素数表。`isprime(n)` 是 `minp[n] == n`，所以 0 和 1 都不是素数。`n = 0` 和 `n = 1` 的素数表为空。后一份同时求欧拉函数：`phi[1] = 1`，素数是 `p - 1`，碰到最小质因子就乘 `p`，否则乘 `p - 1`。

两份分开后，在 `n` 为 0、1、2、30 和 100000 时，素数、最小质因子和欧拉函数都与独立线性筛一致。带 `phi` 的版本在 `n = 0` 时仍写 `phi[1]`，数组长度只有 1，ASan 报越界。`i * p` 是有符号乘法，没有对接近 `int` 上界的 `n` 做验证。

`python3 tests/wida_sieve.py` 跑了普通 `-O2`、ASan/UBSan 和 `phi` 的 `n = 0`。提交页面没有打开，没有新的在线 AC。来源保持 partial。
