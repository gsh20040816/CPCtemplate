\section{容斥与二项式反演：恰好与至少}\label{knowledge-inclusion-exact}
\index{容斥原理}\index{二项式反演}\index{恰好计数}\index{满射}
交集和带重数，不能直接当作“至少”的数量；性质之间不要求独立。

\subsection{从交集和恢复恰好数量}
全集 $\Omega$，性质集合 $A_1,\ldots,A_m$，$q(x)=|\{i:x\in A_i\}|$，
\[
N_t=|\{x\in\Omega:q(x)=t\}|,\qquad
S_j=\sum_{|J|=j}\left|\bigcap_{i\in J}A_i\right|,\quad S_0=|\Omega|.
\]
\[
\boxed{S_j=\sum_{t=j}^m\binom tjN_t,\qquad
N_r=\sum_{j=r}^m(-1)^{j-r}\binom jrS_j\quad(0\le r\le m).}
\]
并集 $|\bigcup_iA_i|=\sum_{j=1}^m(-1)^{j-1}S_j$。

\subsection{至少数量与变换方向}
对 $1\le r\le m$：
\[
\boxed{|\{x:q(x)\ge r\}|=
\sum_{j=r}^m(-1)^{j-r}\binom{j-1}{r-1}S_j.}
\]
$r=0$ 返回 $S_0$，$r>m$ 返回 0。另一方向（下三角）的二项式反演：
\[
b_n=\sum_{k=0}^n\binom nk a_k
\quad\Longleftrightarrow\quad
 a_n=\sum_{k=0}^n(-1)^{n-k}\binom nk b_k.
\]
只含整数乘加减，对任意正模数成立。一般 $S_j$ 需枚举 $2^m$ 个子集；
仅当交集大小只依赖 $|J|$ 时才可写 $S_j=\binom mj\cdot$代表值。

\subsection{例：有标号球放入有标号盒}
$n$ 个互异球放入 $m$ 个互异盒，恰好 $r$ 个非空盒：
\[
\boxed{\binom mr\sum_{j=0}^r(-1)^j\binom rj(r-j)^n
=\binom mr\,r!\,\genfrac{\{}{\}}{0pt}{}{n}{r}.}
\]
以“盒为空”为性质时 $S_j=\binom mj(m-j)^n$，对应 $N_{m-r}$。
$r<0$、$r>m$ 或 $r>n$ 时为 0；$n=0$ 时仅 $r=0$ 为 1；$0^0=1$。

\subsection{直接使用现有组合数与模整数}
固定 $p=998244353$，要求 $m<p$；用第~\ref{compact-ModInt}~节（第~\pageref{compact-ModInt}~页）和
第~\ref{compact-Binomial}~节（第~\pageref{compact-Binomial}~页）：
\begin{lstlisting}
using Z = ModInt<998244353>;
Z answer = 0;
if (0 <= r && r <= m && r <= n)
{
    Binomial<998244353> c(m);
    for (int j = 0; j <= r; j++)
    {
        Z term = c.choose(r, j) * Z(r - j).pow(n);
        if (j & 1) answer -= term;
        else answer += term;
    }
    answer *= c.choose(m, r);
}
\end{lstlisting}
$n$ 须为非负 signed long long（\texttt{pow} 指数类型）。时间 $O(m+\log p+(r+1)\log(n+2))$、空间 $O(m)$。
素数限制来自 \texttt{Binomial} 的费马逆元；合数模或 $m\ge p$ 改用 Pascal、Lucas 或扩展 Lucas。
