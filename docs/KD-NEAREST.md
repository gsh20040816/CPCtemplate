# 静态 K-D Tree 最近与最远点

`KDNearest<D>` 保存固定维度整数点。`query(q,k)` 返回最近的 k 个输入编号，`query(q,k,true)` 返回最远的 k 个。编号从0开始，按距离优先、等距编号小者优先排列；第k个就是结果的back()。k必须在0..n内，k=0返回空。允许重合输入点，按不同编号分别保留；不会排除与查询重合的点或所谓“自身”。p保存输入顺序，p/a/root仅可读取，重新赋值即可重建。

为便于赛时抄写，维度是模板参数，只有一个查询入口；不增加距离策略、动态插入、删除或自定义编号。最近与最远共用一个堆和递归搜索。坐标为有符号32位int，减法之前转为128位，平方与求和也在128位执行，避免极值溢出或浮点把相差1的距离视为相等。固定维度使用KDNearest<2>等；演示中的KDNearest<10>通过其余维补0支持输入维度1..10，但有额外常数。

## 正确性要点

中位数建树只重排编号数组，节点编号就是原输入编号。比较键为(当前轴坐标,编号)，即使全部点重合也满足严格弱序。每个包围盒是本点和两棵子树包围盒的并，同时维护子树最小编号。

统一以(有符号距离,编号)作为键：最近点用正平方距离，最远点用负平方距离，较小键更优。大根堆始终保留已访问点中最优的k个。最近点包围盒下界是到各坐标区间的最短平方距离之和；最远点用各区间最远端的平方距离和取负。再配上子树最小编号，形成所有子树候选键的字典序下界。只有堆已满且下界不优于堆顶才剪枝，故不会丢失更优距离或更小编号的等距点。输出反转堆的弹出顺序。

建树平均O(Dn log(n+1))，存储O(Dn)。近邻查询对任意点集没有次线性最坏保证；最坏O(Dn+n log(k+1))，查询工作空间O(k+log(n+1))。高维、很大的k或不利分布可能大量访问节点。递归建树和查询的深度O(log(n+1))，没有改成显式DFS栈。

## 来源与题面边界

kuangbin《ACM template (2018)》3.8.1（印刷页108–111）提供HDU4347的多维k近邻源码；本实现覆盖其静态近邻模型。上游用int先相减再转double，且循环坐标比较在全部相等时返回true，这两个边界错误不沿用。HDU官网本轮不可访问，尚未确认原题完整约束、等距输出规则、时空限制或在线结果；本次不宣称完整HDU协议验证。3.8总节仍为partial，3.8.2 CF44G及3.8.3 HDU4742仍待分别处理。

WIDA固定commit cfdb12db6792eb2303798541fb5c760ed2bc618b的《08 - 数据结构.md》KD Tree代码，是动态二维插点和坐标逐维≤的点数查询。issue11附件4.7（印刷页126起）是动态二维点权累加与矩形求和。两者均不能因为标题相同而计入本静态近邻模板的覆盖；当前保留待单独核验，已有KDTreeSum可作为后续适配基础。

[Luogu P2093题面](https://www.luogu.com.cn/problem/P2093)给互异二维点，求第k远点，相同距离时较小输入编号算更远。n≤100000，m≤10000，k≤20且有效查询须k≤n，点和查询坐标绝对值≤10^9。题面包含随机分布条件；本轮未取得其时空限制。用法268是竞赛应用，不计正式模板题覆盖；用法267仅为多维API演示。两者无新增在线AC或速度榜记录。

## 本地验证

独立Python任意精度整数枚举全部点并排序，覆盖1/2/3/5/10维、空集、k=0/1/n、重合点、等距、小范围随机、单轴退化、有符号32位极值，以及平方距离接近2^64且只相差1的舍入反例。C++探针另行检查节点唯一性、中位数子树大小、包围盒、子树最小编号、输入次序、复制、清空和重复查询。

普通与ASan/UBSan各测试header/copied × assert/NDEBUG四种核心形式，每种156份输入。把距离改为double、破坏编号键的两个错误变体均被正确答案拒绝。新增API和P2093完整用法各测试driver/expanded/minimal-copy三种形式，分别156/35份输入。P2093另测10万互异共线点、1万次查询、k至20；对共线点，最远k点必在两端各k点中，参考答案独立只枚举两端再排序。该压力样例不代表原题随机分布，也不证明最坏性能。
