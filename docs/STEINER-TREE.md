# 最小斯坦纳树（本地验证通过，已通过P6192）

`SteinerTree(n)`，点号 0..n-1。`add(u,v,w)` 添加无向边并返回从 0 开始的原边编号；支持自环、重边和零权。要求 n≥1、w≥0，所有添加边的权值总和严格小于 `LLONG_MAX/4`。不能直接修改公开的图数据来绕过这些约定。

`solve(terminals)` 不修改图，可重复调用；自动去重关键点。返回 `{cost, edges}`，其中 edges 为不重复、升序的原边编号。空关键点返回 0 和空方案；关键点无法连通时返回 -1 和空方案。可行方案是连接全部关键点的最优子图，不额外保证对零权环作树化。递归恢复方案，不模拟 DFS 栈。

k 为去重后的关键点数。位掩码允许 k≤20，但时间 O(3^k n + 2^k(m+n)log n)、空间 O(2^k n+n+m)，实际适合 k 较小的题目；不要把 20 当作任意 n 下可行的性能保证。正式模板题 [洛谷 P6192](https://www.luogu.com.cn/problem/P6192) 为 n≤100、m≤500、k≤10、正权，允许重边自环。模板扩展的空关键点、断连与零权语义由本地测试检查。

## 递推与正确性

`dp[mask][v]` 表示连接 mask 中全部关键点以及 v 的最小权值。单关键点在该点的初值为 0。先枚举 mask 的两个非空互补子集，在同一根 v 处合并；再用所有有限 dp 值作多源 Dijkstra，沿图边扩展根。所有真子集均比 mask 小，已经完成最短路闭包。

对任一最优连通子图，非负权允许删环得到不更差的树。以 v 为根，若根只接一条有效分支，则沿该路径归入最短路扩展；遇到分叉或另一个关键点时，将关键点分到两个非空部分，在该根合并。因此递推能表示一棵最优树。反过来，每次合并、沿边扩展都表示一个连接相应关键点及根的子图（重复边先按重数计费），其实际边集费用不超过记录值，故递推不能低于最优解。二者相等。

## 方案与数值边界

合并记下子集，最短路严格改善时记下最后一条边并清除合并标记。回溯合并会严格缩小 mask；同 mask 的前驱来自 Dijkstra 中已弹出的节点，即使有零权边，也不会形成前驱环。`seen[mask][v]` 合并重复回溯，最后按原边编号去重。

恢复的边并集一定连通全部关键点，且费用不超过 dp 最优值；若严格小于该值就与最优性矛盾。因此实际边权和等于返回的 cost。使用 long long，总边权界保证所有可行最优值小于 inf，两个 dp 值之和及距离加单边权均不会溢出。输入条件也适用于关闭 assert 的版本。
