# 稠密图 Dijkstra 与三份来源核对

## 新增矩阵版

`DenseDijkstra(n)` 与已有堆版分别保留，避免以堆版覆盖 kuangbin 4.1.1 的 O(n²) 稠密图合同。图使用1-based点号，`add(u,v,w)`为有向非负signed64边；重边取最小值，自环和零权均允许。无向边分别添加两个方向。

矩阵 `cost` 用−1标记缺边，`LLONG_MAX`是合法边权；不保存原边编号。`run(s)`每次重置距离和父点。`dis`为int128，`inf=2^126`表示不可达；`path(t)`返回正向顶点列表，源点自身为`{s}`，不可达为空。`pre`为父点，根和不可达点为−1。成员只读；`add`使旧结果失效，重新`run`后再查询。支持换源、重复调用和独立对象复制。

构造和存储 O(n²)，加边 O(1)，求解 O(n²)，路径输出 O(路径长)。矩阵约8(n+1)²字节，另有O(n)距离及辅助数组；n须按实际内存选择，稀疏图仍优先堆实现。每个有限最短距离可由至多n−1条边达到，n<INT_MAX时小于2^94，int128足够；不能无条件转回long long。

每步选距离最小的未定点；非负权保证此距离已最优。只向未定点松弛，且只接受严格改善，因此父点总是更早确定的点，零权环也不能造成父点环。所有剩余点距离为inf时立即终止，不让不可达哨兵参与运算。

## 上游源体与明确差异

本次视觉核对 kuangbin 2018 正文130–131页（PDF物理132–133页），读取 WIDA 固定提交 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的打印稿图论节。测试用源体保存在 `tests/fixtures/dijkstra_sources/`，仅作参考，不是重新发布传统数组模板。

- kuangbin 4.1.1：0-based邻接矩阵扫描、前驱数组；固定MAXN=1010，int费用和0x3f3f3f3f哨兵。新矩阵版保留O(n²)算法及顶点方案能力，改为vector、1-based、缺边独立标记和int128距离。原代码的有限距离必须低于哨兵，且中间加法不能溢出，不能直接当成完整signed64实现。
- kuangbin 4.1.2：1-based、固定数组存邻接vector，int权及相同哨兵，vis跳过已定点。每次求解清空vis/dist，重新构图须由调用方清邻接。映射到已有 `Dijkstra` 的动态邻接、懒删除堆；已有模板用long long保存距离，要求**所有有限最短距离严格小于LLONG_MAX**，并通过加法前比较避免溢出。此合同未改成矩阵版的int128合同。
- WIDA 打印稿“（正权稀疏图）动态数组存图+Djikstra算法”：距离数组在闭包外，vis在闭包内。测试将该片段的int以64位展开，明确提供其1E18初始化所需的宽整数上下文；不声称普通32位int直接接收1E18安全。每个源点的正常对比重新构造闭包，数值处于双方共同范围。

WIDA闭包复用反例已经实际编译运行：仅有1→2、权1，先调用源1，再不重置dis直接调用源2，原片段留下`dis[1]=0`，而正确结果是不可达。这说明换源前必须重新初始化距离；并非原片段承诺了多源重跑接口却通过了测试。当前两种结构体均在run里重建距离，随机与逐源测试覆盖这一要求。

kuangbin文本提取仅去行号、页眉，并把数学减号转成ASCII减号；一行自动折行的说明注释未保留，执行语句和常量不改。两个源体分别包进测试命名空间，矩阵源体输入由1-based转换为0-based；WIDA仅加测试函数/邻接准备和上述64位int上下文。所有源文件及原PDF/Markdown均有SHA256记录。

## 堆复杂度说明修正

没有改已有堆模板代码。只将其手册复杂度明确为多重边图下 `O(n+m log(m+1))`，空间 `O(n+m)`；简单图常写 `O((n+m)log(n+1))`。懒删除堆最多保留O(m)个候选，平行边任意多时不能无条件用log n代替log m。专项还覆盖两点间十万条递减权平行边。

## 完整用法

`example-312` 为 [AOJ ALDS1_12_B](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=ALDS1_12_B&lang=en) 正式算法练习：输入邻接表格式的0-based点号，转成矩阵；求0到各点距离，输出原点号和距离。题面n≤100、m≤10000、非负权≤100000，保证所有点从0可达，因此该驱动可将距离转回long long。

`example-313` 是完整接口演示：有向非负signed64边，指定源点，逐点输出INF或int128距离和正向顶点列表。支持重边、零权环与不可达点；不是在线题，也不计正式模板题。两份用法打印依赖和实际页码，不重复模板内容。

## 本地证据与限制

普通和ASan/UBSan各运行12种程序形式、7个错误变体。核心每种34710次运行、2070238项检查：1..3点无自环有向图全部四态边（缺边/0/1/2）、4点前向边全部四态配置，各自遍历全部源点；300组随机增量多重图覆盖自环、重边、重复换源、结果失效和复制。同步Bellman–Ford为独立距离参照，逐边核验当前矩阵、现有堆及kuangbin矩阵前驱输出的路径，检查无重复点、方向和精确权和。三份上游源体的距离也与该独立参照比较，未用Dijkstra互相对拍作为唯一依据。

宽整数边界包括LLONG_MAX边、两条最大权相加、不可达点与零权环；2000点矩阵链验证超过64位的端点距离和完整顶点路径。旧堆版另检验LLONG_MAX以下的有限距离、超过可表示范围的非最优候选、换源及加边重跑，保持其原合同。

312在实际驱动、展开、仅复制模板和NDEBUG四种形式中各验证103个输入（包括100点10000边）；313每种104个输入（包括2000点矩阵和原点路径证书）。错误变体包括用最后重边覆盖最小边、把零权当缺边、忽略源点、反向路径、遗漏父点，以及忽略输入邻接行的点号、接口固定源1。

这些是本地证据，不构成在线AC、在线排名或线上资源通过。其他最短路子算法、负权图能力与父节覆盖没有凭这三项映射自动关闭；总目标仍继续。
