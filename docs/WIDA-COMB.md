# WIDA 08A 小范围组合数

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `a4516bc3dc14a2b13b381606f30dc6c778dff976`，路径 `03 - jiangly模板收集/03 - 数论、几何与多项式/08A - 组合数（小范围预处理，逆元+杨辉三角）.cpp`。

模数 `P = 1000000007`，阶乘和逆阶乘预处理到 `L = 10000`。`binom(n, m)` 在 `n < m` 或 `m < 0` 时返回 0，否则是 `n! / (m! (n-m)!)` 模 `P`。调用公式时 `n` 必须在 0 到 10000 之间，否则会读出数组。

`sumbinom[n][j]` 满足 `S(n, j) = S(n-1, j) + S(n-1, (j-1) mod 7)`，`S(0, 0) = 1`。这是 `C(n, k)` 里所有 `k ≡ j (mod 7)` 的和，再模 `P`。`n <= 40` 的整张表与这个和一致。更大的 `n` 只核对了递推本身和若干 `binom`，没有逐项再求和。
