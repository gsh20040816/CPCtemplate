# WIDA 在线模板：样例构造

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `33b3a24292968479385753f2ff6b1d820484ac44`，路径 `01 - 常用在线模板汇总/01 - 初始与杂类/08 - 样例构造（随机数、树、图生成）.cpp`。它使用 `mt19937`、`vector` 和 `cout`，但没有头文件，单独编译失败。

`r(a, b)` 用 `rnd() % (b - a + 1) + a`。`r(3, 3)` 是 3，`r(0, 0)` 是 0。种子来自 `steady_clock`，输出不能跨运行固定。取模对不是 2 的幂的区间有偏差，这轮没有把分布写成均匀。

`graph` 先在 `0..n-1` 上连一棵树，再平移成 `1..n`。1、2、6 个点的结果都有 `n-1` 条边，没有自环和重边，并且连通。`m` 表示总边数。4 个点、6 条边得到完全图。3 个点最多 3 条边，再要第 4 条时循环不会停。`random_shuffle` 在 C++17 标准里已删除，但这份 libstdc++ 在 C++20 下仍提供它，并警告改用 `shuffle`。

`python3 tests/wida_gen.py` 在普通 `-O2` 和 ASan/UBSan 下通过这些结构检查。没有新的在线 AC，也没有新增模板。来源保持 partial。
