## 对应范围

原稿由单段 Simpson、带粗估计参数的递归 asr、自动计算初值的 asr 三个函数构成，被积函数 F 由调用者提供。计算两半估计L、R，以 `abs(L+R-A) <= 15*eps` 停止，返回 `L+R+(L+R-A)/15`；否则把区间及绝对容差各分为两半递归。

本库 `AdaptiveSimpson` 及既有用法235覆盖这个可调用积分模型。保留二分估计和修正，使用long double并缓存样本；改为以error、met显式报告估计状态，增加深度和求值上限、停滞及非有限检查。原稿没有这些停止保护，也没有独立完整题目协议。核心接口与错误处理合同见 [实现说明](ADAPTIVE-SIMPSON.md)。本次不新增重复组件，也不继承来源提交成绩。

## 独立数值核验

`tests/simpson_source.py` 在普通和ASan/UBSan两种模式下，分别编译原稿与当前头文件组成的探针，并各跑assert/NDEBUG两种形式。每种形式140组：120个0..5次整数系数多项式（端点为四分之一整数）、18个atan/exp/cos原函数参考案例、一个四次修正案例及一个漏采样反例。包含反向、零长区间和连续多组调用。

多项式参考由Python Fraction精确积分；三种超越函数用Python math原函数差提供浮点参考。数值测试使用显式容差，不把它视为严格误差证明。四次函数x⁴在[0,1]、eps=0.001时，根层修正结果应为1/5，单独采用1e-14比较阈值；把原稿修正项的加号改成减号，会以答案差异被拒绝。普通与ASan/UBSan结果一致，常规案例最大绝对误差约4.55e-13。

原稿根层接受时调用F九次（含重复点），缓存实现调用五次。零长区间原稿仍调用九次，缓存接口不调用F。这里的计数直接来自函数调用探针，不推断整题运行时间或排行榜。LSan关闭。

## 误差估计不能充当严格保证

取 `[x(x-1/4)(x-1/2)(x-3/4)(x-1)]²`。Fraction展开积分得到准确值 `5/1419264`，大于测试eps=1e-12；原稿及现有实现的五个不同样本都为0，立即返回0。现有接口还返回error=0、met=true。

该测试必须保持这一结果：met只说明采样估计条件满足，不能宣称任意光滑函数的实际误差≤eps。增加资源上限也不能消除固定采样点漏掉函数形状的问题。来源原稿没有严格误差界或万能终止保证；实际使用仍要分析函数并拆分困难区间。
