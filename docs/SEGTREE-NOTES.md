# 通用线段树的组合与搜索约定

`op` 满足结合律，`e` 为双侧单位元；不要求交换律。半开区间查询维护左累积 `a` 和右累积 `b`：左段从右侧追加，右段从左侧追加，最后合并 `op(a,b)`。这保证字符串拼接、矩阵乘积和函数复合的顺序。

`max_right(l,ok)` 从左到右合并覆盖节点，第一次失败时下降定位。累积值始终等于已接受前缀；左子树可接受才跳到右子树。`min_left` 镜像扫描，但合并次序必须是 `op(新段,已有后缀)`。树上的扫描与下降各为 O(log n)，前提是值复制、运算和谓词为 O(1)。

谓词必须无副作用，且从空区间开始为真，沿指定方向扩展时只能由真变假。若条件不单调，接口不保证找到全局最远边界。测试使用“不出现 ab”的字符串谓词，对两个方向做独立扫描；它不交换，能发现只用区间和对拍难以发现的方向错误。

函数复合模板题将 `op(f,g)` 定义成先 f 后 g。若 f(x)=ax+b、g(x)=cx+d，则返回 (ac,bc+d)。驱动测试通过直接逐函数代入求答案，不调用参考线段树。题目只覆盖构造、set、prod；边界搜索仍需自己的线上题，不能套用该驱动的 AC。

当前本地测试覆盖空树、全部小区间、点更新、两个方向搜索及 50 万叶子，普通与 ASan/UBSan 通过。Predecessor Problem 已在线通过 402089，22 点，383 ms、184.02 MiB；覆盖构造、set/get 和两个边界搜索。函数复合驱动 402090 也已 AC，16 点、247 ms、26.82 MiB，覆盖构造/set/prod。all 和空区间仍以本地测试为证据。接口及分段代码已加入总册和数据结构册。
