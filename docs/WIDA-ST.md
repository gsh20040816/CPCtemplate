# WIDA 在线模板：ST 表

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `06a677a1266cfbf065cf103431af670b25091e7c`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/30 - ST 表.cpp`。它使用 `vector` 和 `__lg`，但没有头文件，单独编译失败。下标从 1 开始。

`init` 把 `in1` 放进最大值表，把 `in2` 放进最小值表。两者不必是同一份数据。对长度 8 的表，任意左右端点，包括写反的端点，区间最大和最小都与逐个扫描一致。只有一个元素时，`getMax` 和 `getMin` 分别是 7 和 -4。

`k` 用 `__lg(n)` 计算。`n` 为 0 时这不是合法参数，这轮没有构造。表在构造后不会跟着 `in1` 或 `in2` 自动更新，调用方要先填好再 `init`。

`python3 tests/wida_st.py` 在普通 `-O2` 和 ASan/UBSan 下通过这些区间。没有新的在线 AC，也没有新增模板。来源保持 partial。
