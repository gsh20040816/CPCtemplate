# 三角形内切圆

接口 `triangle_incircle(a,b,c)` 依赖RealPlane，返回optional<Circle>。顺逆时针均可；三点全重合或计算得到的有向面积恰为0返回nullopt。不修改输入。浮点零判定不是任意实数的精确共线判定。

## 公式与数值边界

令a,b,c的对边长分别为x,y,z，周长为s。内心的重心坐标为x:y:z，故o=(xa+yb+zc)/s。三条边到内心的距离相同，三块三角形面积相加得到半径r=2A/s。

实现相对a计算u=b-a、v=c-a；边向量按最大绝对分量归一化，求边长后计算o=a+scale·(u·y/s+v·z/s)。有向叉积在归一化之前计算，因此AOJ范围内整点的面积与零判定不会因归一化先引入舍入。实际半径为abs(cross(b-a,c-a))/scale/s，其中s是归一化后的周长。不是用可能消去的海伦公式求面积，也不需要求三角函数或两条角平分线的交点。

要求输入、差向量、原始叉积及输出等中间运算有限可表示，且没有影响结果的下溢。O(1)时间和空间。任意实数近共线时叉积仍可能因舍入失真；极大平移可能使结果小偏移不可表示。不能把缩放当作所有数量级都安全的保证，也不能假定long double精度总高于double。本机long double有效位为53位。

[AOJ CGL_7_B官方题面](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=CGL_7_B&lang=en)规定三个非共线整点、坐标绝对值不超过10000，输出内心及半径，误差小于1e-6。差坐标不超过20000，叉积不超过8e8，可被53位浮点精确表示；边长、加权结果和半径仍会舍入。驱动输出12位小数。题面抓取中的时间/内存栏为空，未猜测资源上限。
