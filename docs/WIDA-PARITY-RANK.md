# WIDA 08A 与 08D：持久化奇偶计数、重数分裂

本批为 323 个组件、438 份完整用法。WIDA 固定来源树为 cfdb12db6792eb2303798541fb5c760ed2bc618b；原稿精确字节与 GPL 来源分别保存在 tests/fixtures/wida_parity_index 和 tests/fixtures/wida_rank_split。

## 08A：完整计数接口改写

新增 PersistentParityIndex(n)，保留原始整数位置 [0,n)，支持在任何历史版本上把某个位置的重数加上带符号 delta。结果重数非负，整个版本总重数不超过 LLONG_MAX；delta=0 也产生新版本号，但不分配节点。原始整数奇偶不能替换为离散化编号奇偶。

- difference(before,after)：总重数和奇数位置重数的差，允许有符号结果。
- stop(before,after,k)：从大到小尝试删除至多 k 个偶数元素，遇到奇数即停，返回剩余最大位置，全部删完返回 -1。只查询，不改版本。
- odd_kth(before,after,k)：在奇数位置元素中取降序 0-based 第 k 项，返回 {位置,该位置总重数,该位置内偏移}；不足则 {-1,0,k-奇数总重数}。

后两项要求逐位置版本差非负。有删除操作时，祖先版本与后代版本也不自动满足；不使用仅检查总数的方法冒充逐位置检查。空结果改为 -1，因为 0 是合法位置。要复现原稿 query1/query2 的哨兵，只需在结果位置上取 max(0,位置)，其余计数和剩余排名完全相同。

正确性：子树 count 和 odd 分别保持总重数与奇数重数。stop 在右子树存在奇数或右侧重数超过剩余删除次数时必须进入右子树，否则整段右子树都是可删偶数且可一次扣除；odd_kth 按右侧奇数重数决定排名所在分支。每次只递归一个分支，查询 O(log(n+1))，没有节点分配。更新沿一条根到叶路径复制，保持所有旧版本；带符号增量在叶子检查非负，上层从两个孩子重新求和。

每种构建 300000 次原稿、新组件、字面删除过程和独立奇数序列对照，覆盖任意历史分叉、删除、零增量、合法非祖先版本差、位置0与空集合；递归检查所有节点计数及历史版本。另测 n=INT_MAX、重数与k达到LLONG_MAX的边界。普通及ASan/UBSan通过。完整用法437另有60组完整API协议对照，两种构建均通过。

## 08D：按重数升序与降序分裂

扩展既有 MergeSplitTree：split_rank(s,k,reverse=false) 从集合 s 移走最小 k 个元素，放入新的集合并返回编号；reverse=true 改为最大 k 个。k=0 也创建空集合；k=总重数时全部转移。重复值可以分到两边，旧集合保留其余重数；不共享节点。

递归按左、右子树的重数分配取走量。整棵取走或取零时直接转移根，只有排名边界上的一个分支会进一步部分分裂。部分叶子的重数分成 k 与原重数-k，正反方向均合法。因此单次 O(log(n+1))，最多新增 O(log(n+1)) 节点；原有合并回收与集合号复用规则保持不变。

每种构建 920352 次森林证书对照未修改的08D原稿、独立重数数组与新接口，检查所有活节点无共享、回收池无重号、总节点均可达或已回收。覆盖任意拼合、升降序、重复值、空集合及极端重数；另测 n=INT_MAX 和总重数LLONG_MAX。普通及ASan/UBSan通过。完整用法438另有60组API协议对照，两种构建均通过；既有P5494、UVA1479用法同步回归。

## 不扩大解释 cntnew

08D叶子部分分裂时，原稿保留第一块的整个cntnew，新块cntnew为0。单独探针：同位置两个isnew=1元素合并后按1个分裂，第一块cnt=1、cntnew=2，第二块cnt=1、cntnew=0。这证明不能直接假设它是“任意重复元素逐个标记的计数”，不证明原题有错。它可能依赖完整主程序中的特殊不变量；Info中的psum/rev也必须连同主程序审计。

因此当前只覆盖cntnew=0域的多重集合计数、升降序分裂和合并，08D来源保持partial。没有删除或改写原稿来让测试变绿，也没有把专用元数据默默丢掉后声称全覆盖。

证据：verification/persistent-parity-index.json、verification/rank-split.json、verification/parity-rank-protocols.json 与准确纸面用法记录。当前两项新增接口没有线上OJ判定。
