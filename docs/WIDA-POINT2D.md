这轮只核对了 `Point`、`Line`、点积、叉积、长度、点到直线和线段的距离、旋转、`sgn`、平行、点在线段上，以及 `lineIntersection`。文件后半的多边形和半平面没有逐项验证，不能记成已完成。

`(3,4)` 与 `(1,0)` 的点积是 3，叉积是 -4，平方长度是 25。旋转 90 度得到 `(-4,3)`。`sgn` 在上半平面和正 x 轴返回 1，负 x 轴和原点返回 -1。水平线段 `(0,0)-(4,0)` 与竖线 `x=1` 的真实交点是 `(1,0)`，但公式使用整数除法，`2/8` 变成 0，结果是 `(0,0)`。点 `(5,1)` 落在线段外侧，距离是到端点 `(4,0)` 的 √2。
