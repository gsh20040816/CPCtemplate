# 子串、反串与拼接双哈希

参考 [OI Wiki 字符串哈希](https://oi-wiki.org/string/hash/)，正式题面为 [P3370](https://www.luogu.com.cn/problem/P3370)。这是概率判等工具，不提供零碰撞保证。

## 接口与算术

`StringHash(s,base)` 预处理两个素数模数 1000000007、1000000009 的多项式前缀。base 是两个分量的底数，分别位于 [257,mod-2]；需要比较的所有字符串必须使用同一组底数。字节先转 unsigned char 再加1，支持零字节和128..255，不把 UTF-8 字节下标当字符下标。s.size() 必须小于 INT_MAX，且内存足够。

`get(l,r)` 返回0-based半开区间 [l,r)；`get(l,r,true)` 返回这个区间反转后的哈希，参数仍是原串坐标。允许 l=r，返回 {0,0}。比较前必须检查长度相等，哈希值不携带长度。

`join(a,b,len_b)` 返回 a 对应串后接 b 的哈希。a、b 必须是同一组底数、相同两个模数下的规范余数，len_b 必须是 b 对应串的实际长度，且 0<=len_b<=当前对象的n。拼接后的总长可以超过n；该操作只需要 b 的幂，但不能借此从原对象查询越界区间。构造 O(n)，get/join O(1)，三组双 int 数组约24(n+1)字节。成员仅供读取，不应修改。

令 H(s)=sum(code(s[i])*base^(len-1-i))。子串消去前缀得 pre[r]-pre[l]*base^(r-l)；反串坐标为[n-r,n-l)。拼接为H(a)*base^len_b+H(b)。所有乘积和加项低于约1.01e18，小于 signed64 上界；取子串时先对乘积取模，减法范围在(-mod,mod)，加mod后规范化。

## 随机性与反例

两个**固定、与底数选择无关、同长且不同**的字节串，其哈希差是素数域上的非零多项式，次数至多L-1。若两个底数分别从各自允许区间独立均匀抽样，单次同时碰撞概率不超过两项 min(1,(L-1)/(mod[j]-258)) 的乘积。对固定的Q对比较可用联合界，最坏上界为Q乘单对界并截断到1；并非简单保证1/(mod[0]*mod[1])，也不能把相关比较当独立事件相乘。L=0没有两个不同空串。

正式驱动只随机初始化一次，然后所有对象共享底数。mt19937配合random_device是实用抽样方式，不是密码学随机性承诺；种子可预测、随机源质量差、对手在看到底数后构造输入或自适应比较时，以上固定输入的理想抽样界不能直接套用。固定底数下更没有随机成功率保证。

显式反例：两分量底数都取各自mod-2，相当于-2。两个字节串[0,2]和[1,4]都得到{1,1}，长度也相同。这是合法底数上的真实双哈希碰撞，测试中保留该例，防止“对拍通过所以没有碰撞”的错误结论。

需要确定性判等时，可在哈希相等后直接比较原串；大量静态子串比较可用已有SuffixArray和SuffixLCP，多串拼接须编码独立分隔符并限定查询长度。回文检测可选Manacher，模式匹配可选KMP/Z。选择取决于操作模型。

## 完整用法和验证范围

P3370输入最多10000个非空数字/大小写字母串，最大长度1500，输出不同字符串数；用长度与双哈希作为set键，仍允许概率性误判。此驱动验证全串去重，不覆盖反串和拼接。API用法首行是字符串（可空），随后两个合法底数、询问数，每次给l r a b，依次输出[l,r)正向、反向以及[l,r)+[a,b)的两分量；API指定底数便于重现实验，不作为推荐的固定底数。

本地测试以逐字节独立幂求和为真值，核对全部短串区间、反向坐标、空区间、跨对象及重复拼接、全部256种字节和边界底数；包含上述真实碰撞。完整驱动需分别验证头文件、NDEBUG、展开、最小抄写及sanitizer。线上记录和耗时另行登记，未有记录前不声称AC。

本批四种完整驱动形式及ASan/UBSan均通过，4个错误变体检出。P3370实际提交 [302216358](https://www.luogu.com.cn/record/302216358) 为100分/11AC，C++20 O2，最慢单点464ms，逐点合计1896ms，页面总计舍入显示1.90s。只验证全串去重；不把AC解释为碰撞概率为零。上传字节与本地最小抄写版本一致，未声称下载了服务器源码。
