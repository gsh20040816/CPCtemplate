# 浮点圆交点的显式无容差模式

本批为既有 `line_circle_intersections`、`circle_intersections` 自由函数新增 `eps=0` 分支，并新增完整浮点用法229/230。没有新算法计数，也没有用整数版调用替代浮点 API。`eps>0` 的计算代码原样保留，默认仍为 `1e-12L`；旧默认近切反例继续成立。`RealGeometry` 兼容构造仍要求正 eps。

## 选择接口

- 一般浮点输入、允许近切归并：沿用正 eps 的近似分类，但自行核对任务需要的坐标误差
- 下述 AOJ 有界整数输入，long double 满足平台条件：可直接调用浮点 API，显式传0
- 更大整数输入：考虑既有整数分类接口，遵守其自身界限；不把其证据归到浮点函数
- 任意实数的精确分类：本次没有解决。零容差只是不主动归并，无法消除舍入、上溢、下溢或病态性

## 公式与独立的数值界

直线设 v=b−a、q=v·v、c=v×(a−o)，Δ=r²q−c²。q=0返回退化；Δ<0/＝0/>0分别无交点/相切/两点。垂足 h=o+perp(v)c/q，偏移 w=v√Δ/q。

两圆设 v=b.o−a.o、q=v·v、k=q+r²−s²，Δ=4r²q−k²。同心先单独处理，其他情况 h=a.o+vk/(2q)，w=perp(v)√Δ/(2q)。这避免先将距离开方舍入，再相减求很小的半弦长。

AOJ [CGL_7_D](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=CGL_7_D&lang=en)、[CGL_7_E](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=CGL_7_E&lang=en) 给整数坐标，绝对值≤B=10000，整数半径1..B，保证交点；D每组1..1000条非退化直线，E圆心不同。坐标绝对误差要求小于1e−6。

q≤8B²、|c|≤8B²、|k|≤9B²，逐步乘加的整数绝对值小于81B⁴=8.1e17<2^60。二进制 long double 的有效尾数至少64位时，这些整数和判别式计算精确。要求正常最近舍入、正常有效精度、无 fast-math 或单独开启的危险重结合优化；驱动静态检查 radix/digits，拒绝 __FAST_MATH__，运行时拒绝非最近舍入。宏检查不能识别所有单独启用的危险编译选项，仍须遵守合同。

设u=2^−64，有交点时 h−圆心和w的每个分量都≤B。正确舍入的除法和乘法使垂足偏移误差小于3uB，加圆心后小于5uB；sqrtl误差至多一ulp时，偏移w误差小于5uB；最后相加的误差小于4uB。保守合计20uB<1.1e−14；固定12位小数再增加≤5e−13。此为带前提的误差分析，不是从有限测试最大误差推断全域保证。参见 [glibc数学函数精度说明](https://sourceware.org/glibc/manual/latest/html_node/Errors-in-Math-Functions.html)、[GCC优化选项](https://gcc.gnu.org/onlinedocs/gcc/Optimize-Options.html)。

排序也不需要epsilon：两个不同交点的非零x差在D中至少2/q，在E中至少1/q≥1.25e−9，比构造误差大。相等x来自对应方向整数分量为0，计算x也相等；直接按(x,y)字典序，相切重复同一点。

## 为什么不支持53位尾数的同一保证

合法输入 o=(0,−5710)、r=9805、A=(9797,−5314)、B=(9178,10000)：
q=234901757，c=−150276382，r²q=22582990987009925，c²=22582990987009924，所以Δ=1。
直接二进制53位运算可能把Δ算成0，实际两点的y间隔约0.000130386423632。测试保留此负控；它不是对其他机器ABI的运行认证。

## 验证设计与证据边界

`tests/circle_zero_mode.py` 直接测试实际浮点 API 的完整头和最小标准头上下文，以100位 Decimal 独立参考比较坐标：直线参考解参数二次方程，两圆先用距离平方分类，再解根轴的坐标消元方程。包含小网格穷举、固定种子随机、近切判别式1、反向直线、交换圆、反射、退化线、点圆、同心、最大坐标和小q大半径等。

核心测试的半径允许0，包含AOJ之外的点圆/无交点/退化扩展；完整用法只选题面允许的正半径、有交点、非退化输入，并测试D的1000查询。每个新增用法分别执行直接驱动、登记展开、实际复制组件三个程序形式。比较器有错序、错数量、错分类、缺相切重复、NaN/Inf和大误差负控。平台编译/舍入拒绝与普通、ASan/UBSan结果单独记录。
