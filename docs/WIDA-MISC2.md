# WIDA 杂类：int128、重载和快读

三份原稿都在 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 `03 - jiangly模板收集/01 - 杂类`。来源保持 partial，不新增模板，也没有打开注释里的提交页面。

## int128

blob `91a016e76a923cedf9f15636d39064f06c0a27ce`。

输出只在 `n > 0` 时取位。0 输出 `0`，负数输出空串。`toi128` 不识别符号：`"-12"` 得到 -288，空串得到 0。开方的上界是 double 常量 `1E16`，它正好等于 10^16；因此 `(10^16+1)^2` 的结果仍是 10^16，负数开方返回 0。`gcd(-15, 10)` 返回 -5，不是绝对值。

## 重载

blob `0b91ba07bf4066c04479a158f5507d7939b2ed66`。片段使用 `assert`，自身没有包含 `<cassert>`。

`ceilDiv`、`floorDiv` 在除数为正时，对测过的 -6、-5、5 除以 3 符合向上或向下取整。除数为 -3 时，`-5` 的向上取整得到 1、向下取整得到 0，都不是实数除法的取整。`ceilDiv(LLONG_MAX, 2)` 在 UBSan 下报 `9223372036854775807 + 2` 溢出。

`sqrt` 先调用 `std::sqrt`，再用相邻整数修正。2^53 附近的完全平方边界在普通和 ASan/UBSan 下都得到正确下取整。`sqrt(LLONG_MAX)` 会计算 `3037000500 * 3037000500`，有符号溢出。

`get` 想找满足三角数不少于 n 的最小正下标。`get(0)` 会把下标一直减小；UBSan 在 `-3037000500 * -3037000501` 中止。不开消毒器的 `-O2` 返回 `-3037000500`，这只是溢出后的观察值，不是定义好的答案。`logi(1, 2)` 的底数幂始终是 1，两秒内没有返回。

## 快读

blob `8f665a510e27028bcd803f274c9cc741f2a0eee6`。文件自身没有包含 `<cstdio>` 或 `<cstdint>`，只有调用者先包含后才能编译。

四个 `operator>>` 里只有 `uint32_t` 有函数体，`int64_t` 版本无法链接。`uint32` 读取会跳过非数字；输入 `0012 34` 和 `4294967296` 得到 `12 34 0`，超出 32 位后回绕。没有数字时，指针越过结尾的 0，ASan 报全局缓冲区溢出。

两个数组各 `1<<25` 字节且相邻。输入正好填满时，`a[fread(...)] = 0` 写到输出数组的首字节，不是 ASan 能看见的对象外地址。整数输出进缓冲区，C 字符串输出却直接 `fwrite` 到标准输出。

## 证据

`python3 tests/wida_misc2.py`：int128、重载和 `uint32` 快读在普通 `-O2` 与 ASan/UBSan 下通过；溢出、`get(0)`、`logi(1, 2)`、空输入和缺失的 `int64` 读取单独记录。见 verification/wida-misc2.json。没有在线 AC。
