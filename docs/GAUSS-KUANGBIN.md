本节包含两份应用程序：2.10.1 的 POJ1681 开关题和 2.10.2 的 POJ2947 Widget Factory。逐页核对固定 2018 PDF 的物理39–43页（印刷37–41页），完整恢复125行及101行；父节无其他实现。固定来源 SHA256 为 f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad。只去掉行号、页眉，接回折行，恢复可见空格和 Unicode 减号，并补标准头。

## 当前接口与适用范围

开关题使用 GaussXor，输入为方形棋盘，自身和四邻格一起翻转。消元得到特解与完整零空间基，再递归枚举自由变量，取按键数最小值。一个特解并不保证最少操作。所有合法方案恰为特解加零空间，枚举不会漏解。方形网格可由第一行按键决定其余行，零空间维数不超过边长；具体边界、复杂度和说明见 SWITCH-MINIMUM.md。书册 example-145 保留完整读入、建模和方案枚举。

Widget Factory 使用 GaussMod<7>。每条记录中同一编号可以多次出现，系数必须累加；起止星期包含首尾，右端为 finish-start+1 模7。7是素数，非零主元可逆，因此消元保留解集；矛盾行表示无解，否则秩小于变量数表示多解，满列秩表示唯一解。每个余数恰好对应3..9中的一个整数，余数0、1、2分别变为7、8、9。不能把该实现直接用于合数模数。当前返回分类、秩和特解；应用最多300个变量、300条记录，使用 O(mn min(m,n)) 时间、O(mn) 空间。书册 example-414 给出重复输入、多解和天数转换的完整入口，所需依赖为 ModInt、GaussMod。
