## 新增的实质内容

补上按行多线性展开的证明：每个非根点选一条出边，含环的项行列式为零，无环则所有路径到根，经同时重排行列得到对角全1的三角矩阵。由此统一解释内向树、反边后的外向树、无向转双向、重边、自环及单点空树。恒等式没有除法，因此可在整数、多项式或任意正模数下成立；素数限制来自所选消元接口。

这只证明同根主余子式，不引入任意非主余子式、森林定理或新的求逆接口。原文关于双版本及在线记录的叙述仍属于原批次；当前专项应用测试仅运行compact P6178，不能把旧记录当成新提交。
