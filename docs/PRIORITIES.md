# 编写顺序

按用户最新澄清：常用程度优先，难度至少以平衡树、Tarjan 这类赛时不易写稳的算法为参照。不扩充拓扑排序、Kruskal、ST 表等简单条目。完整来源覆盖目标保留，基础重复内容的处理方式需在覆盖审计中注明。

1. 常用且易错：平衡树（已有 Treap、Splay，先补 OJ）、Tarjan 强连通缩点、点双/边双分量及圆方树；完善线段树、树链剖分与可持久化相关模板。
2. 常见进阶：点分治、树上启发式合并、回文树、常见数论与组合算法、常用几何。
3. 最后继续带权带花树、复杂多项式、动态树特殊扩展及特殊赛题模板。

这是编写优先级判断，不是三年赛题精确频次统计。已经完成的高级模板保留，不继续优先堆积复杂算法。

已完成码风审计：Treap 序列输出、状态序列节点回收及建树后聚合已改为递归辅助函数；笛卡尔树构造的单调栈、Tarjan 分量栈与 LCT 的 splay 祖先下传栈属于算法本身，不混为 DFS 调用栈。

## 删减原则（issue #21）

总册按 600 页左右控制，不分核心/非核心册。新增或回填条目前先对照以下规则，详见 [ISSUE-21.md](ISSUE-21.md)：

1. 同一算法只保留有独立价值的一份实现；变体（换聚合、换标记、换查询方式）写成已有模板说明中的一两句，不另建文件。
2. 简单算法（扩展欧几里得、逆元、筛法、Kruskal、Floyd、SPFA 等）并入所属家族头文件，代码保留但压到 30 到 50 行，不加 `__int128`、valid 标志和大段 assert，不单独成章；ST 表、分数类这类现场直接手写的条目不收录。
3. 单题解法不作为模板收录；驱动与 AC 记录留在 verify/ 与 verification/。
4. 不添加只做转发的兼容层 struct 或头文件；测试需要的适配放在 tests/ 中。
5. 每个模板最多印一份模板题使用示例；应用题与接口演示只作为本地测试。
6. 知识节只印公式、适用条件和复杂度；推导、反例与验证范围放在 docs/knowledge-full 与 KNOWLEDGE-DETAILS.md。
