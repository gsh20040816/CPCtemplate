# 编写顺序

按用户最新澄清：常用程度优先，难度至少以平衡树、Tarjan 这类赛时不易写稳的算法为参照。不扩充拓扑排序、Kruskal、ST 表等简单条目。完整来源覆盖目标保留，基础重复内容的处理方式需在覆盖审计中注明。

1. 常用且易错：平衡树（已有 Treap、Splay，先补 OJ）、Tarjan 强连通缩点、点双/边双分量及圆方树；完善线段树、树链剖分与可持久化相关模板。
2. 常见进阶：点分治、树上启发式合并、回文树、常见数论与组合算法、常用几何。
3. 最后继续带权带花树、复杂多项式、动态树特殊扩展及特殊赛题模板。

这是编写优先级判断，不是三年赛题精确频次统计。已经完成的高级模板保留，不继续优先堆积复杂算法。
