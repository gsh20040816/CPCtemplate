# WIDA 打印稿：杂项

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `85b94a25b993c8938d736a43e4d022c2483cb2d0`，路径 `02 - 打印稿模板汇总/14 - 杂类.md`。

从 `1,2,3` 里选 2 个数，DFS 和 Gosper 状压都依次输出 3、4、5。阶为 2 的哈达玛矩阵把 0 看成 -1 后，不同行的点积是 0。三阶幻方用了 1 到 9 各一次，每行、每列的和是 15。

一维 LIS 用 `upper_bound`，所以 `1,2,2,3` 的非严格长度是 4。二维版本的片段没有声明 `n`。补上读入后，点 `(1,1)` 和 `(2,2)` 输出长度 2，方案是 `1 2`，末尾没有换行。

约瑟夫函数使用了没有定义的 `repeat`，原文不能编译。定义成从 1 到 `n` 的循环后，`n=5,k=2` 的两份公式都返回 2。基姆拉尔森公式对 2000 年 1 月 1 日返回 6。单调队列需要 `IOS` 和 `MAX`。数组 `1,3,2,4`、窗口 2 的最大值是 3、3、4。一行 `1 2 3` 读入后输出 100、200、300。

区间不同数依赖没有定义的 `BIT`。浮点比较依赖 `equal` 和 `ans`。德州扑克、数独、进制转换、装箱、高精度幂、欧拉降幂、int128、对拍、随机数、手工哈希、Python 和 OJ 测试这轮没有运行。

`python3 tests/wida_miscprint.py` 在普通 `-O2` 和 ASan/UBSan 下通过上面这些例子。没有新的在线 AC，也没有新增模板。来源保持 partial。
