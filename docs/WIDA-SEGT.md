# WIDA 在线模板：线段树

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `f855e1e84e2e499e7e891b7060ac7bef6f225308`，路径 `01 - 常用在线模板汇总/04 - 串与数据结构/26 - Segt.cpp`。它使用 `vector` 和 `min`，但没有头文件，单独编译失败。下标从 1 开始。`n` 为 0 时建树会递归停不下来，这轮没有构造。

`Segt_<long long>` 对 `1,2,3,4,5` 做区间加 `2..4` 加 10、再整段减 1。所有子区间的和与最小值都与普通数组一致。`Ask` 在跨过中点的区间 `2..4` 上合并出正确的和与最小值，但返回的左右端点是 0。完全落在一个结点里的询问会带回那个结点原来的端点。

`Min` 的初始值写成浮点字面量 `1E18`。在这台编译器上，它放进 `int` 变成 `2147483647`，UBSan 没有拒绝。全 0 数组上，对齐区间 `1..2` 和跨中点的 `2..3` 最小值仍是 0。`long long` 则得到 `1000000000000000000`。别名 `Segt` 用的是 `int`。

`python3 tests/wida_segt.py` 在普通 `-O2` 和 ASan/UBSan 下通过 `long long` 例子，并记录了这个 `int` 初值。没有新的在线 AC，也没有新增模板。来源保持 partial。
