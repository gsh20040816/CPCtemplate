# 静态仙人掌森林最短路

Issue #15；Cactus；用法382 / P5236。独立轻量结构体，不依赖通用圆方树或另抄整份LCA。

## 输入与使用

点号1..n，0≤n<INT_MAX/2。构造Cactus(n)，逐边add(u,v,w)，build()一次，随后distance(u,v)。仅对原点查询；同点0，断连-1。允许n=0并build但不能查询。复制独立，重复build从零重建；加边后须再次build。无边权修改、路径方案或用户指定根接口。

调用方保证无自环无重边、每条边至多属于一个简单环；允许断连及孤立点。输入结构不合法时不保证行为，不应拿本结构当仙人掌判定器。权非负，包括零权；所有边权之和≤LLONG_MAX/4。pref、len和dis至多为总边权和，查询加法、两倍根距离及差分均不会溢出long long。负权无向图的最短行走有负环，不适用。

虚点n+1..cnt对应环；t只有父到子的有向边，是内部森林；up、pos等成员仅供阅读，不支持外部修改。dfs/prepare仅内部调用。

## 构造与查询

递归DFS中，每条返祖边(u,v)与DFS树上u到祖先v的路径形成一个环。建立环虚点b，把v连到b（权0），沿par回走，把其他环点x连到b。记pos[x]=pref[x]-pref[v]，环长len[b]=pref[u]-pref[v]+w；b到x的权是min(pos[x],len[b]-pos[x])。这是x到环顶v的最短距离。

bel[x]标记x的父边已归某环；DFS返回时，只把未归环的父边作为桥加入森林。多个环可共割点：一个环的顶部不写bel或pos，不会覆盖该点在上方父环中的坐标。仙人掌每条边至多在一环中，所有沿par回走总长度O(m)，不是每个返祖边都独立支付O(n)。这段循环是枚举环路径，并非用显式栈模拟DFS。

第二次递归沿内部森林算根距离、深度与倍增祖先。查询提升两点到公共祖先的两个儿子：若LCA是原点，答案是原始两点dis和减2dis[LCA]；若是虚点b，当前u、v是同一环的两个入口，答案是原始dis和减dis[u]、dis[v]，再加min(|pos[u]-pos[v]|,len[b]-|pos[u]-pos[v]|)。直接套树距离会错误强迫路径经过环顶。

正确性来自块森林路径唯一，且非负权最短路可取简单路径，不会离开某块后再次进入同一块。每个桥必走；每个环只需选两入口之间较短弧，各块最优可独立拼接。

构造原图及环O(n+m)，倍增后预处理与总空间O((n+m)log(n+1))；查询O(log(n+1))。简单仙人掌m=O(n)，虚点少于n。两次DFS均递归，深度O(n)，赛时环境须有相应栈空间。

## 验证

- 定义式独立枚举所有简单环，按每条边参与环数判定输入；n≤6的全部简单无向图中筛出10025个仙人掌森林，再与Floyd所有点对比较。覆盖多环共点、断连、零权、任意DFS形状。
- 3000随机仙人掌，打乱点号、端点和边序，再删除随机边测试森林；重复build、值复制、build后继续加边再重建、64位安全大权。
- 两个官方样例、150个随机驱动；核心头文件/NDEBUG/最小抄写、用法头文件/NDEBUG/全展开/最小抄写均在O2及ASan/UBSan运行。去掉环距离修正、错误保留环内树边、仅取单向根距离三个错误变体都检出。
- Linux放开栈后，10万点链/整环/星形图、99999点三角形环链及40万次公式真值询问。属于超过题面规模的递归压力，不是OJ限时排名。

[P5236](https://www.luogu.com.cn/problem/P5236)为直接模板题：n,q≤10000，m≤20000，正权≤100000，无重边连通仙人掌，300ms / 125MB。两个官方样例输出分别为5、6及7、5、2。扩展的空图、断连、零权、复制和大权域依靠本地证据，不能从此题AC直接推导。

实际[AC302334786](https://www.luogu.com.cn/record/302334786)：C++20 O2，100分、20 AC，总计202ms，最慢单点12ms，峰值4.69MB。提交归档与当前最小抄写版逐字节一致；未核验通过记录速度排名或SOTA。实现与证明按上述仙人掌专用构造给出；一般图圆方树背景参考[OI Wiki 圆方树](https://oi-wiki.org/graph/block-forest/)，不将本结构声称为一般图最短路算法。
