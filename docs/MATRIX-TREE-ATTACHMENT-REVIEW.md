# 附件 3.7 Matrix-Tree 核对

来源：issue #11 附件实际第 85–89 页，SHA-256 见 `issue11-inventory.json`。本次核对包含代码的建图和余子式方向，不仅比较主题名。

附件对有向边 u→v、权 w 执行 L[v][v]+=w、L[u][v]-=w，删除点 1 对应的行列。这是入度拉普拉斯的列写法，所计数的是以点 1 为根的外向树：根沿原边能到达每个点。不能误作所有点沿边流向根的内向树。

当前 `MatrixTree<mod>::count` 默认通过按行的出度拉普拉斯构造内向树；选择 `away_from_root` 时交换 u、v，得到附件矩阵的转置余子式。转置不改变行列式，因此语义相同。P6178 驱动把 opt=1 映射为 `away_from_root`，根传 0；opt=0 映射为无向生成树。附件的 1-based 点号仅在输入处转换。

附件固定模数 1000000007、根 1、使用数组消元。当前版本用 vector，素数模数为模板参数，根可指定；额外支持内向树，并保留重边独立计权、自环不贡献、单点空树乘积为 1 的语义。返回的是边权乘积之和；模意义下答案为零不表示不存在生成树。任意合数模数另由 MatrixTreeMod 处理，不属于这段附件代码的能力。

验证分为两层：

- 模板核心：独立枚举 n−1 条边的子集，按连通性和方向检查是否合法树，用 cpp_int 累乘和求和。对所有根、三种方向、模 2/3/998244353 比较，覆盖重边、自环、负权和 signed64 边界；220 点完全图用加权 Cayley 公式作规模检查。测试不再依赖旧 classic 实现。
- P6178 完整输入输出：100 组独立子集枚举，300 点/100000 条边的有向与无向规模输入，以及单点自环。普通和 ASan/UBSan 分别编译执行，标准错误非空即失败。

当前源码与测试哈希、执行结果见 `verification/matrix-tree-attachment.json`。本次没有新增在线提交或运行速度排名。附件 3.6 矩阵求逆是独立接口需求，现已另增 matrix_inverse；其实现和验证见 MATRIX-INVERSE.md，不由矩阵树或行列式间接计入覆盖。
