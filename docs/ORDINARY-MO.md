# 普通莫队

`Mo(n)` 管理长度为n的静态数组区间，`add(l,r)`登记0-based半开区间并返回原查询编号，允许空区间以及n=0。`run(add,del,ans,block=0)`按蛇形顺序移动区间；加删回调接收数组下标，答案回调接收原查询编号。调用前统计状态必须为空，每个位置至多在活动集合中出现一次，调用结束删除剩余位置并恢复空状态。可重复run，但调用期间不能修改查询表；回调不可抛出异常，否则不承诺恢复。

本接口适用于加删任意位置均有相同语义的集合统计，例如不同值数、频次平方和。逆序对等依赖左右插入方向的维护不能直接套这组回调，需要分别处理左加、右加、左删、右删，不将这里的简短接口声称为任意顺序敏感问题的通用封装。

排序复制查询数组，不改变登记顺序。先扩张再收缩，确保即使新区间与旧区间不相交，每次删除的位置仍在活动集合内。空区间不贡献元素；每个查询只调用一次ans。蛇形排序只改变访问顺序，不改变区间语义。

n与查询数均须能用int表示。给定正块长B，在加删和记录答案均为O(1)时，时间O(q log(q+1)+qB+n²/B+n)，额外空间O(q)。默认B=max(1,floor(n/sqrt(q)))；q=0直接返回，不做除法。比较器仅比较左端块和右端，不要求相同区间稳定排序，答案由id还原。

本地1200组区间集，默认、1、7、100四种块长，共4800次运行，逐次答案检查完整活动下标集合，并检查加点前不存在、删点前存在、每个答案恰好一次及最终空状态；覆盖空数组、空查询集、空区间和重复区间。头文件、NDEBUG及最小抄写形式均通过O2、ASan/UBSan。证据为verification/ordinary-mo-local.json。

正式用法 example-394 对应 P2709：维护频次平方和，加点增加 2c+1，删点先减频次再减 2c+1。样例、100 组随机题目输入和两组 n=m=100000 的独立真值测试通过；三种错误变体均被测试检测。当前提交 [https://www.luogu.com.cn/record/302624429](https://www.luogu.com.cn/record/302624429) 已获得 100 分 AC，30 个测试点，单点最大 69ms、页面总时间 1.41s、峰值 4.41MB。排名尚未核查。线上存档见 verification/ordinary-mo-online.json。
