# DA来源程序：后缀数组求最长回文

kuangbin §1.5.1不仅有倍增后缀数组，还附有反串、RMQ和输出最长回文子串的完整程序。本次补齐这个来源应用协议，未新增一种后缀数组算法。用法343组合现有`SuffixArray`与`SuffixLCP`；单纯求最长回文时仍应优先使用线性Manacher，此用法主要解释后缀LCP如何用于回文。

## 输入输出与边界

读取非空字符串直到EOF，逐组输出最靠左的最长回文子串，不输出长度。空文件或只有空白没有输出。字符串按C locale空白分词，空白不是字符串内容；新程序可处理其余字节，包括0、1、128和255，不把它们当C字符串终止符。

设原串长度为L，组合序列为原串、独立分隔符、反串，长度N=2L+1。每个字节按unsigned char加2映射到[2,257]，分隔符为1，传入alphabet=258。无需补空后缀哨兵。长度要求L≤(INT_MAX−2)/2，并实际满足内存限制。倍增与稀疏表共同消耗O(L log L)时间、空间；长度整数合法不等于内存一定足够。

以i为右半边起点的偶中心半径为LCP(i,N−i)，对应原串左半边从i−1反向读取。以i为中心的奇回文半径为LCP(i,N−i−1)，包含中心字符，长度为2r−1。偶长答案起点i−r，奇长答案起点i−r+1。分隔符不出现在任何输入符号中，匹配不能越过两侧原串边界。

当i=0时，偶中心第二个后缀起点恰为N，即空后缀。`SuffixLCP::query`已经支持端点N，直接返回0；不能改为读取rk[N]，也不能把该查询错位到N−1。中心从左到右扫描，仅在长度严格增大时替换结果。同长的回文起点随中心递增，因此保留最靠左的答案，而不是字典序最小答案。

## 完整来源审计

固定PDF SHA256为`f1c90eae0c3fb309d58a14b050fe12b239efb474b033299a547b55646c2768ad`。印刷11–14页/物理13–16页的完整121行逐页目视核对，包括da、RMQ、lcp和main。测试夹具保留全部逻辑；仅归一化数学减号、合并PDF折行及去掉印刷行号。提供标准头，在独立命名空间中包含片段并调用其main，以避免原全局rank与std::rank同名引起歧义；没有修改原算法。

原程序使用m=128、char转int、分隔符1、零哨兵和MAXN=20010的静态数组。来源对照明确限定可打印ASCII[33,126]、1≤L≤10004；后者使N+1≤20010。原稿没有给出线上题号，不能因为协议常见就随意登记为某道OJ题，也不能把新字节扩展的测试当作原程序支持这些输入。

用法343登记为来源应用/API演示，而不是线上独立模板题。原DA核心的既有验证继续保留，DC3完整片段验证见[DC3.md](DC3.md)。父§1.5的DA算法、DA应用协议与DC3三个部分现均有本地证据，状态由partial改为local-tested；不等于线上AC或性能排名。

## 本地证据

`python3 tests/da_palindrome_source.py`及`--sanitize`覆盖原完整程序、新头文件驱动、NDEBUG、实际展开、最小抄写四种新程序形式。真值独立枚举所有奇偶中心并向外比较字符，按长度与起点选择答案，不使用后缀数组或LCP。

11988组原协议输入包括长度至12的全部二元串、至7的全部三元串、500组随机可打印ASCII、并列最优、单字符、奇偶回文，以及10002/10003/10004长度的全同、交替和随机串。大串后再次输入小串，检查原静态数组跨组遗留状态；最后一个token没有结尾换行，另测空文件。

新程序另测308组，包括非空白任意字节、内嵌0/1/255、长度500000/500001的全同和交替串。大规模全同与交替答案由闭式构造给出，避免以另一份后缀实现互相证明。四个故障变体分别改变并列更新、奇中心偏移、偶中心空后缀偏移和分隔符唯一性，全部被检出。报告保存在`verification/da-palindrome-normal.json`和`verification/da-palindrome-sanitizer.json`；没有新增线上提交、AC或速度排名。
