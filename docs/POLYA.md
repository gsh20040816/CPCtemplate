# Burnside 与 Pólya 计数的模型

参考：[OI Wiki 的 Pólya 计数](https://oi-wiki.org/math/combinatorics/polya/)、[P4980](https://www.luogu.com.cn/problem/P4980)、[P1446](https://www.luogu.com.cn/problem/P1446)。

## 群平均与模除法

对有限集合上的完整有限群作用，将每个群元素固定的对象数量相加，结果等于轨道数乘群阶。可以通过双计数所有“对象、固定它的群元素”对证明：每个轨道的贡献恰为群阶。

`BurnsideAverage(g,p)` 在模 `q=g*p` 下维护分子。设真实分子为 `S=g*A`，则 `S mod q = g*(A mod p)`，所以规范余数再用整数除以 g，得到所需答案。既不要求 p 为素数，也不要求 g 可逆。**先模 p 再整除不成立**；例如四个位置两色、仅旋转的轨道数为6，分子24，目标模数4，分子先模4后除4会错误返回0。

要求 g,p 为正且 g*p<=LLONG_MAX/2；构造前在 int128 中验证。add 的两个非负 long long 参数乘积加旧余数小于有符号 int128 上界。power 的余数乘积也在界内。result 的整除断言只能发现部分错误；无法证明传入的确为完整群作用。不允许仅列出生成元、漏恒等、漏群元素或任意重复枚举。

## 置换与命名颜色

置换固定一个染色，当且仅当每个不交循环内部颜色相同。无限定用量的 k 种命名颜色产生 k 的循环数次方个不动点；空置换有一个空染色，包含 k=0 时的0^0=1。`permutation_cycles` 要求合法0-based置换，不做输入校验。输入非双射可能越界或不终止，不能将任意函数图传入。

P1446 限定三色数量，因此每个循环只能整体交给其中一色。二维背包记录已使用的红、蓝数量，绿色数量由已处理位置数扣除红蓝得到。每步用新数组，防止一个循环重复使用。题面保证给出的洗牌及恒等是完整群；驱动补恒等后去重，兼容恒等已经在输入中的情况，但不替任意生成元集合计算闭包。每色<=20，m<=60，时间O((m+1)*n*((r+1)*(b+1)+log(m+1)))，空间O(m*n+r*b)。中间计数模group_size*p，实际小于6040，每个next格至多累加三项，long long安全。

## 环的旋转与翻转

长度 n 的旋转 k 有 gcd(n,k) 个循环。按循环长度 d 分组，旋转分子为各 d|n 的 phi(d)*colors^(n/d) 之和。实现先分解 n，再枚举成对约数；phi(d)只需检查 n 的不同质因子。

翻转时：奇数 n 的每条轴有一个固定位置，其余配对，循环数n/2+1，共n条轴；偶数 n 各有n/2条穿过相对顶点/相对边的轴，循环数分别n/2+1、n/2。连同旋转分子平均于2n。n=1、2时可以视为抽象二面体群的不忠实作用，重复的置换各有相同核重数，平均结果仍然正确。

接口允许颜色不全部使用，颜色名本身不能交换。相邻异色、固定颜色数、颜色重命名都需要另算不动点。P4980 仅验证旋转且colors=n的正式模板模型；翻转、零颜色、合数模数、群阶不可逆和极值另用本地独立轨道枚举及宽整数测试，不借用线上AC声称这些已线上验证。

## 验证与边界

独立枚举小染色的所有群作用，取字典序最小轨道代表，避免仅对拍同一平均公式。置换循环分解与连通分量合并真值比较；宽乘法和幂与boost cpp_int比较。完整驱动分别检查头文件、NDEBUG、实际展开和最小抄写；ASan/UBSan另跑。大规模P4980批量输入与P1446 60位置循环群压力分别验证性能和固定颜色配额。

本批普通、NDEBUG、实际展开、最小抄写与ASan/UBSan均通过；5个错误变体全部检出。线上记录：P4980 [302212651](https://www.luogu.com.cn/record/302212651)，P1446 [302212973](https://www.luogu.com.cn/record/302212973)。实际上传源代码与本地最小抄写版本逐字节一致，独立归档；未声称下载了服务器保存的源码。
