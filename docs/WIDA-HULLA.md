# WIDA 11A 旧版静态凸包

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `e2dc852fc236b66f55be847d8dbd6f1f4fed1e68`，路径 `03 - jiangly模板收集/03 - 数论、几何与多项式/11A - 静态凸包（with. Point，旧版）.cpp`。`Point` 使用 `i64`，文件没有定义它，单独编译失败。

`getHull` 先按 x、再按 y 排序，并删掉重复点。点数不超过 1 时原样返回，空集和单点都安全。叉积的两个参数是 `当前点 - 栈顶` 和 `当前点 - 栈顶前一个点`，不是常见的两条相邻边。按这个式子，上链在结果 `<= 0` 时弹栈，下链在结果 `>= 0` 时弹栈，共线点会被去掉。最后从下链去掉最右点，从上链去掉最左点，再接成一条从最左点出发的多边形。

`(3,4)` 与 `(1,0)` 的点积是 3，叉积是 -4。`norm` 把 y 最小、相同 y 时 x 最小的点转到开头。`sgn` 在上半平面或正 x 轴返回 0，负 x 轴和原点返回 1。这和 11C 的半平面约定不同。

`python3 tests/wida_hulla.py` 在普通 `-O2` 和 ASan/UBSan 下对照了空集、单点、重复点、共线、正方形、内部点和竖线。没有证明坐标乘法不溢出。提交页面没有打开，没有新的在线 AC，也没有新增模板。来源保持 partial。
