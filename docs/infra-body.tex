\section{值、引用与调用边界}
\index{reference}
参数 \texttt{T} 按值，\texttt{const T\&} 只读借用，\texttt{T\&} 允许修改原对象。返回引用必须保证被引用对象仍存活，不能返回局部变量的引用。结构化绑定 \texttt{auto [x,y]} 默认复制，\texttt{auto\& [x,y]} 引用原元素；只读遍历常用 \texttt{const auto\&}。

\section{std::move：允许移动，不是立即移动}\label{infra-move}
\index{std::move}
\texttt{std::move(x)} 本身是转换表达式，使后续重载选择可以使用移动构造或移动赋值；它自己不搬运数据。对 const 对象使用 move 不会去掉 const，常见容器因此仍走复制。除有更强保证的特例外，标准库对象移动后有效但状态未指定：可销毁、重新赋值，或调用满足其前提的操作，不假定内容保持原样或必定为空。
\begin{lstlisting}
vector<int> a{1, 2, 3};
vector<int> b = std::move(a);
a.clear();
a.push_back(7);
const vector<int> c{4, 5};
vector<int> d = std::move(c);
\end{lstlisting}
上例 b 得到原序列，d 从 const c 复制。调用接受值参数的卷积函数且之后不再需要输入时，传 \texttt{std::move(a)} 可以避免额外副本；函数参数为 const 引用时不会因此取得所有权。返回本地变量通常直接 \texttt{return a;}；多加 move 可能失去具名返回值优化机会。

\section{vector、array、deque 与字符串}
\index{vector}\index{array}\index{deque}\index{string}
vector 连续存储，随机访问常数时间，尾部追加摊还常数时间。\texttt{reserve} 只改容量，不增加元素；\texttt{resize} 才改变 size。重分配使原指针、引用和迭代器失效；erase 使被删位置及之后失效。不要保存 vector 节点引用后再 push 新节点；需要跨扩容引用时保存下标并重新访问。

array 的长度为编译期常量；局部基本类型元素需用 \texttt{\{\}} 初始化。deque 支持两端操作且可下标访问，但整体不连续；修改后不要盲目保留迭代器。vector<bool> 的元素可能是代理对象，不等同于普通 bool 引用。

string 适合字符序列；\texttt{substr(pos,len)} 第二个参数是长度。\texttt{find} 未找到返回 npos，不能直接转 int 再判断。\texttt{getline} 读整行，与 \texttt{cin>>} 混用时处理遗留换行。字符串反复头部删除可能线性搬移；需要复杂序列操作见分册 rope 与序列树。

\section{set、map 与哈希表}
\index{set}\index{multiset}\index{map}\index{unordered-map}
set/map 去重，multiset/multimap 允许等价键。比较器必须是严格弱序；不能用 less\_equal 假装多重集合，也不直接用不传递的 epsilon 比较做排序或树比较。map 的下标访问会插入默认值，只查询用 find。

浮点键若含 NaN，普通小于比较也不再满足严格弱序：NaN 与不同有限数都可能互不小于，但这些有限数之间仍有大小关系。几何排序前应遵守有限输入约定，不能把 NaN 或 epsilon 当成普通相等键。

multiset 的 \texttt{erase(key)} 会删掉全部等价元素；只删一个时先 find，再 erase 该迭代器。树容器的 lower\_bound 用成员函数，通用算法在非随机访问迭代器上可能线性走步。关联容器的键不可原地修改为破坏排序的值。

unordered\_map 的普通查改平均常数时间，最坏可线性；rehash 会使迭代器失效。需要容量控制时看其 reserve/max\_load\_factor 接口，不把这些名字照搬到 PBDS。GNU 的 gp/cc 哈希表、选型和范围见本册末的分册索引。

\section{queue、stack 与优先队列}
\index{queue}\index{stack}\index{priority-queue}
queue 先入先出，stack 后入先出；取 front/top 和 pop 前检查非空。标准 priority\_queue 默认大根堆，pop 不返回值，先复制 top 再 pop。它没有按句柄修改和合并接口。
\begin{lstlisting}
priority_queue<int, vector<int>, greater<int>> q;
q.push(7);
q.push(2);
int x = q.top();
q.pop();
\end{lstlisting}
需要修改已入堆的键、删除指定元素或合并时，使用数据结构册的 PBDS 配对堆；不要混用两种 priority\_queue 的接口或句柄保证。

\section{排序、查找与区间算法}
\index{sort}\index{lower-bound}\index{unique}\index{nth-element}
算法区间通常为半开区间。sort 要求严格弱序，stable\_sort 保留等价元素的原顺序；nth\_element 只保证第 k 位及两侧分区，平均线性，不等于完整排序。lower/upper\_bound 要求对应有序或分区前提，并使用一致比较规则。
\begin{lstlisting}
sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());
auto it = lower_bound(a.begin(), a.end(), 7);
if (it != a.end()) {
    cout << *it << '\n';
}
\end{lstlisting}
unique 只合并相邻等价值，返回逻辑终点；它不改容器 size。remove/remove\_if 同理，配合 erase；C++20 可用适用容器的 erase/erase\_if。reverse、rotate、merge、copy 的目标区间必须有效，不能把未扩容的 vector.begin() 当作足够大的输出区间。

\section{pair、tuple、optional 与回调}
\index{pair}\index{tuple}\index{optional}\index{function}
pair/tuple 默认按字典序比较，适合把值与唯一编号组合。optional 区分无解与合法零值，先判断再解引用。\texttt{std::function} 可保存不同可调用对象，但有类型擦除开销；泛型 lambda 或模板回调更容易内联。递归 lambda 捕获的引用不能活得比被引用对象更久。

\texttt{tie(a,b)} 创建引用元组，保存后仍引用原变量，不是值快照。次小生成树用它比较权值与编号；模整数扩展欧几里得用右侧的值 pair 先保存旧值，再赋给左侧引用。不能把 \texttt{tie(a,b)=tie(b,a)} 当作可靠的交换：右侧也在引用会被改写的变量。
\begin{lstlisting}
long long a = 17, b = 5;
long long q = a / b;
tie(a, b) = pair{b, a - q * b};
assert(a == 5 && b == 2);
\end{lstlisting}
普通数值变量要保存快照可用 \texttt{pair\{a,b\}} 或 \texttt{make\_tuple(a,b)}，交换则直接 swap。

\section{数值累加与前缀和}
\index{numeric}\index{accumulate}\index{partial-sum}
accumulate 的初值决定累加类型，64 位求和用 \texttt{0LL}；把返回结果装进 long long 不会改变中间累加类型。乘积也须先提升，例如 \texttt{1LL*a*b}，但仍应保证宽类型可表示结果。

partial\_sum 的累加器类型取自输入迭代器的值类型，不由输出容器决定。SAM 的长度桶前缀计数用 int，前提是总状态数可表示；更大的前缀和应先将输入转为 long long，或用显式的宽类型循环。只把输出改为 vector<long long> 不能避免 int 累加溢出。允许输出起点等于输入起点：
\begin{lstlisting}
vector<int> a{1000000000, 1000000000, 1000000000};
vector<long long> prefix(a.begin(), a.end());
partial_sum(prefix.begin(), prefix.end(), prefix.begin());
assert(prefix.back() == 3000000000LL);
\end{lstlisting}
空区间不写输出；非空时输出区间必须足够大。iota 适合连续编号。gcd/lcm 仍有可表示范围前提，最小负数的绝对值应先转宽或转无符号幅值。浮点整数精确范围和 long double 有效位数用 numeric\_limits 查询；几何数值条件另看几何册。

\section{complex 与 FFT}
\index{complex}\index{conj}
FFT 使用 \texttt{complex<long double>}；\texttt{C(re,im)} 分别设置实部、虚部，real()/imag() 读取分量，conj(z) 取共轭。abs(z) 是模长，norm(z) 是模长的平方；尤其不要与本库 RealPlane::norm 的长度含义混淆。逆变换使用共轭单位根，并按模板约定除以长度。
\begin{lstlisting}
using C = complex<long double>;
C z(3, 4);
assert(z.real() == 3 && z.imag() == 4);
assert(conj(z) == C(3, -4));
assert(abs(z) == 5 && norm(z) == 25);
\end{lstlisting}
复数乘法仍是浮点运算，norm 也可能溢出，不能因 API 名称而放宽 FFT 的输入范围与舍入误差界。精确整数卷积是否适用浮点版本，应看数学册说明。

\section{C++20 位操作与零边界}
\index{bit-width}\index{popcount}\index{bitset}
bit\_width、popcount、countl\_zero、countr\_zero 接受无符号整数类型。bit\_width(x) 表示 x 所需的二进制位数，零返回0；popcount 返回1的个数。两个 count-zero 函数对零都返回该类型的位宽，不是0。不要把 countl\_zero 的结果直接当作最高位下标。
\begin{lstlisting}
static_assert(bit_width(0u) == 0);
static_assert(bit_width(8u) == 4);
static_assert(popcount(10u) == 2);
static_assert(countr_zero(0u) == numeric_limits<unsigned>::digits);
\end{lstlisting}
划分树、WaveletMatrix 用 \texttt{bit\_width((unsigned)max(1,n)-1)} 这类表达式计算层数；其中 n 分别取数组长度与去重后的值域大小。先保护零再减一，避免无符号回绕；各模板是否另加一层按接口说明。GCC 的 \texttt{\_\_builtin\_ctz(0)} 与 \texttt{\_\_builtin\_clz(0)} 均不能调用，处理64位输入还须选对应 ll 版本。

\texttt{1ULL<<k} 须满足 k 非负且小于 unsigned long long 的位宽。WaveletMatrix 按64位块存储，用 \texttt{k=i\%64} 得到0到63；k=0 时 \texttt{(1ULL<<k)-1} 为零掩码，不能用移位64构造整块掩码。bitset 的大小固定，批量位运算不是与位数无关的常数操作。

\section{GNU 扩展与查询范围}
\index{PBDS}\index{rope}
PBDS 有序树、gp/cc 哈希表、配对堆以及 \texttt{\_\_gnu\_cxx::rope} 在所属知识点详细介绍，本册提供集中页码跳转。rope 不叫 std::rope；复制版本的内存成本和已知失败用法不因它是库容器而消失。


\section{Boost 任意精度整数}
\index{Boost}\index{cpp-int}
\texttt{boost::multiprecision::cpp\_int} 是有符号任意精度整数，须显式包含
\nolinkurl{boost/multiprecision/cpp_int.hpp}；它不属于 ISO C++ 标准库或 GNU 标准头文件，赛场必须提供 Boost。
可使用十进制流输入输出，整数除法仍是截断除法，不会自动变成有理数，除数不能为零。
Bareiss 消元依靠数学上的整除性质保存精确整数，矩阵树用它计算不取模答案；目录末有对应分册跳转。
数值越大，运算和存储越贵，不应把任意精度操作视为机器字常数时间。
Boost 使用表达式模板，需跨语句保存计算结果时写明确的 \texttt{cpp\_int} 类型，避免用 \texttt{auto} 保存依赖随后修改变量或临时量的表达式。
