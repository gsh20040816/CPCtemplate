# WIDA 在线模板：全排列生成

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `ffa41b5e4a9fe8bc71d8b9edf357e38cbc54d4fe`，路径 `01 - 常用在线模板汇总/01 - 初始与杂类/05 - 全排列生成.cpp`。它读入 `n` 和 `n` 个整数，先排序，再用 `next_permutation` 输出。没有头文件，也没有 `std::`，单独编译失败。

`3 1 2` 排序后输出 6 个不同排列，顺序与字典序一致。`1 1` 只输出一行。`n=0` 时循环仍会先打印一次，得到一行空行。读入失败时 `n` 没有初始化，这轮没有执行那种输入。

`python3 tests/wida_perm.py` 在普通 `-O2` 和 ASan/UBSan 下通过这三组输入。没有新的在线 AC，也没有新增模板。来源保持 partial。
