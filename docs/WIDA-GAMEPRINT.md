# WIDA 打印稿：博弈论

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `bd90a128c5ae7351295225790b333d7be220d4e7`，路径 `02 - 打印稿模板汇总/11 - 博弈论.md`。

巴什博弈在 `M=1..5`、`N=0..30` 上，先手胜负与 `N % (M+1) != 0` 一致。扩展巴什在 `a=1..4`、`b=a..6`、`N=0..40` 上与四段余数规则一致。反 Nim 在三堆、每堆不超过 3 的范围内与两条结论一致。阶梯 Nim 把最靠近地面的一级当作奇数级，石子数为 0 或 1、级数不超过 4 时，与奇数级异或一致。

Lasker 的 SG 公式在 1 到 20 与递推一致。`x=0` 时递推是 0，公式给出 -1。斐波那契博弈在 1 到 30 上，先手必败正好是从 1、2 开始的斐波那契数。代码把这个序列算到第 86 项，`int` 会溢出，这轮没有跑那个循环。

威佐夫代码在 `k=1..200` 上，冷位与 `floor(k*phi)` 及其加 `k` 一致。相邻的非冷位判成胜。大于 `2^53` 的堆数没有测。

Moore 写法是「每一位上 1 的个数都不是 `K+1` 的倍数」才先手必胜。`K=1` 时这就是普通 Nim，一堆 1 颗先手必胜，但更高位的个数是 0，0 是 2 的倍数。全称条件和这个局面不一致。

SG 代码使用 `N`、`no` 和 `yes`，没有在这里编成完整程序。Every-SG 只说步数为奇数，没有可执行的步数定义。无向图删边只有缩环说明，没有代码。

树上删边的 lambda 写了 `int x = 0`，把参数 `x` 又定义了一次，单独编译失败。注释里的叶子 SG 值是 0，而 `return x + 1` 在没有孩子时会得到 1。这两句没有一起跑通。

`python3 tests/wida_gameprint.py` 记录了上述递推和编译结果。没有新的在线 AC，也没有新增模板。来源保持 partial。
