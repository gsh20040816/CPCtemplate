## 边界与反例

1. 原稿pow对全零输入先返回零，因此0^0按其实现得到零。例{0}.pow(0,4)返回四个零；本库返回{1,0,0,0}。零次幂约定在调用时必须明确。
2. 原稿sqrt初值固定为1，没有求模平方根或处理前导零。其合理前提是常数项1；例{4}.sqrt(1)返回{1}，并非4的平方根。本库同输入返回较小首根2。
3. 原稿dft长度1计算负移位，ASan/UBSan实际报告`shift exponent -1 is negative`。原稿Poly乘法的短边<128朴素分支绕过了这一问题，不能因此宣称直接变换支持长度1。
4. Z(int)只执行一次加/减模数，要求注释中的-P≤x<2P。Z(INT_MAX)未完全归一化；Z((long long)INT_MAX)先取模则正确。本库ModInt接受其公开约定内的整数输入。不能将int构造器和i64构造器混为一谈。
5. Poly的const下标只检查idx<size，负下标不合法；可写下标必须已分配。移位/截断参数须非负，逆元需非空且常数非零，精度与NTT容量还须满足中间卷积要求。

## 检查范围

普通NDEBUG和ASan/UBSan各126297项小规模接口检查：固定边界长度0、1、2、3、7、16、31、64、127、128、129、257，加250组随机输入长度与输出精度不同的级数。逆元、log、exp独立递推；幂用重复朴素乘法；平方根输入通过独立卷积生成；求值使用Horner。

另各266251项较大解析核验：长度32768的1/(1-x)、log(1-x)、exp(x)、1/(1-x)^2的平方根，以及2049项稀疏多项式在2048个点的求值。解析答案来自整数模幂/逆元系数公式。此规模用于发现仅在NTT分支出现的问题，不代表所有操作达到最大容量。

两个模式各17项原稿边界反例检查；singleton dft的消毒器失败单独记录为预期失败。原稿普通构建看似正常不能证明没有未定义行为。
