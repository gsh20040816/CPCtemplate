# WIDA 在线模板：树的直径

原稿是 hh2048/XCPC 树 `cfdb12db6792eb2303798541fb5c760ed2bc618b` 的 blob `67eb91943e0cf0234a3181d847b74e5f19109624`，路径 `01 - 常用在线模板汇总/02 - 图、树、网络流/01 - 树的直径.cpp`。它使用 `vector`、`map` 和 `function`，但没有包含头文件，也没有 `std::`，单独编译失败。

`getlen(root)` 从给定点做两次深度优先搜索，返回所在连通块的无权直径，单位是边数。单点是 0，一条边是 1，四点路径是 3，星是 2。局部变量 `st` 和 `ed` 记下了两个端点，但函数没有使用它们。森林里从 1 出发只看到 1–2 的直径 1，看不到另一条边 3–4。边没有权。

`python3 tests/wida_diameter.py` 在普通 `-O2` 和 ASan/UBSan 下得到 `0 1 3 2 1 1`。没有新的在线 AC，也没有新增模板。来源保持 partial。
