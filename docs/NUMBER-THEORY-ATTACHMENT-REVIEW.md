# 附件原根、CRT 与扩展 Lucas 核对

来源：issue #11 的固定附件，SHA-256 见 `issue11-inventory.json`。本次核对实际 PDF 第 71–74 页、89–97 页；89–95 页的嵌入图片已渲染阅读，不能用提取文本缺失判定无内容。未改动模板接口，也没有新增线上 AC。

## 原根（3.2、3.2.1）

附件先判定模数属于 2、4、奇素数幂或两倍奇素数幂，再分解 phi，通过各不同素因子检验候选；找到最小原根后枚举与 phi 互质的指数，排序，每隔 d 个输出。`PrimitiveRoot` 与 P6091 驱动覆盖该流程，额外提供乘法阶和有符号底数归一化。

判定候选之前必须检查可逆性。原根判别是对每个质因子 p 检查 `g^(phi/p) != 1`；从一个原根枚举 `g^k` 时，其阶为 `phi/gcd(k,phi)`。模数 2 的 phi=1、空质因子列表仍能正确返回原根 1。模数 1 不在这个接口的定义域。

初始化使用试除，范围是 `2 <= n <= INT_MAX`，没有覆盖 Library Checker 的 10^18 原根题。`all()` 的枚举和排序成本不能用最小原根查询的成本替代；大模数只应按需求调用 `minimum()` 或 `order()`。

当前单元测试不再依赖 classic：模数 2..400 逐个重复乘法求阶，比较所有候选、存在性、最小根和完整集合；检查 LLONG_MIN/LLONG_MAX 输入、int32 大模数，并遍历模 999983 的完整单位循环。完整 P6091 驱动独立扫描候选，124 组检查素数幂、无根、排序采样与空输出行。

## CRT（3.8）

附件 89 页是两两互质模数的 CRT；90 页继续给出非互质的两式合并。`crt_merge` 覆盖两者，调用者从 `(r,m)=(0,1)` 逐式合并。令 `g=gcd(m,n)`，必须满足 `g | (b-r)`；用扩展欧几里得解出步长，再把周期更新为 `m*(n/g)`。

模板使用正的 long long 模数、任意 long long 余数和 128 位中间乘法。有解但新周期超过 LLONG_MAX 时抛出 overflow_error，无解返回 false。两种失败都会保留原 m，但 r 已归一化；不能把失败解释为原始参数完全不变，也不能失败后继续合并并输出部分结果。模数 1 和重复模数有效。

本次测试直接包含并调用独立 `crt_merge.hpp`，不再通过旧的 NumberTheory 聚合接口：小模数完整枚举剩余类和答案，15000 组任意精度参考、负余数、64 位极值、无解与周期溢出。另以直接枚举检查最多三条方程的全部 1111 个小系统，以及两种顺序的末式冲突；空系统保持 (0,1)。P4777 实际驱动 186 组 Python 精确整数对拍，包括 100000 条同余式及接近 10^18 的最小公倍数。

## 扩展 Lucas（3.9）

附件 90–94 页先把模数分解为互素素数幂 q=p^e，把阶乘分为 p 的幂与可逆单位，最后 CRT 合并；95–97 页代码对应 P4720。`ExLucas` 预处理每个素数幂的单位前缀积，重复查询复用这些表。

单位部分满足 `U(n)=U(floor(n/p))*F[q]^(floor(n/q))*F[n%q] (mod q)`。其中 F 忽略 p 的倍数，不能把它当作普通阶乘。组合数的 p 次数达到 e 时该分量为零，否则仅对单位分母求逆，补回 p 的幂。CRT 系数是 `(mod/q)*inverse(mod/q mod q)`，因此在本分量上为 1、其他分量上为 0。

附件代码将 `v_p(n!)` 存入 int；P4720 允许 n=10^18，这个类型不足。现有模板使用 unsigned long long，`v_p(n!) <= n`，并且当 k<=n 时 `v_p(n!) >= v_p(k!)+v_p((n-k)!)`，连续相减不会发生无符号下溢。查询支持完整 uint64 下标，k>n 返回 0，模数 1 返回 0。负下标不属于接口定义域，不能传入后依赖隐式无符号转换得到 0。

附件对递推层数的 O(log_p n) 描述不包含每层快速幂与扫描前缀的成本。当前模板已预处理前缀，但每层仍有快速幂，文档中的保守查询界 `sum(log_p(n+1)*log(n+1)+log q)` 保持不变。空间与预处理依赖素数幂 q 的总和，适合模数 <=10^6，不能用于 10^9 级素数的整表预处理。

当前独立验证包括：模数 1..300 的 Pascal 三角；cpp_int 精确组合数、uint64 极限、对称性；小素数的逐位 Lucas；完整中间项；逐个整数剥除 p 因子得到阶乘单位和指数，与内部递推比较。新增 6000 组完整 uint64 随机下标，直接数 k+(n-k) 在 p 进制中的进位（Kummer），检查素数幂余数恰好具有正确的 p 次数或应为零。P4720 完整驱动增至 144 组 Python math.comb 对拍，含附件两例、n=10^18、k 与 n-k、小素数幂和接近 10^6 的模数。

## 本地结果与复现

四项单元/系统测试及三项完整驱动均分别运行普通和 ASan/UBSan 模式；带源文件 SHA-256 的结果见 `verification/number-theory-attachment.json`。测试源中不再引用 classic，但历史记录保留，不将历史提交自动视为当前源码的线上 AC。

在仓库根目录，用 GNU C++20 分别编译 `tests/primitive_root.cpp`、`tests/crt.cpp`、`tests/crt_system.cpp`、`tests/exlucas.cpp` 并执行；普通模式 `-O2`，消毒器模式 `-O1 -g -fsanitize=address,undefined -fno-omit-frame-pointer`。macOS 的 Boost 在非默认位置时另加 `-I/opt/homebrew/include`。对应三个 `tests/*_application.py` 可直接运行；环境变量 `SANITIZE=1` 或 `CPC_SANITIZE=1` 启用消毒器编译，`CXX` 指定编译器。驱动检查会拒绝非零退出状态和 stderr，并设置 120 秒进程超时。GitHub CI 不参与。
