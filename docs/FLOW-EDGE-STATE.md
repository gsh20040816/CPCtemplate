# Dinic 边状态的修改前提

本库原边编号是 add 返回的偶数编号，反边为 id^1，不能直接套用 ACL 的第 i 条逻辑边编号。get_edge 返回原端点、容量、流量；change_edge 同时设置正向剩余容量 cap-f、反向剩余容量 f，并更新初始容量。

接口只维护局部残量对，不会替用户恢复全局流量守恒。安全的常见操作是增大容量同时保留当前流；若将容量减到现有流量以下，只截断一条边会使中间顶点不再守恒。继续求最大流前，应恢复合法流，或把全部原边的流量清零后重算。重复 flow 必须使用原来的源汇，返回的是新增流量。

本地验证以枚举所有源汇割独立求出最大流值，再核对每条边的上下界、正反残量，以及所有非源汇点的净流为零。随机图包含自环、平行边与反向原边；分别测试限流之后增容续算、整图清零后缩容。另手工初始化路径流、环流、自环流，并检查继续增广；LLONG_MAX 容量的最后一个单位增广验证溢出边界。

新接口只有本地普通与 ASan/UBSan 证据。历史提交源码保持原样，当前包含该头文件的打包源码摘要可能改变；源码审计如实记录这种变化，没有把历史 AC 当作新增 API 的在线验证。
