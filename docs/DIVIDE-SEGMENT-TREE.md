# 区间加、赋值、整除与求和

组件 `DivideSegmentTree` 使用 vector 和递归线段树，补充 WIDA 懒标记片段中折半操作的可复用接口；同时支持任意正整数除数。本库现有 336 个组件、459 个完整用法。

## 公开接口与范围

构造传入 vector<long long>。允许空数组，n≤500000；初值和每次修改后的所有点值必须位于 [0,10^12]。区间统一为零基半开 [l,r)，空区间合法。

- add(l,r,x)：区间加，可负，调用者负责保持值域。
- assign(l,r,x)：区间赋值，0≤x≤10^12。
- divide(l,r,x)：每个点变为 floor(value/x)，1≤x≤LLONG_MAX。折半即 divide(l,r,2)。
- sum(l,r)：返回 long long 区间和，空区间返回 0；查询会下推标记。

点赋值使用 assign(p,p+1,x)。n、t 和所有辅助方法仅供实现内部使用，不能修改节点或直接调用 change/update/push。关闭 assert 不意味着允许非法输入；特别是不支持负数被除数，也不支持除数零。

## 剪枝为什么正确

每个节点存和、最小值 low、最大值 high。固定正整数 d，对非负整数 v，商 q(v)=floor(v/d) 单调不减，减少量 h(v)=v-q(v) 也单调不减。

若 q(low)=q(high)，所有元素的商都相同，可以整段赋值。否则，若 h(low)=h(high)，每个元素减少的量都相同，可以整段加负的减少量。两者都不满足才递归左右子树；叶子的两端相同，必能停止。d=1 时减少量恒为零，可以直接剪枝。

WIDA 原稿 half 只检查相同减少量 `(v+1)/2`。这里额外加入“相同商”的剪枝，避免已统一结果的区间继续递归。源片段的 all-active 非负折半实例与当前模板实际对照，原稿字节不改。

赋值标签覆盖旧加法；之后加法若已有赋值则修改赋值，否则累加 delta。下推先赋值再加法。非负值域使 cover=-1 可以作为无赋值标签。每个分量始终在规定范围，区间和最多 5×10^17；延迟加量对应旧值到当前值的统一差，绝对值不超过 10^12，加量乘长度和求和均不溢出 signed64。

## 时间与空间，不夸大均摊保证

建树 O(n)，节点空间 O(n)，递归栈 O(log(n+1))。区间加、赋值、求和为 O(log(n+1))；单次整除最坏 O(n)，最值剪枝有效时可以直接处理整段。这里不对任意区间加、赋值、整除混用宣称统一对数均摊界。反复整体折半且没有增大操作时，值域最多经过 40 次后全部变零。

源码不依赖第二最值等复杂节点，较易抄写；但对需要严格性能保证的题目，仍要根据操作种类和值域分析。测试中的整段均匀更新是剪枝路径验证，不是最坏输入性能证明。

## 完整用法

用法 458 是自定义完整 API 输入输出，含四种操作和空区间，见 verify/api/divide_segment_tree.compact.cpp。用法 459 是 [ABC256 Ex 官方题面](https://atcoder.jp/contests/abc256/tasks/abc256_h) 的完整协议，见 verify/atcoder/abc256_h.compact.cpp：原题一基闭区间只需 L 减一，操作 1 整除、2 赋值、3 求和；原题不含区间加。

官方 N≤500000、Q≤100000、初值及赋值≤100000，除数≥2，均在组件接口域内。两个官方样例均本地通过；这不等于在线 AC 或完整官方数据通过。
