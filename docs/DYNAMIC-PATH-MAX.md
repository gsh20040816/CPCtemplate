# 动态森林路径加与最大值

`DynamicPathMax` 为vector节点的LCT，支持连边、直接边删除、换根后的父边删除、路径加和路径最大值。它与原 `LinkCutTree` 的异或接口分开，避免混淆聚合与懒标记；不维护虚子树和动态直径。

## 接口及边界

以0-based `vector<long long>` 点权构造，初始为孤立点，公开点号1..n；要求n<INT_MAX。空vector可构造，但没有合法点操作。外部不可修改a或直接调用内部标记/旋转方法。

- `link(x,y)`：只连接不同树，成功返回true，重复边、成环和自环返回false。
- `cut(x,y)`：只删除直接存在的无向边，方向不限；连通但不相邻也返回false。
- `cut_parent(root,x)`：将root视为根，删除x和该根方向的父亲之间的边。root与x不必相邻；不连通或root=x返回false。
- `add(x,y,w)`：给路径全部点加w；不连通返回false。
- `query(x,y)`：返回路径最大值 `optional<long long>`，不连通返回空。x=y返回该点权，负权及LLONG_MIN值不被零哨兵干扰。
- `make_root/find_root`：改变或查询表示树根。其他操作可能换根，因此根不是固定业务含义。失败操作保持表示森林和点权，可调整辅助树及其根。

所有节点点权、聚合值与累计懒加标记的加法中间结果都必须落在long long范围内。仅保证“最终答案可表示”不足以满足这一合同；未使用饱和加法或自动扩位。不向0号节点施加标记，pull只合并非空孩子，因此无需有限负无穷哨兵。

每次公开操作均摊O(log n)，节点空间O(n)。splay前递归沿辅助树向上，再自顶向下下传标记；单次辅助树高度可达O(n)，递归栈应足够大。不会把DFS改成显式调用栈。测试为进程入口配置256MiB pthread栈；该配置是测试运行条件，不在模板内修改OJ环境。

## 易错处

`access`把旧右孩子变成虚边时保留其fa作为路径父亲，而不是清零。翻转与统一加法可交换，但旋转前必须按祖先到后代下传两种标记。find_root在向左找到表示树根后再次splay，不能省掉访问末点的伸展而直接套用均摊保证。

`expose(x,y)`先换根x并确认连通，再让y的辅助树包含整个x-y路径。删除直接边需检查该路径只有x、y；删除父边则拆开y与整个左辅助子树的连接。后者左子树可含许多祖先，拆开仍仅删除表示树中紧邻y的父边。不能把来源操作2写成cut(x,y)。

## 本地验证

`tests/dynamic_path_max.cpp`枚举n=1..4的全部48个有标号森林及二值点权，形成674个状态。每个状态所有有序点对分别尝试连边、直接删边、换根删父边和负路径加，共41064个单步转移；每次检查所有点对的连通性与最大值。参考模型用邻接表BFS恢复唯一路径，不依赖LCT内部结构。

另30组随机森林操作各1000次，穿插独立换根和全点对核查；检查LLONG_MIN/LLONG_MAX及安全的端点加法。10万点长链使用全负大权，先整链加，再进行1000轮端点查询、父边切断、直接边删除、重连和不连通加法拒绝。头文件、独立复制、NDEBUG三种核心形式运行同一oracle，require不会被NDEBUG关闭。

完整协议用202个EOF数据集验证（200组随机、每组400操作，另两组定向边界）。原212行来源、完整驱动、手册实际展开、标准头最小抄写、NDEBUG驱动均与独立Python BFS模型逐字比较，包括多组间空行。三种突变：把父边删除写成直接边、用端点权代替路径最大值、漏下传左孩子加法，均通过独立短数据的答案差异拒绝。
